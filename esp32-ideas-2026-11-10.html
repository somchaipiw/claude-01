ESP32-P4
ESP32-P4 Chip Revision v3.x — 400 MHz + AES DPA + ECC P-384

Espressif ประกาศ Chip Revision v3.x (พฤษภาคม 2026) สำหรับ ESP32-P4 ซึ่งเป็นอัพเดทครั้งใหญ่ที่สุดในปีนี้ ด้วย dual-core RISC-V 400 MHz ที่เสถียรกว่าเดิม และ Pixel Processing Accelerator (PPA) รองรับบล็อก 32x32 พร้อมฟอร์แมต YUV422/YUV420

ด้านความปลอดภัย AES accelerator ได้รับการป้องกัน DPA (Differential Power Analysis) และ ECC เพิ่ม P-384 support พร้อม RNG module แยก ทำให้เหมาะกับงาน secure IoT ระดับสูง

หมายเหตุ: ชิปไม่มี Wi-Fi/Bluetooth ในตัว ต้องใช้ ESP32-C6 หรือ ESP32-H2 เป็น companion module

ESP32-H2
ESP32-H2 — Zigbee + Thread 1.3 + Matter Certified รุ่นแรกของ Espressif

ESP32-H2 ได้รับการรับรองเป็น Zigbee-Compliant Platform และ Thread-Certified 1.3.0 Component อย่างเป็นทางการ เป็นชิป RISC-V single-core ที่รวม IEEE 802.15.4 และ Bluetooth 5 (LE) มาในตัว

รองรับ Matter over Thread ทำให้สามารถสร้าง end-point device ที่ทำงานร่วมกับ Apple HomeKit, Google Home, Amazon Alexa ได้โดยตรง โดยไม่ต้องพึ่ง Wi-Fi gateway หากใช้ Thread border router

M5Stack NanoH2 เป็น development board ขนาดเล็กมากสำหรับ ESP32-H2 พร้อม Thread 1.4 support บน firmware ล่าสุด

ESP32-C6
ESP32-C6 ในฐานะ Zigbee Coordinator — Wi-Fi 6 + Zigbee ในตัวเดียว

ESP32-C6 มีจุดเด่นพิเศษคือรวม Wi-Fi 6 (802.11ax), BLE 5.3, และ IEEE 802.15.4 ไว้ในชิปเดียว ทำให้สามารถทำหน้าที่เป็น Zigbee Coordinator หรือ Thread Border Router ได้โดยไม่ต้องใช้ dongle เพิ่ม

Espressif's ESP-Zigbee-SDK รองรับการสร้าง coordinator, router, และ end device ด้วย Arduino และ ESP-IDF พร้อม Zigbee2MQTT compatibility สำหรับเชื่อมกับ Home Assistant

ESP32-C6
DIY Zigbee Coordinator + Wi-Fi Gateway ราคาต่ำกว่า $5

ใช้ ESP32-C6 (RISC-V ราคา ~$3–5) สร้าง Zigbee coordinator ที่ทำงานร่วมกับ Zigbee2MQTT และ Home Assistant ได้เลยโดยไม่ต้องใช้ dongle แยก ลดต้นทุนจาก ~$20–30 เหลือ ~$5

Espressif's ESP-Zigbee-SDK รองรับการทำ coordinator mode บน C6 ตรง ส่วน Thread border router ทำได้เช่นกันหากต้องการ Matter over Thread

VibroSense — Predictive Maintenance ด้วย TinyML + MPU-6050

โปรเจกต์ VibroSense (มิถุนายน 2026 บน ElectronicWings) ใช้ ESP32-S3 + MPU-6050 รัน anomaly detection model แบบ real-time โดยไม่ต้องใช้ cloud ตรวจจับความผิดปกติของเครื่องจักรจาก vibration pattern

งานวิจัย Applied Sciences (พฤษภาคม 2026) พัฒนาระบบ predictive maintenance แบบ hybrid edge-cloud บน ESP32-S3 ใช้ quantized inference + explainable AI สำหรับ industrial motor monitoring

2เก็บ vibration data ด้วย sampling rate 1 kHz
3เทรน anomaly detection model บน Edge Impulse
4deploy model บน ESP32-S3 (512 KB SRAM)
5ตั้ง threshold ตาม ISO 10816 vibration severity

Matter Smart Plug ด้วย ESP32-H2 — ทำงานกับทุก Ecosystem

สร้าง smart plug ที่ใช้ Matter over Thread ทำงานร่วมกับ Apple HomeKit, Google Home และ Amazon Alexa ได้ในตัวเดียว โดยใช้ ESP32-H2 เป็น Thread end device เชื่อมผ่าน Thread Border Router

Espressif มี matter-examples ใน ESP-IDF พร้อมตัวอย่าง on/off plug, dimmable light, temperature sensor สามารถ commission ผ่าน Apple Home app หรือ Google Home ได้โดยตรง

ไม่ต้องกลัว vendor lock-in — Matter device ทำงานกับทุกระบบ ไม่ว่าจะ Apple, Google, Amazon หรือ Samsung SmartThings รุ่น 2026+ ทั้งหมด
