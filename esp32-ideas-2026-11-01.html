ESP32 + GPS Tracking — ติดตามตำแหน่งด้วย GNSS

GPS tracking บน ESP32 เป็นหนึ่งในงานที่นิยมมากที่สุด ตั้งแต่ระบบติดตามยานพาหนะ ไปจนถึง Asset Tracker แบบพกพา โมดูล GNSS รุ่นใหม่รองรับหลายระบบดาวเทียม (GPS, GLONASS, Galileo, BeiDou) พร้อมกัน ทำให้ Fix Time เร็วขึ้น และแม่นยำกว่าเดิมมาก

🛰 เปรียบเทียบโมดูล GPS/GNSS ที่ใช้กับ ESP32

โมดูล ระบบดาวเทียม ราคาโดยประมาณ Interface จุดเด่น
NEO-6M GPS เท่านั้น ~$5–8 UART ราคาถูก เริ่มต้นง่าย
NEO-M8N GPS+GLONASS+Galileo ~$15–25 UART / I²C / SPI Multi-GNSS ราคากลาง
NEO-M9N GPS+GLONASS+Galileo+BeiDou ~$30–45 UART / I²C / SPI 92-channel, Fix ไว มี SMA connector
L76K (Quectel) GPS+GLONASS+BeiDou ~$8–15 UART ประหยัดพลังงาน Backup Battery
GT-U7 GPS+GLONASS ~$6–10 UART ราคาถูก มี LED Indicator
แนะนำ: สำหรับโปรเจกต์ที่ต้องการความแม่นยำสูง ใช้ NEO-M9N (92 channels, รองรับทั้ง 4 ระบบดาวเทียม) ถ้างบจำกัด ใช้ NEO-M8N ก็เพียงพอสำหรับงานส่วนใหญ่

📡 Library ยอดนิยม: TinyGPS++

TinyGPS++ คือ library มาตรฐานสำหรับ Parse NMEA Sentences จาก GPS module บน Arduino/ESP32 รองรับ GGA, RMC, GSA, GSV ฯลฯ พร้อม Custom NMEA Parser สำหรับ Protocol เฉพาะ

// ติดตั้ง TinyGPS++ ผ่าน Arduino Library Manager #include <TinyGPS++.h> TinyGPSPlus gps; HardwareSerial gpsSerial(1); void setup() { gpsSerial.begin(9600, SERIAL_8N1, 16, 17); } void loop() { while(gpsSerial.available()) gps.encode(gpsSerial.read()); if(gps.location.isUpdated()) { Serial.printf("Lat: %.6f, Lng: %.6f\n", gps.location.lat(), gps.location.lng()); } }

ESP32 OTA Firmware Update — อัปเดตโค้ดไร้สาย

OTA (Over-The-Air) Update คือฟีเจอร์สำคัญสำหรับ IoT Deployment จริง ช่วยให้อัปเดต Firmware โดยไม่ต้องเดินสายหรือถอดอุปกรณ์ ESP32 รองรับ OTA หลายรูปแบบ ตั้งแต่ Development บน LAN ไปจนถึง Production Fleet Management

⚖️ เปรียบเทียบวิธี OTA บน ESP32 — เลือกให้เหมาะกับงาน

วิธีระยะความปลอดภัยเหมาะกับ
ArduinoOTA (mDNS/UDP) LAN เท่านั้น Password ธรรมดา Development, Debug เร็ว
ElegantOTA LAN / Web UI Basic Auth Home Automation, Maker Project
HTTP/HTTPS OTA (HTTPUpdate) Internet HTTPS + CA Cert Production Deployment
MQTT-triggered OTA Internet MQTT Auth + TLS Large Fleet Management
Mongoose OS / ESP-IDF native Internet Code Signing + Rollback Enterprise / Critical System

🚀 ArduinoOTA — เริ่มต้นง่ายใน 10 บรรทัด

ใช้สำหรับ Development — อัปโหลดจาก Arduino IDE / PlatformIO ผ่าน WiFi แทน USB

#include <ArduinoOTA.h> void setup() { WiFi.begin(ssid, pass); ArduinoOTA.setPassword("mypassword"); ArduinoOTA.begin(); } void loop() { ArduinoOTA.handle(); // ต้องเรียกทุก loop! // ... โค้ดหลัก }
⚠️ ข้อควรระวัง: ถ้า loop() block นาน OTA จะ Timeout ใช้ Async หรือ FreeRTOS Task แยก
ArduinoOTA mDNS Development

☁️ HTTPS OTA — Production-grade Update

ESP32 Poll เซิร์ฟเวอร์เพื่อเช็ค Version ใหม่ ถ้ามี ดาวน์โหลดและติดตั้งอัตโนมัติ ใช้ HTTPS พร้อม Root CA Certificate เพื่อความปลอดภัย

#include <HTTPUpdate.h> #include <WiFiClientSecure.h> WiFiClientSecure client; client.setCACert(root_ca); // Pin CA cert httpUpdate.update(client, "https://myserver.com/firmware.bin");
HTTPUpdate HTTPS CA Certificate

🛡 Security Best Practices สำหรับ OTA

OTA ที่ไม่ปลอดภัยเท่ากับเปิดช่องให้โจมตีอุปกรณ์จากระยะไกล

  1. ใช้ HTTPS เสมอ — Pin Root CA Certificate ใน Firmware
  2. Verify Firmware Hash — SHA256 ก่อน Apply
  3. Version Check — ป้องกัน Downgrade Attack
  4. Rollback Partition — ถ้า Boot ใหม่ไม่ผ่าน กลับ Version เก่า
  5. อย่า Hardcode Password — เก็บใน NVS หรือ SPIFFS
Security Rollback SHA256

ESP32 + NFC/RFID ด้วย PN532 — ระบบ Access Control และ Smart Tag

NFC และ RFID เป็นเทคโนโลยี Contactless ที่ใช้กันแพร่หลายในบัตรเข้าออก, ระบบชำระเงิน, และ Smart Label PN532 คือ NFC Controller ยอดนิยมที่เชื่อมต่อกับ ESP32 ได้ง่าย รองรับ MIFARE, ISO 14443 Type A/B, FeliCa และ Peer-to-Peer Mode

🔌 PN532 กับ ESP32 — เชื่อมต่ออย่างไร

PN532 รองรับ 3 interface: I²C, SPI, UART โดย I²C ง่ายที่สุด แต่บน ESP32 บางบอร์ดอาจมีปัญหา SPI เสถียรที่สุด แนะนำใช้ Elechouse library แทน Adafruit PN532 สำหรับ ESP32
