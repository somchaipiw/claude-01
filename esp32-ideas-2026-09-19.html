ESP32 TWAI Controller — CAN Bus ในตัวชิปสำหรับยานยนต์

ESP32 มี TWAI (Two-Wire Automotive Interface) built-in ซึ่งเป็น CAN-compatible controller ที่ไม่ต้องซื้อ IC เพิ่ม เพียงต่อ SN65HVD230 transceiver ราคา $1 ก็เชื่อมต่อ OBD-II ของรถยนต์ได้ทันที อ่านค่า RPM, ความเร็ว, อุณหภูมิน้ำหล่อเย็น, และ DTC error codes แล้วส่งขึ้น cloud ผ่าน Wi-Fi

TWAI CAN Bus OBD-II ESP-IDF
⚡

SimpleFOC + FOCn Module — ควบคุม BLDC Motor ด้วย ESP32-S3

FOCn เป็น ESP32-S3 based BLDC driver module ที่รองรับ SimpleFOC library ครบครัน มี Wi-Fi + Bluetooth ในตัว, รองรับ motor ถึง 500W, กระแส peak 20A, มี position/velocity/current loop ปรับ PID ได้ผ่าน Serial หรือ Web interface เหมาะสำหรับหุ่นยนต์และ CNC

SimpleFOC ESP32-S3 BLDC FOC
⚡

PZEM-004T + ESP32 — Smart Energy Meter Open Source

PZEM-004T วัดค่า Voltage, Current, Power, Energy (kWh), Frequency, และ Power Factor ได้ในชิปเดียว เชื่อมต่อ ESP32 ผ่าน UART ง่ายมาก แล้วส่งข้อมูลผ่าน MQTT ไปแสดงบน Node-RED หรือ Home Assistant ได้ทันที มี alarm แจ้งเตือนเมื่อแรงดันเกินหรือต่ำกว่ากำหนด

PZEM-004T MQTT Home Assistant ESPHome

โปรเจกต์ open source ล่าสุดที่ใช้ ESP32 + sensors ตรวจ soil moisture, temperature, humidity, rainfall, แสง พร้อม camera + AI สำหรับตรวจโรคพืชและแมลง ทำงานได้แม้ไม่มี internet, มี mobile app แจ้งเตือน พร้อมรองรับภาษาท้องถิ่น เหมาะสำหรับ smallholder farmer

Smart HydroSense — วัดคุณภาพน้ำแบบ Real-time ด้วย IoT

OBD2_CAN_Bus_Library — ISO 15765-4 บน ESP32 Arduino

Library ใหม่ที่รองรับ OBD2 protocol (ISO 15765-4) เต็มรูปแบบบน ESP32 Arduino IDE ใช้ TWAI built-in controller, รองรับทั้ง 11-bit และ 29-bit CAN ID, อ่านค่า PID มาตรฐาน SAE J1979 ได้โดยตรง เช่น engine load, fuel trim, O2 sensor, catalyst temperature และอีกกว่า 100 parameters

ISO 15765-4 Arduino IDE SAE J1979 Open Source

📖 Tutorial ประจำวัน

🚗

อ่านข้อมูลรถยนต์ผ่าน OBD-II ด้วย ESP32 TWAI + SN65HVD230

ตั้งแต่ต้นจนจบ — wiring, code, แสดงผลบน Serial และ Web Dashboard

1

เตรียม Hardware

ต่อ SN65HVD230 กับ ESP32: GPIO_21 → TX, GPIO_22 → RX, 3.3V → VCC, GND → GND
ต่อ CANH และ CANL ของ SN65HVD230 เข้ากับสาย OBD-II (pin 6 = CANH, pin 14 = CANL)
หมายเหตุ: ใช้ resistor 120Ω เป็น termination ถ้าสายยาวเกิน 1 เมตร

2

ติดตั้ง Library และตั้งค่า Arduino IDE

เปิด Arduino IDE → Library Manager → ค้นหา OBD2_CAN_Bus_Library ติดตั้ง library ของ muki01 หรือใช้ ESP-IDF TWAI native API สำหรับ ESP-IDF environment

// ตัวอย่าง config TWAI ด้วย ESP-IDF
#include "driver/twai.h"

twai_general_config_t g_config =
    TWAI_GENERAL_CONFIG_DEFAULT(GPIO_NUM_21, GPIO_NUM_22,
                                TWAI_MODE_NORMAL);
twai_timing_config_t t_config = TWAI_TIMING_CONFIG_500KBITS();
twai_filter_config_t f_config = TWAI_FILTER_CONFIG_ACCEPT_ALL();
3

ส่ง OBD-II Request PID และรับผล

OBD-II ใช้ CAN ID 0x7DF สำหรับ broadcast request และ 0x7E8 สำหรับ ECU response
Service 0x01 = show current data, PID 0x0C = Engine RPM, PID 0x0D = Vehicle Speed

// ส่ง request อ่าน RPM (PID 0x0C)
uint8_t data[8] = {0x02, 0x01, 0x0C, 0,0,0,0,0};
twai_message_t msg;
msg.identifier = 0x7DF;
msg.data_length_code = 8;
memcpy(msg.data, data, 8);
twai_transmit(&msg, pdMS_TO_TICKS(100));

// ถอดรหัส RPM จาก response
// RPM = ((A*256) + B) / 4
uint16_t rpm = ((resp.data[3] * 256) + resp.data[4]) / 4;
4

ส่งข้อมูลขึ้น MQTT และแสดงบน Dashboard

ใช้ PubSubClient library ส่งค่า RPM, speed, coolant temp ทุก 1 วินาที
Subscribe topic บน Node-RED แล้วสร้าง gauge chart แสดงผล real-time ได้เลย

// Publish ค่า RPM ไป MQTT
char payload[32];
snprintf(payload, sizeof(payload), "{\"rpm\":%d}", rpm);
client.publish("vehicle/obd/rpm", payload);
5

เพิ่มฟีเจอร์: อ่าน DTC Error Code

ใช้ Service 0x03 อ่าน Diagnostic Trouble Codes (DTC) ที่ค้างอยู่ในรถ
แปลค่าตาม OBD-II DTC format เช่น P0301 = Cylinder 1 Misfire Detected
ใช้ Service 0x04 เพื่อ clear DTC ได้โดยไม่ต้องมี scan tool
