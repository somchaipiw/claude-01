ESP32-P4 v3.x — Pixel Processing Accelerator อัปเกรดใหม่
P4 UPGRADE
Espressif ออก firmware/SDK อัปเดตสำหรับ ESP32-P4 ชุดใหม่ โดยมีการปรับปรุง Pixel Processing Accelerator (PPA) ให้รองรับบล็อก 32×32 pixel และรองรับรูปแบบวิดีโอ YUV422/YUV420 ทำให้ UI และวิดีโอ Playback ลื่นขึ้นอย่างเห็นได้ชัด รวมถึง USB Video Class (UVC) Streaming ที่ 480 Mbps เปิดทางสำหรับกล้อง PTZ DIY, inspection camera, และ endoscope ราคาประหยัด

ตัวประมวลผล Dual-Core RISC-V @ 400 MHz + 32 MB embedded PSRAM ทำให้รัน 1080p touchscreen HMI ได้โดยไม่ต้องพึ่ง GPU ภายนอก
RISC-V 400MHz PPA YUV420 UVC Streaming MIPI-CSI/DSI
ESP32-C6 + Matter 1.4 — ยุคใหม่ DIY Smart Home ที่ครบวงจร
MATTER 1.4
ESP32-C6 กลายเป็น บอร์ดยอดนิยม 2026 สำหรับ DIY Smart Home เพราะรวม Wi-Fi 6, BT 5 LE, Zigbee, Thread และ Matter ไว้ในชิปเดียวราคา ~$5 USD ปีนี้ Matter 1.4 ขยาย device categories ใหม่ โดยเฉพาะด้าน Energy Management (smart meter, solar, EV charging) ทำให้โปรเจกต์ตรวจวัดพลังงานบ้านด้วย ESP32-C6 เชื่อมต่อกับ Apple Home, Google Home, และ Alexa ได้โดยตรง

ESPHome 2026.8 รองรับ ESP32-C6 เต็มรูปแบบแล้ว integration กับ Home Assistant ง่ายมาก

TinyML + ONNX บน ESP32-S3 — INT4 Quantization มาแล้ว

สร้างระบบตรวจวัดความชื้นดินแบบ real-time สำหรับไร่นา โดยใช้ ESP32 node พร้อม Capacitive Soil Moisture Sensor และโมดูล LoRa RA-02 (หรือ SX1276) สื่อสารระยะไกลสูงสุด 3–5 กม. กับ Gateway อีกตัว Gateway ส่งข้อมูลขึ้น Cloud ผ่าน Wi-Fi และสั่งปั๊มน้ำอัตโนมัติตามค่า threshold

  • Capacitive soil moisture ± threshold trigger
  • LoRa 433/868 MHz สื่อสารระยะไกล
  • Solar panel + LiFePO4 แบตเตอรี่ Off-Grid
  • Dashboard บน Node-RED หรือ Home Assistant
  • DS18B20 วัดอุณหภูมิดิน
  • DHT22 วัดความชื้นอากาศ

AD8232 — Single-Lead ECG Signal Conditioning Module
BIOMETRIC
ผู้ผลิต: Analog Devices (โมดูลพร้อมใช้จากหลายยี่ห้อ)
ราคา: ~80–150 บาท

IC ออกแบบมาเพื่อวัดสัญญาณ ECG โดยเฉพาะ มี instrumentation amplifier + right-leg drive (RLD) + filter built-in ในตัวเดียว ให้สัญญาณ analog output พร้อมส่งเข้า ADC ของ ESP32 โดยตรง (pin ADC1 recommended)
Specค่า
Supply Voltage2.0 – 3.5V
OutputAnalog (0–3.3V)
CMRR80 dB (typ)
InterfaceAnalog OUT + LO+/LO− detect pins
// อ่าน ECG จาก AD8232 บน ESP32 #define ECG_PIN 34 // ADC1_CH6 #define LO_PLUS 32 #define LO_MINUS 33 void loop() { if (digitalRead(LO_PLUS) || digitalRead(LO_MINUS)) { Serial.println("!"); // electrode off } else { Serial.println(analogRead(ECG_PIN)); } delayMicroseconds(4000); // 250 SPS }
ECG Analog Health Monitor
MAX30102 — Pulse Oximeter & Heart Rate Sensor (PPG)
BIOMETRIC
ผู้ผลิต: Analog Devices (Maxim)
ราคา: ~60–120 บาท

Sensor PPG (Photoplethysmography) วัด SpO₂ และ Heart Rate ด้วย LED สีแดงและ infrared ในตัว รองรับ I2C interface ต่อกับ ESP32 ได้ทันที มี library MAX30105 บน Arduino IDE พร้อมใช้ ใช้ใน wearable ได้เพราะกินไฟต่ำมาก

InterfaceI2C (addr 0x57)
LEDRed 660nm + IR 880nm
Sample Rate50–3200 SPS
Resolution18-bit ADC
SpO2 Heart Rate I2C Wearable

AGRICULTURE

AS7341 — 11-Channel Spectral Color Sensor (AMS-OSRAM)
SPECTRAL
ผู้ผลิต: AMS-OSRAM
ราคา: ~250–400 บาท (breakout board)

Sensor วิเคราะห์แสงแบบ spectral ได้ 11 ช่อง (F1–F8: 415–680nm, Clear, NIR, Flicker) ใช้ I2C เชื่อมต่อ ESP32 ง่ายมาก มี Adafruit library รองรับ ประยุกต์ใช้ได้หลากหลาย เช่น ตรวจสอบคุณภาพผลไม้, วัดค่า NDVI พืช, ตรวจจับสีสำหรับอุตสาหกรรม, หรือวัดความเข้มแสงแบบหลายช่วงความถี่
