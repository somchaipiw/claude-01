ESP32-C5 — Dual-Band Wi-Fi 6 + Matter สำหรับ IoT รุ่นใหม่

ทำไม ESP32-C5 ถึงน่าสนใจในปี 2026

ESP32-C5 เป็นชิปตัวแรกในตระกูล ESP32 ที่รองรับ Wi-Fi ทั้ง 2.4 GHz และ 5 GHz พร้อม Bluetooth 5.0 LE ในชิปเดียว ทำให้เหมาะมากสำหรับ Smart Home ที่ต้องการความเร็วและหลีกเลี่ยงความแออัดของคลื่น 2.4 GHz ใช้คอร์ RISC-V 32-bit ประหยัดพลังงาน และรองรับ Matter + Thread ผ่าน ESP-IDF v5.5.3+

XiaoZhi ESP32 — AI Voice Assistant บนชิปราคาไม่กี่ร้อย

🔊 XiaoZhi คืออะไร และทำงานอย่างไร?

XiaoZhi (小智) เป็น open-source AI voice assistant framework สำหรับ ESP32 ที่ Espressif พัฒนา ทำงานโดยส่งเสียงผ่าน WebSocket หรือ MQTT+UDP ไปยัง LLM backend เช่น Qwen, DeepSeek หรือ server ของตัวเอง ตอนนี้มี official component esp_xiaozhi ใน ESP Component Registry แล้ว รองรับ ESP-IDF v5.5+

  1. ผู้ใช้พูดใส่ไมค์ ESP32-S3 → wake word detection (ESP-SR) ทำงาน on-device
  2. ส่ง audio stream (OPUS/G.711/PCM) ผ่าน WebSocket ไปยัง cloud LLM
  3. LLM (Qwen/DeepSeek) ตอบกลับมาเป็น text-to-speech audio
  4. ESP32 เล่นเสียงตอบกลับผ่านลำโพง และสั่งงาน IoT ผ่าน MCP tools
Component

esp_xiaozhi v0.1.2 — Official Component

ติดตั้งได้ผ่าน ESP Component Registry ง่ายแค่บรรทัดเดียว รองรับ Audio Codec หลายรูปแบบ

  • OPUS, G.711 μ-law, PCM audio
  • WebSocket + MQTT+UDP transport
  • MCP tools: GPIO, LED, servo, sensor
  • Decoupled AudioService architecture
idf.py add-dependency \ espressif/esp_xiaozhi@0.1.2

Water Quality & Contactless Water Sensors — ตรวจน้ำรุ่นใหม่

แนวโน้ม Water Sensor ปี 2026

sensors น้ำรุ่นใหม่หันมาใช้ capacitive และ ultrasonic sensing แทน contact-based เพื่อลดการกัดกร่อน เพิ่มอายุการใช้งาน และเหมาะกับน้ำเคมีหรืออาหารมากขึ้น นอกจากนี้ยังมี multi-parameter sensors ที่วัดได้หลายค่าในตัวเดียว

New Sensor

SemLab CLS-24BP — Contactless Liquid Sensor

sensor ตรวจจับระดับน้ำแบบ capacitive ที่ไม่ต้องสัมผัสของเหลวเลย ติดภายนอกถัง ใช้ได้กับน้ำเคมี น้ำดื่ม หรือน้ำมัน

  • ติดภายนอกถัง ไม่เจาะรู ไม่ต้องกลัวรั่ว
  • ทำงานกับถังพลาสติก/แก้ว/เซรามิก
  • Output: digital HIGH/LOW หรือ analog
  • ใช้ร่วมกับ ESP32 ได้ทันที (3.3V/5V)

Use Case

Smart Water Tank Monitor: ติดที่ถังน้ำบนดาดฟ้า วัดระดับน้ำ + แจ้งเตือน LINE เมื่อน้ำใกล้หมด

Framework

ESP-DL — Deep Learning บน ESP32

Espressif's official deep learning library สำหรับรัน neural network บน chip โดยตรง ไม่ต้องส่งข้อมูลไป cloud ทำให้ response เร็วมากและ private

  • รองรับ ESP32-S3 (SIMD instructions)
  • Model quantization INT8 ลด model size
  • รองรับ ONNX model import
  • Face detection, voice activity ตัวอย่าง

Framework

TensorFlow Lite Micro บน ESP32-S3

TFLite Micro รันบน ESP32-S3 ได้ดีเนื่องจาก 512 KB SRAM + PSRAM 8 MB เหมาะกับ model ขนาดเล็ก เช่น gesture recognition, anomaly detection

  • รองรับ keyword spotting (ESP-SR)
  • Anomaly detection บน sensor data
  • Gesture recognition ผ่าน IMU
  • รัน inference ใน <10ms สำหรับ small model

🥾 TrailGuard — Fall Detection Wearable ด้วย Gyroscope + ESP32

โปรเจกต์ที่น่าสนใจ: สร้างสายรัดข้อมือสำหรับนักเดินป่า ใช้ MPU-6050 gyroscope ตรวจ orientation และ motion ตลอดเวลา เมื่อ algorithm ตรวจพบ impact pattern ที่ผิดปกติ (การล้ม) จะส่ง SOS ผ่าน LoRa หรือ Wi-Fi ทันที

Hardware

  • ESP32-C3 (ultra compact, low power)
  • MPU-6050 6-axis IMU (I2C)
  • SX1276 LoRa module 915 MHz
  • LiPo 350 mAh + TP4056 charger
  • Custom 3D printed enclosure

Algorithm

  • วัด acceleration magnitude ทุก 50ms
  • Fall: spike >3g ตามด้วย near-zero movement
  • ยืนยัน 2 วินาทีก่อนส่ง alert (กัน false positive)
  • GPS coordinates แนบใน LoRa packet
