⚡ ESP32-E22 — Wi-Fi 6E Tri-Band Co-Processor

ชิปรุ่นใหม่ที่ทรงพลังที่สุดในตระกูล ESP32 ปัจจุบัน ออกแบบเป็น connectivity co-processor รองรับ 3 ย่านความถี่พร้อมกัน

RAM1 MB on-chip
Wi-Fi6E tri-band 2.4/5/6 GHz, 160 MHz ch, 2×2 MIMO
Throughputสูงสุด 2.1 Gbps (iperf)
Bluetooth6.0 dual-mode (LE + BR/EDR)
InterfacePCIe, USB, SDIO

🔋 ESP32-H21 — Ultra-Low Power BLE + Thread

RAM320 KB
RadioBLE 5.x + 802.15.4 (Thread/Zigbee)
GPIO19 GPIO

💧 อ่านค่า TDS + pH พร้อมกัน

อ่านค่า TDS sensor และ pH sensor บน ESP32 พร้อม temperature compensation:

float readTDS(int pin, float temp) { int raw = analogRead(pin); float v = raw * 3.3f / 4095.0f; float comp = 1.0f + 0.02f * (temp - 25.0f); float cv = v / comp; return (133.42f*cv*cv*cv - 255.86f*cv*cv + 857.39f*cv) * 0.5f; } // ค่าที่ได้เป็น ppm (parts per million)
