⭐ ไฮไลต์ประจำวัน

ESP32-P4 พลิกโฉมวงการ HMI Display — จากสมาร์ทโฮมถึงโรงงานอุตสาหกรรม

ปี 2026 เป็นปีทองของ ESP32-P4 ซึ่ง Espressif ออกแบบมาเป็น SoC ด้าน multimedia & HMI โดยเฉพาะ โดดเด่นด้วย dual-core RISC-V ความเร็ว 400 MHz, Pixel Processing Accelerator (PPA) แก้ปัญหา screen tearing, และ MIPI-DSI/CSI สำหรับจอและกล้อง ผู้ผลิตหลายรายเปิดตัวบอร์ด HMI ขนาด 7", 8", 10.1" พร้อม Wi-Fi 6 ทำให้สร้าง Industrial Control Panel ราคาประหยัดได้จริง

ทำไมน่าสนใจ? ESP32-P4 รองรับ H.264 encoding, ISP สำหรับกล้อง, และ ML inference ที่เร็วกว่า S3 หลายเท่า รองรับ framework อย่าง LVGL และ Arduino ทำให้ entry barrier ต่ำมาก ราคา module เริ่มต้นเพียงไม่กี่ร้อยบาท
ESP32-P4

Makerfabs MaTouch 10.1" — HMI พร้อม 4G LTE + Ethernet

Makerfabs เปิดตัว MaTouch ESP32-P4 จอ 10.1 นิ้ว รองรับ 4G LTE ผ่าน SIM7670G modem, RJ45 Ethernet, และกล้อง 2MP เหมาะสำหรับ remote monitoring ในพื้นที่ที่ไม่มี Wi-Fi

10.1" IPS 4G LTE Ethernet RJ45 Camera 2MP ESP32-P4
ESP32-H2

ESP32-H2 — Heart of Matter Protocol สำหรับบ้านอัจฉริยะ

ESP32-H2 ไม่มี Wi-Fi แต่โฟกัสที่ 802.15.4 (Zigbee/Thread) + BLE 5.0 รับบท endpoint ใน Matter network สมบูรณ์แบบ ใช้พลังงานต่ำมาก เหมาะกับ battery-powered sensor เช่น door sensor, occupancy sensor

IEEE 802.15.4 Zigbee / Thread BLE 5.0 Matter Ready Ultra Low Power
SDK: ESP-Zigbee-SDK production-ready ใช้ร่วมกับ Home Assistant ผ่าน ESPHome ได้เลย
TinyML

TinyML บน ESP32-S3 — "Machine Learning บน MCU" ปี 2026 ไม่ใช่ฝัน

TensorFlow Lite Micro (TFLM) ใช้ RAM เพียง 16 KB รัน model ที่ compile มาเป็น C header file บน ESP32-S3 ใช้ SIMD vector instructions เร่ง 8-bit MAC หลายตัวพร้อมกัน ทำให้ keyword detection & image classification เร็วพอสำหรับ real-time use case

TFLite Micro Edge Impulse 16KB RAM SIMD Vector ESP32-S3
Industrial

ESP32 + CAN Bus (TWAI) — IoT ในสายการผลิตแบบ Wireless

ESP32 มี built-in TWAI controller รองรับ CAN 2.0B ใช้ SN65HVD230 transceiver เชื่อมต่อกับ bus ได้เลย นำ Wi-Fi + CAN มารวมกัน ทำ wireless gateway สำหรับ automotive diagnostics และ factory automation โดยไม่ต้องมี external CAN IC

TWAI / CAN 2.0B SN65HVD230 FreeRTOS Wi-Fi Gateway

Sensors น่าสนใจ — Biometric & Industrial Focus

Sensors เหมาะสมกับโปรเจกต์ wearable และ industrial IoT

5 ตัว
Biometric

MAX30102 — Pulse Oximeter & Heart Rate Monitor

IC รวม LED (Red + IR), photodetector, ADC, และ ambient light rejection ไว้ในชิปเดียว วัด SpO2 และ HR ผ่าน I2C กินกระแสเพียง 600 µA ในโหมดวัด และ 0.7 µA standby เหมาะสำหรับ wearable สุดๆ

I2C 600 µA active SpO2 + HR 3.3V
Library: SparkFun MAX3010x (Arduino)  |  ราคา: ~100-150 บาท (breakout)
Temperature

MAX30205 — Digital Human Body Temperature Sensor

วัดอุณหภูมิร่างกายด้วยความแม่นยำ ±0.1°C ในช่วง 37°C–39°C รองรับ alert interrupt เมื่ออุณหภูมิเกิน threshold ใช้ I2C address สูงสุด 32 device บน bus เดียวกัน เหมาะสำหรับ patient monitor และ wearable fever detector

I2C ±0.1°C accuracy Alert pin 32 addresses
IMU

MPU6050 — 6-Axis IMU (Accelerometer + Gyroscope)

IMU 6-axis ยอดนิยมมี Digital Motion Processor (DMP) ทำ orientation fusion ในตัว รองรับ I2C/SPI ใช้ detect ก้าวเดิน, fall detection, gesture recognition ได้โดยตรง เหมาะกับ wearable และ robotics

I2C/SPI DMP onboard ±16g / ±2000°/s ราคา ~50 บาท
Industrial

SN65HVD230 — CAN Bus Transceiver (3.3V ใช้กับ ESP32 ได้เลย)

Transceiver CAN 2.0 ทำงานที่ 3.3V ไม่ต้องใช้ level shifter กับ ESP32 รองรับ bus ยาวสูงสุด 1 กม. noise immunity สูง ทนแรงดัน ±12V บน bus line เหมาะสำหรับ automotive และ industrial ได้ทั้งคู่

3.3V logic CAN 2.0 1Mbps max ±12V protection
ใช้คู่กับ: ESP32 built-in TWAI controller — ไม่ต้องซื้อ CAN controller IC เพิ่ม
Motor

AS5600 — Magnetic Rotary Encoder (Contactless)

Encoder แบบ magnetic ไม่มีชิ้นส่วนสัมผัส อ่านมุมแบบ absolute 0-360° ผ่าน I2C ความละเอียด 12-bit (4096 steps/rev) ทนฝุ่น ทนความชื้น เหมาะสำหรับ motor feedback ใน robotic arm และ gimbal ราคาถูกกว่า optical encoder มาก

I2C 12-bit (4096 steps) Contactless ราคา ~80-120 บาท

ตัวอย่างโค้ด — ESP32 + MAX30102 วัด SpO2 & Heart Rate

Arduino sketch สำหรับ wearable health monitor เบื้องต้น

C++ / Arduino esp32_max30102_health.ino 
#include <Wire.h>
#include <MAX30105.h>           // SparkFun MAX3010x library
#include <spo2_algorithm.h>      // SpO2 algorithm from SparkFun
#include <Adafruit_SSD1306.h>

MAX30105 particleSensor;
Adafruit_SSD1306 display(128, 64, &Wire, -1);

// Buffers for SpO2 algorithm
uint32_t irBuffer[100], redBuffer[100];
int32_t  spo2, heartRate;
int8_t   validSpO2, validHeartRate;

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);            // SDA=21, SCL=22 on ESP32

  // Init MAX30102
  particleSensor.begin(Wire, I2C_SPEED_FAST);
  particleSensor.setup(
    60,   // LED brightness (0–255)
    4,    // sample average
    2,    // LED mode: 1=Red only, 2=Red+IR, 3=Red+IR+Green
    100, // sample rate (Hz)
    411, // pulse width (µs)
    4096 // ADC range
  );

  display.begin(SSD1306_SWITCHCAPVCC, 0x3C);
  display.clearDisplay();
  display.setTextColor(WHITE);
}

void loop() {
  // Collect 100 samples first
  for (byte i = 0; i < 100; i++) {
    while (!particleSensor.available())
      particleSensor.check();
    redBuffer[i] = particleSensor.getRed();
    irBuffer[i]  = particleSensor.getIR();
    particleSensor.nextSample();
  }

  // Calculate SpO2 and Heart Rate
  maxim_heart_rate_and_oxygen_saturation(
    irBuffer, 100, redBuffer,
    &spo2, &validSpO2, &heartRate, &validHeartRate
  );

  // Display on OLED
  display.clearDisplay();
  display.setCursor(0, 0);
  display.setTextSize(2);
  display.printf("HR: %d bpm\n", validHeartRate ? heartRate : 0);
  display.printf("SpO2:%d%%",  validSpO2    ? spo2      : 0);
  display.display();
}
