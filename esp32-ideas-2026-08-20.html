ESP-KVM — IP KVM โอเพ่นซอร์สบน ESP32-P4 ราคา $45

ควบคุม PC ระยะไกลผ่าน Browser ด้วย HDMI Capture + USB HID

ESP-KVM คือโปรเจกต์โอเพ่นซอร์สล่าสุด (Apache 2.0) ที่ใช้ ESP32-P4 ทำหน้าที่เป็น IP KVM ระดับ Production — จับภาพ HDMI จากคอมพิวเตอร์เป้าหมาย ส่งสัญญาณ Keyboard/Mouse ผ่าน USB HID และสตรีมวิดีโอผ่าน Browser ด้วย HTTPS+TLS ทั้งหมดด้วย Hardware ราคาถูก

ไม่ต้องต่อสายพิเศษ ไม่ต้องติดตั้ง Agent ใดๆ บนคอมที่ถูกควบคุม รองรับทั้ง MJPEG และ H.264 encoding เหมาะสำหรับ Server Management, Homelab, Remote Development

BOM ทั้งหมด (~$45)

ชิ้นส่วนราคา
Waveshare ESP32-P4-ETH~$20
Geekworm C790 HDMI→CSI~$24
PC817 Optocoupler (Power/Reset)~$1.3

Features สำคัญ

  • HDMI Capture ผ่าน MIPI CSI Bridge
  • USB HID Keyboard & Mouse Emulation
  • H.264 / MJPEG Video Streaming
  • HTTPS + TLS Login Security
  • Power/Reset Button Control
ESP32-P4 Open Source IP KVM HDMI Capture H.264 Homelab

Solar + Supercapacitor — ESP32 Self-Powered Node

ระบบ Solar Panel + Supercapacitor (แทน LiPo) ให้ ESP32 ทำงานได้โดยไม่ต้องเปลี่ยนแบต ที่ 200 lux supercapacitor ชาร์จเต็มใน 17 วินาที รองรับ Deep Sleep + Wake อ่านค่า Sensor ส่ง MQTT แล้วหลับต่อ

Duty cycle: ตื่น 2 วินาที → ส่งข้อมูล → หลับ 5 นาที = ใช้พลังงานเฉลี่ยต่ำกว่า 2mW ซึ่ง Solar Panel 2W พอสำหรับ Deploy กลางแจ้ง

วงจรพื้นฐาน

  • Solar Panel 2W → CN3965 Solar Charger IC
  • Supercapacitor 50F 2.7V (×2 ต่อ Series)
  • TPS63031 Buck-Boost → 3.3V สำหรับ ESP32
  • ESP32-C3 (Ultra-Low Power) + BME280 Sensor

Piezoelectric Energy Harvesting — พลังงานจากการสั่นสะเทือน

Piezoelectric Disc แปลงการสั่นสะเทือนเชิงกล (เครื่องจักร, พื้นถนน, โครงสร้าง) เป็นไฟฟ้า ผ่าน Full-Wave Rectifier + LTC3588 Energy Harvesting IC → ชาร์จ LiPo ขนาดเล็ก เพื่อจ่ายไฟให้ ESP32

ใช้ใน Structural Health Monitoring — ฝัง Sensor ใน Bridge, อาคาร, ท่อน้ำ โดยไม่ต้องเดินสายไฟหรือเปลี่ยนแบตเลย

Sensor Node แบบ Autonomous

  • Piezo Disc 35mm → LTC3588 Harvester
  • LiPo 150mAh Buffer + BQ25570 MPPT
  • MPU6050 Accelerometer + ADXL362
  • ESP32-C3 + LoRa SX1276 ส่งข้อมูล

  • Waterproof Housing IP67

📝 ตัวอย่างโค้ด — อ่านค่า pH และ TDS ส่ง MQTT
// ESP32 Water Quality Monitor — pH + TDS + MQTT #include <WiFi.h> #include <PubSubClient.h> const int PH_PIN = 34; // ADC1 CH6 const int TDS_PIN = 35; // ADC1 CH7 float readPH() { int raw = analogRead(PH_PIN); float voltage = raw * (3.3f / 4095.0f); return -5.70f * voltage + 21.34f; // Calibration } float readTDS(float tempC) { int raw = analogRead(TDS_PIN); float v = raw * (3.3f / 4095.0f); float comp = 1.0f + 0.02f * (tempC - 25.0f); return (133.42f*v*v*v - 255.86f*v*v + 857.39f*v) / comp; } void loop() { float ph = readPH(); float tds = readTDS(25.0f); char payload[64]; snprintf(payload, sizeof(payload), "{\"ph\":%.2f,\"tds\":%.1f}", ph, tds); mqttClient.publish("water/quality", payload); esp_deep_sleep(300e6); // หลับ 5 นาที }

ESP32 BLE Beacon + Indoor Positioning

ESP32 ทำงานเป็น BLE Beacon (iBeacon/Eddystone) กระจายทั่วอาคาร อุปกรณ์ที่ถืออยู่รับสัญญาณ RSSI จากหลาย Beacon แล้วคำนวณตำแหน่งด้วย Trilateration

ความแม่นยำ 1–3 เมตร เหมาะสำหรับ Asset Tracking ในโรงงาน, โรงพยาบาล หรือ Museum Exhibit Guide

ระบบ IPS แบบประหยัด

  • ESP32-C3 Mini (BLE Beacon) × N โหนด ราคา $3/ชิ้น
  • RSSI Trilateration Algorithm (Arduino หรือ Python)
  • Kalman Filter ลด Noise ของ RSSI
  • Map Overlay บน Web Dashboard
