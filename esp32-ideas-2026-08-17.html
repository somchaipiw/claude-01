Low-Code Edge AI & Computer Vision Framework

Espressif ปล่อย ESP-VISION — framework Python unified สำหรับ computer vision บน ESP32-P4 ใช้ได้ตั้งแต่ camera capture, image processing, video encode, AI inference ถึง network streaming ในชุด API เดียว ไม่ต้องเขียน C/C++ เหมือนเดิม

ESP32-P4-EYE + YOLOv11 + MQTT Dashboard

ใช้ ESP32-P4-EYE ถ่ายรูปผลไม้/ผัก ส่ง frame ผ่าน YOLOv11-nano ที่รันอยู่บน board โดยตรง ตรวจจับตำแหน่ง, ขนาด, รอยตำหนิ — ผ่าน MQTT ส่งผล pass/fail + metadata ขึ้น Node-RED dashboard ทั้งหมดทำงาน offline เชื่อมต่อเฉพาะ LAN local ไม่ต้องพึ่ง cloud

  • 1
    Train YOLOv11-nano บน Roboflow dataset รูปผลไม้ของเรา → export ONNX → แปลงผ่าน ESP-DL converter
  • 2
    Flash model ลง ESP32-P4-EYE พร้อม ESP-VISION firmware ตั้งค่า confidence threshold 0.6
  • 3
    ติดตั้ง board ในสายพาน conveyor กลับข้างลง (camera ชี้ลง) ต่อไฟ 5V จาก USB-PD
  • 4
    ส่ง JSON ผล detect ผ่าน MQTT → Node-RED → แสดง real-time + เก็บ log SQLite + กระตุ้น relay ปัด defect ออก
ต้นทุน: ESP32-P4-EYE ~$25 + LED ring light ~$3 + relay module ~$1 = <$30 ต่อสถานี เทียบกับ camera inspection system ระดับอุตสาหกรรม ราคา $500–$2,000

NILM — ตรวจจับเครื่องใช้ไฟฟ้าแบบ Non-Intrusive ด้วย TinyML
IJERT Research 2026 · Accuracy 99.49% บน ESP32

งานวิจัยล่าสุด (IJERT Vol.15, 2026) พิสูจน์ว่า ESP32 สามารถทำ Non-Intrusive Load Monitoring (NILM) ได้แบบ edge โดยใช้สูตร P = V × I วัด electrical signature ของแต่ละเครื่อง ผ่าน TinyML model ที่รันบน microcontroller โดยตรง — ความแม่นยำ 99.49% โดยไม่ต้องใช้ cloud

NILM คืออะไร? แทนที่จะติด sensor แยกทุกเครื่อง ใช้ sensor ตัวเดียวที่ distribution board แล้วให้ AI แยกแยะว่าตอนนี้เปิดเครื่องอะไรอยู่บ้าง จาก pattern กระแสไฟรวม — ไม่ต้องรื้อสายไฟเพิ่มเลย

Architecture:

Voltage Sensor ZMPT101B (ต่อไฟ 220V ผ่าน transformer)
Current Sensor ATM90E36 Energy IC (SPI) หรือ SCT-013 + burden resistor
Feature Engineering RMS power, reactive power, power factor, harmonic signatures
ML Model Decision Tree (EON Compiler) — ใช้ RAM เพียง 8 KB
Framework Edge Impulse + Arduino IDE หรือ PlatformIO
Output MQTT → Home Assistant → แจ้งเตือน LINE ถ้ากระแสผิดปกติ

ESP-SR MultiNet + INMP441 I2S Microphone

ESP-SR คือ framework ของ Espressif สำหรับ offline speech recognition บน ESP32-S3 ล่าสุด (2026) รองรับ custom wake word ภาษาไทย ผ่าน MultiNet model — ไม่ต้องส่งเสียงขึ้น cloud ใช้ RAM เพียง ~200 KB ทำงาน real-time ตลอด 24/7

🔑 ทำไม ESP32 + Modbus จึงน่าสนใจในปี 2026?

โรงงานทั่วโลกยังใช้ Modbus RTU (RS-485) อยู่เป็น 90% — เครื่องจักรเก่าหลายสิบปียังส่ง data ผ่าน protocol นี้ ESP32 มี UART 3 ช่อง ราคาถูก มี Wi-Fi ในตัว จึงเป็น gateway ที่สมบูรณ์แบบในการ bridge ข้อมูลจาก PLC/sensor legacy เข้า MQTT, InfluxDB, หรือ cloud โดยไม่ต้องเปลี่ยนอุปกรณ์เดิมเลย

🌉
Modbus RTU → MQTT Cloud Gateway
ESP32-S3 + RS-485 → Grafana Dashboard

สร้าง gateway อ่านข้อมูล Modbus slave สูงสุด 247 ตัว ผ่าน RS-485 แล้วส่ง JSON ขึ้น MQTT broker ทุก 10 วินาที

Hardware ESP32-S3 + TTL-to-RS485 (MAX3485 module) + terminal block
Library ModbusESP8266 / modbus-esp8266 (รองรับ ESP32 ด้วย)
Register Types Coil (0x), Discrete Input (1x), Input Reg (3x), Holding Reg (4x)
Output MQTT JSON → InfluxDB → Grafana (stack เต็ม $0)

Smart Factory: อ่าน VFD ผ่าน Modbus + Dashboard
Variable Frequency Drive Monitor — ประหยัดไฟ 20–40%

VFD (Variable Frequency Drive) ควบคุมมอเตอร์ส่วนใหญ่มี Modbus RTU interface ในตัว ใช้ ESP32 อ่าน ความถี่ปัจจุบัน, กระแส, แรงดัน, อุณหภูมิ inverter ทุก 5 วินาที ส่งขึ้น Home Assistant หรือ industrial SCADA เพื่อวิเคราะห์ energy efficiency

  • Register 0x0001: Output frequency (Hz × 100)
  • Register 0x0002: Output current (A × 10)
  • Register 0x0003: DC Bus voltage (V)
  • Register 0x0004: Heatsink temperature (°C)
  • Register 0x2000: Control word (Start/Stop/Reset)
ข้อควรระวัง: ต้องใช้ isolated RS-485 transceiver (เช่น ISO3082, ADM2587E) เพื่อป้องกัน ground loop จาก VFD ที่มี switching noise สูง — ไม่ควรใช้ module RS-485 ราคาถูกโดยตรง
