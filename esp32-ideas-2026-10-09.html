NEW

ESP32-H2 Zigbee 3.0 + Thread 1.3 — ครบจบในชิปเดียว

ESP32-H2 เป็น RISC-V SoC ตัวแรกของ Espressif ที่มี IEEE 802.15.4 ในระดับ hardware พร้อม Zigbee-Compliant Platform certified และ Thread-Certified 1.3.0 Component ครบในตัวเดียว มี RAM 320 KB และ BLE 5.2 รองรับทั้ง Mesh Network และ Smart Home ecosystem

RISC-V Single Core 320 KB SRAM IEEE 802.15.4 BLE 5.2 Zigbee 3.0 + Thread 1.3

ใช้คู่กับ ESP32-S3 (Wi-Fi) → สร้าง Matter-Zigbee Bridge หรือ Thread Border Router ได้ทันที โดยไม่ต้องพึ่งฮาร์ดแวร์ third-party

SDK

ESP-Matter SDK v1.5 — รองรับ ESP32-C5 + Matter-Zigbee Bridge

ESP-Matter SDK เวอร์ชันล่าสุดรองรับ ESP32-C5 อย่างเป็นทางการ พร้อม example ใหม่สำหรับ Matter-Zigbee Light Bridge ที่ใช้ชิปเดียวรัน dual stack ได้ (สลับโหมดระหว่าง Zigbee และ Matter) เหมาะสำหรับการอัปเกรด Smart Home รุ่นเก่าเข้า Matter ecosystem โดยไม่ต้องเปลี่ยนอุปกรณ์ทั้งหมด

Matter 1.4+ Thread 1.3 ESP32-C5 support Dual-Stack
HARDWARE

ESP Thread BR + Zigbee GW Board — Gateway สำเร็จรูปจาก Espressif

บอร์ดสำเร็จรูปจาก Espressif ที่รวม ESP32-S3 (จัดการ Wi-Fi + System) กับ ESP32-H2 (ทำหน้าที่ Thread + Zigbee radio) บนบอร์ดเดียว ทำให้ได้ Thread Border Router และ Zigbee Gateway ในกล่องเดียว ไม่ต้องต่อวงจรเอง เหมาะสำหรับนักพัฒนาที่ต้องการ Proof-of-Concept ด้าน Smart Home อย่างรวดเร็ว

ESP32-S3 + ESP32-H2 Thread BR Zigbee GW Wi-Fi Bridge
SOLAR

ESP32-C6 Solar Sensor Node — Ultra-Low Power พร้อม Matter

บอร์ดใหม่สร้างจาก ESP32-C6 Mini + แผงโซลาร์เล็ก + แบต LiPo หนึ่งก้อน ออกแบบมาเพื่อ Deploy นอกอาคารโดยไม่มีไฟฟ้า ด้วย Deep Sleep ที่ดึงกระแสเพียง 2.5 µA ในโหมด Hibernation ทำให้ใช้พลังงานต่ำมาก รองรับ Wi-Fi 6, BLE 5, Zigbee, Thread, Matter ในชิปเดียว

2.5 µA Hibernate Wi-Fi 6 Solar Charge Matter Ready

กระแสเมื่อ Wi-Fi active: 160–260 mA แต่ใน Hibernation: เหลือแค่ 2.5 µA — Duty Cycle 1 นาที/ชั่วโมง ใช้แบตน้อยมาก!

MAX30102 — PPG Heart Rate & SpO₂

Photoplethysmography sensor พร้อม IR + Red LED ในตัว วัด Heart Rate และ Oxygen Saturation ได้แม่น ใช้ไฟ 3.3V เชื่อมต่อ I2C ขนาดเล็กมาก เหมาะ Wearable

✅ Wearable health monitor, SpO₂ meter, Pulse logger
💧

Capacitive Soil Moisture Sensor — ทนทาน ไม่กัดกร่อน

ใช้ Dielectric Property วัดความชื้นดิน ไม่มีขั้ว metal โลหะสัมผัสดินโดยตรง ทำให้ทนทานกว่า resistive แบบเก่ามาก ราคาถูก ใช้ ADC บน ESP32 อ่านค่าโดยตรง

✅ Smart garden, precision agriculture, greenhouse monitoring
📡

Semtech SX1262 — LoRa Transceiver รุ่นใหม่

LoRa transceiver ที่ใช้พลังงานต่ำ ส่งได้ไกลถึง 15 กม. ใน LoRaWAN mode เป็น chip ใน Wio-SX1262 ของ Seeed ใช้ SPI เชื่อมต่อ ESP32 รองรับ 868 MHz (EU) และ 915 MHz (US)

✅ LoRaWAN TTN node, long-range sensor, rural monitoring
🌡️

DS18B20 — Waterproof Digital Thermometer

Sensor อุณหภูมิ 1-Wire ที่ฝังในปลอกโลหะกันน้ำ แม่นยำ ±0.5°C วัดได้ -55°C ถึง +125°C เหมาะกับน้ำ ดิน และสภาพแวดล้อมชื้น เชื่อมต่อ Single GPIO ต่อได้หลายตัวบนสาย Bus เดียว

✅ Soil temperature, water temperature, hydroponics, aquaculture
🧪

TDS Probe — Total Dissolved Solids for Water Quality

วัดความเข้มข้นของสารละลายในน้ำ (ppm) เพื่อตรวจสอบคุณภาพน้ำหรือปุ๋ยในระบบ Hydroponics ค่า TDS สูง = น้ำมีแร่ธาตุมาก วัดด้วย ADC ของ ESP32 ผ่าน module conditioning

✅ Hydroponics nutrient control, water purification, aquarium monitoring
