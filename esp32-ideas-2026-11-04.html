🌍 LoRa vs LoRaWAN คืออะไร แตกต่างกันอย่างไร?

LoRa (Long Range) คือเทคโนโลยีการมอดูเลตสัญญาณวิทยุ (Chirp Spread Spectrum) ที่พัฒนาโดย Semtech ช่วยให้ส่งข้อมูลได้ไกลในสภาพแวดล้อมที่มีสัญญาณรบกวน

LoRaWAN คือ protocol มาตรฐาน MAC layer ที่ทำงานบน LoRa กำหนดวิธีจัดการ device หลายพันตัวบน network เดียวกัน ทำงานผ่าน Gateway → Network Server → Application Server

คุณสมบัติLoRa P2PLoRaWAN
ระยะ2–15 กม.2–15 กม. ผ่าน Gateway
โครงสร้างPoint-to-PointStar-of-Stars (Gateway + Server)
จำนวน Deviceจำกัด (ทำเอง)หลายพันตัวต่อ Gateway
ความซับซ้อนง่าย เริ่มได้เร็วต้องมี Network Server (ChirpStack/TTN)
เหมาะกับPrototype, Farm sensorSmart City, Industrial scale
Module ยอดนิยมRFM95W, SX1276Seeed LoRa-E5, RAK811
SX1276 RFM95W LoRa-E5 868 MHz EU 915 MHz US/TH

เทคนิค Deep Sleep ที่ต้องรู้

ESP32 ใช้เวลา 2–4 วินาทีในการ reconnect WiFi หลัง wake up ซึ่งกินไฟมาก เทคนิคสำคัญคือเก็บ WiFi credentials ไว้ใน RTC Memory เพื่อข้าม channel scan

// บันทึก BSSID + Channel ใน RTC RTC_DATA_ATTR uint8_t bssid[6]; RTC_DATA_ATTR int32_t channel; WiFi.begin(ssid, pass, channel, bssid, true); // เร็วขึ้น ~1.5 วิ
RTC Memory Fast Connect

MOSFET Power Gating — ตัด Sensor ตอน Sleep

Sensor อย่าง BME280, DS18B20 ยังดึงกระแสไฟแม้จะ sleep อยู่ วิธีแก้คือใช้ GPIO ควบคุม P-Channel MOSFET ตัดไฟ Sensor โดยสมบูรณ์ระหว่าง deep sleep

// เปิด/ปิด Sensor ด้วย GPIO pinMode(GPIO_SENSOR_PWR, OUTPUT); digitalWrite(GPIO_SENSOR_PWR, HIGH); // เปิด delay(100); // รอ sensor warm-up // ... อ่านค่า ... digitalWrite(GPIO_SENSOR_PWR, LOW); // ปิด
MOSFET Power Gate

Batch Sending — ส่งข้อมูลหลาย sample ต่อครั้ง

แทนที่จะ wake up ทุก 10 นาทีแล้วส่ง 1 ค่า ให้เก็บค่าใน RTC memory ก่อน พอครบ 12 sample (2 ชั่วโมง) ค่อย wake up WiFi แล้วส่งทีเดียว ประหยัดพลังงานได้มาก

ผล: ลดเวลา Active WiFi จาก 144 ครั้ง/วัน เหลือ 12 ครั้ง/วัน ประหยัดพลังงานไปกว่า 90%
Batch RTC Buffer

🕸 BLE Mesh คืออะไร ทำงานอย่างไร?

ESP-BLE-MESH คือ implementation ของ Bluetooth Mesh SIG Standard v1.0.1 บน ESP-IDF ทำให้ ESP32 กลายเป็น node ในเครือข่าย mesh ที่ส่งข้อมูลผ่านกันแบบ multi-hop ไม่ต้องพึ่ง WiFi Router และ self-heal เองเมื่อ node หนึ่งล้มเหลว

BLE Mesh Gateway → AWS IoT / Firebase
