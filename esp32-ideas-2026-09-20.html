🆕 ESP-IDF v6.0

ESP32-C5 ได้ Stable Support แล้ว — Dual-Band Wi-Fi 6 บน RISC-V 240 MHz

ESP-IDF v6.0 เลื่อนสถานะ ESP32-C5 จาก Preview เป็น Stable พร้อม OTA Safe Bootloader, Wi-Fi 6 ทั้ง 2.4 GHz และ 5 GHz ในชิปเดียว รองรับ Zigbee, Thread และ Matter อย่างสมบูรณ์

CPURISC-V Single-Core 240 MHz
RAM400 KB SRAM
Wi-Fi2.4 GHz + 5 GHz (Wi-Fi 6)
WirelessBLE 5.0, Zigbee, Thread, Matter
FrameworkESP-IDF v6.0 (Stable)

จุดเด่น: เป็น ESP32 ตัวแรกที่รองรับ 5 GHz Wi-Fi 6 — เหมาะสำหรับโปรเจกต์ Smart Home ที่ต้องการแบนด์วิดท์สูงและ latency ต่ำ

📦 Mass Production

ESP32-C61 เข้าสู่ Mass Production — Wi-Fi 6 ราคาประหยัดที่สุดในตระกูล C

Espressif ประกาศ ESP32-C61 เข้าสู่สายการผลิตจริงแล้ว เน้นเป็น Wi-Fi 6 co-processor ราคาต่ำมาก เหมาะสำหรับบอร์ดที่ต้องการเพิ่มความสามารถไร้สาย

ESP32-C6

  • 160 MHz RISC-V HP
  • Wi-Fi 6 + BLE 5.0
  • Zigbee + Thread
  • 512 KB SRAM
  • ราคา: ปกติ

ESP32-C61

  • 160 MHz RISC-V
  • Wi-Fi 6 + BLE 5.0
  • ไม่มี Zigbee/Thread
  • 256 KB SRAM
  • ราคา: ถูกกว่ามาก

Use Case: เหมาะกับ consumer electronics ที่ต้องการ Wi-Fi 6 แต่ไม่จำเป็นต้องใช้ Zigbee/Thread เช่น Smart Plug, Smart Bulb, IP Camera

⚙️ Framework

ESP-IDF v6.0 — Installation Manager ใหม่ + Picolibc + OTA Bootloader

นอกจาก C5/C61 support แล้ว ESP-IDF v6.0 ยังมาพร้อม ESP-IDF Installation Manager (EIM) ที่ทำให้ติดตั้ง framework ง่ายขึ้นมาก เปลี่ยนมาใช้ Picolibc แทน newlib เพื่อ footprint ที่เล็กลง และรองรับการอัปเดต Bootloader ผ่าน OTA

📡 LoRa Mesh

Private LoRa Mesh Network ด้วย Meshtastic + ESP32-S3 — Off-Grid สื่อสารไร้อินเทอร์เน็ต

สร้างเครือข่ายสื่อสารแบบ mesh ระยะไกลด้วย ESP32-S3 + SX1262 LoRa module และ Meshtastic firmware แต่ละ node ทำหน้าที่เป็น repeater อัตโนมัติ ส่งข้อความหา-รับ Encrypted text, GPS position และ telemetry ได้ไกลถึง 10-20 km ในพื้นที่โล่ง

HardwareHeltec WiFi LoRa 32 V3 หรือ TTGO LoRa32
FirmwareMeshtastic v3.x (ติดตั้งง่ายผ่าน Web Flasher)
ระยะส่ง2-5 km ในเมือง / 10-20 km พื้นที่โล่ง
Band868 MHz (EU) / 915 MHz (US) / 923 MHz (APAC)
AppMeshtastic App (Android/iOS) ต่อผ่าน BLE
ค่าใช้จ่ายเริ่มต้น ~600 บาท/node

Use Case: ทีมงานนอกสถานที่, กิจกรรมกลางแจ้ง, ระบบเตือนภัยชุมชน, งานกู้ภัยพื้นที่ไม่มีสัญญาณมือถือ

📍 LoRaWAN

LoRaWAN Environmental Sensor Node — ส่งข้อมูลสภาพแวดล้อมผ่าน TTN/ChirpStack ทุก 5 นาที

สร้าง sensor node กินไฟต่ำ ส่งข้อมูล temperature, humidity, CO2 และ pressure ขึ้น The Things Network หรือ ChirpStack server แบตเตอรี่ 18650 เดียวใช้ได้นาน 1-2 ปี ด้วยเทคนิค deep sleep + LoRaWAN OTAA

MCUESP32 + SX1276/SX1262
SensorsBME280 (T/H/P) + SCD40 (CO2)
NetworkLoRaWAN Class A, OTAA Join
Battery Life12-24 เดือน (18650 3000 mAh)
LibraryLMIC / RadioLib สำหรับ Arduino
DashboardGrafana + InfluxDB ผ่าน TTN Integration

เคล็ดลับ: ใช้ ADR (Adaptive Data Rate) ของ LoRaWAN ให้เครือข่ายปรับ spreading factor อัตโนมัติเพื่อประหยัดพลังงาน

👁️ mmWave Presence

Smart Room Presence System — LD2450 + ESP32-C6 + ESPHome ตรวจจับหลายคนพร้อมกัน

ระบบตรวจจับการมีคนในห้องแบบ multi-target ด้วย HLK-LD2450 24 GHz mmWave radar เชื่อมต่อ ESP32-C6 ผ่าน UART และ expose ผ่าน ESPHome เข้า Home Assistant สามารถติดตาม X/Y coordinate ของสูงสุด 3 คนพร้อมกัน พร้อมแบ่ง zone อัตโนมัติ

RadarHLK-LD2450 (24 GHz, UART)
MCUESP32-C6 (Zigbee + Wi-Fi 6)
DetectionMulti-target: สูงสุด 3 คน
OutputX/Y coordinate, speed, distance
IntegrationESPHome → Home Assistant
Zone Configกำหนด zone 1-3 ผ่าน HA UI

Automation ตัวอย่าง: เปิดไฟเมื่อมีคนเข้าโซน 1, หรี่ไฟเมื่อทุกคนอยู่โซน 2 (โซฟา), ปิดไฟเมื่อไม่มีคน 5 นาที

📐 UWB RTLS

UWB Indoor Positioning System — ESP32-S3 + DWM3000 ติดตาม Asset แม่นยำ 10 cm

ระบบ Real-Time Location System (RTLS) ในอาคารโดยใช้ Ultra-Wideband (UWB) กับ Qorvo DWM3000 module ติดตั้ง anchor 3 จุดขึ้นไปตามมุมห้อง แล้วใช้ tag ที่ผู้คนหรือสินทรัพย์พกพา วัด ToF (Time of Flight) ได้ความแม่นยำ ~10 cm

MCU+UWBESP32-S3 + Qorvo DWM3000 (SPI)
Accuracy~10 cm (ดีกว่า BLE RSSI 10x)
Topology≥3 Anchors + N Tags
AlgorithmTWR (Two-Way Ranging) → Trilateration
OutputJSON ผ่าน Wi-Fi/MQTT ทุก 100 ms
Use CaseWarehouse, Healthcare, AR/VR, Robot Nav

เปรียบเทียบ: BLE iBeacon ≈ 1-3 m accuracy · Wi-Fi RTT ≈ 1-2 m · UWB DWM3000 ≈ 0.1 m — ต่างกัน 10-30 เท่า!

🌱 Capacitive

Capacitive Soil Moisture v2.0 — ปลอดสนิม วัดความชื้นดินแม่นยำกว่าแบบ Resistive

Sensor วัดความชื้นดินแบบ capacitive ไม่มีหน้าสัมผัสโลหะในดิน ทำให้ไม่เกิดปัญหาการกัดกร่อน อายุการใช้งานยาวนานกว่า และให้ค่าที่เสถียรกว่า แบบ resistive อย่างเห็นได้ชัด

OutputAnalog (0-3.3V) หรือ I2C (v2.0+)
Power3.3V / 5V
Lifespan>5 ปี (vs Resistive <3 เดือน)
ความแม่นยำ±3% RH (ดีกว่า resistive ~5x)

🌊 Flow Sensor

YF-S201 Water Flow Sensor — วัดอัตราการไหลของน้ำด้วย Hall Effect

Sensor วัดอัตราการไหลของน้ำแบบ Hall effect ส่ง pulse ออกมาตามรอบการหมุนของ impeller 1 L น้ำ = 450 pulse (calibrate ได้) เชื่อมต่อ ESP32 ผ่าน GPIO interrupt ใช้ในโปรเจกต์ smart irrigation, water meter และ leak detection

🛠️ DIY Tutorial

สร้าง Meshtastic LoRa Node ตั้งแต่ศูนย์ — Off-Grid สื่อสารระยะ 10+ km

Meshtastic เป็น open-source firmware ที่ทำให้ ESP32 + LoRa กลายเป็น mesh communication node ส่งข้อความ, GPS location และ telemetry ระหว่างทีมงานได้โดยไม่ต้องมี internet หรือสัญญาณมือถือ

เตรียม Hardware

ซื้อบอร์ด Heltec WiFi LoRa 32 V3 (ESP32-S3 + SX1262, ~900 บาท) หรือ TTGO LoRa32 V2.1 (~650 บาท) ทั้งคู่มี LoRa antenna built-in และ OLED display สำหรับแสดงข้อมูล

Flash Meshtastic Firmware ผ่าน Web Flasher

เปิด flasher.meshtastic.org ในเบราว์เซอร์ Chrome, เสียบบอร์ดด้วย USB, เลือก device type และ click Flash — ใช้เวลา 2 นาที ไม่ต้องติดตั้ง software อะไรเลย

ตั้งค่าผ่าน Meshtastic App

ดาวน์โหลด Meshtastic app (Android/iOS) เปิด Bluetooth เพื่อ pair กับบอร์ด ตั้งค่า Region (Thailand = LORA_REGION_SEA_923), ตั้งชื่อ node และ enable GPS ถ้ามี GPS module

เพิ่ม GPS Module (optional แต่แนะนำ)

ต่อ U-blox NEO-6M หรือ NEO-M8N เข้า UART2 ของ ESP32 (GPIO 34=RX, GPIO 12=TX) ตั้งค่า GPS_TX/RX pin ใน Meshtastic app — node จะส่ง GPS coordinate ให้ทีมเห็น realtime บน map

ทดสอบการส่งข้อความและ Range

นำ node สองตัว ออกไปทดสอบ กด Send message ใน app แล้วเดินออกไปเรื่อยๆ ดู SNR และ RSSI ที่ลดลงใน app สำหรับ Thailand Band 923 MHz — ในเมือง ≈ 2-4 km, พื้นที่โล่ง ≈ 10-20 km

ต่อยอด: MQTT Bridge สู่ Internet

ถ้ามี node หนึ่งตัวที่เชื่อมต่อ Wi-Fi ได้ ตั้งค่า MQTT uplink ใน Meshtastic app เพื่อ bridge ข้อมูล mesh ออก internet ทำให้คนที่ไม่มีบอร์ดก็ติดตาม node บน map.meshtastic.org ได้

# ติดตั้ง meshtastic Python CLI สำหรับ advanced config
pip install meshtastic

# อ่านค่า config ปัจจุบันจาก node
meshtastic --info

# ตั้ง region เป็น SEA (Southeast Asia 923 MHz)
meshtastic --set lora.region SEA_923

# ส่งข้อความทดสอบผ่าน CLI
meshtastic --sendtext "Hello from ESP32 Mesh!"

# ดู list ของ nodes ในเครือข่าย
meshtastic --nodes

Pro Tip: ใช้ Solar panel 5V 2W + LiPo 18650 สร้าง outdoor node ที่ทำงานได้ตลอด 24 ชั่วโมงโดยไม่ต้องชาร์จ เหมาะสำหรับ repeater node ติดบนหลังคาหรือยอดเขา
