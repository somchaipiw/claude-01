นวัตกรรม ESP32 ใหม่ล่าสุด

Edge AI, TinyML และ Matter/Thread ที่กำลังเปลี่ยนโลก IoT

🧠
ESP32-S3 + Edge Impulse — TinyML On-Device ไร้คลาวด์
Edge AI
ปี 2026 ESP32-S3 กลายเป็นขุมพลังหลักของ TinyML บน Microcontroller ด้วย SIMD vector instructions ทำให้รัน Neural Network ได้เร็วขึ้น 3–5 เท่าเทียบกับ ESP32 รุ่นเดิม โดยใช้ร่วมกับ Edge Impulse สำหรับ train และ deploy model ได้ในไม่กี่นาที
  • Latency: Image Classification ใต้ 20ms (vs 80ms บน S2)
  • Framework: TensorFlow Lite Micro, Edge Impulse, ESP-DL
  • Use Cases: Voice keyword, face detection, anomaly detection
  • ราคา: XIAO ESP32-S3 Sense (กล้อง + mic) ~$15
⚡
ESP32-P4 AI Accelerator — Inference เร็ว 4× สำหรับ Vision AI
ESP32-P4
ESP32-P4 (ออกปลาย 2024) มี Hardware AI Accelerator ในตัวที่เร่ง image processing และ neural inference ได้อย่างมีนัยสำคัญ — audio classifier และ sensor anomaly detector รันใต้ 20ms ทำให้เหมาะกับงาน real-time ที่ S3 ยังทำได้ช้า
  • AI Accel: Integrated vector accelerator สำหรับ CNN layers
  • Vision: เชื่อมกล้องความละเอียดสูงได้โดยตรง (MIPI CSI)
  • RAM: 32 MB PSRAM ในตัว รองรับ model ขนาดใหญ่
  • Display: ขับ 10.1" IPS Touch ผ่าน MIPI DSI
🏠
ESP32-C6 $5 — Matter + Thread Border Router ประตูบ้านอัจฉริยะ
Matter 1.3
ปี 2026 ESP32-C6 คือ chip ยอดนิยมที่สุดสำหรับ smart home ราคาประหยัด รวม WiFi 6 (802.11ax) + BLE 5 + IEEE 802.15.4 (Thread/Zigbee) ไว้ในชิปเดียว RISC-V 160 MHz และ IKEA ประกาศเลิกใช้ Zigbee หันมาใช้ Matter/Thread แล้ว
  • ราคา: XIAO ESP32-C6 ประมาณ $5 (Seeed Studio)
  • Protocol: WiFi 6, BLE 5, Thread, Zigbee, Matter 1.3
  • Lead time: 12–16 สัปดาห์ในปี 2026 (demand สูง)
  • ใช้กับ: Apple Home, Google Home, Amazon Alexa
📻
ESP-DL v3 + TFLite Micro — ระบบนิเวศ Edge AI ใหม่บน IDF 6
ESP-IDF 6
ESP-DL v3 ที่มาพร้อม ESP-IDF 6 นำเสนอ API ใหม่สำหรับ quantized model, layer fusion และ memory optimization ทำให้ model ที่เคยต้องการ PSRAM สามารถรันบน IRAM ได้ — เปิดประตูสู่ AI บน ESP32-C3/C6 ที่ไม่มี external RAM
  • Model Format: ONNX → ESP-DL conversion tool
  • INT8 Quantization: ลด model size 4× ไม่เสีย accuracy มาก
  • Supported: MobileNetV3, EfficientDet-Lite, Keyword Spotting
  • Memory: รัน 50KB model บน S3 IRAM โดยไม่ต้อง PSRAM

Edge AI Home Security — กล้องจำหน้าคน + แจ้งเตือน ไม่ต้องคลาวด์
TinyML · ESP32-S3
ระบบ security กล้อง DIY ที่รัน face detection และ person detection โดยตรงบน ESP32-S3 Sense ด้วย Edge Impulse — ไม่ส่งภาพไปคลาวด์เลย ข้อมูลอยู่ในบ้าน แจ้งเตือน LINE Notify หรือ Telegram เมื่อตรวจพบคนแปลกหน้า
  • Hardware: XIAO ESP32-S3 Sense + OV2640 Camera + LED Strip
  • Train model: อัปโหลดรูปใน Edge Impulse → export TFLite Micro
  • Inference: รัน model ใต้ 20ms → trigger GPIO → buzzer/relay
  • แจ้งเตือน: ส่ง thumbnail + timestamp ผ่าน WiFi → Telegram Bot
  • Storage: บันทึก log บน SD Card ในตัว (XIAO Sense มี built-in)

Wearable Health Monitor — SpO₂ + ECG + อุณหภูมิ Dashboard แบบ real-time
Health IoT
อุปกรณ์ติดตามสุขภาพ DIY ราคาต่ำกว่า 500 บาท วัด SpO₂, Heart Rate (BPM), ECG และอุณหภูมิกาย ส่งค่าแบบ real-time ผ่าน WiFi ไปยัง Web Dashboard — เหมาะสำหรับผู้สูงอายุ ผู้ป่วยโรคหัวใจ หรือนักกีฬา
  • Sensors: MAX30102 (SpO₂+HR) + AD8232 (ECG) + DS18B20 (Temp)
  • MCU: ESP32 WROOM-32D หรือ ESP32-S3 Mini
  • Dashboard: ESP32 รัน WebServer → แสดง chart แบบ live ผ่าน Browser
  • Alert: ถ้า SpO₂ < 94% หรือ HR > 120 bpm → แจ้งเตือนเสียง + LINE
  • Power: Li-Po 500mAh + TP4056 charger → ใช้งานได้ ~12 ชั่วโมง

mmWave Gesture Smart Home — ควบคุมไฟและแอร์ด้วยท่าทางมือ
mmWave Radar
ใช้ RD-03E 24GHz mmWave Radar ตรวจจับท่าทางมือได้ในระยะ 0.5–1 เมตร ทำงานในความมืดสนิท — ไม่ต้องสัมผัส ไม่ต้องพูด เพียงโบกมือก็สั่งเปิด/ปิดไฟและแอร์ผ่าน ESP32-C6 + Matter ได้เลย
  • Radar Sensor: RD-03E (UART) — Detection range ±30° H / ±40° V
  • MCU: ESP32-C6 พร้อม Matter/Thread สำหรับ smart home integration
  • Gesture: Swipe left = เปิดไฟ, Swipe right = ปิด, Tap = สลับโหมด
  • Integration: ส่ง MQTT → Home Assistant → ควบคุม relay/switch
  • ติดตั้ง: ฝังใน wall plate ดูดีไม่เห็นว่าเป็น radar

Voice Keyword Spotting — "เปิดไฟ" / "ปิดแอร์" บน ESP32 ไม่ต้องอินเทอร์เน็ต
TinyML · คำสั่งเสียง
สร้าง voice command ภาษาไทยบน ESP32-S3 ด้วย Edge Impulse Keyword Spotting — train ด้วยเสียงของตัวเองประมาณ 50 ตัวอย่าง แล้ว deploy ลง MCU ทำงาน offline 100% ใช้ mic MEMS ราคา 10 บาท ตรวจจับคำสั่งได้แม่นยำ >90%
  • Hardware: ESP32-S3 + INMP441 I2S MEMS Microphone (~10 บาท)
  • Train: Record คำสั่ง 50 ตัวอย่าง/คำ บน Edge Impulse web platform
  • Model size: Keyword model ~30KB INT8 → fit ใน SRAM ESP32-S3
  • Latency: ตรวจจับคำสั่งภายใน 100ms หลังพูดจบ
  • ควบคุม: GPIO → relay board → ไฟ, แอร์, ปลั๊ก, ประตู

Biometric, Radar, ECG — sensor รุ่นใหม่ที่ใช้กับ ESP32 ได้เลย

❤️
MAX30102 — Pulse Oximeter & Heart Rate Sensor
Biometric
Maxim Integrated MAX30102 เป็น sensor ชีวภาพที่วัด SpO₂ (ออกซิเจนในเลือด) และ Heart Rate (BPM) พร้อม temperature sensor ในตัว ใช้ LED สีแดง + Infrared สะท้อนแสงผ่านผิวหนัง เชื่อมต่อ ESP32 ผ่าน I2C ง่ายมาก
  • Interface: I2C (address 0x57)
  • SpO₂ Range: 70–100% ความแม่นยำ ±2%
  • Heart Rate: 0–3000 bpm (อ่านค่า per pulse wave)
  • Temperature: built-in temp sensor ±1°C
  • Library: SparkFun MAX3010x (Arduino)
  • ราคา: ~25–50 บาท (Shopee/Lazada)
📻
HiLink LD2410 — 24GHz mmWave Presence Sensor
mmWave Radar
LD2410 คือ mmWave radar sensor ยอดนิยมที่สุดสำหรับ ESP32/ESPHome ในปี 2026 ตรวจจับ "การมีอยู่" ของคนได้แม้กระทั่งขณะ นั่งนิ่ง ๆ หรือนอนหลับ (ตรวจจับการหายใจ) — PIR sensor ทั่วไปทำไม่ได้
  • Frequency: 24 GHz FMCW Radar
  • Range: สูงสุด 6 เมตร (LD2410B สูงสุด 8+ เมตร)
  • Interface: UART 256000 bps
  • Output: Motion zone distance + Stationary zone distance
  • ESPHome: รองรับ native ตั้งแต่ ESPHome 2023.x
  • ราคา: ~80–120 บาท
💓
AD8232 — Single-Lead Heart Monitor (ECG Sensor)
ECG · Biometric
AD8232 (Analog Devices) เป็น sensor สำหรับวัด ECG (Electrocardiogram) ด้วย electrode patch 3 จุด ผ่าน RL, LA, RA ทำให้วาดกราฟการเต้นของหัวใจในรูปแบบ PQRST waveform ได้จริง เหมาะสำหรับ DIY cardiac monitor
  • Output: Analog voltage (ADC ของ ESP32)
  • Bandwidth: 0.5 Hz – 40 Hz (cardiac frequency range)
  • Lead Off: มี LOD+ / LOD- pin แจ้งเมื่อ electrode หลุด
  • Power: 3.3V compatible กับ ESP32
  • Library: ใช้ analogRead() + serial plot ได้เลย
  • ราคา: ~60–90 บาท
👋
RD-03E — 24GHz mmWave Gesture Recognition Sensor
Gesture · mmWave
Ai-Thinker RD-03E ขยับขึ้นจาก RD-03D มา support Hand Gesture Recognition — detect การโบกมือและทิศทางในพื้นที่ ±30° × ±40° ระยะ 0.5–1 เมตร ทำงานในที่มืดสนิท ไม่กระทบแสง ใช้ UART ส่งผล gesture type ออกมา
  • Frequency: 24 GHz FMCW Radar
  • Gestures: Swipe Left, Swipe Right, Swipe Up, Swipe Down, Tap
  • Detection zone: ±30° H / ±40° V / 0.5–1.0 m
  • Human Presence: ตรวจจับคนได้ถึง 5 เมตร (secondary feature)
  • Interface: UART 115200 bps
  • ราคา: ~150–250 บาท

Tutorial ประจำวัน

ขั้นตอนต่อ MAX30102 กับ ESP32 วัด SpO₂ และ Heart Rate พร้อม Web Dashboard

💡 ESP32 + MAX30102: วัด SpO₂ & Heart Rate แสดงบน Web Dashboard

อุปกรณ์ที่ต้องการ
  • ESP32 DevKit (WROOM-32 หรือ S3 Mini)
  • MAX30102 Pulse Oximeter Module (~30 บาท)
  • สาย I2C 4 เส้น (3.3V, GND, SDA, SCL)
  • สาย USB + Browser ไม่ต้องอื่นอีก
การต่อสาย (Wiring) 
// MAX30102 → ESP32
VCC  → 3.3V
GND  → GND
SDA  → GPIO 21  // I2C SDA
SCL  → GPIO 22  // I2C SCL
INT  → ไม่ต่อ (optional)
ติดตั้ง Library (Arduino IDE) 
// Tools → Manage Libraries → ค้นหา:
"SparkFun MAX3010x Pulse and Proximity Sensor Library"
// ติดตั้ง version ล่าสุด
Code หลัก (ส่วนสำคัญ) 
#include <Wire.h>
#include <SparkFun_MAX3010x_Sensor.h>
#include <WiFi.h>
#include <WebServer.h>
#include <spo2_algorithm.h>

MAX30105 particleSensor;
WebServer server(80);

int32_t spo2, heartRate;
int8_t  validSPO2, validHR;
uint32_t irBuffer[100], redBuffer[100];

void setup() {
  particleSensor.begin(Wire, I2C_SPEED_FAST);
  particleSensor.setup(60, 4, 2, 100, 411, 4096);
  WiFi.begin("SSID", "PASSWORD");
  server.on("/data", handleData);
  server.begin();
}

void loop() {
  // เก็บ 100 samples ก่อนคำนวณ
  for (int i = 0; i < 100; i++) {
    while (!particleSensor.available())
      particleSensor.check();
    redBuffer[i] = particleSensor.getRed();
    irBuffer[i]  = particleSensor.getIR();
    particleSensor.nextSample();
  }
  maxim_heart_rate_and_oxygen_saturation(
    irBuffer, 100, redBuffer,
    &spo2, &validSPO2, &heartRate, &validHR
  );
  server.handleClient();
}
ผลที่ได้
  • เปิด browser ไปที่ IP ของ ESP32 เห็น SpO₂ และ Heart Rate แบบ real-time
  • เพิ่ม alert เมื่อ SpO₂ ต่ำกว่า 94% ด้วย LINE Notify API
  • ต่อยอดเพิ่ม AD8232 ECG → แสดง waveform บน Web Canvas Chart.js
  • เพิ่ม BME280 วัดอุณหภูมิห้องและบันทึกลง Google Sheets ผ่าน IFTTT
