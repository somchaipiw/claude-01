ESP32-S31 — RISC-V 320 MHz + Wi-Fi 6 + Display ในราคา $4
ชิปตัวใหม่ล่าสุดจาก Espressif ที่เพิ่งเปิดตัว devkit พร้อมหน้าจอ IPS 0.96 นิ้ว ในราคาเพียง $4 โดดเด่นด้วยสถาปัตยกรรม RISC-V ความเร็ว 320 MHz และรองรับ Wi-Fi 6 (802.11ax) รวมถึงมี gigabit Ethernet ผ่าน ESPHome 2026.7.0 ซึ่งรองรับชิปตัวนี้โดยตรง เหมาะสำหรับโปรเจกต์ที่ต้องการแสดงผลข้อมูล real-time พร้อมการเชื่อมต่อ Wi-Fi รวดเร็ว
RISC-V 320 MHz Wi-Fi 6 (802.11ax) IPS Display Gigabit Ethernet ~$4 USD
อัปเดต
ESP32-P4 Rev 3.x — I2S 160 MHz Clock + Dedicated RNG Module
Espressif ประกาศ chip revision 3.x ของ ESP32-P4 (พ.ค. 2026) โดยเพิ่ม clock source ขนาด 160 MHz สำหรับ I2S ซึ่งสำคัญมากสำหรับงาน audio processing ความละเอียดสูง นอกจากนี้ยังเพิ่ม dedicated RNG module ใหม่ รองรับ ECC P-384 และ AES ที่ป้องกัน Differential Power Analysis ได้ดีขึ้น ผู้พัฒนาควรอัปเกรด firmware ทันที — โปรดระวัง ROM-770 bug กับ Secure Download Mode บน board revision v3.1
I2S 160 MHz Clock Dedicated RNG ECC P-384 AES Anti-DPA 400 MHz Stable
ร้อนแรง
ESPHome 2026.7.0 — Native ESP-IDF Toolchain + NVS Encryption
ESPHome เวอร์ชันล่าสุดที่น่าสนใจ: ย้ายไปใช้ native ESP-IDF toolchain เป็น default แทน PlatformIO (build เร็วขึ้นมาก) และเพิ่มฟีเจอร์ความปลอดภัยสำคัญคือ NVS Encryption (เข้ารหัสข้อมูลบน Flash) และ OTA Downgrade Protection ป้องกันการลด firmware เวอร์ชัน นอกจากนี้ยังรองรับ ESP32-S31 ใหม่ รวมถึง Gigabit Ethernet สำหรับ wired smart home devices
Native ESP-IDF Default NVS Encryption OTA Downgrade Protection ESP32-S31 Support
Open Source
ESPHome Native Zigbee End-Device — ไม่ต้องมี Hub แยก
ESPHome 2026.5.x เพิ่ม native Zigbee End-Device support สำหรับ ESP32-C6 และ ESP32-H2 โดยตรง ทำให้สามารถเขียน YAML ง่ายๆ เพื่อสร้าง Zigbee sensor หรือ actuator ได้โดยไม่ต้องใช้ code เพิ่มเติม ประกอบกับการมี ESP32-P4 + ESP32-H2 ทำงานเป็น Zigbee/Thread Gateway บอร์ดเดียว ทำให้การสร้าง smart home ecosystem แบบ local ทำได้ง่ายมากขึ้น
ESP32-C6 + ESP32-H2 YAML Config Zigbee End-Device Local Processing

Home Automation
Apple HomeKit Controller ด้วย ESP32 (ไม่มี Hub)
สร้าง ESP32 device ที่เชื่อมต่อกับ Apple Home โดยตรงผ่าน HomeKit Accessory Protocol (HAP) ไม่ต้องใช้ Hub หรือ Cloud ตัวกลาง เหมาะสำหรับสร้าง smart switch, sensor, หรือ accessory ที่ควบคุมด้วย Siri/iPhone ได้ทันที
  1. ใช้ library arduino-homekit-esp32 หรือ esp-idf-homekit
  2. กำหนด accessory type (switch, sensor, light ฯลฯ)
  3. เชื่อมต่อ Apple Home แบบ manual pairing code
  4. Deploy OTA update ผ่าน Wi-Fi
ESP32-C6 แนะนำ Wi-Fi 6 Local Only
Edge AI
Object Detection Camera ตอบสนอง < 200ms บน ESP32-S3
ESP32-S3 + กล้อง OV2640 ประมวลผล CNN สำหรับตรวจจับวัตถุบน device โดยตรงโดยไม่ต้องส่งภาพไป Cloud ใช้ Edge Impulse หรือ TensorFlow Lite Micro แปลง model เล็กๆ ให้ทำงานได้ใน latency ต่ำกว่า 200ms เหมาะสำหรับ: ระบบนับคน, ตรวจจับสัตว์, หรือ quality control ในโรงงาน
  1. Train model ด้วย Edge Impulse (FOMO หรือ MobileNet)
  2. Export เป็น Arduino Library
  3. รวมกับ ESP32-S3 Camera Kit
  4. ส่ง result ผ่าน MQTT หรือ WebSocket
TFLite Micro Edge Impulse <200ms Latency
Industrial
Predictive Maintenance สำหรับมอเตอร์/คอมเพรสเซอร์
ใช้ ESP32 + Vibration sensor + Current sensor + Temperature sensor วิเคราะห์สัญญาณ FFT เพื่อทำนายความผิดปกติของมอเตอร์ก่อนที่มันจะพังจริง ระบบนี้มีงานวิจัยรองรับแล้วและมีราคาถูกกว่า Commercial PdM solution มาก
  1. ติด vibration + current + temperature sensors
  2. ทำ FFT analysis ด้วย arduinoFFT library
  3. ส่งข้อมูลขึ้น Firebase / ThingSpeak
  4. ตั้ง alert เมื่อ frequency signature ผิดปกติ
FFT Analysis Firebase SVM / LSTM Model
Offline AI
Offline Voice Control ด้วย ESP32 — ไม่ต้องอินเทอร์เน็ต
สร้าง voice command system ที่ทำงาน 100% บน device โดยใช้ ESP32-S3 + microphone INMP441 + wake word detection engine เช่น ESP-SR หรือ WakeNet จาก Espressif รู้จำคำสั่งไทย/อังกฤษ เปิด/ปิดไฟ, ควบคุมอุปกรณ์ได้แบบ local ไม่ต้องพึ่ง Cloud เหมาะสำหรับพื้นที่ที่ไม่มีอินเทอร์เน็ต
  1. ใช้ ESP32-S3 + INMP441 I2S Microphone
  2. ติดตั้ง ESP-SR / WakeNet library
  3. กำหนด custom wake word และ commands
  4. เชื่อม GPIO หรือ MQTT สำหรับ actuators
ESP-SR WakeNet INMP441 100% Local
Network Tool
Wi-Fi Dead Zone Finder ด้วย ESP32 + OLED Display
พกพาอุปกรณ์เล็กๆ เดินสำรวจสัญญาณ Wi-Fi ในบ้านหรืออาคาร แสดง RSSI แบบ real-time บนหน้าจอ OLED บันทึก heatmap ลง SD card และระบุ dead zone ได้ทันที ต้นทุนต่ำกว่า commercial Wi-Fi analyzer มาก โปรเจกต์นี้ยังสามารถต่อยอดเป็น site survey tool สำหรับมืออาชีพได้
  1. ESP32 + SSD1306 OLED + micro SD card
  2. สแกน SSID พร้อม RSSI ด้วย WiFi.scanNetworks()
  3. บันทึก GPS coordinate (ถ้ามี) + RSSI ลง CSV
  4. Plot heatmap บน PC ด้วย Python
SSD1306 SD Card CSV Export Python Heatmap
Health IoT
Air Quality Monitor แบบ Advanced ด้วย BME680 + MQ135
สร้างระบบตรวจสอบคุณภาพอากาศในบ้าน/ออฟฟิศ รวม CO₂, VOCs, ความชื้น, อุณหภูมิ, ฝุ่น และ gas หลายชนิดพร้อมกัน ส่งข้อมูลขึ้น Dashboard แบบ real-time มีประโยชน์มากในช่วงที่คุณภาพอากาศเป็นปัญหาสาธารณสุข
  1. BME680 (VOC + temp + humidity) + MQ135 (CO/CO₂)
  2. เพิ่ม PM2.5 sensor (SDS011 หรือ PMS5003)
  3. ส่งข้อมูลผ่าน MQTT ไปยัง Grafana/Home Assistant
  4. ตั้ง alert เมื่อค่าเกินมาตรฐาน WHO
BME680 MQ135 MQTT + Grafana
