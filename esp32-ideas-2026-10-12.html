ESP32-E22 — ชิปใหม่ Wi-Fi 6E ตัวแรกจาก Espressif (CES 2026)

Espressif เปิดตัว ESP32-E22 ที่งาน CES 2026 ในฐานะ Wi-Fi 6E Connectivity Co-Processor ตัวแรก รองรับสามย่านความถี่ 2.4 / 5 / 6 GHz พร้อม Bluetooth 5.4/6.0 ผ่าน PCIe 2.0 หรือ SDIO และเพิ่งผ่านการรับรอง Wi-Fi CERTIFIED 6E (มิถุนายน 2026) พร้อม Linux Driver แบบ Open-Source

  • Dual-core RISC-V สูงสุด 500 MHz
  • ทดสอบ iperf ได้ถึง 2.1 Gbps
  • RAM 1 MB ในตัว + 41 GPIO
  • รองรับ PCIe 2.0 และ SDIO interface
  • Linux drivers ปล่อย GitHub แล้ว (มิ.ย. 2026)
  • Engineering samples พร้อมจัดส่ง

ESP32-P4 + ESP32-C5 — บอร์ดแรกรองรับ Raspberry Pi MIPI

บอร์ดใหม่ที่วางขายตั้งแต่พฤษภาคม 2026 รวม ESP32-P4 (มีพลัง multimedia) กับ ESP32-C5 (Wi-Fi 6 dual-band) ไว้ด้วยกัน รองรับขั้วต่อ MIPI CSI/DSI แบบ Raspberry Pi ใช้กล้องและหน้าจอของ RPi ได้เลย ทำให้ต้นทุน HMI ลดลงมาก

ESP32-P4 ESP32-C5 MIPI CSI/DSI Wi-Fi 6

ESP-IDF v6.x + BMI270 IMU Component รองรับแล้ว

Espressif ออก component bmi270_sensor เวอร์ชัน 0.1.2 (กรกฎาคม 2026) รองรับ ESP-IDF v6.0 ถึง v6.2 และ ESP32-S3 รุ่นใหม่ พร้อมเปลี่ยนไปใช้ New I2C Driver API ซึ่งเป็น breaking change จาก legacy — ต้องอัปเกรดโปรเจกต์เก่าด้วย

BMI270 ESP-IDF v6 IMU 6-axis New I2C API

Matter Camera บน ESP32-P4 — รองรับ Matter 1.5 (มกราคม 2026)

Espressif เผยแพร่ตัวอย่าง Matter Camera ที่รันบน ESP32-P4 พร้อมรองรับ Matter 1.5 สามารถสตรีมวิดีโอไปยัง Matter Controller และ Smart Home Hub ต่าง ๆ ได้โดยตรง นับเป็นก้าวแรกของกล้องรักษาความปลอดภัยแบบ Open Standard

ESP32-P4 Matter 1.5 Camera Smart Home

DHT22 Clone Library — RMT Peripheral แก้ปัญหาเซ็นเซอร์ปลอม

Library ใหม่ (กุมภาพันธ์ 2026) จัดการ DHT22 ปลอมที่รายงานอุณหภูมิลบผิดปกติ ใช้ RMT peripheral ของ ESP32 อ่านค่าแบบ hardware-based ทนต่อ interrupt จาก Wi-Fi/BLE รองรับ ESP32, S2, S3 และ C3

DHT22 RMT Peripheral Temperature Interrupt-safe

ไอเดียโปรเจกต์ที่น่าสร้าง

Light Pollution Meter — วัดมลพิษแสงด้วย ESP32 + MQTT

วัดค่าความสว่างท้องฟ้า (Sky Brightness) ด้วยเซ็นเซอร์แสง พร้อมวัดอุณหภูมิ-ความชื้น ส่งข้อมูลผ่าน MQTT ไปเก็บ database ระยะไกล เหมาะสำหรับโปรเจกต์วิจัยคืนดาวหรือ พื้นที่อนุรักษ์ธรรมชาติ ข้อมูล long-term วิเคราะห์แนวโน้มมลพิษแสงได้

TSL2591 BME280 MQTT Data Logger

3D Printer Enclosure Monitor — ตรวจ VOC + ฝุ่นอัตโนมัติ

ติดตั้ง ESP32 ในตู้ครอบเครื่องพิมพ์ 3 มิติ วัดระดับ VOC (ก๊าซพิษจาก filament) และ ฝุ่น PM2.5 เมื่อเกินค่าขีดจำกัดจะสั่งเปิดพัดลมระบายอากาศพร้อมฟิลเตอร์อัตโนมัติ แสดงผลแบบ real-time บน dashboard และแจ้งเตือนผ่าน Home Assistant

SGP30 VOC PMS5003 Home Assistant Automation

Dual-Axis Solar Tracker — MicroPython + 4 LDR Sensors

ใช้เซ็นเซอร์แสง 4 ตัวในตำแหน่ง N/S/E/W เปรียบเทียบค่าเพื่อหาทิศที่สว่างที่สุด ควบคุม servo 2 แกนด้วย MicroPython มี Sensitivity Threshold ปรับได้เพื่อป้องกัน การขยับโดยไม่จำเป็น ช่วยเพิ่มประสิทธิภาพแผงโซลาร์ได้ถึง 30%

MicroPython LDR x4 Servo Motor Solar Energy

Smart Mailbox Notifier — ESP-NOW + Solar Repeater Node

วาง ESP32 ในกล่องไปรษณีย์ที่อยู่ไกลจากบ้าน ส่งสัญญาณผ่าน ESP-NOW โดยมี โหนด solar-powered repeater ช่วยขยายระยะ เหมาะสำหรับบ้านในชนบทที่ Wi-Fi ไม่ถึง แจ้งเตือนทันทีเมื่อมีจดหมายหรือพัสดุมาส่ง

ESP-NOW Solar Powered Deep Sleep Reed Switch

AI HVAC Fault Diagnosis — ESP32-C6 + เสียง + Thermal Imaging

วิเคราะห์เสียงผิดปกติจากเครื่องปรับอากาศด้วย microphone + ESP32-C6 และผนวกกับ ภาพ thermal camera (MLX90640) ตรวจหาความร้อนผิดปกติ รันโมเดล TinyML จำแนก ความผิดปกติได้ก่อนพัง ลดค่าซ่อมบำรุงในโรงงานและอาคาร

ESP32-C6 TinyML MLX90640 Predictive Maintenance

Sensors น่าสนใจสำหรับโปรเจกต์ใหม่

TSL2591 — High Dynamic Range Light Sensor

เซ็นเซอร์วัดความสว่างช่วงกว้างมาก (600,000,000:1 dynamic range) แยก Full Spectrum และ Infrared ออกจากกัน เหมาะสำหรับ light pollution meter และระบบ auto-brightness ใช้งานผ่าน I2C ง่าย มี library Arduino พร้อม

I2C Lux Sensor Low Power Adafruit

SGP30 — VOC & eCO₂ Gas Sensor

เซ็นเซอร์ตรวจวัด Volatile Organic Compounds (VOC) และ equivalent CO₂ ในอากาศ เหมาะสำหรับ indoor air quality monitor และตรวจสารพิษในตู้ 3D Printer มี baseline compensation algorithm ในตัว ทำงานผ่าน I2C

VOC eCO₂ I2C Air Quality

BMI270 — 6-Axis IMU สำหรับ Wearable

IMU 6 แกน (Accelerometer + Gyroscope) ประหยัดพลังงานสูง จาก Bosch ออกแบบมาสำหรับ wearable device มี built-in gesture recognition และ step counter Espressif ออก ESP-IDF component รองรับแล้วตั้งแต่ IDF v6.0 (กรกฎาคม 2026)

Accel + Gyro ESP-IDF v6 Wearable SPI/I2C

PMS5003 — Laser Particle Sensor PM1/PM2.5/PM10

เซ็นเซอร์ฝุ่นแบบ laser scattering วัด PM1.0, PM2.5 และ PM10 แบบ real-time ใช้งานผ่าน UART, มี library สำหรับ ESP32 โดยตรง เหมาะกับ indoor air quality monitor, 3D printer enclosure และสถานีตรวจวัดอากาศกลางแจ้ง

PM2.5 UART Laser Air Quality

MLX90640 — Thermal Camera Array 32×24

กล้อง thermal แบบ array 32×24 pixel ผ่าน I2C อัปเดต frame rate สูงสุด 64 Hz เหมาะสำหรับ HVAC monitoring, การตรวจจับการเคลื่อนไหว และ predictive maintenance บน ESP32-S3 หรือ ESP32-P4 ประมวลผล heatmap ได้แบบ real-time

Thermal I2C 32×24px Melexis
