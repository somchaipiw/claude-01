ESP32-P4 · v3.x

ESP32-P4 Revision 3.0 — 400 MHz พร้อม ISP ขั้นสูง

Espressif ปล่อย ESP32-P4 v3.x (พ.ค. 2569) อัปเกรด Dual-core RISC-V เป็น 400 MHz (จาก 360 MHz) และเพิ่มฟีเจอร์ ISP ใหม่ได้แก่ Black Level Correction และ Dead Pixel Correction พร้อมแก้ไขบั๊ก MSPI wake-up และ Secure Boot แนะนำสำหรับดีไซน์ใหม่ทั้งหมด

  • Pin 54 เปลี่ยนจาก NC เป็น Power Rail — PCB เก่าต้องอัปเดต
  • revision 1.0, 1.1, 1.3 ไม่แนะนำสำหรับดีไซน์ใหม่
ESP32-P4 · Open Source

ESP-KVM — IP KVM แบบ Open Source บน ESP32-P4

โปรเจกต์ ESP-KVM ใช้ ESP32-P4 จัดการ HDMI capture และควบคุมผ่าน browser ทำให้ได้ IP KVM ราคาประหยัดที่สุดในตลาด บน v3.x frame rate คาดว่าดีขึ้นจาก v1.3 อย่างมีนัยสำคัญ

  • รองรับ HDMI Capture → stream ผ่าน Web Browser
  • ควบคุม keyboard/mouse ผ่าน USB HID
  • Source: CNX Software, ก.ค. 2569
ESP32-C5 · Wi-Fi 6

ESP32-C5 — Dual-Band Wi-Fi 6 (2.4 + 5 GHz) พร้อม BLE

ESP32-C5 เป็น RISC-V ชิปตัวแรกของ Espressif ที่รองรับ Wi-Fi 6 แบบ Dual-Band (2.4 GHz + 5 GHz) พร้อม Bluetooth LE 5, Zigbee 3.0 และ Thread 1.4 — ทำงานที่ 240 MHz, SRAM 384 KB ขณะนี้เข้า Mass Production แล้ว

  • OFDMA (UL/DL), MU-MIMO, Target Wake Time (TWT)
  • เหมาะกับสภาพแวดล้อม Wi-Fi 6 ที่ congested มาก
  • รองรับ 5 GHz ช่วยหลีกเลี่ยง interference กับ IoT sensor อื่น
TinyML · ESP32-S3

TensorFlow Lite Micro บน ESP32-S3 — Edge AI ในมือถือ

ปี 2569 มีทั้ง tutorial ใหม่และหนังสือ Embedded Intelligence: Implementing On-Device TinyML on the ESP32 (ม.ค. 2569) ที่ครอบคลุมการ deploy AI model โดยตรงบนชิป ESP32-S3 ที่มี PSRAM 8 MB

  • Keyword Spotting ใช้เวลาประมวลผล 30–100 ms ต่อ 1 วินาที audio
  • Image Classification บน camera module ได้เลยไม่ต้องส่ง Cloud
  • รองรับโมเดล quantized INT8 เพื่อลด RAM ใช้
Industrial IoT

ESP32 Modbus Gateway — RTU/TCP/MQTT ในตัวเดียว

บอร์ด ESP32 รุ่นใหม่จากชุมชนรองรับ Modbus RTU & TCP ทั้ง Master/Slave พร้อม MQTT, FOTA ผ่าน FTP และ watchdog ในตัวเดียว เหมาะงาน Smart Factory และการอ่านข้อมูลจากอุปกรณ์ legacy

  • RS-485 ผ่าน SP485EE Transceiver
  • สลับ Wi-Fi/Ethernet อัตโนมัติเมื่อ connection ตก
  • FOTA update ผ่าน FTP โดยไม่ต้องเชื่อมสาย

Sensors น่าสนใจสำหรับโปรเจกต์ใหม่

เน้น wearable, industrial และ imaging
❤️

MAX30101 — PPG Optical Sensor รุ่นอัปเกรด

รุ่นต่อจาก MAX30102 มี 3 LED (Red, IR, Green) ช่วยวัด SpO₂ และ Heart Rate แม่นยำกว่า รองรับ I2C ใช้ไฟเพียง 1.1 V

I2C 1.1–5 V SpO₂ + HR Green LED
🌡️

TMP117 — เซ็นเซอร์อุณหภูมิความแม่นยำสูง

ความแม่นยำ ±0.1°C ที่ 37°C (เหมาะ body temperature) ไม่ต้องทำ calibration I2C ใช้พลังงานต่ำมาก รองรับ alert เมื่อเกิน threshold ที่กำหนด

±0.1°C I2C 1.8–5.5 V Alert Pin
🏃

MPU-6050 — IMU 6-axis (Accel + Gyro)

IMU ยอดนิยมสำหรับ wearable และหุ่นยนต์ วัด acceleration 3 แกน + angular rate 3 แกน มี DMP ประมวลผล motion ในตัว ลด load CPU ESP32

I2C / SPI 3.3 V 6-DOF DMP
📷

MIPI CSI Camera Module — สำหรับ ESP32-P4

กล้อง 2 MP MIPI CSI เชื่อมต่อโดยตรงกับ ESP32-P4 รองรับ ISP ในตัวชิป (AWB, AE, Dead Pixel, Black Level) เหมาะ Video Doorbell, Computer Vision ระดับ Edge

MIPI CSI-2 2 MP ISP ในชิป ESP32-P4
🏭

SP485EE — RS-485 Transceiver ทนทาน

Transceiver สำหรับ Modbus/RS-485 มี ESD protection ±15 kV รองรับ half-duplex ทนสัญญาณรบกวนในโรงงาน เชื่อมต่อกับ UART ของ ESP32 ได้โดยตรง

RS-485 ESD ±15 kV 3.3 V Modbus
