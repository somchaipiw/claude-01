Matter 1.5 — Camera + Energy Management บน ESP32

Matter 1.5 (ประกาศ พ.ย. 2025) ขยาย device types เป็น 80+ ประเภท รองรับ Camera Streaming ผ่าน RTSP, Soil Sensor, Closure Device และ Advanced Energy Management ใหม่ ESP32-C6 และ ESP32-H2 ผ่าน Thread 1.3 สามารถ integrate ได้โดยตรงไม่ต้องพึ่ง bridge — เปิดประตูสู่ smart home ที่ interoperable กับ Apple HomeKit, Google Home, Amazon Alexa ได้พร้อมกัน

💡 ESP32-CAM + Matter 1.5 = กล้องวงจรปิด DIY ที่ทำงานกับทุก platform โดยไม่ต้องพึ่ง cloud vendor
Matter 1.5 ESP32-C6 Smart Home Thread 1.3
📡

ESP32-C5 Dual-Band Wi-Fi 6 — พร้อม Mass Production แล้ว!

ESP32-C5 เป็น RISC-V MCU ตัวแรกของ Espressif ที่รองรับ Wi-Fi 6 ทั้ง 2.4 GHz และ 5 GHz พร้อม BLE 5 + IEEE 802.15.4 (Zigbee/Thread) รองรับ TWT, MU-MIMO, OFDMA ทำงานได้ใน network ที่ congested มาก ความเร็ว CPU 240 MHz, SRAM 384 KB, ชิปเข้าสู่ Mass Production แล้ว ในปี 2025 เหมาะสำหรับ IoT device ที่ต้องการ bandwidth สูงและ latency ต่ำ

📶 5 GHz band แออัดน้อยกว่า 2.4 GHz มาก — ESP32-C5 เหมาะสำหรับ factory floor หรือ office IoT ที่มี WiFi รบกวนเยอะ
ESP32-C5 Wi-Fi 6 5 GHz RISC-V
🕸️

mesh_now — ESP-NOW Mesh Network ไม่ต้องพึ่ง Router

Library mesh_now บน Espressif Component Registry ทำให้ ESP32 หลายตัวสร้าง Mesh Network กันเองผ่าน ESP-NOW โดยไม่ต้องมี router หรือ gateway: Auto-discovery ผ่าน periodic beacon, multi-hop routing พร้อม TTL configurable, message types 7 แบบ, ACK retransmit, AES-128-GCM encryption และ FreeRTOS integration — รองรับ ESP32, S2, S3, C3, C6

🔒 Encrypted peer-to-peer mesh โดยไม่ต้องพึ่ง cloud หรือ Wi-Fi router — เหมาะมากสำหรับ remote farm หรือ disaster response sensor network
ESP-NOW Mesh Network AES-128-GCM Serverless

Hackaday ประกาศผลรางวัล 2026 Green Powered Challenge โปรเจกต์ที่ชนะได้แก่: LightInk Solar Watch — นาฬิกา e-ink พลังงานแสงอาทิตย์บนข้อมือ ลด power 50% ด้วย RTC wakeup stub และ Heliotrax — Solar Supercapacitor Charger ที่เก็บพลังงานใน supercap ผ่าน high-efficiency boost converter ทำงานได้หลายวันในสภาวะมืดครึ้ม ใช้ชิป BQ25504 สำหรับ ultra-low-power energy harvesting

EdgeCare Wearable — XIAO ESP32-C6 Bio-Datalogger อัจฉริยะ

Industrial Predictive Maintenance — ESP32 วินิจฉัยมอเตอร์ก่อนพัง

ใช้ ESP32 + MPU-6050 (vibration, 24 kHz sampling) + ACS712 (current sensing) + DS18B20 (temperature) ติดที่มอเตอร์โรงงาน ตรวจจับความผิดปกติ: vibration pattern, current spike, thermal runaway ส่งข้อมูลผ่าน MQTT → InfluxDB → Grafana dashboard ML threshold alert ส่ง LINE Notify ล่วงหน้าก่อน fault เกิดขึ้น 1–2 วัน

MPU-6050 ACS712 MQTT Grafana

Clean Water AI — ตรวจคุณภาพน้ำด้วย ML บน ESP32

ออกแบบระบบ IOT ตรวจน้ำดื่มหรือน้ำประปาแบบ real-time ด้วย Atlas Scientific (pH + ORP + DO) + turbidity + TDS sensor รัน edge ML บน ESP32-S3 เพื่อตรวจ algae bloom warning และ contamination detection ข้อมูลส่ง dashboard ผ่าน BLE → phone หรือ Wi-Fi → cloud ได้ รองรับ multi-point monitoring สำหรับระบบน้ำชุมชน

Water Quality Atlas Scientific Edge ML ESP32-S3

Matter 1.5 Soil Sensor Node — ฟาร์มอัจฉริยะ Thread Native

Matter 1.5 เพิ่ม Soil Sensor device type อย่างเป็นทางการ ใช้ ESP32-C6 เป็น Thread End Device + Capacitive Soil Moisture + SHT41 (temp/humidity) เชื่อม Thread Border Router เข้า Apple HomeKit / Google Home ได้โดยตรง ไม่มี proprietary cloud — เกษตรกรรมแม่นยำ ดูข้อมูลผ่านแอปบ้านได้เลย พลังงานจาก solar cell + Li-Po เปลี่ยนแบตปีละครั้ง

Smart Water Tank Monitor — ESP32 + ESP-NOW Mesh ไม่มี Router

ติดตาม water level หลายถัง ไม่ต้องลาก cable Wi-Fi ถึงทุกถัง ใช้ ESP-NOW Mesh (mesh_now) ส่งข้อมูลหลาย hop Node: ESP32-C3 + HC-SR04 (ultrasonic level) + ลงทุนหลักร้อย Gateway: ESP32-S3 รับข้อมูลทุก node → MQTT → Home Assistant trigger pump อัตโนมัติ + แจ้งเตือน LINE เมื่อน้ำต่ำ/เต็ม ใช้แบต 18650 2 ก้อน อยู่ได้ 3+ เดือน per node

ESP-NOW Mesh HC-SR04 ESP32-C3 Home Assistant

Sensors น่าสนใจสำหรับโปรเจกต์ใหม่Featured Sensors & ICs

MAX30102
Biometric — PPG / Pulse Oximeter

Optical sensor วัด Heart Rate + SpO2 (ออกซิเจนในเลือด) ในชิปเดียว ใช้ LED สีแดง + อินฟราเรด ราคาถูก (~50-80 บาท) Interface I2C, ใช้ไฟ 1.8V–3.3V เหมาะสำหรับ wearable ใช้ library Sparkfun MAX3010x หรือ PulseSensor Playground กับ ESP32 ได้ทันที

I2C 1.8–3.3V SpO2 + HR ~80฿
ACS712
Industrial — Current Sensing

Hall-effect current sensor วัดกระแส AC/DC แบบ non-invasive รุ่น 5A, 20A, 30A ราคาถูกมาก (~30-50 บาท) ต่อ analog กับ ADC ของ ESP32 ตรงได้เลย เหมาะสำหรับ predictive maintenance motor, smart plug วัดการใช้ไฟ, solar charge controller monitoring

Analog Out 5/20/30A AC/DC ~50฿
TMP117
Health — High-Accuracy Temperature

อุณหภูมิ digital ความแม่นยำสูง ±0.1°C ตั้งแต่ -20 ถึง +50°C ต่ำกว่า LM35 มาก, ใช้ไฟน้อยเพียง 3.5 µA (shutdown) Interface I2C, เหมาะสำหรับ medical wearable, incubator, precision lab ต่างจาก DS18B20 ตรงที่ calibration ดีกว่าและ power ต่ำกว่ามาก

I2C ±0.1°C 3.5µA Medical Grade
Atlas Scientific pH/ORP/DO
Water Quality — Professional Grade

Circuit modules สำหรับวัดคุณภาพน้ำระดับ pro ใช้ในงานวิจัยและอุตสาหกรรม รองรับ I2C/UART, ราคาสูงกว่า sensor ทั่วไปแต่ accuracy ดีกว่ามาก pH (±0.001), ORP (±1mV), DO (±0.05mg/L) มี Arduino/ESP32 library อย่างเป็นทางการจาก Atlas Scientific

I2C / UART pH ±0.001 ORP ±1mV Professional
BQ25504 IC
Power — Ultra-Low Power Energy Harvesting

Texas Instruments boost converter + battery charger สำหรับ energy harvesting รับพลังงานจาก solar, RF, piezo, thermal ที่แรงดันต่ำเพียง 0.1V input กำลังควบคุมไฟฟ้าไม่ต้องมีแหล่งจ่ายภายนอก — เหมาะ deploy ในพื้นที่ห่างไกล ใช้คู่กับ supercapacitor หรือ Li-Po ขนาดเล็กเพื่อ buffer พลังงาน

0.1V Input Min Solar/RF/Thermal MPPT Ultra-Low Power
