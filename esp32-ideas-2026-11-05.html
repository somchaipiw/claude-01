LLM 28.9M Parameter บน ESP32-S3 — ที่สุดแห่งปี 2026
esp32-ai · MIT License · ~9.5 tokens/sec

โปรเจกต์ esp32-ai (MIT License) สามารถรัน Language Model ขนาด 28.9 ล้าน parameter บน ESP32-S3 ได้จริง ด้วยความเร็วประมาณ 9.5 tokens/วินาที ถือเป็น proof-of-concept ที่พิสูจน์ว่าขีดจำกัดของ microcontroller กำลังถูกทลายลง

🔧 เทคนิคที่ใช้
INT4 quantization + PSRAM ขนาดใหญ่ (8–16MB) + vector instructions ของ ESP32-S3 ช่วยเพิ่มประสิทธิภาพ inference อย่างมีนัยสำคัญ
⚠️ ข้อจำกัด
ยังเป็น proof-of-concept ไม่ใช่ chatbot ใช้งานจริง แต่เป็นก้าวสำคัญในการนำ AI มาใกล้ edge มากขึ้น
📐 Hardware ที่เหมาะสม
ESP32-S3 + PSRAM 8MB ขึ้นไป เช่น Waveshare ESP32-S3-Touch-LCD-4.3B หรือ LILYGO T-HMI
🚀 ทิศทางต่อไป
INT4 quantization ใน TFLite Micro ยังมี operator coverage ไม่ครบ แต่กำลังพัฒนาอย่างต่อเนื่องใน 2026
LLM on MCU INT4 Quantization ESP32-S3 PSRAM

TensorFlow Lite Micro + ESP32-S3
Framework มาตรฐานสำหรับ On-device AI

TFLite Micro ยังคงเป็นมาตรฐานหลักสำหรับ Edge AI บน ESP32 ในปี 2026 โดย INT8 quantization เป็น practical standard ที่ใช้กันจริงในโปรเจกต์ต่างๆ

  • INT8: operator coverage ครบ ใช้งานได้จริงทุก use case
  • INT4: ยัง partial coverage แต่กำลังพัฒนาเพิ่ม
  • ESP32-S3 มี vector instructions เร่ง inference ได้ชัดเจน
  • ESP32-S3-BOX-3 เป็น dev board ที่นิยมใช้กับ TFLite Micro

ระบบ Security บ้าน ด้วย TinyML
Offline · ไม่พึ่ง Cloud · Real-time

ผสาน ESP32-S3 + TFLite Micro + PIR + กล้อง OV2640 สร้างระบบตรวจจับความผิดปกติแบบ on-device ไม่ต้องส่งข้อมูลไป cloud ทำให้ privacy ดีขึ้นมาก

  • Anomaly detection model บน accelerometer ตรวจจับสั่น/เคาะประตู
  • Keyword spotting ตรวจจับเสียงผิดปกติ เช่น กระจกแตก
  • Flash encryption + Secure Boot ป้องกัน firmware tampering
  • แจ้งเตือนผ่าน MQTT เมื่อตรวจพบเหตุผิดปกติ

ESP32-C6 + ESP32-H2 = Thread Border Router
Espressif dual-chip solution

ผสาน ESP32-C6 (Wi-Fi 6 + Thread) กับ ESP32-H2 (Thread/Zigbee) เพื่อสร้าง Thread Border Router ส่วนตัวราคาไม่แพง

// ESP32-C6 เป็น Thread BR, H2 เป็น end device
// ESP32-C6: Wi-Fi Interface (uplink)
//         + Thread Interface (downlink)
// ESP32-H2: Thread/Zigbee Sensor Node
//         ↓ ส่งค่า sensor ผ่าน Thread
//         ↓ → Border Router → Home Assistant
ot_esp_br_start(); // เริ่ม OpenThread BR

  • Controller: ESP32 ประมวลผล logic ในตัว
  • Actuator: Relay → Solenoid valve เปิด/ปิดน้ำ
  • Monitor ผ่าน Web Dashboard หรือ App มือถือ
  • ประหยัดน้ำได้ 30–50% เทียบกับ manual schedule

01
ICM-42688-P — 6-Axis IMU ความแม่นยำสูง
IMU รุ่นใหม่จาก InvenSense/TDK มี noise ต่ำกว่า MPU6050 มาก เหมาะสำหรับ vibration analysis และ TinyML gesture recognition มี SPI/I2C และ interrupt เร็ว ทำงานร่วมกับ ESP32 ได้ดีเยี่ยม — ใช้ใน predictive maintenance และ wearable
SPI/I2C ±32g accel Low noise 3.3V
02
SCD41 — CO₂ Sensor รุ่นใหม่ Photoacoustic
Sensirion SCD41 ใช้เทคโนโลยี photoacoustic sensing ทำให้กินไฟน้อยกว่า SCD30 มาก (พักไว้ที่ 0.4mA) มาพร้อม built-in humidity/temperature compensation แม่นยำสูง ± 40 ppm เหมาะสำหรับ indoor air quality และ greenhouse control
I2C 400–5000 ppm 0.4mA sleep Photoacoustic
03
TFLUNA-I — ToF LiDAR ระยะไกล I2C
TF-Luna LiDAR จาก Benewake วัดระยะ 0.2–8 เมตร ด้วย I2C/UART ราคาถูก (~$8) เหมาะสำหรับ obstacle detection, level sensing ในถัง, หรือ robot navigation — compact กว่า HC-SR04 และแม่นกว่ามาก ไม่ได้รับผลกระทบจากสิ่งกีดขวาง
LiDAR ToF I2C/UART 0.2–8m ~$8
04
SEN0322 — Electrochemical O₂ Sensor (DFRobot)
วัดปริมาณออกซิเจนในอากาศ ใช้ใน confined space monitoring, hydroponics (DO ในน้ำ ต้องใช้คู่), greenhouse automation ที่ต้องควบคุมองค์ประกอบอากาศ — Analog output เชื่อมต่อ ESP32 ADC ตรง ราคา ~$30
Analog O₂ 0–25% 3.3–5V
05
MAX30102 — Heart Rate & SpO2 Wearable
Maxim Integrated MAX30102 — Pulse oximeter สำหรับ wearable โปรเจกต์ เชื่อมต่อ ESP32 ผ่าน I2C วัด heart rate และ SpO2 แบบ optical ใช้ใน DIY smartwatch, fitness band, หรือ pet health monitor — ต้องการ SparkFun library หรือ Arduino MAX30105 library
Heart Rate I2C SpO2 1.8V
