🔵 ESP32-H2
ESP32-H2 — IEEE 802.15.4 Native: Zigbee 3.0 + Thread 1.3 + Matter ในชิปเดียว

ESP32-H2 คือชิป RISC-V ตัวแรกของ Espressif ที่รวม IEEE 802.15.4 ไว้ในฮาร์ดแวร์โดยตรง ทำให้รองรับ Zigbee 3.0, Thread 1.3 และ Matter ได้พร้อมกันโดยไม่ต้องใช้ชิปภายนอก

ราคาถูก ประหยัดพลังงานสูง เหมาะสำหรับ Smart Home, อุปกรณ์ที่ใช้ถ่าน, และ End Device บน Mesh Network ขนาดใหญ่

💡 ข้อได้เปรียบ: GPIO wake-on-interrupt + deep sleep ใต้ 10µA — เหมาะกับอุปกรณ์ประตู/หน้าต่างที่ใช้ถ่านได้หลายปี
  • Core: RISC-V 32-bit @ 96 MHz
  • BLE 5.0 + IEEE 802.15.4 (Zigbee/Thread)
  • RAM: 320 KB SRAM | Flash: 4 MB
  • Deep Sleep: ~7 µA
  • ราคา: ~$3–5 USD (module)
🟢 TinyML 2026
ESP32-P4 AI Accelerator — TinyML Inference ใต้ 20ms ไม่ต้องใช้ Cloud

ESP32-P4 (ออกปลาย 2024) มี AI Accelerator ในตัว ทำให้รันโมเดล TinyML ได้เร็วขึ้นอย่างก้าวกระโดด — Image Classifier และ Audio Keyword Spotter ทำงานใน <20ms เทียบกับ 80ms บน ESP32-S3 รุ่นก่อน

Framework ที่ใช้ได้: TensorFlow Lite for Microcontrollers (TFLM) และ Edge Impulse SDK ซึ่งขณะนี้รองรับ ESP32-P4 อย่างเป็นทางการ

⚡ เปลี่ยนเกม: โมเดล Anomaly Detection บน Sensor Data (Vibration, Temperature) รันบน MCU ราคา $10 ได้เลย
  • Dual-Core Xtensa LX9 @ 400 MHz
  • AI Accelerator (Neural Network Acceleration)
  • RAM: 768 KB SRAM + 32 MB PSRAM
  • ใช้ TFLM / Edge Impulse / EloquentML
🟣 Matter 1.5
ESP32-H2 กับ Matter over Thread — มาตรฐานใหม่สำหรับ IoT ที่ Interoperable 100%

Matter 1.5 ที่ออกในปี 2025 เพิ่ม Device Type ใหม่หลายประเภท ทั้ง Water Leak Detector, Smoke Sensor และ Energy Management — และ ESP32-H2 เป็นชิปที่รองรับ Matter over Thread ได้สมบูรณ์ที่สุดในราคาประหยัด

พัฒนาบน ESP-IDF v6.x ร่วมกับ esp-matter SDK ซึ่งมี example เต็มรูปแบบสำหรับ Door Lock, Contact Sensor และ Occupancy Sensor

🏠 ใช้ร่วมกับ Apple HomeKit, Google Home, Amazon Alexa ได้ทันทีโดยไม่ต้อง Custom Integration
🟠 Edge Impulse
Edge Impulse + Bosch BMI270 IMU — Gesture Recognition บน ESP32 แบบ No-Code

แพลตฟอร์ม Edge Impulse ช่วยให้เราเทรน Gesture Recognition Model บน IMU Data (Accelerometer + Gyroscope) และ Deploy ลง ESP32 ได้โดยตรงผ่าน Arduino library หรือ ESP-IDF component

Bosch BMI270 ให้ข้อมูล 6-axis @ 6400 Hz — ผสานกับ Edge Impulse ทำ Hand Gesture Classifier หรือ Fall Detection ได้แม่นยำ >95%

🎯 Use Case: ถุงมือ Smart ตรวจท่าทาง, รีโมตคอนโทรล Gesture, ระบบตรวจจับการล้มสำหรับผู้สูงอายุ
1
เก็บ Data จาก BMI270 ผ่าน SPI/I2C บน ESP32
2
อัปโหลด Dataset ขึ้น Edge Impulse Studio (เว็บ)
3
เทรน Neural Network Model (Neural Network Classifier)
4
Export เป็น Arduino Library และ import เข้าโปรเจกต์

💧 Water Quality
🌊 ESP32 Water Quality Monitor — pH + TDS + Turbidity + EC Real-time Dashboard

สร้างระบบตรวจวัดคุณภาพน้ำแบบ IoT ด้วยงบประมาณ ~1,500 บาท วัดได้ 4 พารามิเตอร์พร้อมกัน ส่งข้อมูลขึ้น Firebase หรือ ThingSpeak แบบ Real-time

  • pH Sensor — วัดค่าความเป็นกรด-ด่าง (0–14 pH, ±0.1 accuracy)
  • TDS Sensor — Total Dissolved Solids, วัดความบริสุทธิ์ของน้ำ (0–1000 ppm)
  • Turbidity Sensor — ความขุ่นของน้ำ (0–1000 NTU)
  • DS18B20 — อุณหภูมิน้ำ (ชดเชยความคลาดเคลื่อนของ pH)
  • ESP32 + OLED 0.96" — แสดงผลแบบ Real-time
📊 ส่งข้อมูลขึ้น Firebase → แสดงผ่าน Web App หรือ LINE Notify เมื่อค่าผิดปกติ
// อ่านค่า pH และแปลงเป็น voltage float readPH() { int raw = analogRead(PH_PIN); float voltage = raw * 3.3 / 4095.0; // Calibrate: pH = -5.6548 * voltage + 15.509 return -5.6548 * voltage + 15.509; }
🏠 Smart Home
🔑 ESP32-H2 Matter Door/Window Sensor — ใช้ถ่าน CR2032 ได้หลายปี

สร้าง Contact Sensor สำหรับประตูและหน้าต่างด้วย ESP32-H2 ที่รองรับ Matter over Thread แบบ Native ไม่ต้องมี Bridge หรือ Hub เชื่อมกับ Apple HomeKit, Google Home ได้โดยตรง

  • ESP32-H2 Mini Module (~$5)
  • Reed Switch + Magnet — ตรวจจับการเปิด/ปิด
  • CR2032 x2 (~3V) ผ่าน LDO 3.3V
  • Deep Sleep: <10µA (อยู่ได้ 3+ ปี)
  • Wake on GPIO → ส่ง Matter Event → กลับ Sleep
⏱ Wake latency: ~80ms (Thread reconnect + Matter report) — เร็วพอสำหรับ automation ทุกประเภท

⚙️ ESP32-S3 Vibration Anomaly Detector — Predictive Maintenance ด้วย TinyML

ติดตั้ง ADXL345 หรือ BMI270 บนมอเตอร์ เก็บข้อมูล Vibration Pattern แล้วเทรนโมเดล Anomaly Detection ด้วย Edge Impulse หรือ TensorFlow Lite เมื่อมีความผิดปกติให้แจ้งเตือนผ่าน MQTT/LINE

🌊 Water
Atlas Scientific EZO-pH — pH Sensor ระดับ Lab ราคาจับต้องได้

EZO-pH จาก Atlas Scientific เป็น pH Circuit ที่แม่นยำ ±0.001 pH ใช้การสื่อสาร I2C/UART กับ ESP32 พร้อม Auto-calibration และมี Waterproof Probe ให้เลือก เหมาะสำหรับ Aquaponics, บำบัดน้ำเสีย, สระว่ายน้ำ

  • Range: 0–14 pH | Resolution: 0.001 pH
  • Interface: I2C (default addr 0x63) หรือ UART
  • Continuous, Single, Calibration Commands
  • ราคา: ~$60–90 USD (Circuit + Probe)
// ส่งคำสั่งอ่านค่า pH ผ่าน I2C Wire.beginTransmission(0x63); Wire.write("R"); // Read command Wire.endTransmission(); delay(900); // รอ 900ms สำหรับการวัด Wire.requestFrom(0x63, 7);
🏃 Motion
Bosch BMI270 — IMU 6-Axis สำหรับ Gesture & Activity Recognition

BMI270 เป็น IMU ความแม่นยำสูงจาก Bosch ที่มี Accelerometer ±2–16g และ Gyroscope ±125–2000 dps ออกแบบมาเพื่อ Wearable และ Edge AI โดยเฉพาะ รองรับ SPI/I2C

  • Accel: ±2/4/8/16g @ 6400 Hz max ODR
  • Gyro: ±125–2000 dps @ 6400 Hz max ODR
  • Built-in Step Counter, Gesture, Tilt Detection
  • FIFO: 2KB — ลด MCU Interrupt Overhead
  • ราคา: ~$5–8 USD (Module)
🤝 ใช้คู่กับ Edge Impulse → เทรน Gesture Model แม่นยำ >95% บน ESP32
🔬 TDS
Gravity TDS Sensor (DFRobot) — วัดความบริสุทธิ์ของน้ำดื่ม

TDS (Total Dissolved Solids) Sensor จาก DFRobot ใช้ Analog Output เชื่อมต่อกับ ESP32 ADC ได้ทันที วัดความบริสุทธิ์น้ำ 0–1000 ppm เหมาะสำหรับตรวจสอบน้ำดื่ม, ระบบ RO, Aquarium

  • Range: 0–1000 ppm | Resolution: 1 ppm
  • Output: Analog 0–2.3V (ESP32 ADC ได้เลย)
  • ต้องชดเชย Temperature (ใช้ NTC หรือ DS18B20)
  • ราคา: ~$15–20 USD

📖 Guide
วิธีสร้าง ESP32-H2 Zigbee End Device ด้วย ESP-IDF v6.x

ESP32-H2 รองรับ Zigbee ผ่าน Espressif Zigbee SDK ที่รวมอยู่ใน ESP-IDF v5.x/6.x สร้าง End Device (เช่น Temperature Sensor, On/Off Light) ได้ในไม่กี่ขั้นตอน

1
ติดตั้ง ESP-IDF v6.x และ clone esp-zigbee-sdk: idf.py --version ต้องได้ 5.3+ ขึ้นไป
2
เลือก Example: esp-zigbee-sdk/examples/esp_zigbee_HA_sample/HA_temperature_sensor
3
Configure: idf.py menuconfig → ZigBee → Enable Zigbee → Role: End Device
4
Flash: idf.py -p /dev/ttyUSB0 flash monitor
5
Pair: กด Button บน Coordinator (หรือ Zigbee2MQTT) เพื่อเปิด Permit Join แล้ว Device จะ Join Network อัตโนมัติ
// กำหนด Cluster และ Attribute สำหรับ Temperature Sensor esp_zb_attribute_list_t *esp_zb_temperature_meas_cluster_create() { esp_zb_attribute_list_t *cluster = esp_zb_zcl_attr_list_create( ESP_ZB_ZCL_CLUSTER_ID_TEMP_MEASUREMENT ); int16_t temp_value = 2500; // 25.00°C (×100) esp_zb_temperature_meas_cluster_add_attr( cluster, ESP_ZB_ZCL_ATTR_TEMP_MEASUREMENT_VALUE_ID, &temp_value ); return cluster; }
⚡ Quick Tip
วิธีใช้ ESP32 ADC ให้แม่นยำ — แก้ปัญหา Non-linearity

ESP32 ADC มีปัญหา Non-linearity โดยธรรมชาติ โดยเฉพาะในช่วง 0–100mV และใกล้ 3.3V แก้ได้ด้วย Calibration Curve ใน ESP-IDF

  • ใช้ esp_adc_cal_characterize() ใน ESP-IDF
  • ตั้ง Attenuation: ADC_ATTEN_DB_12 สำหรับ 0–3.3V
  • อ่าน 64 ครั้ง แล้วเฉลี่ย ลด Noise ได้ 8×
  • หลีกเลี่ยง GPIO34–39 บางตัวที่ noise สูง
💡 เคล็ดลับ: ถ้าวัด pH หรือ TDS ให้ใช้ External ADC (ADS1115, 16-bit) แทน — แม่นกว่า ESP32 ADC มาก
// เฉลี่ย ADC 64 ครั้ง uint32_t avgADC(adc_channel_t ch) { uint32_t sum = 0; for(int i = 0; i < 64; i++) { sum += adc1_get_raw(ch); delayMicroseconds(100); } return sum / 64; }
