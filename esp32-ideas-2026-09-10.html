Tutorial ประจำวัน

📶 ESP32-C5 WiFi 6 Dual-Band — เชื่อมต่อ 5GHz เพื่อ Throughput สูงและ Latency ต่ำ

WiFi 6 บน ESP32-C5 รองรับ Target Wake Time (TWT) ให้อุปกรณ์ IoT หลับลึกและตื่นตรงเวลา ประหยัดพลังงานได้มากกว่า WiFi 5 ถึง 67% และ OFDMA ให้ AP รับส่งข้อมูลกับอุปกรณ์หลายตัวพร้อมกันโดยไม่แย่งช่องสัญญาณ — เหมาะสำหรับบ้านที่มีอุปกรณ์ IoT มากกว่า 20 ตัว

ข้อแตกต่างสำคัญ: 5GHz มี bandwidth กว้างกว่า แต่ระยะสั้นกว่า 2.4GHz ให้ใช้ 5GHz สำหรับอุปกรณ์ใกล้ Router (กล้อง IP, Smart Display) และ 2.4GHz สำหรับ Sensor ไกลๆ (สวน, โรงรถ)

ตัวอย่าง code เชื่อมต่อ 5GHz Network บน ESP32-C5 ด้วย ESP-IDF v6.0:

// ESP32-C5 WiFi 6 - เชื่อมต่อ 5GHz AP #include "esp_wifi.h" #include "esp_netif.h" void wifi_init_5ghz() { wifi_config_t cfg = { .sta = { .ssid = "MyRouter_5G", .password = "mypassword", // บังคับให้ใช้ 5GHz band เท่านั้น .band_mode = WIFI_BAND_MODE_5G_ONLY, // เปิด TWT สำหรับ Power Saving .twt_enabled = 1, }, }; esp_wifi_set_mode(WIFI_MODE_STA); esp_wifi_set_config(WIFI_IF_STA, &cfg); esp_wifi_start(); esp_wifi_connect(); }
  • 1
    ตรวจสอบว่า Router รองรับ WiFi 6 (802.11ax) และเปิด SSID แยกสำหรับ 5GHz
  • 2
    ใช้ ESP-IDF v6.0+ และเลือก target เป็น esp32c5 ใน menuconfig
  • 3
    ตั้งค่า WIFI_BAND_MODE_5G_ONLY เพื่อบังคับ 5GHz
  • 4
    เปิด TWT (twt_enabled = 1) เพื่อประหยัดพลังงานสูงสุด
  • 5
    วัด RSSI ด้วย esp_wifi_sta_get_ap_info() ให้ได้ไม่ต่ำกว่า -70 dBm
