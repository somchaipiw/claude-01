ESP32-C5 — Dual-Band Wi-Fi 6 + Thread/Zigbee ชิปแรกของ Espressif 2026
ESP32-C5 คือก้าวใหม่ของ Espressif: ชิป RISC-V 240 MHz ตัวแรกที่รองรับ Wi-Fi 6 ทั้งคลื่น 2.4 GHz และ 5 GHz พร้อมกัน รวมถึง Bluetooth 5 LE และ 802.15.4 (Thread/Zigbee) ในชิปเดียว ทำให้เป็นตัวเลือกเดียวในตลาดที่ครอบคลุมทุก protocol สำหรับ Smart Home สมัยใหม่

จุดเด่นหลัก: Target Wake Time (TWT) ของ Wi-Fi 6 ช่วยยืดอายุแบตเตอรี่ได้ 3–5 เท่าเมื่อเทียบกับ Wi-Fi 4, MU-MIMO ลดความแออัดในเครือข่ายที่มีอุปกรณ์มาก, กิน Active current ~80 mA เท่านั้น

Board พร้อมใช้: Waveshare ESP32-C5-LCD-1.47 (จอสี 1.47 นิ้ว) · Seeed XIAO ESP32-C5 (~$7) · ESP32-C5-DevKitC-1 (~$15)
Wi-Fi 6 5GHz Thread/Zigbee RISC-V 240MHz Dual-Band

ESP32-C6 ทำ Matter Thread Border Router ได้เอง — $5 DIY HOT
เดิมต้องซื้อ hub แยกต่างหากราคาหลายร้อยบาท แต่ตอนนี้ ESP32-C6-WROOM ราคา ~$5 สามารถเป็น Thread Border Router ได้เองโดยใช้ firmware OpenThread RCP เชื่อมกับ Home Assistant ทาง USB ผ่าน Docker หรือจะ flash เป็น Standalone Native Border Router ที่รันทุกอย่างบนตัว ESP32 เองเลย ไม่ต้องพึ่ง OTBR add-on

ระดับความยาก: ปานกลาง (ต้องพิมพ์ command ใน terminal) ใช้เวลา ~2-3 ชั่วโมง
ใช้ ESP-IDF v5.4.1 หรือสูงกว่า รองรับ matter.js setup พร้อม mesh extender และ otbr-proxy
Matter 2.0 Thread BR Home Assistant $5 DIY

SN1 Solar Node — ESP32-C3 + IP67 + Solar + ESPHome พร้อม deploy 2026
SN1 Solar Node เป็น board สำเร็จรูปที่ออกแบบมาสำหรับ IoT นอกอาคารระยะยาว โดยเฉพาะ มาพร้อม ESP32-C3, ตัวจัดการพลังงานโซลาร์ในตัว (MPPT), IP67 enclosure กันน้ำ/ฝุ่น, และ ESPHome firmware ทำให้ integrate กับ Home Assistant ได้ทันที

ออกมาในเดือนเมษายน 2026 เหมาะสำหรับ: สถานี weather monitoring ข้างนอกบ้าน, ระบบรดน้ำอัตโนมัติในสวน, node ตรวจสอบดินในฟาร์ม, หรือจุดนับรถยนต์บนถนน
Solar MPPT IP67 ESPHome ESP32-C3

ESP-DL v2 — Espressif's TinyML Library สำหรับ ESP32-S3 & P4 เร็วกว่าเดิม 4×
ESP-DL คือ library TensorFlow Lite Micro ที่ Espressif ปรับแต่งโดยเฉพาะสำหรับ ESP32-S3 และ ESP32-P4 โดยใช้ SIMD vector instructions ของ Xtensa LX7 ทำให้ inference latency ต่ำกว่า 5ms สำหรับ model ขนาด 10–200KB ใช้ไฟฟ้าในระดับ milliwatt

รองรับ: image classification, person detection, keyword spotting, anomaly detection
ใช้งานร่วมกับ Edge Impulse Studio → train model บน cloud → export มา deploy บน ESP32 ได้ใน 1 คลิก เหมาะสำหรับ security camera ในบ้าน, ระบบตรวจจับ smoke/fire จาก camera, และ industrial quality inspection

Smart Farm Monitor ด้วย ESP32 + LoRaWAN + Satellite Fallback — ครอบคลุมพื้นที่ไร้สัญญาณ
LoRa Alliance ประกาศใน Q3/2026 ว่า LoRaWAN รองรับ Satellite-Backed Connectivity แล้ว ทำให้สามารถส่งข้อมูล sensor ได้แม้อยู่ในพื้นที่ที่ไม่มี gateway LoRaWAN ในรัศมีหลายร้อยกม. (เช่น สวนทุเรียนในพื้นที่ห่างไกล หรือฟาร์มปศุสัตว์บนภูเขา)

ตัวอย่างในมาเลเซีย: ฟาร์ม MIE Agro ติด LoRaWAN soil sensor กว่า 20 จุดบนพื้นที่ 6,000 ต้นทุเรียน วัดความชื้นดิน, อุณหภูมิ, ความชื้นอากาศ, แสงแดด ส่งข้อมูลทุก 15 นาที ลดการใช้น้ำได้ 50%
// ESP32 + SX1262 LoRaWAN node ส่งข้อมูล sensor ทุก 15 นาที void setup() { LoRaWAN.begin(BAND); // 923MHz สำหรับ Thailand LoRaWAN.joinOTAA(devEUI, appKey); } void loop() { float soil = readSoilMoisture(); // Capacitive sensor float temp = readTemp(); // DS18B20 LoRaWAN.sendPacket(soil, temp); // ส่งผ่าน TTN / Helium esp_deep_sleep(15 * 60 * 1000000); // หลับ 15 นาที }

Solar-Powered Autonomous Sensor Node — ทำงานได้ปีหลายปีโดยไม่ต้องชาร์จแบต
รวม ESP32-C3/S3 เข้ากับ MPPT Solar Charger (CN3791 หรือ SPV1040) + แบต 18650 + solar panel 5V/1W ทำ node ที่รัน deep sleep ตลอด เว้นแต่ตื่นขึ้นมา 2 วินาทีเพื่ออ่านค่า sensor แล้วส่ง MQTT/LoRaWAN ก่อนหลับต่อ ใช้ไฟ ~5–10 µA ขณะหลับ (20,000 เท่าน้อยกว่า active mode)

ใช้งานได้: outdoor weather station, soil monitor ในสวน, ป้ายแจ้งเตือนน้ำท่วม, ตรวจจับสัตว์ป่า

Edge AI Home Security — ESP32-S3 + TinyML ตรวจจับบุคคลแบบ Real-Time ไม่ต้องใช้ Cloud
ใช้ XIAO ESP32-S3 Sense (กล้อง OV2640 + Mic) รัน ESP-DL model ตรวจจับบุคคล (person detection) บนตัวชิปเอง ไม่ส่งภาพออก cloud เลย ข้อมูลส่วนตัว 100% inference ที่ <5ms ต่อ frame กิน ~milliwatt เท่านั้น

Architecture: กล้องถ่าย frame → crop 96×96 px → ส่งเข้า TFLite Micro model → ถ้า confidence >80% → trigger alarm MQTT → ส่งภาพแค่ 1 frame ไป Home Assistant

ESP32 + RS485 Modbus Gateway — เชื่อม PLC/เครื่องจักรเก่าเข้า Cloud แบบ Retrofit
ใช้ ESP32-S3 + MAX485 module (หรือ Waveshare ESP32-S3-RS485-CAN board พร้อม isolated RS485) เป็น Modbus RTU → MQTT Gateway อ่านข้อมูลจาก VFD, meter, PLC, inverter ที่ใช้ Modbus RTU/TCP แล้วส่งขึ้น cloud หรือ InfluxDB + Grafana ได้ทันที ไม่ต้องเปลี่ยนเครื่องจักร

รองรับ: สายยาวถึง 1,200 เมตร, ทนสัญญาณรบกวนในโรงงาน, ใช้ไฟ 9–26V DC
