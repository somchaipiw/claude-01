ESP32-S31 — Dual-Core RISC-V พร้อม Wi-Fi 6 + Gigabit Ethernet

ชิปใหม่ล่าสุดจาก Espressif เพิ่งเข้าสู่การผลิตจำนวนมากในเดือนกรกฎาคม 2026 มาพร้อม CPU RISC-V 2 แกนความเร็ว 320 MHz รองรับ Wi-Fi 6, Bluetooth 5.4 (LE Audio + Classic), IEEE 802.15.4 (Zigbee/Thread) และ Gigabit Ethernet MAC ในชิปตัวเดียว เหมาะสำหรับ AIoT Hub, Smart Speaker และ Edge Gateway

Dual-core 320MHz RISC-V 512KB SRAM Wi-Fi 6 (2.4GHz) BT 5.4 LE Audio Gigabit ETH MAC Matter over Thread 60 GPIOs
CES 2026 · Wi-Fi 6E

ESP32-E22 — Co-Processor Wi-Fi 6E แบบ Tri-Band 2.1 Gbps

ชิปแรกของ Espressif ที่รองรับ Wi-Fi 6E ย่านความถี่ 6GHz ด้วย 2×2 MIMO และ 160MHz channel ให้ throughput สูงถึง 2.1 Gbps พร้อม Bluetooth 6.0 รองรับ PCIe, USB, SDIO สามารถใช้เป็น Connectivity Co-Processor ให้กับ Linux SBC หรือ MCU อื่นๆ

Dual-core 500MHz RISC-V Wi-Fi 6E 2.4/5/6GHz 2×2 MIMO 160MHz BT 6.0 LE+Classic PCIe / USB / SDIO 1MB on-chip
CES 2026 · Ultra-Low Power

ESP32-H21 — BLE MCU สำหรับ Wearables & Presence Sensing

ตรงข้ามกับ E22 ชิป H21 ออกแบบมาสำหรับโหนดเซนเซอร์ที่กินพลังงานต่ำมาก ใช้แบตเตอรี่ Button Cell ได้นานเป็นปี รองรับ Bluetooth LE, Zigbee และ Thread แข่งขันโดยตรงกับ Nordic nRF52840 เหมาะสำหรับ Wearable, Smart Label, Presence Detection และ IoT Sensor Node ในอาคาร

Ultra-low power BLE Zigbee / Thread Battery-powered years Wearable grade Presence sensing

ESP32-S3 + TensorFlow Lite Micro — Edge AI จริงจัง

ในปี 2026 การรัน TinyML บน ESP32-S3 ไม่ใช่แค่ proof-of-concept อีกต่อไป Vector/SIMD instructions ของ S3 ทำให้รัน quantized CNN model ได้ภายใน ไม่กี่สิบ ms ด้วยกระแสเฉลี่ยเพียง single-digit mA — เหมาะสำหรับ wake-word detection, anomaly detection, gesture recognition

INT4 Quantization — โมเดลเล็กลงอีก 2 เท่า

ปี 2026 นำ INT4 quantization มาใช้จริงใน TFLite Micro แม้ operator coverage ยังไม่ครบ แต่สำหรับ CNN ง่ายๆ เช่น keyword detection หรือ image classification ขนาดเล็ก สามารถลด model size ลง 50% จาก INT8 ทำให้โมเดล 400KB ใส่ใน Flash ของ ESP32-S3 ได้สบาย

Sensors น่าสนใจประจำวันนี้

เซนเซอร์ที่เข้ากับชิปรุ่นใหม่และเทรนด์ Edge AI

1

ICS-43434 — MEMS Microphone I2S ความละเอียดสูง

Microphone ดิจิทัล I2S คุณภาพสูง SNR 65dB AOP 116 dBSPL ใช้ไฟ 3.3V ต่อตรงกับ ESP32 I2S peripheral ไม่ต้องใช้ ADC ภายนอก เหมาะสำหรับ Wake Word Detection, Sound Classification, Noise Monitoring — ราคา ~40 บาท

2

LSM6DSO — 6-Axis IMU + Machine Learning Core

IMU จาก STMicroelectronics ที่มี Machine Learning Core ในตัว ประมวลผล Activity Recognition ได้โดยตรงในชิปเซนเซอร์ โดยไม่ใช้ CPU ของ ESP32 เลย Interrupt ESP32 ก็ต่อเมื่อ detect activity ที่กำหนด ประหยัดพลังงานสูงมาก

3

MAX30102 — Pulse Oximeter + Heart Rate Sensor

เซนเซอร์ Optical สำหรับวัด SpO2 และ Heart Rate บน I2C ราคา ~50 บาท แม้จะไม่ได้ความแม่นยำระดับ Medical แต่สำหรับ Personal Wellness Tracker เพียงพอมาก ใช้ Deep Learning บน Edge Impulse เพิ่ม accuracy ได้อีก

4

OV5640 — Camera 5MP Auto-Focus สำหรับ ESP32-S3

Camera Module ที่ดีกว่า OV2640 ของเดิมอย่างมาก มี Optical Auto-Focus, 5MP resolution, กำลังรับแสงดีขึ้น เหมาะสำหรับ Vision AI project ที่ต้องการ object detail ชัดเจน ราคา ~250 บาท ต่อกับ ESP32-S3 ผ่าน DVP Interface

5

ZMOD4510 — Outdoor Air Quality Sensor (NO2 + O3)

เซนเซอร์วัดคุณภาพอากาศกลางแจ้งจาก Renesas รองรับ NO₂ และ O₃ ที่เป็นตัวบ่งชี้สำคัญของมลพิษจากรถยนต์และอุตสาหกรรม มี AI Algorithm ในตัว ต่อผ่าน I2C เหมาะสำหรับ Environmental Monitoring Station กลางแจ้ง
