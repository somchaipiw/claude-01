Solar Energy Harvesting สำหรับ ESP32

Deep Sleep · MPPT · Battery Life

⚡ คำนวณอายุ Battery แบบง่ายๆ

กำหนด Duty Cycle ให้ถูก คือสิ่งสำคัญที่สุด

Wake ทุก 10 นาที~16 วัน (2400 mAh)
Wake ทุก 1 ชั่วโมง~99 วัน (2400 mAh)
Deep sleep current10 µA (bare ESP32)
Dev board (ไม่แก้)~800 µA – 2.8 mA

ต้องแก้ไขบอร์ดเพื่อให้ Deep Sleep ต่ำจริง

• ถอด/bypass Power LED
• เปลี่ยน onboard LDO เป็นแบบ low-quiescent (กินไม่เกิน 100 µA)
• ปิด peripherals ที่ไม่ใช้ก่อน deep sleep
• วัด current จริงด้วย INA219 ก่อนออกแบบ solar

MPPT

Input voltage0.1 V – 3.0 V (จาก solar cell)
Cold-start330 mV เท่านั้น
Efficiency>90% ที่ load เบา
Outputปรับได้ 1.8–5.1 V
🌤 เหมาะสำหรับ indoor solar หรือพื้นที่มีแสงน้อย — เปลี่ยนแสงจากหน้าต่างเป็นพลังงานได้

/* ตัวอย่าง: Wake ทุก 30 นาที, 20 วินาที */
wake_mAh   = 180mA × 20s / 3600 = 1 mAh
sleep_mAh  = 0.1mA × (30×60-20)s/3600
           = 0.083 mAh
total_per_cycle = 1.083 mAh per 30 min
daily_use  = 1.083 × 48 = ~52 mAh/day

ESP32 TWAI — CAN Bus สำหรับ Robotics & Automation

TWAI · CAN 2.0B · Industrial
ESP-IDF

🔌 TWAI — CAN Controller ในตัว ESP32

ESP32 มี CAN controller ในตัว ที่ Espressif เรียกว่า TWAI (Two-Wire Automotive Interface) รองรับ CAN 2.0B ต้องใช้ Transceiver ภายนอกเพิ่มอีกชิ้น

StandardCAN 2.0B (Classical CAN)
CAN-FDไม่รองรับ (ใช้ ESP32-C6 แทน)
TransceiverTJA1050 / TJA1051 / SN65HVD230
Designใกล้เคียง NXP SJA1000
Speedถึง 1 Mbit/s
⚠️ CAN-FD ต้องการ ESP32-C6 หรือ ESP32-P4 — ถ้าต้องการ baudrate สูง หรือ payload >8 bytes ต้องเปลี่ยน chip
Hardware

⚡ เลือก CAN Transceiver ให้ถูกต้อง

Transceiver ทำหน้าที่แปลง logic-level TX/RX จาก ESP32 เป็น differential signal บนสาย CAN Bus

TJA1050High-speed, 5V supply, ราคาถูก
TJA1051ปลอดภัยกว่า, slope control, 3.3/5V
SN65HVD2303.3V native, เหมาะกับ ESP32 มาก
MCP2551ใช้คู่ MCP2515 ถ้าต้องการ 2nd port
💡 แนะนำ SN65HVD230 สำหรับโปรเจกต์ ESP32 เพราะทำงานที่ 3.3V โดยตรง ไม่ต้องใช้ level shifter
Robotics

🦾 ESP32 + CAN Bus สำหรับ Robotic Arm / Motor Control

CAN Bus เป็นโปรโตคอลมาตรฐานในหุ่นยนต์และเครื่องจักรอุตสาหกรรม ช่วยให้ ESP32 เป็น central controller ที่สั่ง motor driver หลายตัวพร้อมกันบนสายเดียว

// ส่งคำสั่งไป Motor Driver ID=1
twai_message_t msg;
msg.identifier = 0x01;     // Motor ID
msg.data_length_code = 4;
msg.data[0] = 0x01;      // CMD: velocity
msg.data[1] = 0x00;      // direction
msg.data[2] = 200;       // speed (0-255)
msg.data[3] = 0;         // spare
twai_transmit(&msg, pdMS_TO_TICKS(100));
Industrial

🏭 ESP32 + CAN สำหรับ Industrial Sensor Gateway

เชื่อมต่อ sensor เก่าที่ใช้ CAN bus (เช่น อุปกรณ์ยานยนต์ หรือ factory equipment) เข้ากับ cloud ผ่าน ESP32 Wi-Fi โดยไม่ต้องเปลี่ยนฮาร์ดแวร์เดิม

ESP-MESH

🌡 10-Node Temperature Array ด้วย ESP-MESH

สร้าง sensor network ครอบคลุมอาคารทั้งหมดโดยที่ root node เชื่อมกับ router ผ่าน Station mode พร้อมกัน — node ที่เหลือส่งข้อมูลผ่าน mesh โดยอัตโนมัติ

// ESP-MESH Setup (ESP-IDF)
mesh_cfg_t cfg = MESH_INIT_CONFIG_DEFAULT();
cfg.mesh_id = MESH_ID;
cfg.router.ssid_len = strlen(CONFIG_ROUTER_SSID);
memcpy(cfg.router.ssid, CONFIG_ROUTER_SSID,
       cfg.router.ssid_len);
esp_mesh_set_config(&cfg);
esp_mesh_start();

Root node ที่ระยะ 5 hop สามารถครอบคลุม ~200 m ในอาคาร

ESP-NOW

⚡ ESP-NOW Sensor Network — Latency <1ms, ไม่ต้อง Router

ESP-NOW เหมาะสำหรับโปรเจกต์ที่ต้องการ response time เร็ว เช่น remote control, wireless sensor กระจายในพื้นที่ โดยไม่ต้องมี Wi-Fi infrastructure

Killer Use Cases ปี 2026:
• Wireless macropad / gamepad ไร้ Wi-Fi
• Multi-sensor alarm system (trigger เร็ว)
• Barn monitoring ที่ไม่มี Wi-Fi
• Low-latency robot remote control
