ESP-IDF v6.1 — Released 31 กรกฎาคม 2026
ESP-IDF v6.1 ออกอย่างเป็นทางการเมื่อ 31 ก.ค. 2026 ต่อยอดจาก v6.0 ที่เพิ่ม ESP32-C5, C61, H21, H4 รุ่นนี้ปรับ PSRAM config สำหรับ S31 และ H4 เพิ่ม PSA Crypto เป็น default แทน legacy MbedTLS และปรับ bootloader recovery partition ให้เสถียรขึ้นบน C5 และ C61
  • 1 Picolibc C library แทน newlib — ROM footprint เล็กลง
  • 2 OTA Bootloader update ผ่านเครือข่ายได้โดยตรง
  • 3 PSA Crypto เป็น default + deprecated legacy MbedTLS
  • 4 PSRAM config อัปเดตสำหรับ ESP32-S31 และ H4
  • 5 Recovery Bootloader เสถียรบน C5, C61

📡 Human Detection
mmWave 24GHz Radar Human Tracker — ESP32-S3 + RD-03D + Web Dashboard
ใช้ Ai-Thinker RD-03D radar module 24GHz FMCW ต่อกับ ESP32-S3 ผ่าน UART ติดตามคนได้สูงสุด 5 คน พร้อมระยะ (distance), มุม (angle) และความเร็ว (speed) แบบ real-time แสดงผลผ่าน WebSocket บน Touchscreen TFT หรือ Web Browser ไม่ต้องมีกล้อง ปกป้อง ความเป็นส่วนตัวได้ดีกว่า ใช้ในระบบความปลอดภัย, นับคน, Smart Lighting
  • 1 ต่อ RD-03D TX/RX เข้า GPIO 17/18 บน ESP32-S3
  • 2 Parse protocol 4 bytes header + target data ผ่าน UART2
  • 3 Serve WebSocket server ด้วย AsyncWebServer
  • 4 วาด radar sweep ด้วย HTML5 Canvas + JavaScript
  • 5 แจ้งเตือนผ่าน MQTT เมื่อตรวจพบการเคลื่อนไหว
ESP32-S3 RD-03D 24GHz FMCW WebSocket Privacy-Safe
🧠 TinyML / Edge AI
TinyML Vibration Anomaly Detection — ESP32-S3 + ADXL345 + Edge Impulse
ใช้ ESP32-S3 กับ accelerometer ADXL345 เก็บ vibration signature ของมอเตอร์/ปั๊มในสภาวะปกติ แล้ว train โมเดล anomaly detection บน Edge Impulse deploy กลับมารันบน ESP32-S3 ใช้ int8 TFLite Micro inference latency <5ms เตือนเมื่อ vibration ผิดปกติ ก่อนที่เครื่องจะพังจริงๆ เป็น Predictive Maintenance ต้นทุนต่ำมาก
  • 1 อ่านข้อมูล ADXL345 ผ่าน SPI @ 3.2kHz sampling
  • 2 แบ่ง time window 2 วินาที สร้าง FFT features
  • 3 Upload dataset ไป Edge Impulse Studio
  • 4 Train Anomaly Detection (K-means clustering)
  • 5 Export Arduino library + deploy ไป ESP32-S3
  • 6 ส่ง alert ผ่าน MQTT เมื่อ anomaly score > threshold
TinyML Edge Impulse TFLite Micro ADXL345 Predictive Maintenance
🎥 Computer Vision
ESP32-P4 Face Recognition Door Lock — ไม่ต้องมี Cloud ความเป็นส่วนตัว 100%
ใช้ ESP32-P4-EYE รัน ESP-WHO (Espressif's face detection framework) พร้อมกล้อง MIPI OV5640 5MP ทำ face detection + recognition บน device โดยตรง ไม่ส่งภาพใดๆ ไป cloud เลย ประมวลผลที่ 360MHz dual-core RISC-V + AI instruction extensions สามารถ enroll ใบหน้าผู้ใช้ได้ถึง 20 คน ต่อ servo ล็อคประตูผ่าน GPIO หรือส่งสัญญาณ relay ได้ทันที
  • 1 ตั้งค่า ESP-IDF + ESP-WHO บน ESP32-P4-EYE
  • 2 Init MIPI-CSI OV5640 + H.264 encoder pipeline
  • 3 Enroll ใบหน้า 3 ภาพต่อคน ผ่าน USB serial
  • 4 Run face detection @ >10fps + recognition
  • 5 Trigger GPIO relay เปิดล็อคเมื่อจำหน้าได้
  • 6 Log เวลาเข้า-ออกผ่าน Wi-Fi 6 ไป Home Assistant

🌬 Air Quality
SEN55 — All-in-One Environmental Sensor (Sensirion)
Sensirion SEN55 คือ sensor ออลอินวัน ที่รวม 5 การวัดในชิ้นเดียว PM1.0, PM2.5, PM4.0, PM10 (ฝุ่นละออง) + VOC index + NOx index + อุณหภูมิ + ความชื้น รองรับ I2C มี Arduino library พร้อมใช้ เหมาะกับ Air Quality Monitor ที่ต้องการครบทุกค่าใน BOM ชิ้นเดียว
PM วัดได้PM1.0, PM2.5, PM4.0, PM10
GasVOC Index + NOx Index
ClimateTemperature + Humidity
InterfaceI2C (addr 0x69)
LibrarySensirionI2CSen5x (Arduino)
🧪 Gas Sensor
SGP41 — VOC + NOx Dual Gas Sensor (Sensirion)
SGP41 เป็น metal-oxide gas sensor รุ่นใหม่จาก Sensirion วัดทั้ง VOC (สารอินทรีย์ระเหย) และ NOx (ไนโตรเจนออกไซด์) ในชิปเดียว ให้ค่า VOC Index (1-500) และ NOx Index (1-500) เหมาะกับ air purifier, demand-controlled ventilation, HVAC system
วัดได้VOC + NOx (dual sensing)
OutputVOC Index 1-500 / NOx Index 1-500
AlgorithmSensirion VOC/NOx Engine
InterfaceI2C (addr 0x59)
LibrarySensirion/arduino-i2c-sgp41
