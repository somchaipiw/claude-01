❤️ ESP32 + MAX30102 — Wearable Health Station แบบ Open Source

MAX30102 คือ PPG (Photoplethysmography) Sensor ที่สามารถวัด Heart Rate (HR), SpO₂ (ออกซิเจนในเลือด) และ Heart Rate Variability (HRV) ได้พร้อมกัน ราคาเพียง 30-50 บาท ต่อกับ ESP32 ผ่าน I²C เพียง 2 สาย เหมาะสำหรับทำ wearable ต้นทุนต่ำสำหรับ Remote Patient Monitoring และ Sport Performance Tracking

ในปี 2026 มีการนำ MAX30102 มารวมกับ AD8232 ECG Biopotential Amplifier และ GSR Sensor (Galvanic Skin Response) บนบอร์ดเดียวกัน ทำให้ ESP32 สามารถทำ Stress Index Detection แบบ multi-modal ได้โดยไม่ต้องพึ่งระบบ Cloud

ความสามารถของ Health Wearable Stack บน ESP32

  • วัด HR + SpO₂ ด้วย MAX30102 ผ่าน I²C — ความแม่นยำ ±2 bpm
  • วัด ECG Single-Lead ด้วย AD8232 — ดู P-QRS-T waveform จริง
  • คำนวณ HRV (SDNN, RMSSD) แบบ Real-time บน MCU
  • ตรวจ Stress Level ด้วย GSR + HRV Fusion Algorithm
  • ส่งข้อมูลผ่าน BLE ไปยัง App หรือ WiFi ไปยัง MQTT Broker

🏠 ESP32-H2 — Native Zigbee Coordinator ราคา $2 สำหรับ Home Assistant

ESP32-H2 มี Zigbee 3.0 + Thread radio ในตัว ทำให้สามารถเป็น Zigbee Coordinator หรือ End Device ได้โดยไม่ต้องใช้ chip ภายนอก ตั้งแต่ต้นปี 2026 ESPHome รองรับ Zigbee natively ทำให้การตั้งค่า ESP32-H2 เป็น Zigbee Coordinator ใน Home Assistant ทำได้ภายใน 10 นาที

🚗 ESP32 TWAI — CAN Bus / OBD-II Automotive Data Logger แบบ DIY

ESP32 มี TWAI (Two-Wire Automotive Interface) controller ในตัว ที่รองรับ CAN 2.0B specification ทำให้เชื่อมต่อกับ OBD-II port ของรถยนต์ ได้โดยตรงผ่าน CAN transceiver (SN65HVD230 หรือ TJA1050) ราคา 30-50 บาท

สามารถอ่านข้อมูล real-time เช่น RPM, Speed, Throttle, Coolant Temp, MAF, Fuel Trim และ Diagnostic Trouble Codes (DTCs) แล้วส่งไปยัง Cloud Dashboard ผ่าน WiFi หรือ 4G ทำให้สร้าง Fleet Monitoring สำหรับรถยนต์หลายคันในราคาถูกมาก

ESP32 TWAI — Pin Mapping

  • TX Pin: GPIO 5 (ต่อกับ TXD ของ CAN Transceiver)
  • RX Pin: GPIO 4 (ต่อกับ RXD ของ CAN Transceiver)
  • Baud Rate: 250 kbps (OBD-II standard) หรือ 500 kbps
  • Library: ESP32-Arduino TWAI driver + arduino-OBD2 library
  • Power: 12V→5V buck converter จากสาย OBD-II Pin 16

Deep Dive: ESP32 TWAI CAN Bus — ขั้นตอนอ่าน OBD-II จริง

Hardware Wiring + Code + PID Request ครบจบในที่เดียว

⚙️ Hardware Setup — ESP32 + SN65HVD230 + OBD-II Connector

ต่อวงจรง่ายๆ 4 สาย: ESP32 GPIO5 (TX) → TXD ของ SN65HVD230, GPIO4 (RX) → RXD, CANH/CANL ต่อกับ Pin 6/14 ของ OBD-II connector และต่อ 12V จาก Pin 16 ผ่าน buck converter

// ESP32 Arduino — อ่าน RPM จาก OBD-II ผ่าน TWAI/CAN Bus #include "driver/twai.h" void setup() { Serial.begin(115200); // กำหนด CAN config twai_general_config_t g_config = TWAI_GENERAL_CONFIG_DEFAULT( (gpio_num_t)5, // TX pin (gpio_num_t)4, // RX pin TWAI_MODE_NORMAL ); twai_timing_config_t t_config = TWAI_TIMING_CONFIG_500KBITS(); twai_filter_config_t f_config = TWAI_FILTER_CONFIG_ACCEPT_ALL(); twai_driver_install(&g_config, &t_config, &f_config); twai_start(); } void requestOBD(uint8_t pid) { twai_message_t msg; msg.identifier = 0x7DF; // OBD-II Functional Request ID msg.data_length_code = 8; msg.data[0] = 0x02; // Number of bytes to follow msg.data[1] = 0x01; // Mode 01 — Current data msg.data[2] = pid; // PID (เช่น 0x0C = RPM) for(int i=3; i<8; i++) msg.data[i] = 0x00; twai_transmit(&msg, pdMS_TO_TICKS(100)); } void loop() { requestOBD(0x0C); // ขอ RPM twai_message_t response; if(twai_receive(&response, pdMS_TO_TICKS(200)) == ESP_OK) { // RPM = ((A*256) + B) / 4 int rpm = ((response.data[3] * 256) + response.data[4]) / 4; Serial.printf("RPM: %d\n", rpm); } delay(500); }

OBD-II PID สำคัญๆ ที่ต้องรู้: 0x0C (RPM), 0x0D (Vehicle Speed km/h), 0x05 (Engine Coolant Temp), 0x11 (Throttle Position %), 0x2F (Fuel Tank Level %), 0x33 (Barometric Pressure), 0x5C (Oil Temperature)
