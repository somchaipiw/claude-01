Solar-Powered Remote Weather Station — สถานีตรวจอากาศ Off-Grid พลังงานแสงอาทิตย์
แนะนำ

สร้างสถานีตรวจวัดสภาพอากาศที่ไม่ต้องพึ่งไฟฟ้าหลัก ส่งข้อมูลผ่าน MQTT ไปยัง Home Assistant หรือ Grafana Dashboard โดยใช้ PowerFeather V2 เป็นใจกลางการจัดการพลังงาน เหมาะสำหรับติดตั้งในสวน ไร่นา หรือพื้นที่ห่างไกล

ESP32-S3 PowerFeather V2 แผงโซลาร์ 5W 18V BME680 (Temp/Hum/Pressure/VOC) SCD41 (CO₂ NDIR) MQTT + Home Assistant LiFePO4 แบต 3.2V 2000mAh
  • 1ต่อแผงโซลาร์เข้า PowerFeather V2 ตั้ง MPP Voltage ให้ตรงกับแผง
  • 2ต่อ BME680 และ SCD41 ผ่าน I2C (GPIO 21/22)
  • 3เขียน firmware ด้วย ESP-IDF หรือ Arduino — อ่านค่าทุก 5 นาที ส่ง MQTT
  • 4ใช้ Deep Sleep ระหว่างรอ — ประหยัดไฟ <20µA ขณะหลับ
  • 5ตั้ง Dashboard บน Grafana + InfluxDB เพื่อดูกราฟย้อนหลัง
⚡ แบตเตอรี่ LiFePO4 2000mAh + โซลาร์ 5W: สถานีทำงานได้ตลอด 24/7 ตลอดทั้งปีในประเทศไทยที่มีแสงแดดเพียงพอ

ESP32-S3 Offline AI Voice Assistant — สั่งงานบ้านด้วยเสียง ไม่ต้องใช้ Cloud
HOT

สร้าง Voice Assistant ที่ประมวลผลเสียงทั้งหมดในตัวเอง (on-device) ไม่ส่งข้อมูลออก Internet โดยใช้ ESP-SR TTS Pipeline V3 ฝึก Wake Word ภาษาอังกฤษหรือจีน และสั่ง MultiNet 7 ให้รู้จำคำสั่ง เช่น เปิด/ปิดไฟ ปรับแอร์ เปิดม่าน

ESP32-S3 (8MB PSRAM) INMP441 I2S MEMS Mic ESP-SR + MultiNet 7 Relay Module 4-ch MAX98357A I2S Amp + Speaker Arduino IDE / ESP-IDF
  • 1ต่อ INMP441 กับ ESP32-S3 ผ่าน I2S (BCLK, WS, SD pins)
  • 2ดาวน์โหลด ESP-SR จาก GitHub แล้ว import ใน ESP-IDF project
  • 3กำหนด Wake Word ("Hey ESP" หรือฝึก custom wake word) ใน Pipeline V3
  • 4เพิ่ม MultiNet 7 command list: "เปิดไฟ", "ปิดไฟ", "ลดอุณหภูมิ" ฯลฯ
  • 5ต่อ Relay ควบคุมอุปกรณ์ ตอบกลับด้วย TTS ผ่าน MAX98357A
🔒 ทุกการประมวลผลเกิดขึ้นใน ESP32-S3 — ข้อมูลเสียงไม่ออก Internet เลย ความเป็นส่วนตัว 100%
03
Smart NFC/RFID Door Access Control — ระบบเปิดประตูอัจฉริยะพร้อม Web Dashboard + Telegram
ไอเดียใหม่

ระบบควบคุมการเข้าออกด้วยบัตร NFC/RFID ที่รองรับผู้ใช้ได้สูงสุด 1,000 คน มี Web Dashboard สำหรับจัดการบัตร บันทึกประวัติการเข้าออก และแจ้งเตือนผ่าน Telegram Bot ทุกครั้งที่มีการสแกนบัตร เพิ่ม OTA update ผ่าน Wi-Fi

ESP32-S3 PN532 NFC/RFID Module (I2C) Relay (ควบคุม Electric Strike Lock) NeoPixel LED (สถานะ OK/Denied) Web Server (ESPAsyncWebServer) Telegram Bot API
  • 1ต่อ PN532 กับ ESP32-S3 ผ่าน I2C (SDA/SCL) — ตั้ง DIP switch เป็น I2C mode
  • 2เขียน ESP32 เป็น Web Server — จัดการรายชื่อ UID บัตรที่อนุญาต
  • 3สแกนบัตร → ตรวจสอบ UID ใน list → เปิด relay + LED เขียว หรือ LED แดง
  • 4บันทึก log ลง SPIFFS (timestamp + UID) แสดงบน Web UI
  • 5ส่งแจ้งเตือน Telegram พร้อม timestamp และชื่อผู้ใช้ทุกครั้งที่สแกน
📱 ติดตั้งที่ออฟฟิศ หอพัก หรือโรงรถ — จัดการบัตรผ่านมือถือโดยไม่ต้องโปรแกรมใหม่ทุกครั้ง

INMP441 — I2S MEMS Microphone สำหรับ Voice Recognition & Audio Processing
คลาสสิก

ไมโครโฟน MEMS ที่เชื่อมต่อผ่าน I2S ดิจิทัล เป็นตัวเลือกยอดนิยมสำหรับโปรเจกต์ Voice Recognition บน ESP32-S3 ให้ SNR สูงถึง 61 dB และมีน้ำหนักเบา ขนาดเล็ก เหมาะสำหรับงาน edge AI

InterfaceI2S (3-wire: BCLK, WS, SD)

แรงดัน1.8V – 3.3V

ราคาประมาณ30–80 บาท (AliExpress module)

PN532 — NFC/RFID Controller ยอดนิยม รองรับ ISO 14443A/B, MIFARE, FeliCa
ยอดนิยม

NXP PN532 เป็น NFC Controller ที่ได้รับความนิยมสูงสุดในกลุ่ม Maker รองรับทั้ง I2C, SPI และ UART เชื่อมต่อได้ทั้งการ์ด MIFARE Classic, MIFARE DESFire, NFC Type 2/4 และ FeliCa ใช้ library ที่มีเอกสารดีมาก

ความถี่13.56 MHz (ISO 14443A/B, ISO 18092)
InterfaceI2C / SPI / UART (สลับด้วย DIP switch)
ระยะอ่าน~5 cm (ขึ้นกับ antenna)
รองรับMIFARE Classic, DESFire, NFC Forum Type 2–4, FeliCa
แรงดัน3.3V (โมดูลมี level shifter)
LibraryAdafruit PN532 (Arduino / CircuitPython)

SCD41 — CO₂ Sensor แบบ Photoacoustic NDIR จาก Sensirion (ความแม่นยำสูง)
แนะนำ

SCD41 ใช้เทคโนโลยี Photoacoustic NDIR (PASens) วัด CO₂ ได้แม่นยำกว่าเซนเซอร์ chemical ทั่วไป บัดกรีแล้วใช้ได้ทันทีโดยไม่ต้องปรับเทียบเพิ่ม (factory calibrated) เหมาะสำหรับวัดคุณภาพอากาศในห้องหรือออฟฟิศ

หลักการทำงานPhotoacoustic NDIR (PASens)
ช่วงวัด400 – 5,000 ppm CO₂
ความแม่นยำ±40 ppm ±5% ของค่าวัด
InterfaceI2C (address 0x62)
แรงดัน2.4V – 5.5V
พลังงาน~3 mA (low power periodic mode)

BQ25628E — Texas Instruments Solar/USB Battery Charger IC พร้อม MPPT
IC น่ารู้

IC ชาร์จแบตเตอรี่จาก TI ที่ใช้ใน PowerFeather V2 รองรับ input จาก USB-C หรือ Solar Panel สูงสุด 18V มีอัลกอริธึม MPPT ในตัว ทำให้ดึงพลังงานจากโซลาร์ได้เต็มประสิทธิภาพ รองรับแบตหลายเคมี

InputUSB-C หรือ DC 3.9V–18V (Solar)

กระแสชาร์จสูงสุด 2A
รองรับแบตLi-ion, LiPo, LiFePO4

Package20-pin VQFN (SMD)
