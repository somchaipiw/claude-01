New Capability

UWB Indoor Positioning ด้วย ESP32 + Qorvo DWM3000 — แม่นยำระดับ 10 cm

Ultra-Wideband (UWB) เป็นเทคโนโลยี Radio ที่ให้ความแม่นยำสูงกว่า Wi-Fi, Bluetooth, และ GPS ภายในอาคาร เมื่อจับคู่กับ ESP32 และโมดูล Qorvo DWM3000 (IEEE 802.15.4z) จะสามารถสร้างระบบ Real-Time Location System (RTLS) ที่แม่นยำถึง 10 เซนติเมตร ได้ในงบประมาณ DIY

  • เทคนิค: Double-Sided Two-Way Ranging (DS-TWR)
  • โปรโตคอล: IEEE 802.15.4z HRP UWB
  • Interface: SPI ระหว่าง DWM3000 ↔ ESP32
  • สถาปัตยกรรม: ≥3 Anchor (ตำแหน่งคงที่) + 1 Tag (เคลื่อนที่)
  • ข้อมูล: ส่งผ่าน Wi-Fi ไปยัง Dashboard แบบ Real-Time
ทำไมดีกว่า BLE / Wi-Fi? BLE ให้ความแม่นยำ ±1–3 เมตร, Wi-Fi RSSI ±3–5 เมตร — แต่ UWB ให้ ±10 ซม. เหมาะมากสำหรับระบบ Robot Navigation, Warehouse Tracking, และ AR/VR ภายในอาคาร
Native Zigbee

ESP32-C6/H2 เป็น Zigbee Coordinator โดยตรง — ไม่ต้องใช้ Gateway ภายนอก

ด้วย ESP32-C6 หรือ ESP32-H2 ที่มีวิทยุ IEEE 802.15.4 ในตัว เราสามารถตั้งค่าให้เป็น Zigbee Coordinator และสื่อสารกับ End Device ต่างๆ (เซ็นเซอร์, หลอดไฟ, ปลั๊ก) ได้โดยตรงผ่าน Arduino หรือ ESP-IDF โดยไม่ต้องมีฮาร์ดแวร์ Coordinator ภายนอก

  • SDK: esp-arduino ≥ v3.0.6 มี Zigbee built-in
  • รองรับ: Thermometer, Switch, Light, Thermostat, Plug
  • Library: AndroidCrypto/ESP32_C6_Zigbee_Coordinator
  • ต้องการ: XIAO ESP32C6 หรือบอร์ด ESP32-C6/H2 ใดก็ได้
// ตัวอย่าง Zigbee Coordinator บน ESP32-C6 #include "ZigbeeCore.h" #include "ep/ZigbeeColorDimmableLight.h" ZigbeeColorDimmableLight zbLight = ZigbeeColorDimmableLight(10); void setup() { Zigbee.addEndpoint(&zbLight); Zigbee.begin(ZIGBEE_COORDINATOR); }
OpenThread

ESP32-C6 Native Thread Border Router — Single Chip ไม่ต้องใช้ Add-on

ESP32-C6 สามารถทำงานเป็น Thread Border Router ได้บน Single Chip ด้วย ESP-IDF v5.4.1+ โดยใช้วิทยุ Wi-Fi 6 (2.4 GHz) และ IEEE 802.15.4 (Thread) พร้อมกัน ไม่ต้องซื้อ Home Assistant Connect ZBT-2 หรือ OTBR add-on แยกต่างหาก

  • Wi-Fi: Wi-Fi 6 (2.4 GHz) ↔ อินเทอร์เน็ต/LAN
  • Thread: IEEE 802.15.4 ↔ Matter over Thread Devices
  • Firmware: ot_br example ใน ESP-IDF
  • Matter: รองรับ Matter 1.x device บน Thread network
  • GitHub: techo35/esp32-c6-native-thread-border-router
ประหยัดกว่า! ESP32-C6 ราคา ~$5 ทำงานเป็น Thread Border Router ได้ดีเทียบเท่า Home Assistant Connect ZBT-2 ราคา $49 — เหมาะมากสำหรับ DIY Smart Home
Modular IoT

Sensirion Unified Prototyping Toolkit (UPT) — Multi-Sensor Auto-Discovery บน ESP32

Sensirion UPT เป็น Framework ที่ทำให้ ESP32 สามารถ สแกน I2C Bus อัตโนมัติ และเริ่มอ่านข้อมูลจาก Sensirion Sensor ที่ต่ออยู่ทุกตัวโดยไม่ต้องเขียน Code ใหม่สำหรับแต่ละ Sensor รองรับ SCD4x (CO₂), SHT4x (RH/T), SEN5x (PM/VOC), SGP4x และอื่นๆ

  • สแกน: I2C Auto-detection ทุก Sensirion Sensor
  • ข้อมูล: JSON output พร้อม unit และ timestamp
  • Platform: ESP32, Arduino Uno R4, Raspberry Pi Pico
  • Protocol: JSON over Serial หรือ MQTT

IoT Tracking

ระบบติดตามสินทรัพย์ภายในโรงงาน ด้วย ESP32 + DWM3000 UWB

สร้างระบบ RTLS (Real-Time Location System) ในโรงงานหรือโกดัง โดยติด Tag ESP32+DWM3000 บนสินค้า, เครื่องมือ, หรือยานพาหนะ และใช้ Anchor ที่ติดตั้งคงที่บนเพดาน คำนวณตำแหน่งด้วย Trilateration แล้วแสดง Floor Plan แบบ Real-Time บน Web Dashboard

  • 1
    ติดตั้ง Anchor (ESP32 + DWM3000) ≥3 จุดบนเพดาน
  • 2
    Tag ส่ง UWB pulse ไปยัง Anchor ทุก 100ms (DS-TWR)
  • 3
    ESP32 คำนวณระยะทาง → ส่งผ่าน Wi-Fi ไปยัง Server
  • 4
    Server คำนวณ Trilateration → แสดงบน Map Web App (Node.js)
  • 5
    แจ้งเตือนผ่าน LINE Notify เมื่อสินทรัพย์ออกนอกพื้นที่กำหนด
ต้นทุนประมาณ: DWM3000 Module ราคา ~$15–25/ชิ้น, ESP32 ~$3–5 — ระบบ 4 Anchor + 5 Tag ต้นทุนรวม ~$200–300 แต่ความแม่นยำระดับ 10 ซม. ทั้งอาคาร
Smart Home

DIY Zigbee + Thread + Matter Hub บน ESP32-C6 — รวมโปรโตคอลในบอร์ดเดียว

ใช้ ESP32-C6 บอร์ดเดียวทำงานเป็นทั้ง Zigbee Coordinator (ควบคุมอุปกรณ์เก่า) และ Thread Border Router (รองรับอุปกรณ์ Matter ใหม่) ในเวลาเดียวกัน โดยสลับ Mode ผ่าน Web UI ที่อยู่ใน ESP32-C6 เอง

  • บอร์ดแนะนำ: XIAO ESP32C6, M5Stamp C6, ESP32-C6-DevKitC-1
  • Zigbee Mode: Coordinator — ควบคุม Light, Sensor, Plug
  • Thread Mode: Border Router — สะพาน IPv6 ↔ Thread
  • UI: ESPHome + Home Assistant Integration
  • Storage: เก็บ Device List ใน LittleFS บน Flash
USB Host

ESP32-S3/P4 USB Host — เชื่อมต่อกล้อง USB UVC, Keyboard, และ Flash Drive

ESP32-S3 และ ESP32-P4 มีวงจร USB-OTG ในตัว สามารถทำงานเป็น USB Host ได้ รองรับ UVC Camera (จับภาพวิดีโอ), HID Keyboard/Mouse, และ Mass Storage (Flash Drive) โดยใช้ ESP-IDF USB Host Stack ที่รวมอยู่ใน esp-iot-solution

  • UVC Driver: จับภาพจากกล้อง USB และส่งผ่าน Wi-Fi
  • HID Driver: รับ Input จาก Keyboard/Mouse USB
  • MSC Driver: อ่าน/เขียน USB Flash Drive ได้
  • Library: tanakamasayuki/EspUsbHost (Arduino)
ไอเดียโปรเจกต์: ต่อกล้อง USB เว็บแคมธรรมดาราคาถูก (~200 บาท) กับ ESP32-S3 แล้วสร้าง Security Camera ส่ง Stream ผ่าน Wi-Fi ไปยัง Home Assistant — ไม่ต้องซื้อกล้อง ESP32-CAM
// ESP32-S3 USB Host: รับ Input จาก Keyboard #include "EspUsbHost.h" EspUsbHost usbHost; void onKeyboard(hid_keyboard_report_t report, ...) { Serial.printf("Key: %d\n", report.keycode[0]); } void setup() { usbHost.begin(); } void loop() { usbHost.task(); }
Power Tips

Sensor Node อายุแบตเตอรี่ 1 ปี — เทคนิค Deep Sleep ที่ครบครันที่สุดสำหรับ ESP32

ด้วย Deep Sleep ที่ปรับแต่งอย่างดี ESP32 สามารถส่งข้อมูล Sensor ทุก 10 นาที โดยใช้แบตเตอรี่ 18650 (2000 mAh) ได้นานกว่า 1 ปี เทียบกับปกติที่ไม่มี Deep Sleep จะหมดใน <24 ชั่วโมง

Wi-Fi Active Mode
80–240 mA
Light Sleep
~0.8 mA
Deep Sleep (RTC On)
~10–20 µA
Deep Sleep + Low-Q LDO
~2–3 µA
  • 1
    เก็บ Wi-Fi Channel + BSSID ใน RTC Memory — ลด Reconnect จาก 3s → 500ms
  • 2
    ใช้ MOSFET ตัดไฟเซ็นเซอร์ ระหว่าง Sleep — ไม่ให้เซ็นเซอร์กินไฟสูญเปล่า
  • 3
    เปลี่ยน LDO เป็น TI TPS7A02 — Quiescent Current <25 nA (จาก 50 µA ปกติ)
  • 4
    ใช้ ULP Coprocessor อ่านเซ็นเซอร์ใน Sleep โดยไม่ปลุก Main CPU
  • 5
    ปิด Wi-Fi + Bluetooth ทันทีหลังส่งข้อมูล ก่อน Deep Sleep

GUI Library

LVGL 9.x บน ESP32-S3 — GUI Framework ที่สวยที่สุดสำหรับ Embedded Display

LVGL (Light and Versatile Graphics Library) v9.x เป็น Library GUI ที่ได้รับความนิยมสูงสุดสำหรับ Embedded Display บน ESP32-S3 รองรับ Touch, Animation, Widget ครบ และใช้ได้กับ ESPHome ได้โดยตรง

  • บอร์ดแนะนำ: ESP32-S3-Touch-LCD-2.1 (480×480)
  • Display: ILI9488, ST7789, GC9A01, ILI9341
  • Render: ใช้ DMA + Double Buffering
  • ESPHome: รองรับ LVGL v9 โดยตรงใน 2025.6+
  • Widgets: Button, Slider, Chart, Calendar, Roller
เทคนิคสำคัญ: ใช้ LovyanGFX เป็น Display Driver แทน Adafruit GFX เพื่อให้ได้ความเร็วสูงสุดบน ESP32-S3 กับ LVGL v9
LoRa / Mesh

Meshtastic Detection Sensor Module — เปลี่ยน Mesh Node เป็น Remote Monitor

Meshtastic รองรับ "Detection Sensor Module" ที่ทำให้ Node ในเครือข่าย Mesh สามารถส่ง Event แจ้งเตือนเมื่อมีการตรวจจับ (เช่น PIR, ประตูเปิด, น้ำท่วม) ผ่าน LoRa Mesh โดยไม่ต้องมี Wi-Fi หรือ Cellular Coverage

  • บอร์ด: Heltec LoRa32, T-Beam, RAK4631 + ESP32
  • การตั้งค่า: ผ่าน Meshtastic App (iOS/Android)
  • Trigger: GPIO input จาก PIR, Reed Switch, Flood Sensor
  • Range: 1–10 กม. (LoRa) ผ่าน Mesh หลาย Hop
  • Notify: Push ไปยัง MQTT, Telegram, HA webhook
Use Case เด่น: ระบบแจ้งเตือนบ้านนอกเมือง, สถานีเตือนภัยน้ำท่วม, หรือ Security Alert พื้นที่ห่างไกลที่ไม่มีสัญญาณมือถือ
