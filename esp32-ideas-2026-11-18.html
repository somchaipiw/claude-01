Industrial IoT — Modbus, RS485 & OPC-UA

นวัตกรรม
แนวโน้ม 2026: ESP32 กลายเป็น Edge Gateway ยอดนิยมสำหรับโรงงาน ทำหน้าที่เชื่อม Modbus RTU เครื่องจักรเก่าเข้ากับ MQTT, Modbus TCP และ OPC-UA โดยไม่ต้องลงทุน PLC ราคาสูง ค่าใช้จ่ายลดลงมากกว่า 80% เมื่อเทียบกับ gateway เชิงพาณิชย์
🌐
FlowSense Pro — ESP32 OPC-UA SCADA Gateway
โปรเจกต์ล่าสุด (ต.ค. 2026) ใช้ ESP32-S3 เป็น OPC-UA Server เชื่อมตรงกับ SCADA ผ่าน TCP/IP โดยไม่ต้องผ่าน MQTT Broker รองรับ node สูงสุด 50 tag และ timestamp accuracy ระดับ millisecond
OPC-UA ESP32-S3 SCADA Industrial
🔁
Modbus RTU → MQTT Edge Gateway
Pattern ยอดนิยมที่สุด: ESP32 + MAX485 ทำ Modbus RTU Master poll device ทุก X วินาที แปลงเป็น JSON แล้วส่งผ่าน MQTT ไปยัง Home Assistant, Node-RED หรือ Cloud Platform รองรับ multi-slave (up to 247 device บน bus เดียว)
Modbus RTU MQTT MAX485
📦
Waveshare ESP32-S3-RS485-CAN — บอร์ด DIN Rail
บอร์ด industrial ใหม่จาก Waveshare เปิดตัว ก.พ. 2026 มา DIN-rail housing พร้อม isolated RS485 + CAN, ไฟเลี้ยง 7–36V DC ขนาด 91.6×23.3 mm เหมาะสำหรับติดตั้งในตู้ control panel จริง
DIN Rail RS485 + CAN 36V DC Isolated
💾
Offline Data Logger — Buffer หลายสัปดาห์
ESP32-S3 WROVER (8 MB PSRAM) บัฟเฟอร์ข้อมูล Modbus ไว้ใน flash ได้หลายสัปดาห์เมื่อ cloud connection หาย เมื่อ reconnect จะ sync ข้อมูลย้อนหลังอัตโนมัติ เหมาะกับโรงงานในพื้นที่ห่างไกล
PSRAM Offline Buffer Auto Sync
🏗️
Waveshare ESP32-S3-POE-ETH-8DI-8DO
รุ่น DIN-rail อีกรุ่นที่มี PoE (Power over Ethernet), 8 digital input, 8 digital output เหมาะกับ PLC-replacement ระดับเบา ควบคุมผ่าน Ethernet LAN โดยตรง ไม่ต้องพึ่ง Wi-Fi
PoE Ethernet 8DI/8DO
⚠️
ข้อควรระวัง: RS485 Wiring บน ESP32
Bus termination (120Ω) ต้องใส่เองที่ปลายสาย — บอร์ดส่วนใหญ่ไม่มีในตัว ระยะสายไม่ควรเกิน 1,200 m ที่ 100 kbps ใช้ Shielded twisted pair และ bias resistor เมื่อมี noise สูง Baud rate ที่นิยม: 9600 / 19200 / 38400 bps
Termination 120Ω Wiring
📋 Modbus RTU Master — ตัวอย่าง Code (ESP-IDF / Arduino)
// ใช้ library: ModbusMaster หรือ esp32ModbusRTU // RS485: GPIO16=RX, GPIO17=TX, GPIO4=DE/RE (direction control) #include <ModbusMaster.h> ModbusMaster node; HardwareSerial RS485Serial(2); // UART2 void preTransmission() { digitalWrite(4, HIGH); } void postTransmission() { digitalWrite(4, LOW); } void setup() { RS485Serial.begin(9600, SERIAL_8N1, 16, 17); node.begin(1, RS485Serial); // slave ID = 1 node.preTransmission(preTransmission); node.postTransmission(postTransmission); } void loop() { uint8_t result = node.readHoldingRegisters(0x00, 2); if (result == ModbusMaster::ku8MBSuccess) { float voltage = node.getResponseBuffer(0) / 10.0; Serial.printf("Voltage: %.1f V\n", voltage); } delay(1000); }

Energy Monitoring — Smart Power Metering

ไอเดียโปรเจกต์
PZEM-004T v3.0 ยังคงเป็นตัวเลือกอันดับหนึ่งสำหรับ energy monitoring ราคาประหยัด วัด Voltage, Current, Power, Frequency, Power Factor และ Cumulative Energy ครบในโมดูลเดียว ความแม่นยำ ±0.5% voltage / ±1% power เพียงพอสำหรับ home monitoring
🔌
PZEM-004T + ESP32 — Smart Energy Dashboard
วัด AC 80–260V / 0–100A ผ่าน UART (GPIO16/17) ส่ง JSON ผ่าน MQTT ไปยัง InfluxDB + Grafana dashboard ดู consumption real-time เพิ่ม SMS alert เมื่อ power เกิน threshold ผ่าน Twilio หรือ Line Notify
PZEM-004T MQTT Grafana SMS Alert
🏠
Smart Power Strip — Monitor ทุก Socket
ติด PZEM-004T หรือ CT sensor แต่ละปลั๊กใน power strip ระบุว่าอุปกรณ์ไหนกินไฟเท่าไร คำนวณค่าไฟรายวัน/รายเดือน แสดงผลบน OLED หรือ web dashboard ผ่าน ESP32 built-in Wi-Fi
Multi-socket CT Sensor Cost Calc
☀️
Solar Panel Monitor — Production vs Consumption
วัดกำลังผลิตจาก solar panel (CT sensor ที่ inverter output) และการใช้งานในบ้าน (PZEM-004T ที่ main breaker) พร้อมกัน คำนวณ grid import/export อัตโนมัติ บน ESP32-S3 + e-Paper display
Solar Net Metering Inverter
🏭
Industrial 3-Phase Power Monitor
ใช้ PZEM-004T 3 ตัว วัดทั้ง 3 phase พร้อมกัน หาค่า unbalance และ power factor รวม เหมาะกับโรงงานที่มีมอเตอร์ 3 phase ส่งข้อมูลผ่าน Modbus TCP ไปยัง SCADA ได้โดยตรง

Motor Control & Robotics — BLDC, Stepper & Servo

Hardware
ESP32 MCPWM (Motor Control PWM) เป็น hardware peripheral พิเศษที่ออกแบบมาสำหรับ motor control โดยเฉพาะ รองรับ dead-time generation, fault protection, capture และ sync กับ ADC ได้ ทำให้ ESP32 เป็นตัวเลือกที่ทรงพลังสำหรับงาน robotics และ automation ราคาต่ำ
🌀
espFoC v2.0 — Field-Oriented Control สำหรับ BLDC
Library FOC สำหรับ PMSM/BLDC บน Espressif Component Registry velocity loop และ position loop ผ่าน callback ให้ app กำหนดเอง ใช้ MCPWM hardware บน ESP32 ประสิทธิภาพสูง เหมาะกับ drone, electric skateboard และ CNC spindle
FOC BLDC MCPWM v2.0.0
📐
ESP-FlexyStepper — Stepper ที่ยืดหยุ่น
Library stepper motor แบบ non-blocking, smooth acceleration/deceleration รองรับ position, velocity และ homing mode ผ่าน FreeRTOS task ใช้กับ A4988, DRV8825, TMC2208/2209 ได้ทันที เหมาะกับ 3D printer, CNC, pick-and-place
Stepper Non-blocking TMC2209
🔧
ESP-StepperMotor-Server — Web UI + REST API
สร้าง stepper motor controller แบบ standalone ที่มี web interface, REST API และ serial control ในตัว เปิด browser ก็ควบคุม motor ได้ทันที ไม่ต้องเขียน code เพิ่ม อัปเดตล่าสุด กุมภาพันธ์ 2026
Web UI REST API Standalone
🎮
DJIMotorCtrlESP — ควบคุมมอเตอร์ DJI
Library ESP32 สำหรับควบคุม DJI M3508, M2006 และ GM6020 ผ่าน CAN bus มอเตอร์เหล่านี้มี encoder built-in และ torque control ที่แม่นยำ เหมาะกับ robot arm, competition robot (RoboMaster) ต้องใช้ CAN transceiver (TJA1050/MCP2551)
DJI Motor CAN Bus RoboMaster
⚙️
NocMotion — Professional Motor Library
Library ใหม่ (เม.ย. 2026) ที่อ้างว่า professional-grade รองรับ ESP32 และ Arduino สำหรับ motor control หลากหลายรูปแบบ ยังเป็น community project ขอแนะนำให้ทดสอบก่อนใช้งาน production
Multi-motor Apr 2026 Arduino Compat
🦾
ไอเดีย: 6-DOF Robot Arm ราคาต่ำ
ใช้ ESP32 + 6× servo MG996R + PCA9685 PWM expander ควบคุมผ่าน inverse kinematics library บน ESP32-S3 (512KB RAM) รับคำสั่งจาก computer ผ่าน WebSocket หรือ BLE งบประมาณเริ่มต้นประมาณ 1,500–2,500 บาท
6-DOF IK WebSocket ต้นทุนต่ำ

🔄 Pattern: Battery e-Paper Dashboard ด้วย Deep Sleep
⏰
1. Wake Up
Timer หรือ external trigger ปลุก ESP32 จาก deep sleep
📡
2. Fetch Data
เชื่อม Wi-Fi, ดึงข้อมูลจาก sensor หรือ API (~1-3 วินาที)
🖥️
3. Draw
render หน้าจอด้วย LVGL หรือ Adafruit GFX (~2-5 วินาที)
💤
4. Sleep
เข้า deep sleep ทันที กินไฟ <10 µA นาน 5–60 นาที
⚡ ใช้เวลา active เพียง ~5 วินาที ต่อรอบ แบตเตอรี่ 3000 mAh อยู่ได้ 2–6 เดือน ที่ refresh ทุก 15 นาที
