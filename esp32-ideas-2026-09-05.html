Deep Dive: LoRaWAN Node ด้วย ESP32-S3 + SX1262

ขั้นตอนสร้าง Long-Range Sensor Node ส่งข้อมูลได้ไกล 10–15 กิโลเมตร

⚙️ Hardware ที่ต้องการ

Heltec WiFi LoRa 32 V3 (มี ESP32-S3 + SX1262 ในบอร์ดเดียว) หรือ XIAO ESP32-S3 + Wio-SX1262 Module รวมค่าใช้จ่ายเริ่มต้นประมาณ $10–$15 พร้อมเสาอากาศ LoRa 868/915 MHz และแบตเตอรี่ 3.7V LiPo

  1. ติดตั้ง Arduino IDE พร้อม ESP32 Board Package v3.x และ Library: RadioLib หรือ LoRaWAN-Arduino
  2. ลงทะเบียน Device บน The Things Network (TTN) หรือ Chirpstack Server รับ DevEUI, AppEUI, AppKey มาใส่ใน Code
  3. เขียน Code OTAA Join ให้ Node ขอ Join Network แล้วส่งข้อมูลทุก 5 นาที ตาม Duty Cycle ของ LoRaWAN
  4. ใช้ Deep Sleep ระหว่างรอส่งข้อมูล ลดการใช้พลังงานเหลือ 10–50 µA ทำให้แบตฯ 2000mAh อยู่ได้หลายปี
  5. ดูข้อมูลบน Dashboard ผ่าน TTN Console หรือเชื่อม Grafana / Node-RED สำหรับ Visualization

📟 ตัวอย่าง Code: ส่งข้อมูล Temperature ผ่าน LoRaWAN (RadioLib)

Arduino IDE
// ESP32-S3 + SX1262 LoRaWAN Sensor Node // ใช้ RadioLib Library + OTAA Join #include <RadioLib.h> #include <DHT.h> // SX1262 pins สำหรับ Heltec WiFi LoRa 32 V3 SX1262 radio = SX1262(8, 9, 13, 12); // NSS, DIO1, NRST, BUSY LoRaWANNode node = LoRaWANNode(&radio, &EU868); DHT dht(4, DHT22); const uint64_t joinEUI = 0xYOUR_JOIN_EUI; const uint64_t devEUI = 0xYOUR_DEV_EUI; const uint8_t appKey[] = { 0x00, ... }; // 16 bytes const uint8_t nwkKey[] = { 0x00, ... }; void setup() { Serial.begin(115200); dht.begin(); radio.begin(); // Init SX1262 node.beginOTAA(joinEUI, devEUI, nwkKey, appKey); node.activateOTAA(); // Join Network } void loop() { float temp = dht.readTemperature(); float hum = dht.readHumidity(); // Pack data: temp*10 + humidity*10 (2 bytes each) uint8_t data[4]; int16_t t = (int16_t)(temp * 10); int16_t h = (int16_t)(hum * 10); data[0] = t >> 8; data[1] = t & 0xFF; data[2] = h >> 8; data[3] = h & 0xFF; node.sendReceive(data, sizeof(data), 1); // Port 1 // Deep sleep 5 นาที ประหยัดพลังงาน esp_deep_sleep(5 * 60 * 1000000ULL); }
📊

ข้อมูลที่ส่งผ่าน LoRaWAN จะถูกรับที่ TTN Gateway และส่งต่อไปยัง Node-RED หรือ Grafana สำหรับแสดงผล Dashboard สามารถรับข้อมูลจาก Node ได้หลายพันตัวพร้อมกันผ่าน Gateway เดียว
