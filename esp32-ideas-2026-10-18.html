ESPHome 2026.9.0

Faster Builds & Encrypted OTA — รีลีสกันยายน 2026

ESPHome 2026.9.0 ออกมาเมื่อ 16 กันยายน 2026 ประกอบด้วย 6 component ใหม่ และการปรับปรุงกว่า 20 รายการ โดยจุดเด่นหลักคือการ compress OTA upload บน ESP32, RP2040, LibreTiny และ Host — ลดขนาด firmware ที่ส่งผ่านอากาศได้อย่างมีนัยสำคัญ

ฟีเจอร์ใหม่ที่น่าสนใจ: รองรับ Fahrenheit สำหรับ mitsubishi_cn105, ตัวเลือก continuous สำหรับ modbus_client, และ tcp_send_buffer ใน network component — ปรับ buffer ขนาดการส่งข้อมูล TCP ได้เอง
OTA Compress Modbus ESP32 ESP8266
ESPHome Beta

ESPHome 2026.10 Beta — BLE Tracking & ESP8266 Toolchain

ESPHome 2026.10 beta 3 (12 ต.ค.) แก้ไขบั๊กสำคัญ: ESP32 BLE connection tracking ที่ฆ่าการเชื่อมต่อ BLE ผิดพลาด และลด RAM ใช้งานบน ESP8266 ให้น้อยลง

เวอร์ชัน 2026.9 ยังนำ scaffolding สำหรับ ESP8266 native toolchain มาด้วย — เตรียมพร้อมสำหรับการเปลี่ยน build system ในอนาคต

Breaking Change ESPHome 2026.4: เปลี่ยน default เป็น RISC-V compiler สำหรับ ESP32 ซึ่งเร็วกว่า แต่อาจทำให้ binary เก่าไม่เข้ากัน — compile ใหม่ทั้งหมด!
ESP32-S31

ESP32-S31 Touchscreen Development Board — Wi-Fi 6 ครบสูตร

บอร์ดใหม่บน ESP32-S31 chip มาพร้อม จอ IPS 4.3" 800×480 รองรับ Wi-Fi 6, BLE 5.4, Zigbee, Thread ในชิปตัวเดียว ราคาประมาณ $39 — เหมาะสำหรับ HMI และ dashboard display สำหรับ smart home

จุดน่าสนใจ: มาพร้อม ESP-IDF, LVGL และตัวอย่างโปรเจกต์ 18 โปรเจกต์สำเร็จรูป รองรับ Arduino IDE กำลังพัฒนา — อาจเป็นตัวแทน M5Stack ราคาประหยัด
Wi-Fi 6 LVGL Matter HMI Thread
ESP32-C6

ESP32-C6 เป็น Zigbee Coordinator ด้วย Chip เดียว

ESP32-C6 มี radio 802.15.4 ในตัว — รัน Zigbee, Thread พร้อมกัน Wi-Fi 6 บนชิปเดียว ทำให้สามารถสร้าง Zigbee Coordinator สำหรับ Home Assistant โดยไม่ต้องใช้ dongle USB แยก

ข้อสังเกต: output เริ่มต้นเพียง +3 dBm — ควรใช้ external antenna สำหรับบ้านที่มีผนังหลายชั้น หรือพิจารณา ESP32-H2 สำหรับ Zigbee เฉพาะทาง

Zigbee Home Assistant ZHA SEEED XIAO Coordinator

Solar + MPPT

ESP32-C6 Solar Node Board — BQ25186 MPPT Charger

Circuitrocks ออกแบบบอร์ด solar node บน ESP32-C6 Mini พร้อม TI BQ25186 single-cell linear charger — มี reverse-voltage protection และ QWIIC I2C connector สำหรับเชื่อม sensor ภายนอก

แนวทาง firmware: ตั้งค่า deep sleep ระหว่างการอ่านค่า ตื่นทุก 15–30 นาที ส่งข้อมูล แล้วกลับไปนอน

Off-Grid Weather

ESP32 + BME280 — สถานีอุตุนิยมวิทยาไม่ต้องพึ่งไฟบ้าน

บทความ June 2026 จาก ShillehTek สร้าง weather station แบบ off-grid สมบูรณ์: วัด อุณหภูมิ, ความชื้น, ความดันอากาศ ด้วย BME280 ส่งข้อมูลผ่าน Wi-Fi ขึ้น dashboard ฟรี

ครอบคลุมการคำนวณ solar panel sizing, MPPT charging, battery protection circuit และการตั้งค่า deep sleep ให้ทนทานตลอดฤดูหนาว

Battery Life Estimate: ด้วย 2,000 mAh + deep sleep ส่งข้อมูลทุก 10 นาที คาดว่าอยู่ได้ มากกว่า 1 ปี โดยไม่ต้องมีแผงโซลาร์เสริม
LoRa Farm

Solar-Powered LoRa Farm Sensor Node — ฟาร์มระยะไกล

Zbotic เผยแพร่ design สำหรับ smart farm sensor ที่ไม่ต้องวิ่งสายไฟ: ESP32 ตื่นทุก 15–30 นาที อ่านค่า sensor แล้วส่งผ่าน LoRa กลับไปนอนต่อ — ลด average current จาก 120 mA เหลือ ใต้ 1 mA

เหมาะสำหรับฟาร์มที่ไม่มีสัญญาณ Wi-Fi — LoRa ส่งได้ไกล 2–10 กม. ในพื้นที่โล่ง ด้วยแผงโซลาร์ขนาดเล็กเพียง 1–2W

Deep Sleep Tips

Deep Sleep Best Practices — ออกแบบให้ประหยัดสุด

ข้อมูลจาก Espressif forum และ DFRobot: ใน deep sleep mode ระบบปิด CPU, Wi-Fi, Bluetooth และ Main RAM ทั้งหมด — ใช้แค่ RTC module, ULP co-processor และ RTC memory

Wake Sourceใช้งาน
Timerตั้งเวลาตื่น เช่น ทุก 10 นาที
GPIO Pinตื่นเมื่อมีสัญญาณ เช่น ปุ่มกด
ULP Co-Processorรัน script เล็กๆ ตรวจ sensor แล้วปลุก CPU
ข้อควรระวัง: RTC clock drift สูงสุด ~5% ในโหมด deep sleep — เพิ่ม external 32 kHz crystal เพื่อความแม่นยำ หากต้องการ timestamp ที่เที่ยงตรง

Air Quality & Environmental Sensors

ตัวเลือก sensor วัดคุณภาพอากาศสำหรับ ESP32

Particle Sensor

PMS5003 / PMS7003 — วัด PM2.5 แม่นยำสูง

Laser particle sensor จาก Plantower ที่นิยมที่สุด วัด PM1.0, PM2.5, PM10 ด้วยหลักการ laser scattering — เชื่อมต่อ ESP32 ผ่าน UART ง่ายมาก

โปรเจกต์ portable monitor ใช้ PMS7003 + ESP32 แปลงค่าดิบเป็น AQI ตามสูตร NAAQS แสดงบน OLED 0.96" และอัปโหลด ThingSpeak

Gas Sensor

SDS011 + MQ135 + DHT22 — ชุด PM2.5 + Gas ครบ

งานวิจัย 2026 ใช้ชุด sensor สามตัวร่วมกับ ESP32: SDS011 (PM2.5/PM10 laser), MQ135 (CO, CO₂, VOC), DHT22 (อุณหภูมิ/ความชื้น) — รายงานความแม่นยำหลัง calibration ที่ 85%+ เทียบกับเครื่องมาตรฐาน

คำเตือน MQ-series: sensor ประเภทนี้มี cross-sensitivity สูง — อุณหภูมิ และความชื้นส่งผลต่อการอ่านค่า ควร calibrate ในสภาพแวดล้อมจริงก่อนใช้งาน
Weather Station

ESP32 + BME280/680 — Multi-Sensor Environmental Station

งานวิจัย TELKOMNIKA ออกแบบ ESP32 weather station วัด 6 ค่า: wind speed, wind direction, humidity, temperature, pressure, rainfall และ UV index — ส่งผ่าน GSM/MQTT ขึ้น dashboard

BME680 (รุ่นอัพเกรดจาก BME280) เพิ่ม VOC gas sensor ในชิปเดียว คำนวณ IAQ (Indoor Air Quality) ได้โดยตรงผ่าน Bosch BSEC library

BME280 BME680 UV Index MQTT BSEC
Tools

ESPConnect & ESPWebApps — จัดการ ESP32 ผ่านเบราว์เซอร์

ESPConnect (GitHub trending 2026): Zero-install web app ที่ช่วย explore, backup และ manage ESP32 ผ่าน browser โดยตรง — ไม่ต้องลง IDE

ESPWebApps: community-driven firmware hub รองรับ WebSerial flashing ผ่าน browser — นักพัฒนา contribute app ได้โดยตรง มี workflow มาตรฐาน

Use Case: เหมาะสำหรับ maker ที่ต้องการ flash firmware ให้ผู้อื่นโดยไม่ต้องติดตั้ง driver หรือ IDE — แค่มี Chrome/Edge ก็พอ
