Ultra-Wideband

ESP32 + UWB DW3000 — Indoor Positioning แม่นยำ 10 ซม.

การรวม ESP32 กับชิป Decawave DW3000 กำลังปฏิวัติวงการ Real-Time Location System (RTLS) ด้วยความแม่นยำระดับเซนติเมตร เหนือกว่า BLE (1-3 ม.) และ Wi-Fi หลายเท่า

ความแม่นยำ~10 ซม. (เฉลี่ย)
ช่องสัญญาณChannel 5 (6.5GHz) / 9 (8GHz)
หลักการTime-of-Flight (ToF) + TWR
กินไฟ1/3 ของ DW1000 รุ่นเก่า
ใช้กับApple U1 interoperable
ทำไมถึงสำคัญ: UWB ทะลุผ่านวัตถุได้ดี ไม่ได้รับผลกระทบจาก multipath เหมาะกับโกดัง โรงงาน และโรงพยาบาล 
// ESP32 + DW3000 — Double-Sided TWR
#include "DW3000.h"

void setup() {
  DW3000.begin();
  DW3000.setChannel(DW3000_CHANNEL_5);
  DW3000.setTxAntennaDelay(16385);
  DW3000.setRxAntennaDelay(16385);
}

// หน่วย: picoseconds → เมตร

  • ESP32+DW3000 Module × 5 (4 Anchor + 1 Tag)

SOFTWARE STACK

  • ESP-IDF + DW3000 library (Makerfabs)
  • MQTT → Node-RED
  • InfluxDB + Grafana Dashboard

🚗 Smart Parking System — ที่จอดรถอัจฉริยะ MQTT + Web App

ระบบจอดรถอัจฉริยะด้วย HC-SR04 ultrasonic ตรวจจับรถ + Servo ควบคุมไม้กั้น + LED แสดงสถานะ + Web App แบบ Real-time สำหรับอาคารพาณิชย์ หอพัก หรือโรงแรมขนาดเล็ก

อุปกรณ์ต่อช่องจอด

  • HC-SR04 Ultrasonic × 1 ตัว/ช่อง
  • LED RGB แสดงสถานะ (ว่าง/ไม่ว่าง)
  • ESP32 1 ตัว ต่อได้ 4–8 ช่องจอด
  • SG90 Servo สำหรับไม้กั้นทางเข้า

ฟีเจอร์ระบบ

  • MQTT publish สถานะทุก 5 วินาที
  • Web Dashboard แผนผังที่จอดรถ
  • แจ้งเตือน Line/Telegram เมื่อเต็ม
  • บันทึกสถิติการใช้งาน (InfluxDB)
เพิ่มระดับ: เพิ่มกล้อง ESP32-CAM + OCR จดจำทะเบียนรถ เชื่อมกับระบบบัตรสมาชิก ประยุกต์ใช้กับ AWS Rekognition สำหรับ License Plate Recognition

NFC / RFID

🔖 NullTag DIY NFC Toolkit — อ่าน/เขียน/วิเคราะห์ Tag ด้วย ESP32 + PN532

NullTag เป็น open-source toolkit บน ESP32 + PN532 NFC module สำหรับนักวิจัยด้านความปลอดภัยและ maker อ่าน MIFARE Classic, NTAG, ISO 14443 ได้หลากหลาย พร้อม P2P mode รับส่งข้อมูลกับมือถือ Android

ความสามารถ PN532

  • อ่าน/เขียน MIFARE Classic (1K/4K)
  • NTAG 213/215/216 (NFC Business Card)
  • ISO 14443 Type A & B
  • NFC Peer-to-Peer (P2P) กับ Android

ประยุกต์ใช้

  • ระบบ Access Control ห้องสำนักงาน
  • NFC Business Card แบบ Interactive
  • ติดตามสินทรัพย์ด้วย NFC Tag
  • เพย์เมนต์ prototype / Loyalty card
Interface: PN532 รองรับ I2C, SPI, UART — สำหรับ ESP32 แนะนำ SPI (เร็วที่สุด) ใช้ library Adafruit PN532 ซึ่ง compatible กับ Arduino core ESP32

CO₂ Sensor

SCD41 — True CO₂ Sensor (Sensirion)

เซนเซอร์วัด CO₂ แบบ NDIR ขนาดเล็กที่สุดในตลาด วัดแม่นยำถึง ±40 ppm พร้อม temperature/humidity ในตัว เดียว — ไม่ใช่ eCO₂ จาก VOC แต่เป็น CO₂ จริง

หลักการPASens® (NDIR photoacoustic)
Range400–5,000 ppm
ความแม่นยำ±40 ppm ±5% reading
InterfaceI2C (0x62)
กินไฟ3.2 mA เฉลี่ย (5s interval)
ราคา~$15–20 USD
// Sensirion Arduino Library
#include "SensirionI2CScd4x.h"
SensirionI2CScd4x scd4x;

uint16_t co2; float temp, humidity;
scd4x.readMeasurement(co2, temp, humidity);
Serial.printf("CO2: %d ppm\n", co2);

Particle Sensor

PMS7003 — PM1 / PM2.5 / PM10 Particle Counter

Laser particle counter จาก Plantower วัดอนุภาคฝุ่นละเอียด 3 ขนาดพร้อมกัน ใช้กันแพร่หลายในโปรเจกต์คุณภาพอากาศ ราคาถูก ข้อมูลแม่นยำ

วัดได้PM1.0, PM2.5, PM10 (µg/m³)
Range0–1,000 µg/m³
ความแม่นยำ±15% หรือ ±10 µg/m³
InterfaceUART 9600 baud
Response time<1 วินาที
ราคา~$10–15 USD
