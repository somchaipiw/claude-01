TensorFlow Lite Micro (TFLM) บน ESP32-S3

รัน ML model โดยตรงบน ESP32-S3 (512 KB SRAM + PSRAM ถึง 8 MB) โดยไม่ส่งข้อมูลขึ้น Cloud เลย TFLM ใช้ RAM ขั้นต่ำเพียง 16 KB เหมาะกับ keyword spotting, gesture recognition, anomaly detection บน MCU ราคาถูก ประมวลผล audio window 1 วินาทีใน 30–100 ms

TFLite Micro ESP32-S3 Edge AI No Cloud
👋

Gesture Recognition ด้วย IMU + TFLM

ใช้ MPU-6050 หรือ ICM-42688 ส่งข้อมูล 6-DoF ให้ ESP32-S3 ประมวลผลด้วย TFLM แยกแยะท่ามือได้ถึง 10+ gesture แบบ real-time ใช้สำหรับควบคุมอุปกรณ์ smart home, สั่งงานไฟฟ้า, หรือเป็น HMI ที่ไม่ต้องสัมผัส เหมาะมากสำหรับ hospital หรือ clean room

MPU-6050 TFLM IMU Gesture
🔊

Keyword Spotting ด้วย ESP32-S3 + Microphone

ตรวจจับคำสั่งเสียง (wake word) ด้วย INMP441 digital microphone + TFLM โดยไม่ต้องอินเทอร์เน็ต Model DS-CNN ขนาดเล็กสามารถแยกแยะ 10–20 คำได้ accuracy >90% ESP32-S3 มี hardware audio accelerator ช่วยลดการใช้พลังงานขณะ inference

INMP441 DS-CNN Wake Word Offline

Vibration Anomaly Detection — ตรวจเครื่องจักรด้วย AI

ติด ADXL345 หรือ IIS3DWB vibration sensor บน motor หรือ pump แล้วให้ ESP32-S3 รัน autoencoder TFLM model ตรวจหา anomaly ก่อนเครื่องจักรพัง ประหยัดค่าซ่อมได้มหาศาล เหมาะกับโรงงานที่ต้องการ Predictive Maintenance ราคาถูก

ADXL345 Autoencoder Predictive Maintenance Industry 4.0

Wearable Stress Detection — PPG + ML

รวม MAX30102 (PPG/SpO2) + MPU-6050 (accelerometer) ให้ ESP32-S3 วิเคราะห์ HRV (Heart Rate Variability) แล้วประเมินระดับความเครียดด้วย TFLM model trained จาก physiological dataset ข้อมูลอยู่บน device ไม่รั่วออกนอก privacy-first wearable

MAX30102 HRV Wearable Privacy

Sensor Fusion — รวม Sensors ให้ฉลาดกว่าใช้ตัวเดียว

Sensor Fusion คือการรวมข้อมูลจาก sensors หลายตัว (เช่น temp + humidity + CO2 + light) เข้าด้วยกันด้วย Kalman Filter หรือ complementary filter ทำให้ได้ค่าที่แม่นยำกว่า และ ESP32 สามารถรัน fusion algorithm นี้ได้ real-time ตัวอย่างเช่น indoor air quality score จาก 4 sensors

Kalman Filter Multi-Sensor Fusion IAQ

ระบบ Water Quality Monitor — TDS + pH + Turbidity

ESP32 + เซนเซอร์ TDS (Total Dissolved Solids) + pH probe + turbidity sensor ตรวจคุณภาพน้ำ real-time จัดระดับเป็น 3 สถานะ: ปลอดภัย / เตือน / อันตราย ส่งข้อมูลขึ้น Cloud แสดงผลบน dashboard เหมาะสำหรับบ่อปลา, สวน hydroponic, แหล่งน้ำดื่ม

TDS Sensor pH Probe Turbidity Aquaculture

Autonomous Aquaponics Monitor — Solar Powered

ระบบ aquaponics อัตโนมัติพลังงานแสงอาทิตย์ ESP32 + solar panel + LiFePO4 battery ควบคุมปั๊มน้ำ ตรวจ DO (Dissolved Oxygen), อุณหภูมิน้ำ, pH, แอมโมเนีย แจ้งเตือนผ่าน LINE Notify เมื่อค่าผิดปกติ ทำงานได้โดยไม่ต้องมีไฟบ้านใกล้เคียง

DO Sensor Solar LiFePO4 LINE Alert

Smart Hydroponic Controller — EC + pH Automation

ควบคุม nutrient solution ใน hydroponic อัตโนมัติด้วย ESP32 วัดค่า EC (Electrical Conductivity) ด้วย Atlas Scientific EZO-EC และ pH ด้วย EZO-pH สั่งงาน peristaltic pump เพิ่ม nutrient หรือ pH adjuster โดยอัตโนมัติตามค่าที่ตั้ง พร้อม web dashboard บน ESP32

Soil Moisture + NPK Sensor Node LoRa Mesh

กระจาย node ESP32 + SX1262 LoRa ทั่วไร่นา แต่ละ node มี capacitive soil moisture sensor + NPK sensor (ไนโตรเจน-ฟอสฟอรัส-โพแทสเซียม) ส่งข้อมูลผ่าน LoRa mesh ทุก 15 นาที Gateway รวบรวมข้อมูลส่งขึ้น MQTT broker พร้อม map แสดงสุขภาพดินทั้งไร่

Greenhouse Multi-Zone Environmental Monitor

AS7343 Spectral Sensor — วิเคราะห์สีและแสง 14 ช่อง
