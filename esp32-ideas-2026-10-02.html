🔥 Breakthrough ประจำสัปดาห์

LLM 28.9 ล้าน Parameter รันบน ESP32-S3 — ที่ 9.5 token/วินาที!

ไม่ต้องพึ่งคลาวด์อีกต่อไป! นักพัฒนาจาก runaihome.com สาธิตการรัน Tiny LLM ขนาด 28.9M parameter บนชิป ESP32-S3 ราคาเพียง $8 โดยใช้ PSRAM 8 MB และ INT8 Quantization ได้ความเร็ว 9.5 tok/s — เพียงพอสำหรับ chatbot คำสั่งงาน, ตอบโต้ sensor alert และ Edge NLP โดยไม่ส่งข้อมูลออกเครือข่ายเลย

ESP32-S31

LE Audio Unicast + Broadcast บน ESP32-S31

Espressif ปล่อย demo ใหม่สำหรับ ESP32-S31 ที่รวม Classic Bluetooth A2DP และ LE Audio (Bluetooth 5.2+) เอาไว้ในชิปเดียว รองรับ Unicast (ต่อหูฟังโดยตรง) และ Broadcast (Auracast) — ส่งเสียงไปยังผู้รับหลายคนพร้อมกันโดยไม่ต้อง Pair

  • Classic BT A2DP + AVRCP พร้อมเมตาดาต้าเพลง
  • LE Audio Unicast: หูฟัง 2 ข้างซ้าย-ขวา sync
  • Broadcast Auracast: ส่งเสียงไปโรงภาพยนตร์ / โรงพยาบาล
  • HFP Two-Way Call พร้อม echo cancellation
ESP-IDF v5.5.5

ESP-IDF v5.5.5 — Security Patch สำคัญ (กรกฎาคม 2569)

รีลีสแบบ Bugfix ที่สำคัญมากสำหรับโปรเจกต์ Production:

  • Unencrypted PSRAM Option — ตั้งค่า PSRAM ไม่เข้ารหัสได้ เพิ่มประสิทธิภาพบางกรณี
  • jpeg_decoder ป้องกัน Buffer Attack — ตรวจสอบ header ที่ผิดรูปแบบก่อนถอดรหัส
  • ECDSA Secure Boot V2 ถูกปิด บน ESP32-H2, C5, P4 — พบช่องโหว่ ควรอัปเดตทันที
  • แนะนำอัปเดตจาก v5.5.x ทุก Production Device โดยด่วน
TinyML

Plumerai People Detection — ตรวจจับ 20 คน ที่ระยะ 20 เมตร

โมเดล Plumerai People Detection (quantized INT8) รันบน ESP32-S3 ด้วย TensorFlow Lite Micro สามารถตรวจจับคนได้ถึง 20 คนพร้อมกัน ในระยะไกลกว่า 20 เมตร โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต เหมาะสำหรับระบบนับคนเข้า-ออก, ตรวจสอบ Social Distancing และ Smart Retail Analytics

  • Edge Impulse สนับสนุน deployment บน ESP32-S3 แบบ one-click
  • ใช้ PIE Vector Instructions เร่งความเร็ว MAC operation
  • ทำงานคู่กับ ESP32-P4 AI Accelerator ได้ดียิ่งขึ้น
Industrial

ESP-IDF v6.0 MCP Server — AI Coding Assistant สำหรับ Firmware

ESP-IDF v6.0 เพิ่ม MCP (Model Context Protocol) Server built-in ทำให้เชื่อมต่อกับ AI Development Tools เช่น Claude, Copilot, Cursor ได้โดยตรง AI ช่วย generate boilerplate, อธิบาย API, debug และแนะนำ config ได้แบบ context-aware

  • เชื่อมต่อกับ IDE ผ่าน stdio transport
  • ให้ข้อมูล chip capabilities, peripheral pinout, API reference
  • ช่วยวิเคราะห์ stack trace และ crash log อัตโนมัติ

Wearable Safety

TrailGuard — Smart Hiking Safety Wearable

อุปกรณ์ Wearable สำหรับนักปีนเขา/เดินป่า ติด ESP32 + IMU Gyroscope + GPS ตรวจจับการล้มอัตโนมัติด้วย threshold ของ angular velocity เมื่อตรวจพบ — ส่งพิกัด GPS ผ่าน Blynk IoT Platform ให้ผู้ติดต่อฉุกเฉิน

  • MPU6050 / ICM42688-P ตรวจจับ fall event ด้วย interrupt
  • NEO-6M / L76K GPS module แนบท้ายพิกัด Google Maps
  • กด Cancel ภายใน 10 วินาที หากเป็นการสะดุดเล็กน้อย
  • Battery 300 mAh + deep sleep → ใช้งาน 24–48 ชั่วโมง
Astronomy IoT

Light Pollution Meter — วัดความสว่างท้องฟ้าคืน

โปรเจกต์ที่หายาก! ใช้ TSL237 Light-to-Frequency Sensor หรือ SQM (Sky Quality Meter) วัดค่า mpsas (magnitudes per square arcsecond) ของท้องฟ้า บันทึกพร้อม GPS พิกัดและ BME280 สภาพอากาศ ส่งขึ้น MQTT → InfluxDB → Grafana

  • แผนที่ Light Pollution ชุมชนแบบ crowd-sourced
  • ช่วยเลือก site ดูดาว / กล้องโทรทรรศน์
  • LoRa ส่งข้อมูลจากพื้นที่ห่างไกลไม่มี WiFi
  • ต้นทุน: TSL237 ≈ 150 บาท + ESP32 C3 mini
Smart Farm

Plant Growth Recorder — บันทึกการเจริญเติบโตพืชด้วย AI

ระบบ time-lapse อัตโนมัติพร้อม sensor fusion: ESP32-CAM + BME280 + BH1750 + UV-Index Sensor ถ่ายภาพทุก 30 นาที พร้อมบันทึก Temp/Humidity/Pressure/Light/UV ให้ AI วิเคราะห์ว่าปัจจัยใดส่งผลต่ออัตราการเติบโตมากที่สุด

  • OV2640 + SD Card บันทึกภาพ + JSON data log
  • BH1750 วัด lux แม่นยำ, GUVA-S12SD วัด UV Index
  • Dashboard Node-RED แสดง timeline growth + สภาพแวดล้อม
  • Export ข้อมูลเป็น CSV สำหรับ Google Sheets / Excel
Industrial

ESP32 Modbus Gateway — เชื่อมต่อ PLC โรงงานสู่ Cloud

ESP32 + SN65HVD230 (RS-485) ทำหน้าที่เป็น Protocol Converter รับข้อมูลจาก PLC/sensor เก่าผ่าน Modbus RTU (RS-485) หรือ Modbus TCP แปลงเป็น MQTT ส่งขึ้น AWS IoT / ThingsBoard / Home Assistant

  • รองรับ Modbus Function Code 01–04 (Coil, Register)
  • Auto-detect baud rate 9600–115200 bps
  • FOTA update และ Watchdog timer สำหรับ unattended operation
  • รองรับโรงงาน, ฟาร์ม, ระบบน้ำประปา — PLC Siemens/Mitsubishi
Audio AI

ESP32 Anomaly Sound Detector — ตรวจจับเสียงผิดปกติในโรงงาน

ใช้ INMP441 I²S MEMS Microphone + TinyML (Edge Impulse) เทรนโมเดลให้รู้จัก "เสียงปกติ" ของเครื่องจักร เมื่อเกิดเสียงผิดปกติ (เบียริงสึก, belt หลุด) จะแจ้งเตือนผ่าน LINE Notify / MQTT ทันที เป็น Predictive Maintenance ราคาประหยัดสุด

  • INMP441 ราคา ≈ 80 บาท — ไม่ต้องใช้ ADC เพราะเป็น I²S ดิจิทัล
  • Edge Impulse spectral analysis / MFCC feature extraction
  • Accuracy > 95% บน ESP32-S3 (8 MB PSRAM)
  • ติดตั้งด้วย 3M tape ข้างมอเตอร์/คอมเพรสเซอร์
Smart Home

Tiny LLM Voice Assistant — Offline AI Speaker ราคาไม่ถึง 500 บาท

ผสาน Tiny LLM บน ESP32-S3 กับ INMP441 microphone และ MAX98357 I²S Amplifier สร้าง Voice Assistant ทำงาน 100% Offline ไม่มีค่าบริการรายเดือน ไม่ส่งข้อมูลออกบ้าน ควบคุม Home Assistant ด้วยเสียงและตอบโต้ด้วยประโยคสั้นๆ

  • Wake word detection ด้วย MicroWakeWord บน ESP32-S3
  • STT → Tiny LLM inference → TTS ทั้งหมดบนชิปเดียว
  • รองรับภาษาไทยได้ระดับหนึ่ง (fine-tune กับ dataset ภาษาไทย)
  • ต้นทุนรวม: XIAO ESP32-S3 (≈350฿) + INMP441 + MAX98357

ToF Sensor

VL53L5CX — Eyes ของ ESP32

ST Microelectronics VL53L5CX เป็น Time-of-Flight Matrix Sensor วัดระยะ 64 จุดพร้อมกัน (8×8 grid) ในระยะ 0–400 cm ใช้ detect presence, count people, hand gesture และ obstacle avoidance สำหรับ Robot

// ตัวอย่าง I²C setup สำหรับ VL53L5CX #include <SparkFun_VL53L5CX.h> SparkFun_VL53L5CX sensor; sensor.begin(Wire, 400000); // 400kHz I²C sensor.setResolution(64); // 8x8 sensor.startRanging();
Magnetic Encoder

AS5600 — วัดมุมหมุนแบบไม่สัมผัส

AS5600 เป็น 12-bit magnetic rotary encoder อ่านมุม 0–360° ผ่าน I²C ไม่มีชิ้นส่วนสัมผัสกัน อายุการใช้งานยาวนาน ใช้กับมอเตอร์ BLDC, ปุ่มหมุน encoder, หัวหุ่นยนต์, pan-tilt camera mount

  • ติดแม่เหล็ก diametric บน shaft โดยตรง
  • Output: raw angle, RPM, direction
  • ราคาเพียง 100–150 บาท บน AliExpress
Safety Sensor

MQ-7B — CO Detector สำหรับบ้านและโรงงาน

Carbon Monoxide เป็น "ฆาตกรเงียบ" ตรวจไม่ได้ด้วยประสาทสัมผัสมนุษย์ MQ-7B วัด CO ช่วง 10–500 ppm ต่อกับ ADC ESP32 ได้เลย ตั้ง threshold > 35 ppm แจ้งเตือน LINE ทันที — โปรเจกต์ช่วยชีวิตได้จริง

  • ต้องใช้ heater cycle (5V 60 วินาที / 1.4V 90 วินาที)
  • ราคา 80–130 บาท — คืนทุนด้วยความปลอดภัย
  • สร้าง CO Alert Dashboard บน Grafana
