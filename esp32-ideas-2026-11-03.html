📶 ESP32-C6 — Wi-Fi 6 + Matter over Thread + Zigbee 3.0 ในชิปเดียว

ESP32-C6 เป็น SoC จาก Espressif ที่รวม Wi-Fi 6 (802.11ax) กับ IEEE 802.15.4 ไว้ในชิปเดียว ทำให้รองรับ Thread 1.3, Zigbee 3.0 และ Matter ได้พร้อมกัน ซึ่งเป็นมาตรฐาน smart home ที่ Apple, Google และ Amazon ร่วมกันพัฒนา อุปกรณ์ที่ใช้ Matter จะทำงานข้ามแพลตฟอร์มได้โดยไม่ต้องพึ่ง hub เฉพาะแบรนด์

สำคัญ: ESP32-C61 เป็นรุ่นแยกที่มีแค่ Wi-Fi + BLE เท่านั้น — ไม่มี 802.15.4 ดังนั้นถ้าต้องการ Thread/Zigbee ต้องเลือก C6 จริงๆ ระวังสับสนชื่อรุ่น
Protocolรายละเอียดใช้งานกับ
Wi-Fi 6 2.4 GHz, TWT (Target Wake Time) ประหยัดไฟ MQTT, HTTP, OTA
Bluetooth 5 LE Long range, advertising extension Provisioning, BLE Mesh
Zigbee 3.0 IEEE 802.15.4, mesh topology, ≤250 kbps Smart bulb, switch, sensor
Thread 1.3 IPv6 mesh, interop กับ Matter Border Router, end device
Matter Application layer บน Thread หรือ Wi-Fi HomeKit, Google Home, Alexa
ESP32-C6 Matter Zigbee Thread Smart Home

🔋 ESP32-H2 / H21 — Thread + Zigbee เฉพาะทาง ประหยัดไฟสุดขีด

ถ้า C6 คือ "สวิสอาร์มี่" H2 คือ "มีดสายลับ" — ไม่มี Wi-Fi แต่เน้น 802.15.4 + Bluetooth 5 LE อย่างเดียว ทำให้กระแสไฟ active อยู่ที่ประมาณ 20mA เทียบกับ ~77mA ของ C6 เหมาะสำหรับ sensor node ที่ใช้ถ่าน AA หรือ CR2032 และส่งข้อมูลผ่าน Zigbee/Thread เป็นหลัก

ต้นปี 2026 Espressif เปิดตัว ESP32-H21 ซึ่งเป็นการปรับปรุง H2 โดยเพิ่ม DC-DC converter ในตัว ลดกระแสไฟลงอีก และรองรับ deep sleep ได้ดีขึ้น ESPHome รองรับ Zigbee บน H2 แล้วโดยตรง ส่วน H21 อยู่ในแผน roadmap

M5Stack NanoH2 (ประกาศ ธ.ค. 2025) คือบอร์ดพัฒนา ultra-compact ที่ใช้ H2 มาพร้อม Zigbee + Thread + Matter ในแพ็กเกจเล็กกว่าเหรียญ 5 บาท เหมาะมากสำหรับ sensor node ในบ้าน

🧠 TinyML บน ESP32-S3 — Edge AI ไม่ต้องพึ่ง Cloud

ESP32-S3 มี vector instruction set (SIMD) ที่ Espressif ร่วมกับ Google เขียน optimized kernel สำหรับ TensorFlow Lite Micro (TFLM) โดยเฉพาะ ทำให้ inference เร็วกว่า ESP32 รุ่นเดิมอย่างมีนัย library ที่ใช้คือ esp-tflite-micro บน GitHub โดย Espressif

workload ที่ทำได้บน edge:

// ตัวอย่าง use case TinyML บน ESP32-S3 #include "tensorflow/lite/micro/micro_interpreter.h" #include "tensorflow/lite/micro/all_ops_resolver.h" // Keyword spotting → ตรวจจับ "Hey ESP" ด้วย INMP441 mic // Person detection → ระบุว่ามีคนอยู่ใน frame จาก OV2640 // Anomaly detection → จับความผิดปกติของ vibration sensor // Gesture recognize → ตีความ accelerometer MPU6050 เป็น gestures
Edge Impulse เป็น no-code platform ที่ช่วยเทรนโมเดลและ export เป็น Arduino library ได้เลย โดยไม่ต้องเขียน TensorFlow เองทั้งหมด เหมาะสำหรับผู้เริ่มต้น TinyML
TinyML ESP32-S3 Edge AI TFLM Edge Impulse

🎙 ESP32 Audio Pipeline ด้วย I2S — ไมค์ INMP441 + ลำโพง MAX98357A

I2S (Inter-IC Sound) เป็น protocol ดิจิทัลสำหรับเสียงที่ ESP32 รองรับ built-in สามารถรับเสียงจาก MEMS microphone INMP441 (I2S input) และส่งเสียงออก MAX98357A Class-D Amplifier (I2S output) โดยไม่ต้องใช้ DAC ภายนอก เปิดประตูสู่โปรเจกต์ Voice AI บน edge

// I2S RX config — INMP441 microphone i2s_config_t rx_cfg = { .mode = I2S_MODE_MASTER | I2S_MODE_RX, .sample_rate = 16000, .bits_per_sample = I2S_BITS_PER_SAMPLE_32BIT, .channel_format = I2S_CHANNEL_FMT_ONLY_LEFT, .communication_format = I2S_COMM_FORMAT_STAND_I2S, .dma_buf_count = 4, .dma_buf_len = 512 }; // I2S TX config — MAX98357A amplifier (3W, 8Ω)
library แนะนำ: ESP32-audioI2S โดย schreibfaul1 บน GitHub รองรับ MP3, AAC, FLAC streaming จาก URL, SD card, SPIFFS ได้ทันที ใช้งานง่ายมาก เหมาะสร้าง WiFi Speaker / Internet Radio
I2S INMP441 MAX98357A Voice AI WiFi Speaker

Voice Command Robot ด้วย TinyML + I2S

กระแสไฟ: active ~20mA, deep sleep ~10µA | ถ่าน CR2032 = 220mAh ≈ 3 ปี

DFRobot Gravity DO Sensor

Dissolved Oxygen sensor วัดออกซิเจนละลายน้ำแบบ analog ใช้คู่กับ ESP32 ADC ผ่าน library ของ DFRobot คาลิเบรตด้วย air saturation และ zero oxygen solution ความแม่นยำ ±0.5 mg/L

Water Quality Analog DFRobot
🎙

INMP441 — MEMS I2S Microphone

ไมโครโฟน MEMS ดิจิทัล I2S ความถี่ตอบสนอง 60Hz–15kHz SNR 61 dB ราคาถูก (~60 บาท) เชื่อม ESP32 แค่ 3 สาย ใช้ทำ keyword detection, audio logging, noise monitoring ได้ดีเยี่ยม

I2S Microphone MEMS
📊

SHT41 — High-Accuracy Temp/Humidity

รุ่นล่าสุดจาก Sensirion ความแม่นยำ ±0.2°C และ ±1.8% RH กินไฟน้อย (550µA active) เชื่อมต่อ I2C ง่าย รองรับ heater ภายในสำหรับ de-condensation เหมาะ Zigbee/Thread node สุดๆ

Temperature Humidity Sensirion
🌀

TS300B Turbidity Sensor

sensor วัดความขุ่นน้ำ (turbidity) แบบ analog output ใช้หลักการ light scattering ผ่าน IR LED วัดค่า NTU ใช้งานง่ายกับ ESP32 ADC ผ่าน op-amp คาลิเบรตด้วยน้ำสะอาดเป็น baseline
