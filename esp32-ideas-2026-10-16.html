ESP32-S31 — Dual-Core RISC-V พร้อม Gigabit Ethernet & Wi-Fi 6

ชิปรุ่นใหม่ล่าสุดจาก Espressif ที่เข้าสู่การผลิตจริง (Mass Production) ในเดือนกรกฎาคม 2026 นับเป็นก้าวกระโดดครั้งใหญ่ด้านประสิทธิภาพเครือข่าย โดยเพิ่ม Gigabit Ethernet MAC และ Wi-Fi 6 บน RISC-V core รุ่นใหม่

  • CPU: Dual-core RISC-V สูงสุด 320 MHz พร้อม 128-bit SIMD data path
  • RAM: 512 KB SRAM on-chip + DDR PSRAM 250 MHz รองรับ
  • Wireless: Wi-Fi 6 (802.11ax, 2.4 GHz) + Bluetooth 5.4 + 802.15.4 (Zigbee/Thread)
  • Wired: Gigabit Ethernet MAC (1000 Mbps) — อัปเกรดจาก 10/100 Mbps ของรุ่นเก่า
  • GPIO: 60 พอร์ต, แพ็คเกจ QFN80 (8×8 mm)
  • Dev Board: Function CoreBoard-1 พร้อม RJ45 10/100/1000 auto-negotiate

✅ เหมาะสำหรับ: Edge gateway, Industrial IoT, NAS ราคาประหยัด, Smart NVR

Hot — ตุลาคม 2026

ESP-SDR — เปลี่ยน ESP32 เป็น Software-Defined Radio 2.4/5 GHz

Firmware จากโปรเจกต์ ESPARGOS ที่ bypass โมเด็ม Wi-Fi/Bluetooth แล้วอ่าน raw I/Q samples ส่งไปยัง PC ผ่าน USB — สามารถรับสัญญาณวิทยุในย่าน 2.4 GHz และ 5 GHz ด้วย ESP32 ธรรมดา

  • ชิปที่รองรับ: ESP32, C3, C5, C6, C61, S2, S3, S31 (preview)
  • Sample rate: สูงสุด 80 MSa/s
  • UI: ESP-WebSDR — แสดง spectrum + waterfall บน browser
  • Transmit (esp32-sdr-trx): ESP32-S3 ส่ง Narrowband FM/SSB บนย่าน 13cm (2320–2450 MHz) สำหรับสมัครเล่นวิทยุ
  • หลักการ: Polar modulation — ปรับความถี่และแอมพลิจูด 40,000 ครั้ง/วินาที

⚠️ การส่งสัญญาณต้องมีใบอนุญาตสมัครเล่นวิทยุ (Amateur Radio License)

ESP32 TWAI — CAN Bus Controller ในตัวสำหรับระบบอุตสาหกรรม

TWAI (Two-Wire Automotive Interface) คือ CAN 2.0B controller ที่ฝังอยู่ใน ESP32 ทุกรุ่น ไม่ต้องใช้ IC controller ภายนอก เหมาะสำหรับงาน industrial automation, automotive, และ J1939/NMEA 2000

  • Protocol: CAN 2.0B — รองรับทั้ง 11-bit standard และ 29-bit extended frame ID
  • ต้องการ: External transceiver IC เช่น SN65HVD230 หรือ MCP2551 สำหรับ differential bus
  • Board สำเร็จรูป: LILYGO T-CAN485 — รวม CAN + RS-485 บนบอร์ดเดียว
  • Use case: OBD-II vehicle monitor, Modbus+CAN gateway, Building automation (BACnet)
  • หมายเหตุ: RTC ใน deep sleep มีความเบี่ยงเบนสูงสุด ~5% ควรใช้ external 32KHz crystal

🌾 LoRaWAN Smart Farm Monitor — ระบบตรวจสอบฟาร์มระยะไกล

ESP32 + LoRa Deep Sleep Solar Power Node-RED Agriculture

ระบบตรวจสอบฟาร์มด้วย ESP32 + LoRa module ที่ครอบคลุมพื้นที่ได้ถึง 5–15 กม. ในที่โล่ง Gateway 1 ตัวรองรับ Node ได้ถึง 100 จุด เหมาะสำหรับฟาร์มขนาด 20–50 ไร่ ด้วย node ประมาณ 5–10 จุด

  • 1ติดตั้ง ESP32 node แต่ละจุด — ต่อ Capacitive Soil Moisture + BME280 (อุณหภูมิ/ความชื้น/ความดัน)
  • 2ใช้ Deep Sleep + Solar charging — ESP32 ตื่นทุก 15 นาที อ่านค่า ส่งข้อมูล แล้วนอนต่อ
  • 3ส่งข้อมูลผ่าน LoRa (SF12 สำหรับระยะไกลสุด) ไปยัง LoRaWAN Gateway
  • 4Gateway ส่งต่อไป Network Server (ChirpStack) → Node-RED → Dashboard Grafana
  • 5ตั้ง Alert เมื่อดินแห้งเกินกำหนด สั่งปั๊มน้ำอัตโนมัติผ่าน Relay node

📡 ESP32-S3 Spectrum Analyzer — วิเคราะห์ RF Interference

ESP32-S3 ESP-SDR WebSocket 2.4 GHz DIY Radio

ใช้ ESP-SDR firmware บน ESP32-S3 สร้างเครื่องตรวจสอบ RF interference บนย่าน 2.4 GHz เพื่อวิเคราะห์ปัญหาสัญญาณรบกวนใน Smart Home หรือสำนักงาน โดยส่ง I/Q stream ผ่าน USB ไปแสดงผลใน ESP-WebSDR บน browser

  • 1Flash ESP-SDR firmware บน ESP32-S3 Development Board
  • 2เชื่อมต่อ USB กับ PC เปิด ESP-WebSDR บน Chrome
  • 3ตรวจสอบ spectrum 2.4 GHz — ดู channel overlap ของ Wi-Fi, Bluetooth, Zigbee
  • 4บันทึก I/Q data ไฟล์ .wav วิเคราะห์ลึกด้วย GNU Radio หรือ SDR++
  • 5เพิ่ม antenna ภายนอก (SMA connector) เพื่อ sensitivity ที่ดีขึ้น

🚗 ESP32-S31 Vehicle OBD-II & Gigabit Data Logger

ESP32-S31 TWAI/CAN OBD-II Gigabit Ethernet Fleet Management

ใช้ ESP32-S31 ที่มี TWAI (CAN 2.0B) + Gigabit Ethernet สร้าง OBD-II Data Logger ความเร็วสูงสำหรับยานพาหนะ — อ่านข้อมูลยานยนต์ผ่าน CAN Bus แล้วส่งขึ้น Cloud Server ผ่าน Gigabit LAN พร้อมบันทึกลง Flash Storage

  • 1ต่อ SN65HVD230 (CAN transceiver) กับ TWAI TX/RX ของ ESP32-S31
  • 2เชื่อม OBD-II port ของรถ — อ่าน PID: RPM, Speed, Coolant Temp, Fuel Level
  • 3ส่งข้อมูลผ่าน Gigabit Ethernet (RJ45) ไปยัง Server (latency ต่ำกว่า Wi-Fi)
  • 4แปลงข้อมูลเป็น MQTT → InfluxDB → Grafana dashboard fleet tracking
  • 5เพิ่ม GPS module (UART) บันทึก route และคำนวณ fuel efficiency
// TWAI CAN Bus config (ESP-IDF) twai_general_config_t g = TWAI_GENERAL_CONFIG_DEFAULT( GPIO_NUM_21, GPIO_NUM_22, TWAI_MODE_NORMAL); twai_timing_config_t t = TWAI_TIMING_CONFIG_500KBITS(); twai_filter_config_t f = TWAI_FILTER_CONFIG_ACCEPT_ALL(); twai_driver_install(&g, &t, &f);

เปรียบเทียบ

Resistive vs Capacitive Soil Moisture

เซ็นเซอร์วัดความชื้นดินแบบ Resistive (มี probe สองอัน) จะผุกร่อนเร็วเมื่อใช้ในดินชื้น อายุใช้งาน 1–3 เดือน ส่วนแบบ Capacitive ไม่มีการสัมผัสโดยตรงกับดิน — วัดความจุ (Capacitance) ที่เปลี่ยนตามความชื้น อายุใช้งาน 1–2 ปี เหมาะสำหรับโปรเจกต์ระยะยาวมากกว่า

เทคนิค

LoRa SF7 vs SF12 — เลือกใช้เมื่อไหร่?

SF7: ส่งข้อมูลเร็ว (250 bps), แบตฯ อยู่นาน, ระยะสั้น ~2 km  |  SF12: ส่งข้อมูลช้า (293 bps), แบตฯ หมดเร็วขึ้น, แต่ระยะไกลสุด ~15 km สำหรับ sensor node ฟาร์มที่ส่งข้อมูลทุก 15 นาที SF12 คุ้มค่ากว่าเสมอ เพราะเพิ่มระยะครอบคลุมได้มากโดยไม่ต้องเพิ่ม gateway
