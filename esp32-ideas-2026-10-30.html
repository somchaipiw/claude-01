ESP32-H2 — Zigbee End Device Sensor Node

ชิปไร้ Wi-Fi ที่เชี่ยวชาญ 802.15.4 / Zigbee / Thread / Matter

🔭

ESP32-H2 คืออะไร และทำงานอย่างไร?

ESP32-H2 เป็นชิปพิเศษในตระกูล ESP32 ที่ ไม่มี Wi-Fi เลย แต่เน้นโปรโตคอล 802.15.4 อย่าง Zigbee, Thread, และ BLE 5.0 รองรับ Matter ผ่าน Thread

เหมาะที่สุดสำหรับ: Battery-powered sensor node ที่ต้องการอายุแบตฯ หลายปี โดยไม่ต้องใช้ Wi-Fi ในทุก node
คุณสมบัติESP32-H2
Wi-Fi❌ ไม่มี
Zigbee / Thread✅ 802.15.4
BLE✅ BLE 5.0
Matter✅ ผ่าน Thread
Deep Sleep~5 µA
Flash4 MB

เชื่อมต่อ Zigbee2MQTT และ ZHA

ESPHome 2026.5.0 รองรับ ESP32-H2 เป็น Zigbee End Device แบบ native สามารถ pair กับ Zigbee2MQTT หรือ ZHA ใน Home Assistant ได้โดยตรง

วิธีเพิ่ม Custom Device: สร้างไฟล์ external converter ใน Zigbee2MQTT configuration เพื่อ map cluster ที่กำหนดเอง
# ESPHome config (zigbee end device) esphome: name: h2-sensor-node esp32: variant: esp32h2 framework: type: esp-idf sensor: - platform: sht3xd address: 0x44 temperature: name: "Temperature" zigbee_cluster: "temperature" humidity: name: "Humidity"

SMLIGHT SLZB — ESP32-H2 Zigbee Coordinator

นอกจาก End Device แล้ว ESP32-H2 ยังถูกใช้เป็น radio chip ในอุปกรณ์ Zigbee Coordinator เชิงพาณิชย์ เช่น SMLIGHT SLZB series ที่มีทั้ง PoE และ Dual-Radio รองรับ Thread Border Router

M5Stack ก็ออก H2 Gateway Unit ที่ใช้ต่อผ่าน Grove UART เพื่อเพิ่ม 802.15.4 radio ให้บอร์ด ESP32 ทั่วไปได้ทันที

ไอเดีย: Battery Zigbee Environment Node

โปรเจกต์ยอดนิยมบน GitHub 2026 คือ ESP32-H2 SuperMini + เซนเซอร์ SHT40 หรือ BME280 ใช้แบตฯ AA 2 ก้อน อายุการใช้งาน 2-3 ปี ส่งข้อมูลผ่าน Zigbee ไป Zigbee2MQTT

Deep sleep ระหว่าง 2 นาทีใช้กระแสเพียง ~5 µA ตื่นขึ้นมาอ่าน sensor 1 วิ แล้วส่ง Zigbee report ใช้ ~20 mA เป็นเวลา 50ms เท่านั้น

ตัวอย่าง repos: zigbee-esp32 (SmartHomeScene), RollBee (ESP-IDF 5.4 + ESP-Zigbee-SDK 5.4)

ENS160 คืออะไร? ดีกว่า CCS811 อย่างไร?

# ESPHome configuration sensor: - platform: ens160 eco2: name: "eCO2" unit_of_measurement: "ppm" tvoc: name: "TVOC" unit_of_measurement: "ppb" aqi: name: "Air Quality Index" # ต้องมี temp/humidity compensation - platform: bme280_i2c temperature: name: "Temperature" id: temp_sensor humidity: name: "Humidity" id: hum_sensor

ESP32-S3 เป็น USB MIDI Device

ESP32-S3 มี USB-OTG hardware ทำให้สามารถแสดงตัวเป็น USB MIDI Controller ต่อ DAW อย่าง Ableton, Logic Pro, GarageBand ได้โดยตรง ไม่ต้องใช้ driver พิเศษ

Library EspUsbDevice (อัปเดต 2026-07-08) รองรับ USB MIDI class บน ESP32-S3 เป็น composite device ร่วมกับ CDC-ACM ใน sketch Arduino เดียว
// ESP32-S3 USB MIDI ใน Arduino #include <USB.h> #include <USBMIDI.h> USBMIDI MIDI; void setup() { USB.begin(); MIDI.begin(); } void loop() { if (buttonPressed) { MIDI.noteOn(60, 127, 1); // C4, vel 127, ch1 delay(200); MIDI.noteOff(60, 0, 1); } }
USB MIDI ESP32-S3 DAW Ableton
🔌

USB Host Mode — รับ MIDI Keyboard เข้า ESP32

ใช้ ESP32-S3 เป็น USB Host อ่านสัญญาณจาก USB MIDI Keyboard แล้วแปลงเป็น BLE MIDI หรือ Wi-Fi OSC ส่งต่อไปยัง device อื่น

Library ESP32_Host_MIDI v5.2.0 (2026-03-11) รองรับ 9 MIDI transports ในหน้าเดียว: USB Host, BLE MIDI, Apple MIDI (RTP), OSC, ESP-NOW, DIN-5 และอื่นๆ Latency <1ms สำหรับ USB path
⚠️ ข้อจำกัด: USB Host และ USB Device ใช้ hardware USB-OTG เดียวกัน ใช้ได้ทีละโหมด ไม่สามารถรันพร้อมกัน
USB Host BLE MIDI 9 Transports OSC

ไอเดียโปรเจกต์: DIY MIDI Controller 12 ปุ่ม

โปรเจกต์จาก Berkeley HOPE course 2026 สร้าง custom PCB ESP32-S3 ที่มี key matrix 12 ปุ่ม, slide potentiometer, และ speaker output แต่ละปุ่มส่ง Note On/Off ผ่าน USB MIDI

ส่วนประกอบ:
• ESP32-S3 mini board
• Key switch matrix 4×3
• Slide potentiometer (MIDI CC)
• WS2812B LED per key
• USB-C ต่อ DAW โดยตรง

แต่ละปุ่มส่ง CC change สำหรับ volume/expression ได้ด้วย ทำให้เป็น multi-function controller ราคา <500 บาท
