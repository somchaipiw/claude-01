ESP32-WROOM · ESP32-S3 Anemoia-ESP32 — เล่นเกม NES ได้ 60 FPS บน ESP32 ราคาไม่กี่ร้อยบาท

Shim Manaloto พอร์ตและ rewrite โปรเจกต์ NES emulator ชื่อ Anemoia ลงบน ESP32 ได้สำเร็จ โดยรันที่ ~60.098 FPS (NTSC) พร้อม audio emulation ครบถ้วน Hackaday รายงานเมื่อ 22 กรกฎาคม 2569 ว่าโปรเจกต์นี้ "น่าทึ่งมาก"

60 FPS I2S Audio Save States 6 Mappers 79% Game Library Web Flasher
  • รันได้บน ESP32-WROOM ธรรมดา (4MB Flash, ไม่ต้องมี PSRAM)
  • รองรับ Super Mario Bros., Zelda, Metroid และอีกหลายร้อยเกม
  • ติดตั้งง่าย — flash ผ่าน browser โดยตรง (Web Flasher)
  • DSN Industries ทำ rebuild บน ESP-IDF แยกต่างหากเพื่อประสิทธิภาพสูงสุด
  • ราคาฮาร์ดแวร์ทั้งหมดต่ำกว่า $20 (ประมาณ 700 บาท)

🎯 ความสำเร็จที่ยิ่งใหญ่: ชิป RISC-V / Xtensa ราคาไม่กี่ดอลลาร์สามารถรันเกม NES ได้ลื่นเท่า console จริง แสดงให้เห็นว่า ESP32 มีพลังซ่อนอยู่มากกว่าที่ใช้กันในงาน IoT ทั่วไป

เครื่องเกมพกพา retro ราคาถูก เหมาะทำของขวัญ DIY หรือสอนเด็กเรื่อง embedded programming

🧠 AI Update

ESP32-S3 · ESP32-P4 ESP-DL อัปเดตใหม่ — Per-Channel Quantization & PIE SIMD Acceleration

Espressif อัปเดต esp-dl (deep-learning library) รองรับ per-channel quantization บน ESP32-P4 เพิ่มความแม่นยำของ model AI อย่างมีนัยสำคัญ พร้อม SIMD skills สำหรับ PIE (Processor Instruction Extension)

ONNX Support Per-Channel Quant ESP-PPQ PIE SIMD Conv/Gemm/Add/Mul
  • Conv และ Gemm operators บน ESP32-P4 อัปเกรดเป็น per-channel quantization
  • ESP-PPQ อ่านไฟล์ ONNX โดยตรง — quantize model จาก PyTorch/TensorFlow ได้เลย
  • Skills ใหม่: esp32s3-pie-simd และ esp32p4-pie-simd เร่ง AI operators
  • ESP-Brasia สำหรับ UI development + ESDL สำหรับ AI inference pipeline
  • Arduino-ESP32 สำหรับ P4 อยู่ในสถานะ beta (เมษายน 2569)

📈 ผลลัพธ์: model accuracy บน ESP32-P4 สูงขึ้นอย่างเห็นได้ชัด เมื่อเทียบกับ per-tensor quantization แบบเดิม

Deploy ONNX model จาก PC มาบน ESP32-P4 ได้โดยตรง — เหมาะงาน edge AI เช่น defect detection, face recognition

ESP32 · Supabase · PWA DoorCTL — ระบบควบคุมประตูโกดังระดับ Production ด้วย JWT + WebAuthn

lnodari97 บน Hackster.io (24 ก.ค. 2569) เปิดเผยโปรเจกต์ควบคุมประตู loading dock ในโรงซักผ้าเชิงพาณิชย์จริงๆ ที่ Brooklyn, NY — ไม่ใช่แค่ prototype แต่ใช้งานจริงทุกวัน

JWT Auth WebAuthn Biometric RBAC Blynk Cloud Supabase RLS 433 MHz RF
  • PWA (Progressive Web App) — vanilla JS บน Netlify, login ด้วย password หรือ biometrics
  • Blynk Cloud ทำหน้าที่ pass-through คำสั่ง (Virtual Pins V1/V2/V3)
  • ESP32 ขับ relay 2 channel (GPIO26=OPEN, GPIO27=CLOSE) + อ่าน RF remote QIACHIP RX480E
  • Supabase จัดการ user identity + Row-Level Security ป้องกัน SQL injection
  • Activity log ทุก action — ใครเปิด/ปิดประตูเมื่อไหร่บันทึกครบ

🏗️ สถาปัตยกรรม: PWA → Supabase (auth + db) → Blynk (pass-through) → ESP32 → Relay → ประตู

ใช้แทนระบบ access control ราคาแพง เหมาะสำหรับโรงงาน คลังสินค้า หรืออาคารสำนักงานขนาดเล็ก

  • DFRobot ESP32-S3 AI Camera Module: OV3660 3MP + IR night vision + onboard mic+speaker

ESP32-P4 Edge AI — เจาะลึกความสามารถปี 2569 Deep Dive: High-Performance AI SoC

📊 ESP32-P4 vs ESP32-S3 — เลือกตัวไหนสำหรับงาน AI ในปี 2569?

หลังจาก ESP32-P4 วางจำหน่ายได้กว่าปีครึ่ง ระบบ ecosystem เริ่มสมบูรณ์ขึ้นมาก WizzDev สรุปเปรียบเทียบสำหรับ IoT roadmap ปี 2569:

🔵 ESP32-S3 — "AI Generalist"

  • Dual-core Xtensa LX7 @ 240 MHz
  • PIE SIMD extensions — CNN inference ดี
  • Wi-Fi + BLE built-in — IoT ครบในตัว
  • FOMO object detection <200ms
  • Arduino + ESPHome support เต็มรูปแบบ
  • เหมาะ: Smart camera, voice assistant, sensor+AI

🟣 ESP32-P4 — "Edge Computing Beast"

  • Dual-core RISC-V @ 400 MHz + LP Core 40 MHz
  • 32MB PSRAM — รัน model ขนาดใหญ่ได้
  • H.264 encoder, MIPI camera/display
  • Per-channel quantization — accuracy สูงกว่า
  • ไม่มี Wi-Fi/BLE — ต้องต่อ ESP32-C6 หรือ module แยก
  • เหมาะ: 1080p AI video, ANPR, display HMI, industrial
💡 สูตรใช้งานจริง: ถ้าต้องการ AI + Wireless ในบอร์ดเดียว → ESP32-S3 | ถ้าต้องการ AI ประสิทธิภาพสูงสุดแบบ wired → ESP32-P4 + ESP32-C6 (wireless add-on)

❤️ Biometric

MAX30102 — Pulse Oximeter & Heart Rate

IC ตรวจวัด SpO2 และ BPM ราคาถูกที่สุดในตลาด ultra-low power เหมาะ wearable ไม่มีบัค pull-up resistor ของ MAX30100 รุ่นเก่า

  • วัด SpO2 (Blood Oxygen) และ Heart Rate (BPM)
  • 600µA ขณะวัด, 0.7µA ขณะ standby
  • I2C interface — ต่อง่ายกับ ESP32 ทุกรุ่น
  • ใช้งานกับ library MAX30105 ของ SparkFun
  • เหมาะสำหรับ smartwatch DIY หรือ health station
ส่วนประกอบหลักสำหรับ wearable health monitor, patient monitoring หรือ fitness tracker ราคาประหยัด
