HLK-LD2410C — 24 GHz FMCW Radar
Hi-Link · รุ่นยอดนิยม · ตรวจสถิตและเคลื่อนที่

เซ็นเซอร์ radar 24 GHz แบบ FMCW แก้ปัญหาที่ PIR ทำไม่ได้คือ ตรวจจับคนนิ่งๆ ได้ เช่น นั่งอ่านหนังสือ หรือนอนหลับ ระยะตรวจสูงสุด 6 เมตร แบ่งเป็น 8 gate ละ 0.75 m ปรับ sensitivity รายเขตได้

✨ รุ่น C มี Bluetooth onboard สำหรับ config ผ่านแอปมือถือ Hi-Link Radar ไม่ต้องเขียน code เพื่อตั้งค่า

// ESPHome YAML - HLK-LD2410
uart:
  id: uart_ld2410
  tx_pin: GPIO17
  rx_pin: GPIO18
  baud_rate: 256000

ld2410:
  uart_id: uart_ld2410

binary_sensor:
  - platform: ld2410
    has_target:
      name: "Presence"
    has_moving_target:
      name: "Motion"
    has_still_target:
      name: "Still Person"

TWAI Controller — CAN ในตัว ESP32
Two-Wire Automotive Interface · CAN 2.0B

ESP32 ทุกรุ่น (ยกเว้น ESP32-C2) มี TWAI controller ในตัว รองรับ CAN 2.0B ต้องต่อแค่ IC transceiver ภายนอก แค่ตัวเดียว

Transceiverแรงดันแนะนำ
SN65HVD2303.3V native✅ ดีที่สุด
TJA10505Vต้องแปลง level
MCP25515Vต้องแปลง level
#include "driver/twai.h"

// กำหนด timing สำหรับ 500 kbps
twai_general_config_t g_config =
  TWAI_GENERAL_CONFIG_DEFAULT(
    GPIO_NUM_21,  // TX
    GPIO_NUM_22,  // RX
    TWAI_MODE_NORMAL);
twai_timing_config_t t_config =
  TWAI_TIMING_CONFIG_500KBITS();
twai_filter_config_t f_config =
  TWAI_FILTER_CONFIG_ACCEPT_ALL();

twai_driver_install(&g_config,
  &t_config, &f_config);
twai_start();

Dual CAN Dashboard — ESP32-S3
Alfa Romeo / สำหรับรถที่มี 2 CAN bus

รถสมัยใหม่หลายรุ่นมี 2 CAN bus แยกกัน เช่น Powertrain CAN + Comfort CAN ESP32-S3 รับมือได้ด้วยการใช้ TWAI built-in ตัวหนึ่ง และ MCP2515 SPI เพิ่มอีกตัว

// Bus 1: TWAI built-in (500 kbps)
// Bus 2: MCP2515 via SPI
MCP2515 can2(CS_PIN);
can2.reset();
can2.setBitrate(CAN_500KBPS,
  MCP_8MHZ);
can2.setNormalMode();

LVGL บน ESP32-S3 AMOLED — Smooth UI 60 fps
LVGL v9 + SH8601 QSPI Driver

ใช้ LVGL v9 (Light and Versatile Embedded Graphics Library) กับ QSPI display driver สำหรับ SH8601 ได้ 60 fps smooth animation บน ESP32-S3 ที่ 240 MHz

// LVGL flush callback สำหรับ QSPI
void lvgl_flush_cb(lv_display_t *disp,
  const lv_area_t *area,
  uint8_t *px_map) {
  sh8601_draw_bitmap(
    area->x1, area->y1,
    area->x2, area->y2,
    (uint16_t*)px_map);
  lv_display_flush_ready(disp);
}

💡 Project Idea: Smart Watch Face สำหรับงาน IoT — แสดง sensor data สวยงามในจอกลม เช่น Temperature dial, AQI gauge, Heart rate

USB HID Host — Keyboard & Mouse
ESP32-S3 / P4 · espp usb_host v1.3.9

ESP32-S3 และ P4 มี USB hardware ในตัว ทำหน้าที่เป็น USB Host ได้ Library espp v1.3.9 มี `usb_host` component ที่ parse HID report ได้ถูกต้องสำหรับ keyboard, mouse, gamepad

⚠️ Hardware Note: บอร์ดหลายรุ่นต้องบัดกรี solder bridge เพื่อเปิด 5V VBUS ขาออก ตรวจ schematic ก่อน เสียบอุปกรณ์ USB

USB HID Host espp v1.3.9 ESP32-S3/P4
📷
USB Barcode Scanner Gateway
ESP32-S3 อ่าน Barcode → WiFi → Backend

ไอเดียที่ใช้งานได้จริง: เชื่อม USB barcode scanner เข้า ESP32-S3 (USB HID host mode) แล้วส่งข้อมูลผ่าน WiFi หรือ MQTT ไปยัง backend แทนที่จะต้องเสียบ scanner เข้า PC

// Pseudo-code: USB HID → MQTT
usb_host.onHIDReport([](
  uint8_t *data, size_t len) {
  String barcode = parseHID(
    data, len);
  mqtt.publish(
    "/scanner/data",
    barcode);
});

USB MIDI Host บน ESP32-S3
ต่อ MIDI Keyboard ตรงเข้า ESP32

ESP32-S3 เป็น USB MIDI Host รับข้อมูล MIDI Note จาก keyboard/controller แล้วประมวลผลตอบสนอง เช่น สั่ง LED strip, ส่ง OSC ไปยัง software หรือทำ MIDI router

🎼 Use Case: เชื่อม MIDI keyboard กับ ESP32-S3 เพื่อสร้าง interactive LED installation — กด note → LED สีต่างกัน เปลี่ยน pattern ตาม velocity
