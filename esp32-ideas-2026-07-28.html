ESPHome 2026.7.0 — Major Release: Native ESP-IDF, ESP-NOW v2, Modbus Overhaul & Security Suite
ESPHome เดือนกรกฎาคม 2026 เป็น release ที่ใหญ่ที่สุดในปีนี้ มีการเปลี่ยนแปลงระดับ infrastructure หลายอย่าง รวมถึง security feature ใหม่ที่ตอบโจทย์มาตรฐาน EN18031 และ hardware รุ่นใหม่
🔧 Toolchain: เปลี่ยน Default จาก PlatformIO เป็น Native ESP-IDF สำหรับ ESP32 platform ทั้งหมด — compile เร็วขึ้น, ccache ทำงาน by default
🔒 Security Suite: NVS Encryption, OTA Downgrade Protection, Transport-Agnostic Provisioning Component (EN18031 compliance)
📡 ESP-NOW v2 Payloads: รองรับ payload format ใหม่ในโปรโตคอล ESP-NOW
🏭 Modbus Overhaul: Parser เขียนใหม่ทั้งหมด + heap-free send path — ประสิทธิภาพสูงกว่าเดิมมาก
🖥️ LVGL Expansion: รองรับ Animations, Dynamic Rotation, Boot Pausing
🌐 Gigabit Ethernet: รองรับบน ESP32-S31 (รุ่นใหม่ล่าสุด)
📦 11 New Components: ครอบคลุม touch controllers, e-paper panels, IMUs, Divoom Pixoo 64
🔷 Zigbee 2.0.2 SDK: รองรับ Endpoint Merging ในโปรโตคอล Zigbee ใหม่

MeshCore บน ESP32 — Bridge ESP-NOW (เร็ว) กับ LoRa (ไกล) ในบอร์ดเดียว
MeshCore รองรับการสร้าง Hybrid Mesh Network ที่ผสม ESP-NOW (2.4 GHz, เร็ว ~600–1200 ฟุต) กับ LoRa (915/868 MHz, ไกลหลายกิโลเมตร) ผ่าน Bridge node เดียว ทำให้อุปกรณ์ ESP32 ราคาถูกสื่อสารกันในระยะใกล้ผ่าน ESP-NOW แล้ว Bridge ไปยัง LoRa Mesh Network กว้างไกลได้
ข้อดี: ใช้ ESP32 ธรรมดาที่ไม่มี LoRa Radio เป็น ESP-NOW Node ได้ • ลดค่าใช้จ่ายต่อ node • Flash ผ่าน MeshCore Web Flasher บนเบราว์เซอร์ได้เลย

ESP32-S3 + INMP441 — Standalone I2S Audio Streaming Server พร้อม WebSocket
โปรเจกต์ปี 2026 สาธิตการสร้าง WebSocket Audio Server ทำงานบน ESP32-S3 โดยตรง โดยไม่ต้องพึ่งเซิร์ฟเวอร์ภายนอก รับเสียงจาก INMP441 I2S microphone ประมวลผล FFT แบบ real-time และสตรีมสเปกตรัมผ่าน WebSocket ด้วย latency ต่ำกว่า 50ms
Spec: FFT 100 Hz resolution • WebSocket 30 packets/s • LED ring update 60 FPS • I2S DMA transfer ไม่บล็อก CPU

Offline Wake Word & Voice Command ด้วย ESP32 + Edge Impulse — ไม่ต้องมี Cloud
สร้าง Voice Assistant บนบอร์ด ESP32 ที่รู้จำ Wake Word และคำสั่งเสียงได้ทั้งหมด Offline โดยใช้ Edge Impulse ฝึก neural network จากเสียงที่บันทึกเอง export เป็น Arduino library แล้ว deploy ลงบนชิปตรงๆ ด้วยหลักการ TinyML ทำให้ระบบทำงานได้แม้ไม่มี Internet

Sensors & ICs น่าสนใจประจำวัน

โมดูลและชิปที่ Maker ควรรู้จักและพิจารณาใช้กับ ESP32

INMP441 MEMS I2S Mic
ไมโครโฟน MEMS ดิจิทัลที่ได้รับความนิยมสูงสุดสำหรับ ESP32 ส่งข้อมูลเสียงผ่าน I2S โดยตรง ไม่ต้องมี ADC ภายนอก ให้คุณภาพเสียงสูงกว่า Analog microphone มาก เหมาะสำหรับโปรเจกต์ Voice Assistant, Spectrum Analyzer และ Noise Monitoring
Sensitivity: -26 dBFS ± 1 dB  •  SNR: 61 dB  •  Interface: I2S (24-bit)  •  Supply: 1.8–3.3 V  •  Direction: Omnidirectional
R503 Fingerprint
Sensor ลายนิ้วมือ Capacitive รุ่นใหม่จาก GROW Technology เร็วกว่าและแม่นกว่า Optical รุ่นเก่าอย่าง AS608 รองรับ RGB LED Indicator แสดงสถานะ มี Aura LED รอบตัว Sensor ดูดีมาก เหมาะสำหรับโปรเจกต์ Door Lock และ Attendance System
Resolution: 400 dpi  •  Templates: 200 (expandable)  •  Recognition: <1 s  •  FAR: <0.001%  •  Interface: UART 57600 baud
MAX98357A I2S Amplifier
Class-D Audio Amplifier ดิจิทัล รับสัญญาณ I2S โดยตรงจาก ESP32 โดยไม่ต้องมี DAC ภายนอก ขับ Speaker ได้ถึง 3.2W ที่ 4Ω เหมาะสำหรับ DIY Smart Speaker, Intercom, และ Audio Notification System บน ESP32-S3 ราคาถูก (โมดูล ~50 บาท)
Output: 3.2 W @ 4Ω  •  Interface: I2S (16/32-bit)  •  THD: 0.015%  •  Efficiency: 92%  •  Supply: 2.7–5.5 V
MAX3485 / RS-485 IIoT Protocol
IC Transceiver สำหรับ RS-485 Bus ที่ใช้กับ Modbus RTU บนสภาพแวดล้อม Industrial ต่อกับ ESP32 ผ่าน UART เพียงแค่ 3 ขา (RX, TX, DE/RE) ทนทานต่อ ESD และ Noise สูง รองรับการต่อ Node ได้ถึง 32 ตัวบน Bus เดียว ส่งข้อมูลได้ไกลถึง 1,200 เมตร
Bus: RS-485 Half-Duplex  •  Speed: 10 Mbps  •  Nodes: 32/bus  •  Range: 1,200 m  •  Supply: 3.3 V
