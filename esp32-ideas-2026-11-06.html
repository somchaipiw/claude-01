ESP32-H21

Zigbee Temperature/Humidity Node ใช้ถ่าน 2 ปี

ESP32-H21 ใช้กระแสต่ำมากขณะ sleep (~15µA) เหมาะทำ Zigbee sensor node วัดอุณหภูมิ-ความชื้นด้วย SHT41 ส่งข้อมูลทุก 10 นาที อายุถ่าน CR2032 นานกว่า 2 ปี

// Deep sleep + Zigbee report esp_zb_sleep_enable(true); esp_zb_set_sleep_threshold(1000); // ms // วัดแล้ว report ผ่าน Zigbee sht41_read(&temp, &hum); esp_zb_zcl_report_attr_cmd_req(&report); // กลับไป sleep esp_zb_sleep_now();

ESP32-P4 คืออะไร?

ESP32-P4 มี dual-core RISC-V 400MHz + AI accelerator รองรับ MIPI CSI camera, USB 2.0 HS และหน่วยความจำ PSRAM 32MB ในตัว เหมาะสำหรับงาน edge AI และ computer vision โดยเฉพาะ — แต่ใช้พลังงานมากกว่าชิปอื่นในตระกูล ESP32

Industrial IoT — Modbus, 4-20mA & Vibration Monitoring

ESP32 เชื่อมต่อกับ sensor อุตสาหกรรมผ่าน RS485 และ current loop

ทำไมต้องใช้ Modbus RTU กับ ESP32?

โปรโตคอล Modbus RTU ผ่าน RS485 เป็นมาตรฐานอุตสาหกรรมที่ใช้กันมาหลายสิบปี เซ็นเซอร์อุณหภูมิ ความชื้น กระแส แรงดัน และการสั่นสะเทือนส่วนใหญ่มี Modbus output — ESP32-C5 กับ RS485 transceiver เชื่อมต่อได้ทันที แล้วส่งข้อมูลขึ้น cloud ผ่าน MQTT หรือ HTTPS

ESP32-C5

Modbus RTU Gateway รวม Sensor หลายตัว

ใช้ ESP32-C5 กับ MAX485 transceiver สร้าง Modbus master ดึงข้อมูลจาก sensor วัดอุณหภูมิ ความชื้น กระแสไฟ และ energy meter ส่งขึ้น MQTT broker ทุก 30 วินาที

// Modbus RTU บน ESP32 #include "ModbusRTU.h" ModbusRTU mb; mb.begin(&Serial2, 9600, RE_DE_PIN); // อ่าน holding register จาก slave 1 uint16_t regs[4]; mb.readHreg(1, 0x0000, regs, 4, cbOnRead); // ส่งขึ้น MQTT mqtt.publish("factory/sensor1", jsonPayload);

ESP32

4-20mA Industrial Sensor Interface

เชื่อม sensor อุตสาหกรรมที่ output 4-20mA (pressure, flow, level) เข้ากับ ESP32 ADC ผ่าน precision shunt resistor 250Ω — 4mA = 0%, 20mA = 100% — เพิ่ม optocoupler isolation ป้องกัน noise และ surge

// 4-20mA to ESP32 ADC // V_shunt = I × 250Ω (1V-5V range) // ต้องใช้ voltage divider ลดเป็น 0-3.3V float raw = analogRead(ADC_PIN); float voltage = raw * (3.3f / 4095.0f); float current_mA = (voltage / 0.165f) + 4.0f; float percent = (current_mA - 4.0f) / 16.0f * 100;
4-20mA ADC Pressure Sensor Flow Meter
ระดับ: กลาง
ESP32-S3

Predictive Maintenance ด้วย Vibration Analysis

ใช้ ADXL345 accelerometer วัด vibration ของมอเตอร์ คำนวณ RMS velocity ตามมาตรฐาน ISO 10816 แล้วแจ้งเตือนผ่าน LINE Notify เมื่อค่าเกิน threshold — ป้องกันเครื่องจักรพัง

หมายเหตุ: ADXL345 เหมาะสำหรับ trending เท่านั้น สำหรับงานอุตสาหกรรมจริงควรใช้ Modbus vibration transmitter (Renke/Banner) ที่ได้มาตรฐาน

// คำนวณ RMS velocity (ISO 10816) float sum_sq = 0; for (int i = 0; i < N; i++) { sum_sq += accel[i] * accel[i]; } float rms = sqrt(sum_sq / N); // ISO 10816 Zone A: <0.71 mm/s (ใหม่) // Zone D: >7.1 mm/s (อันตราย) if (rms > THRESHOLD_D) alertLine();
Vibration ADXL345 ISO 10816 LINE Notify Predictive Maintenance

Sensors ที่น่าสนใจสำหรับโปรเจกต์ ESP32

เซ็นเซอร์ที่เข้ากันกับ Matter, Industrial IoT และ Vision AI

Environmental

SHT41 — ความชื้น/อุณหภูมิ ความแม่นยำสูง

Sensirion SHT41 ให้ค่า ±1.8% RH และ ±0.2°C ติดต่อผ่าน I2C เหมาะสำหรับ Zigbee/Matter sensor node ที่ต้องการความแม่นยำ รองรับ self-heating correction สำหรับการวัดในสภาพแวดล้อมจริง

I2C ±1.8% RH Zigbee Node 1.08–3.6V
Industrial

PZEM-004T — วัดพลังงานไฟฟ้า AC

วัดแรงดัน กระแส กำลัง และพลังงานสะสมของระบบ AC ผ่าน UART เหมาะทำ smart plug หรือ energy monitor ตาม Matter 1.6 spec ราคาต่ำ ใช้ง่าย ตรวจวัดได้ถึง 100A

UART Energy Meter Matter 1.6 100A max
Motion

ADXL355 — Accelerometer อุตสาหกรรม

Low-noise, low-drift accelerometer จาก Analog Devices เหมาะงาน vibration analysis จริงมากกว่า ADXL345 มี noise density ต่ำถึง 25µg/√Hz รองรับ SPI/I2C อุณหภูมิ -40°C ถึง +125°C

SPI/I2C 25µg/√Hz Vibration Analysis Industrial Grade
Soil

Capacitive Soil Sensor v2.0 — ทนต่อการกัดกร่อน

เซ็นเซอร์วัดความชื้นดินแบบ capacitive (ไม่ใช่ resistive) ทนทานกว่า ให้ผล analog output ต่อกับ ADC ของ ESP32 ตรงๆ Matter 1.5 เพิ่ม soil sensor cluster ทำให้ report ค่าเข้า ecosystem ได้มาตรฐาน
