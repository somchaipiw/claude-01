รัน Linux Kernel 6.11 บน ESP32-S3 ได้จริงแล้ว!

เมื่อวาน (15 ก.ย. 2569) ชุมชน Hackaday รายงานความก้าวหน้าครั้งสำคัญ — นักพัฒนาสามารถบูต Linux Kernel 6.11 บน ESP32-S3 ด้วย PSRAM 16 MB ได้สำเร็จ โดย Release 0.8 เป็นเวอร์ชันแรกที่บูตได้อย่างเสถียรพร้อม RAM เหลือใช้งานจริง

หลังบูตสำเร็จ มี RAM ว่างเหลือ 3.7 MB พร้อมประสิทธิภาพที่ปรับปรุงดีขึ้นมากจากรุ่นก่อน ถือเป็นก้าวสำคัญสำหรับโลก Embedded Linux บนชิปราคาประหยัด

ESP32-E22 — Wi-Fi 6E Tri-Band พร้อม RISC-V 500 MHz

Espressif เปิดตัว ESP32-E22 ที่ CES 2026 — ชิปตัวใหม่ที่รองรับ Wi-Fi 6E tri-band (2.4/5/6 GHz) พร้อม 2×2 MIMO ความเร็วสูงสุดถึง 2.1 Gbps เหมาะสำหรับ gateway ความเร็วสูงและอุปกรณ์ streaming

ESP32-H21 — BLE + Thread/Zigbee สำหรับ IoT พลังงานต่ำสุด

คู่หู ESP32-H21 ถูกออกแบบมาเพื่อ IoT nodes ที่ต้องการพลังงานต่ำที่สุด มี single-core RISC-V @ 96 MHz, RAM 320 KB, รองรับ BLE + IEEE 802.15.4 (Zigbee/Thread) พร้อม integrated DC-DC converter ช่วยลดแรงดันการทำงานต่ำกว่าชิปรุ่นเก่า

ESP32-P4 + ESP32-E22 — Edge AI พร้อม Wi-Fi 6E ในชิปเดียวกัน

เนื่องจาก ESP32-P4 ไม่มี Wi-Fi ในตัว วิธีที่ทรงพลังที่สุดในปี 2569 คือจับคู่ ESP32-P4 (AI + multimedia @ 400 MHz) เข้ากับ ESP32-E22 ผ่าน SDIO/SPI เพื่อได้ทั้ง edge inference, display pipeline, และ Wi-Fi 6E ความเร็วสูง

Espressif เรียก pattern นี้ว่า "Host + Co-processor" architecture ซึ่งเห็นได้ใน ESP32-P4-Function-EV-Board development board อย่างเป็นทางการ

กรณีการใช้งาน: Industrial HMI panel, Smart display hub, AI camera gateway, Home automation controller ที่ต้องการ display + AI + Wi-Fi 6E ในกล่องเดียว

Pocket Linux Web Server ด้วย ESP32-S3 + PSRAM 16 MB

ตอนนี้ Linux รันบน ESP32-S3 ได้แล้ว ลองสร้าง micro web server ที่เล็กที่สุดในโลกด้วย ESP32-S3 — รัน Busybox httpd เสิร์ฟ static files ควบคุม GPIO ผ่าน shell script พลังงานจาก power bank ขนาดเล็ก

1
ซื้อ ESP32-S3 board ที่มี PSRAM 16 MB (เช่น ESP32-S3-DevKitC-1)
2
Clone repo Linux-on-ESP32 v0.8 และ build ด้วย cross-compiler Xtensa
3
Flash kernel image ผ่าน esptool.py พร้อม rootfs บน PSRAM
4
บูตเข้า shell และรัน Busybox httpd เสิร์ฟหน้าเว็บ GPIO control
ESP32-S3 Linux Busybox Web Server PSRAM

สร้างเครือข่าย sensor แบบ mesh ทั่วบ้านด้วย ESP32-H21 4-6 ตัว แต่ละตัวติด BME280 (ความชื้น/อุณหภูมิ/ความดัน) และทำงานด้วยถ่าน AA 2 ก้อน ยาวนาน 2+ ปี เชื่อมต่อเข้า Home Assistant ผ่าน Thread Border Router (Apple HomePod หรือ Google Nest Hub)

SGP41 — Multi-Gas Sensor วัด VOC + NOx พร้อมกัน

Sensirion SGP41 เป็นอัพเกรดจาก SGP40 ที่วัดได้ทั้ง VOC index และ NOx index พร้อมกันในชิปเดียว เหมาะสำหรับระบบ air quality monitoring ในบ้านหรืออาคาร ใช้ I²C เชื่อมต่อง่ายกับ ESP32

ต้องการ temperature/humidity compensation จาก BME280 หรือ SHT40 เพื่อให้ค่าถูกต้อง Sensirion มี Arduino library พร้อม VOC/NOx algorithm แบบ built-in

Step-by-Step

สร้าง Thread Border Router ด้วย ESP32-C6 + Raspberry Pi Zero 2 W

Thread Border Router คือสะพานเชื่อม Thread mesh network เข้ากับ IP network (LAN/Wi-Fi) ทำให้ Home Assistant หรือ Apple Home สื่อสารกับ Thread devices ได้ ทำเองได้โดยใช้ ESP32-C6 เป็น RCP (Radio Co-Processor) คู่กับ Raspberry Pi Zero 2 W

1
Flash RCP firmware ลง ESP32-C6: idf.py flash -p /dev/ttyUSB0 -b 460800
2
ติดตั้ง OTBR บน Pi Zero 2 W: docker run --sysctl net.ipv6.conf.all.disable_ipv6=0 openthread/otbr
3
เชื่อมต่อ ESP32-C6 → Pi ผ่าน USB-Serial (CP2102) กำหนด baudrate 115200
4
สร้าง Thread network ผ่าน OTBR web UI (http://pi-ip:80) กด "Form Network" และบันทึก Network Key
5
Pair Thread devices โดยนำ Network Key ใส่ใน firmware ของ ESP32-H21 หรือ ESP32-C6 nodes ทั่วบ้าน
6
เชื่อมกับ Home Assistant ผ่าน OTBR integration — HA จะเห็น Thread devices ทุกตัวอัตโนมัติ
ค่าใช้จ่าย: ESP32-C6 DevKit (~150 บาท) + Pi Zero 2 W (~700 บาท) + case + power = รวมประมาณ 1,100 บาท ถูกกว่า Apple HomePod Mini 10 เท่า
# ติดตั้ง Thread Border Router บน Pi Zero 2 W ด้วย script เดียว curl -sSL https://raw.githubusercontent.com/openthread/ot-br-posix/main/script/setup \ | sudo bash -s -- --backbone-interface eth0 --radio-url spinel+hdlc+uart:///dev/ttyUSB0?uart-baudrate=115200
