ESP32-H2 · RISC-V SoC
ESP32-H2: ราชาแห่ง Thread & Zigbee สำหรับ Matter 1.6

ESP32-H2 เป็น SoC ที่รองรับ IEEE 802.15.4 และ Bluetooth 5 LE โดยเฉพาะ ไม่มี Wi-Fi แต่นั่นคือข้อดี — ใช้พลังงานต่ำมาก ได้รับการรับรองเป็น Zigbee-Compliant Platform และ Thread 1.3.0 Component อย่างเป็นทางการ เหมาะสำหรับ Matter-over-Thread end device เช่น door/window sensor และ occupancy sensor ที่ต้องการอายุแบตเตอรี่นานหลายปี

RadioIEEE 802.15.4 + Bluetooth 5 LE
ProtocolZigbee 3.0 / Thread 1.3.0 / Matter
Deep Sleep~7 µA
ข้อจำกัดไม่มี Wi-Fi ต้องต่อ Thread mesh เท่านั้น

Matter 1.6 + ESP32-H4

Energy Harvesting · Off-Grid IoT
PowerFeather ESP32-S3: โซลูชัน Off-Grid Solar ระดับ Pro

PowerFeather คือ development board ที่ออกแบบมาสำหรับโปรเจกต์ที่ต้องการพลังงานจากโซลาร์เซลล์โดยเฉพาะ มี MPPT (Maximum Power Point Tracking) ในตัว รองรับกระแสชาร์จสูงสุด 2A และมี quiescent current ต่ำกว่า 100 µA เมื่อใช้ร่วมกับ deep sleep mode ของ ESP32-S3 (5-10 µA) สามารถให้ระบบทำงานได้หลายเดือนด้วยแผงโซลาร์ขนาดเล็ก

💧 ระบบตรวจสอบคุณภาพน้ำอัจฉริยะด้วย ESP32 (pH + TDS + Turbidity + Temp)

สร้างระบบ IoT วัดคุณภาพน้ำแบบ real-time ครบ 4 พารามิเตอร์ ส่งข้อมูลขึ้น ThingSpeak หรือ Firebase ดูผ่าน web dashboard ได้ทุกที่ ต้นทุนรวมต่ำกว่า 2,500 บาท เหมาะสำหรับตู้ปลา สระน้ำ บ่อเพาะเลี้ยงสัตว์น้ำ หรือมอนิเตอร์น้ำประปา

  • 1ต่อ pH sensor module (analog) เข้า ADC ของ ESP32 — ต้อง calibrate ด้วย buffer solution pH 4.0 และ 7.0
  • 2ต่อ TDS sensor module (analog) และ DS18B20 (digital OneWire) สำหรับวัดอุณหภูมิน้ำ
  • 3ต่อ Turbidity sensor (analog หรือ digital) วัดความขุ่นของน้ำ
  • 4ส่งข้อมูลทุก 5 นาทีขึ้น ThingSpeak API ผ่าน Wi-Fi สร้าง Chart และ Alert เมื่อค่าผิดปกติ
  • 5เพิ่ม Neural Network บน ESP32 เพื่อแยกแยะโปรไฟล์สิ่งปนเปื้อน (accuracy >99%)

🔋 ESP32-H2 Matter-over-Thread: Door Sensor อายุแบตเตอรี่ 2 ปี

สร้าง door/window sensor ที่เชื่อมต่อกับ Matter network ผ่าน Thread protocol โดยใช้ ESP32-H2 ที่ใช้พลังงานต่ำมาก wake-on-GPIO เมื่อประตูเปิด-ปิด แล้วส่งสถานะไปยัง Thread Border Router (ที่สร้างด้วย ESP32-C6 อีกตัวหนึ่ง) และแสดงผลใน Home Assistant หรือ Apple Home ได้เลย

  • 1ตั้งค่า Thread Border Router ด้วย ESP32-C6 + ESP Thread Border Router SDK
  • 2โปรแกรม ESP32-H2 ด้วย ESP-IDF + ESP-Zigbee หรือ ESP-Thread SDK
  • 3ใช้ reed switch เป็น trigger wake-up GPIO — ไม่ใช้ polling ช่วยประหยัดพลังงาน
  • 4ทดสอบ deep sleep current <10 µA เพื่อให้แบตเตอรี่ CR2032 อยู่ได้ 1-2 ปี
  • 5Commission อุปกรณ์เข้า Matter network ด้วย QR Code pairing

☀️ Solar-Powered Weather Station IoT แบบ Off-Grid ด้วย ESP32-S3

สร้างสถานีตรวจวัดสภาพอากาศที่ทำงานได้โดยไม่ต้องมีไฟฟ้า ใช้แผงโซลาร์ขนาด 5W + แบตเตอรี่ LiPo 3000mAh ร่วมกับ IC MPPT BQ25504 หรือ PowerFeather board วัดอุณหภูมิ ความชื้น ความดันบรรยากาศ และระดับ UV ส่งข้อมูลผ่าน Wi-Fi ทุก 15 นาที ขณะที่ระหว่างนั้น deep sleep อย่างสมบูรณ์

  • 1เลือก PowerFeather board หรือวงจร BQ25504 + TP4056 + solar panel 5–10W (6V)
  • 2ต่อ BME280 (I2C) วัด temp/humidity/pressure + VEML6075 วัด UV-A, UV-B
  • 3ใช้ esp_sleep_enable_timer_wakeup() ตั้ง wakeup ทุก 15 นาที บันทึกค่าลง RTC memory
  • 4ส่งข้อมูล batch (ทุก 4 measurement รวมกัน) ผ่าน MQTT ไป InfluxDB + Grafana dashboard
  • 5ทดสอบ energy budget: วัด current draw แต่ละ state ด้วย PPK2 หรือ INA226

🌬️ เครื่องวัดคุณภาพอากาศภายในอาคาร ESP32 + ENS160 + SCD41

สร้างเครื่องมอนิเตอร์คุณภาพอากาศในห้องทำงานหรือห้องนอน รวม 5 พารามิเตอร์: CO₂ (SCD41), TVOC, eCO₂, AQI (ENS160), อุณหภูมิ และความชื้น (AHT21) แสดงผลบน OLED display และส่งแจ้งเตือนผ่าน LINE Notify เมื่อ CO₂ เกิน 1,000 ppm หรือ TVOC สูงผิดปกติ

  • 1ต่อ ENS160+AHT21 โมดูล combo (I2C) ซึ่งวัด TVOC (0-65,000 ppb), eCO₂, AQI ใน IC เดียว
  • 2ต่อ SCD41 (Sensirion, I2C) สำหรับ CO₂ จริงด้วย Photoacoustic Sensing ±40 ppm accuracy
  • 3แสดงผลบน SSD1306 OLED 128×64 หรือ ST7789 TFT สี พร้อม color-coded AQI indicator
  • 4เชื่อมต่อ Home Assistant ผ่าน MQTT หรือ ESPHome และสร้าง automation เปิด fan เมื่อ CO₂ สูง

📡 ESP32 Ultrasonic Radar ด้วย HC-SR04 + SG90 Servo + Web Visualization

สร้างระบบ radar ตรวจจับวัตถุด้วย ultrasonic sensor และ servo motor ที่หมุน 180 องศา ส่งข้อมูลระยะทาง-มุมมาแสดงบน web interface แบบ real-time ผ่าน WebSocket (FreeRTOS multitasking) สามารถต่อยอดเป็นระบบ proximity alert สำหรับ home security หรือ smart parking ได้

  • 1ต่อ HC-SR04 ultrasonic sensor (Trigger + Echo GPIO) และ SG90 servo บน ESP32
  • 2สร้าง FreeRTOS task แยก: task หนึ่งสั่ง servo หมุน + ping sensor, อีก task รับค่าและส่งผ่าน WebSocket
  • 3สร้าง web page (SPIFFS) ด้วย HTML Canvas วาด radar sweep แบบ real-time รับข้อมูลผ่าน WebSocket
  • 4เพิ่ม buzzer แจ้งเตือนเมื่อตรวจจับวัตถุในระยะ <30 cm พร้อม LED indicator

เคล็ดลับ: ENS160 vs SGP30 vs MQ-135
ENS160 ดีกว่า MQ-135 มากเพราะให้ค่า digital ที่ calibrated และมี AI processing ในตัว ส่วน SGP30 ก็ดีแต่ ENS160 รุ่นใหม่กว่าและมี 4 sensing elements ทำให้แยกแยะ gas ได้ดีกว่า สำหรับ explosive gas detection ต้องใช้ MQ-2, MQ-7 เท่านั้น — ENS160 ไม่ได้ออกแบบมาสำหรับ safety application
