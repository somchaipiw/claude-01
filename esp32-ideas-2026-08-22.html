ESP-VISION — Edge AI Vision Framework แบบ Low-Code

NEW Jul 2026

Espressif เปิดตัว ESP-VISION เมื่อวันที่ 2 กรกฎาคม 2569 ซึ่งเป็น low-code framework สำหรับงาน machine vision บน edge โดยเฉพาะ รองรับ ESP32-P4, ESP32-S31 และ ESP32-S3

จุดเด่น: เขียน Python แค่ไม่กี่บรรทัดก็ได้ camera capture → image processing → on-device inference ครบในครั้งเดียว ไม่ต้องพึ่ง Cloud เลย
  • 1ครอบคลุม camera capture, image processing, video codec และ ESP-DL inference
  • 2มี built-in MCP service — ใช้งานร่วมกับ Claude และ Cursor ได้ทันที
  • 3มี official models สำเร็จรูป: face detection, object detection, pose estimation
  • 4มี Web Programming Platform สำหรับเขียนโค้ดออนไลน์

TinyGS — เครือข่ายสถานีรับสัญญาณดาวเทียมแบบ Open Source

Space IoT

TinyGS คือโปรเจกต์ open source ที่ให้คุณสร้าง ground station รับสัญญาณดาวเทียมด้วย ESP32 + LoRa module ราคาไม่แพง เชื่อมต่อกับเครือข่ายสถานีทั่วโลกได้

ล่าสุด (ส.ค. 2569): ชุมชนแก้ปัญหาการรับสัญญาณที่ 800/900 MHz, ค้นพบความแตกต่างของ SX1262 sync-word สำหรับ LoRaWAN satellites และแลกเปลี่ยนความรู้เรื่องเสาอากาศ
  • 1ใช้ ESP32 + SX1262/SX1278 LoRa module เป็น hardware หลัก
  • 2Flash firmware TinyGS แล้วเชื่อมต่อ MQTT broker กลาง
  • 3ดูข้อมูลดาวเทียมผ่าน TinyGS Dashboard บนเว็บ
  • 4รองรับดาวเทียม cubesat หลายดวงทั่วโลก

ESP32-S3 + ESP-VISION Pet Monitoring Camera

Edge AI

ใช้ ESP-VISION framework รัน face/object detection บน ESP32-S3 เพื่อสร้างกล้องตรวจจับสัตว์เลี้ยงที่ ไม่ต้องพึ่ง cloud ราคาไม่แพง inference ด้วย Python ไม่กี่บรรทัด

import esp_vision as ev

cam = ev.Camera(resolution="VGA")
detector = ev.load_model("person_detection")

while True:
    frame = cam.capture()
    results = detector.run(frame)
    if results.count > 0:
        ev.notify("pet_detected", frame)
  • 1เลือก board ที่มี OV2640 / OV5640 camera module
  • 2Flash MicroPython + ESP-VISION firmware
  • 3เขียน Python script ด้วย esp_vision API
  • 4ส่ง snapshot ขึ้น Telegram bot เมื่อตรวจพบสัตว์เลี้ยง
