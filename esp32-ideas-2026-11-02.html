ESP32-P4 · New Chip

🎬 ESP32-P4 — Video Processing & Dual-Camera Pipeline

Espressif เปิดตัว ESP32-P4 อย่างเป็นทางการ เป็น flagship chip ที่ทรงพลังที่สุดในตระกูล ESP32 ณ ปัจจุบัน เหมาะกับงาน Edge AI, Video Streaming และ Industrial HMI

คุณสมบัติESP32-P4ESP32-S3
CPUDual-core 400 MHz RISC-VDual-core 240 MHz Xtensa
RAM32 MB PSRAM ในตัว512 KB + ภายนอก
CameraDual-camera ISP (H.264)ไม่มี ISP ในตัว
DisplayMIPI DSI/CSI 2-laneไม่รองรับ MIPI
USBUSB 2.0 High-Speed (480 Mbps)USB 2.0 Full-Speed
AI AcceleratorHP-ISP + PIEAI Extensions
💡 จุดเด่น: รองรับ H.264 hardware encoding จาก dual camera ส่งผ่าน MIPI DSI ไปยัง display ความละเอียดสูง เหมาะสร้าง Smart Doorbell หรือ Industrial Vision System ราคาประหยัด
  • LP-CPU (Low Power Core) สำหรับ wake-on-event โดยไม่ปลุก main cores
  • รองรับ TrustZone security สำหรับ firmware signing
  • DevKit EV-BOX-ESP32-P4-FUNCTION-EV-V1.4 มี LCD 7 นิ้วในชุด
UWB · Indoor Positioning

📍 Ultra-Wideband (UWB) + ESP32 — ระบุตำแหน่งแม่นยำ ±10 ซม.

UWB (Ultra-Wideband) เป็นเทคโนโลยี radio ที่ใช้ Time of Flight (ToF) คำนวณระยะทาง ให้ความแม่นยำสูงกว่า Bluetooth/WiFi อย่างมาก เหมาะกับ indoor positioning และ asset tracking

  • DW3000 (Qorvo) — UWB chip รองรับ IEEE 802.15.4z, ทำงานกับ SPI
  • Makerfabs MakerUWB — โมดูล ESP32-S3 + DW3000 ราคา ~$25
  • Pozyx — UWB anchor system พร้อม library Arduino/ESP32
  • ความแม่นยำ: ±10 cm ในพื้นที่ 30×30 ม. ด้วย 4 anchors
// UWB Two-Way Ranging ด้วย DW3000 + ESP32 #include "DW3000.h" void setup() { DW3000.begin(SS, RST, IRQ); // SPI pins DW3000.setMode(DW3000_TAG); DW3000.setChannel(5); // Channel 5 = 6.5 GHz DW3000.setPreambleCode(9); } void loop() { float dist = DW3000.getDistance(ANCHOR_ID); Serial.printf("Distance: %.2f m\n", dist); }
🏗 ใช้ Trilateration (3 anchors ขึ้นไป) คำนวณ x,y position — ดูตัวอย่างใน library arduino-uwb บน GitHub
LVGL 9.x · GUI Library

🖥 LVGL 9.x บน ESP32 — GUI สวยงามโดยไม่ต้องใช้ OS

LVGL (Light and Versatile Graphics Library) เวอร์ชัน 9.x เปิดตัวพร้อมฟีเจอร์ใหม่มากมาย ทำงานได้บน ESP32, ESP32-S3 และ ESP32-P4 กับ display หลายขนาด

🆕 สิ่งใหม่ใน LVGL 9: Vector graphics (SVG-like), ระบบ font แบบ scalable, Layer blending GPU, render thread แยกจาก app thread
  • lv_conf.h — ปรับ LV_COLOR_DEPTH เป็น 16 หรือ 24 bit
  • รองรับ display driver: ILI9341, ST7789, GC9A01, SSD1306
  • Widget ใหม่: lv_scale, lv_imagebutton, lv_spinbox
  • SquareLine Studio — drag & drop UI designer ออก .c ให้ทันที
// LVGL 9 สร้าง Arc gauge + Label lv_obj_t *arc = lv_arc_create(lv_screen_active()); lv_arc_set_range(arc, 0, 100); lv_arc_set_value(arc, 72); // 72% lv_obj_set_size(arc, 150, 150); lv_obj_center(arc); lv_obj_t *lbl = lv_label_create(lv_screen_active()); lv_label_set_text_fmt(lbl, "%d%%", 72); lv_obj_align_to(lbl, arc, LV_ALIGN_CENTER, 0, 0);
Modbus · Industrial

🏭 Modbus RTU/TCP Gateway ด้วย ESP32 — เชื่อม Industry 4.0

Modbus เป็นโปรโตคอล industrial สุดคลาสสิกที่ยังใช้งานอยู่ทั่วโลก ESP32 สามารถทำหน้าที่เป็น Modbus RTU Master อ่านค่าจาก meter/PLC แล้วส่งขึ้น Cloud ผ่าน MQTT ได้

  • Modbus RTU — ผ่าน RS-485 (MAX485 transceiver + ESP32 UART2)
  • Modbus TCP — ผ่าน Ethernet/WiFi โดยตรง
  • Library: ModbusMaster (Arduino) หรือ esp-modbus (ESP-IDF)
  • อ่านค่าจาก: power meter, VFD, temperature controller, PLC
// อ่าน Holding Register ด้วย ModbusMaster #include "ModbusMaster.h" ModbusMaster node; node.begin(1, Serial2); // Slave ID=1 node.readHoldingRegisters(0x0000, 2); uint16_t volt = node.getResponseBuffer(0); uint16_t curr = node.getResponseBuffer(1); Serial.printf("%.1f V %.2f A\n", volt/10.0, curr/100.0);
⚡ เชื่อม RS-485 ด้วย MAX485 ราคา ~5 บาท: DE/RE ต่อกับ GPIO เดียวกัน, toggle ก่อน/หลังส่งข้อมูล

LVGL + ESP32-S3

🌡 Smart Room Dashboard — จอกลมพร้อม LVGL 9 + Sensor Hub

สร้าง standalone smart display ด้วย ESP32-S3 + จอ GC9A01 (กลม 1.28 นิ้ว) แสดงข้อมูล sensor ด้วย LVGL 9 ดีไซน์ modern

  • 📦 Hardware: XIAO ESP32-S3 + GC9A01 round display + SHT41 + BH1750
  • 🌡 แสดงอุณหภูมิ/ความชื้น/แสง ด้วย Arc gauge + animated needle
  • ⏰ NTP time sync แสดงนาฬิกาแบบ analog dial บน LVGL
  • 💤 deep sleep ระหว่างไม่ใช้งาน ปลุกด้วย PIR motion sensor
  • 📡 MQTT publish ทุก 60 วินาที ส่งข้อมูลไป Home Assistant
💰 ราคาวัสดุรวม: XIAO ESP32-S3 (~280฿) + GC9A01 (~120฿) + sensors (~150฿) = ประมาณ 550 บาท
🛠 Library ที่ใช้: LVGL 9.2, Arduino_GFX (display driver), AHTX0 (temp/humidity)
UWB · Asset Tracker

📦 UWB Asset Tracker ในโรงงาน — ติดตามของด้วยความแม่นยำ 10 ซม.

ระบบ real-time asset tracking สำหรับโรงงาน ใช้ UWB anchors 4 จุดและ tag ติดกับอุปกรณ์ แสดงตำแหน่งบน web dashboard

  1. ติดตั้ง UWB Anchor (DW3000 + ESP32) 4 มุมห้อง ขนาด 10×10 ม.
  2. Tag (DW3000 + ESP32-C3) ส่ง ranging request ไปทุก anchor
  3. ทำ Two-Way Ranging (TWR) วัดระยะทางไป 3–4 anchors
  4. คำนวณ position ด้วย Trilateration algorithm บน ESP32
  5. ส่ง x,y coordinate ผ่าน MQTT → Node-RED → Grafana
  6. แสดง Floor Plan แบบ real-time ด้วย canvas JavaScript
📊 ความแม่นยำที่ทดสอบจริง: ±8–15 ซม. ใน LOS (Line of Sight), ±25–40 ซม. ผ่านผนัง
Industrial · Modbus

⚡ ESP32 Modbus-to-MQTT Gateway — โรงงานขึ้น Cloud ง่ายๆ

แปลง Modbus RTU (RS-485) เป็น MQTT เพื่อส่งข้อมูลจาก legacy equipment (power meter, VFD, PLC) ขึ้น cloud โดยไม่ต้องเปลี่ยน hardware เดิม

  • 🔌 ต่อ MAX3485 กับ UART2 ของ ESP32 (TX=17, RX=16, DE=4)
  • 📊 อ่าน Eastron SDM120 power meter ทุก 10 วินาที
  • ☁️ ส่งค่า voltage, current, power, energy ขึ้น AWS IoT Core
  • 📱 แจ้งเตือน LINE Notify เมื่อ power เกิน threshold
  • 💾 บันทึก CSV ลง SD card เป็น local backup
// Modbus → MQTT payload (JSON) snprintf(payload, sizeof(payload), "{\"V\":%.1f,\"A\":%.3f,\"W\":%.1f,\"kWh\":%.3f}", voltage, current, power, energy); mqtt.publish("factory/meter/1", payload);
ESP32-P4 · Vision

📸 ESP32-P4 Dual-Camera Security System — H.264 Stream ราคาไม่แพง

ใช้ ESP32-P4 EV Board กับ dual camera module สร้างระบบ security camera ที่ encode H.264 บน chip เอง ไม่ต้องใช้ SoC แยก

  • 📷 กล้องหน้า: OV5647 (5MP) ผ่าน MIPI-CSI 2-lane
  • 🔒 กล้องหลัง: OV2640 (2MP) IR cut สำหรับ night vision
  • 🎬 H.264 hardware encode ที่ 1080p/30fps ใช้ไฟน้อย
  • 📡 RTSP stream ผ่าน WiFi 6 (802.11ax) ด้วย ESP32-C6 companion
  • 🤖 Face detection บน HP-ISP ด้วย model YOLO-nano ใน firmware
💡 ESP-IDF 5.3+ รองรับ ESP32-P4 อย่างเป็นทางการ — ดู example esp-who บน GitHub สำหรับ face recognition
E-Paper · Dashboard

🗒 E-Paper Modbus Dashboard — แสดงข้อมูลโรงงานโดยไม่ต้องมีไฟ

ESP32 อ่านค่า Modbus แล้วแสดงบน E-Paper 4.2 นิ้ว (B/W/R) อัปเดตทุก 5 นาที ใช้ solar cell ขนาดเล็กเป็น power supply ไม่ต้องเดินสายไฟ

  • 📟 GDEY042T81 — E-Paper 4.2 นิ้ว 400×300 px SPI
  • 🌡 แสดง: อุณหภูมิ, ความดัน, กำลังไฟฟ้า, สถานะ machine
  • ⚡ deep sleep 5 นาที ตื่นมาอ่าน Modbus → อัป display → กลับนอน
  • 🔋 ใช้พลังงาน: ~150 µA เฉลี่ย รัน AAA 2 ก้อน ได้หลายเดือน

Spectral · Color

🌈 AS7341 — 11-Channel Spectral Color Sensor

Sensor วัดสีที่แยก spectrum ได้ 11 ช่อง ตั้งแต่ 415–940 nm เหมาะกับงาน color matching, plant health monitoring และ food quality analysis

พารามิเตอร์ค่า
InterfaceI2C (0x39)
ChannelsF1–F8 + Clear + NIR + Flicker
Wavelength Range415–940 nm
Supply Voltage1.7–3.6V
ราคา (Breakout)~$10–15 (Adafruit/SparkFun)
🌱 Use Case: ส่องแสงใส่ใบพืช วัด chlorophyll index จาก ratio ระหว่าง Red/NIR channel ตรวจสุขภาพต้นไม้โดยไม่ต้องทำลายตัวอย่าง
  • Library: Adafruit_AS7341 ใช้ง่าย พร้อม example
  • มี LED driver ในตัว สำหรับ active illumination
  • Flicker detection: ตรวจ 50/60Hz flicker จากไฟ LED
ToF · Depth

📐 VL53L5CX — 8×8 Multi-Zone Time of Flight

ST Microelectronics ผลิต ToF sensor ที่วัดระยะพร้อมกันได้ 64 โซน (8×8 grid) ในเฟรมเดียว เหมาะกับงาน people counting, gesture, presence detection

พารามิเตอร์ค่า
InterfaceI2C / SPI
Zones8×8 = 64 zones
Max Range400 cm (standard mode)
FoV65°
Frame Rateถึง 60 Hz (4×4 mode)
ราคา~$15 (Pololu breakout)
👤 People Counting: เมาท์ไว้เพดาน ทางเข้า-ออก วิเคราะห์ depth map 8×8 แยกคนเข้า/ออก accuracy สูงกว่า PIR มาก
  • ต่อกับ ESP32-S3 ผ่าน I2C ที่ 400 kHz หรือ 1 MHz (Fast-mode+)
  • Library: SparkFun_VL53L5CX มี example people counting
UV · Light

☀️ LTR-390-UV-01 — UV Index + Ambient Light Sensor

Sensor รวม 2 ฟังก์ชันในชิปเดียว: วัด UV (280–430 nm) สำหรับคำนวณ UV Index และวัด Ambient Light เพื่อปรับ backlight อัตโนมัติ

พารามิเตอร์ค่า
InterfaceI2C (0x53)
UV Range280–430 nm
ALS Range0.01–64000 lux
Resolutionถึง 20 bit
Supply1.7–3.6V
ราคา~$5 (Adafruit breakout)
🏖 Use Case: Wearable UV Monitor แจ้งเตือนเมื่อ UV Index เกิน 6 (High) ผ่าน haptic feedback หรือ buzzer ป้องกันผิวไหม้แดด
  • Library: Adafruit_LTR390 — อ่านค่าทั้ง ALS และ UV ในไลน์เดียว
  • ใช้ร่วมกับ GPS แสดง UV forecast บน map ตาม location
  • สอบเทียบกับ WHO UV Index standard ผ่าน formula ใน datasheet
