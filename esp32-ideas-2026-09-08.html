Espressif · เปิดตัว พฤษภาคม 2026

Espressif ปล่อย ESP32-P4 เวอร์ชัน 3.x ในเดือนพฤษภาคม 2026 ถือเป็นการอัปเกรดครั้งใหญ่ที่สุดนับตั้งแต่ชิปออกสู่ตลาด ด้วยการเพิ่ม clock speed, ระบบ Image Signal Processor (ISP) ที่แม่นยำขึ้น, power management ที่ดีขึ้น และ security features ระดับ enterprise

LLM บน ESP32-S3 — 28.9M Parameters ที่ 10 tokens/sec
Edge AI Milestone · กรกฎาคม 2026

กรกฎาคม 2026 นักพัฒนาทำสิ่งที่หลายคนคิดว่าเป็นไปไม่ได้: รัน LLM ขนาด 28.9 ล้าน parameter บน ESP32-S3 ราคา 8 ดอลลาร์ ได้ความเร็วเกือบ 10 tokens ต่อวินาที โดยใช้เทคนิค INT4 quantization และ SIMD instructions ที่มีใน S3

โมเดลที่ใช้คือ LLM ขนาดเล็กที่ผ่านการ fine-tune สำหรับ embedded systems โดยเฉพาะ เปิดประตูให้ IoT devices มี "สติปัญญา" ในตัวโดยไม่ต้องพึ่ง cloud API ใช้งานได้แม้ในพื้นที่ไร้สัญญาณอินเทอร์เน็ต

🔥 Use Cases ที่น่าสนใจ: Smart Home Voice Assistant ออฟไลน์, Industrial Fault Diagnosis ที่แปลผลด้วยภาษามนุษย์, Agricultural Sensor Hub ที่อธิบายสภาพดิน/อากาศเป็นประโยค

Matter 1.5 + IKEA ทิ้ง Zigbee — ESP32-C6 คือผู้ชนะ
Smart Home Protocol Shift · 2026

Matter 1.5.1.0 เปิดตัวอย่างเป็นทางการในเดือนเมษายน 2026 เพิ่ม support สำหรับ IP Camera, Soil Sensor, Roller Blind/Closure และปรับปรุง ICD (Intermittently Connected Device) ให้อุปกรณ์ที่ใช้แบตเตอรีอยู่ได้นานขึ้น

สัญญาณที่ชัดเจนที่สุดคือ IKEA ประกาศเลิกใช้ Zigbee หันมาใช้ Matter/Thread แทนในสินค้าใหม่ทั้งหมด ตามหลัง Philips Hue, Aqara และ Nanoleaf ที่เปลี่ยนทิศทางมาแล้วก่อนหน้า ESP-IDF v6.0.2 (มิถุนายน 2026) รองรับ Thread/Matter บน ESP32-C6 แบบ production-ready อย่างสมบูรณ์

Sensirion SEN66 — Air Quality Sensor ตัวเดียวครบทุกอย่าง
Particulate Matter + Gas + Climate ใน 1 Module

SEN66 เป็น all-in-one air quality sensor ที่วัดพารามิเตอร์ 6 อย่างในตัวเดียว: PM1.0, PM2.5, PM10 (Particulate Matter), NOx Index, VOC Index, CO₂ (NDIR), อุณหภูมิ และความชื้น สะดวกกว่าการซื้อ sensor แยกแล้วรวม I2C bus มาก

Interface: I2C (address 0x6B), 3.3V supply, ใช้ไฟ ~75mA ขณะวัด Sensirion มี Arduino library พร้อมใช้ใน Arduino IDE และ ESP-IDF

// ตัวอย่าง code ESP32 + SEN66 (Arduino) #include <SensirionI2CSen66.h> #include <Wire.h> SensirionI2CSen66 sen66; void setup() { Wire.begin(21, 22); // SDA, SCL sen66.begin(Wire); sen66.startMeasurement(); } void loop() { float pm25, co2, voc, nox, temp, hum; sen66.readMeasuredValues(pm25, /*pm1*/_, /*pm10*/_, co2, voc, nox, temp, hum); Serial.printf("PM2.5=%.1f CO2=%.0f VOC=%.0f\n", pm25, co2, voc); delay(1000); }

INA228 — Power Monitor ความแม่นยำสูง ±0.1% สำหรับ Solar/Battery
Texas Instruments · 85V, 20-bit, I2C

INA228 เป็น power monitor 20-bit ที่วัดแรงดัน bus ได้สูงถึง ±85V และกระแส shunt ด้วย precision ±0.1% ทำให้เหมาะมากสำหรับระบบ Solar, EV Charger, หรือ Industrial Power Monitoring ที่ต้องการความแม่นยำสูง

รองรับการคำนวณ Power, Energy สะสม และ Charge สะสมใน hardware โดย INA228 จะเก็บ energy accumulator ไว้จนกว่า ESP32 จะมา query ผ่าน I2C ช่วยลด interrupt load บน MCU อย่างมาก

ฟรี
  1. ติดตั้ง ESPHome Dashboard ผ่าน Home Assistant Add-ons หรือ Docker: docker run -p 6052:6052 ghcr.io/esphome/esphome:2026.4.0
  2. สร้าง Device ใหม่ เลือก ESP32-C6 และเปิด Matter/Thread feature
  3. วาง config YAML นี้ใน ESPHome:
    esphome: name: occupancy-c6 friendly_name: "ห้องนอน Occupancy" esp32: board: esp32-c6-devkitc-1 framework: type: esp-idf matter: # Enable Matter over Thread binary_sensor: - platform: gpio pin: GPIO4 name: "Occupancy" device_class: occupancy filters: - delayed_off: 30s on_press: - logger.log: "มีคนในห้อง!"
  4. กด Install → เลือก Plug into this computer → รอ flash ประมาณ 2 นาที
  5. เปิด Apple Home / Google Home / HA → เพิ่ม Matter Device → สแกน QR code จาก ESPHome → เสร็จ!

✅ ผลลัพธ์: PIR sensor ที่ทำงานได้ทันทีบน Apple Home, Google Home, Home Assistant โดยไม่ต้องมี bridge หรือ hub ใดๆ เพิ่มเติม ต้นทุนรวมไม่ถึง 200 บาท
