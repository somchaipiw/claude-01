ESP32-C6 · Thread/Matter
ESP32-C6 กลายเป็น Thread Border Router แบบ Single-Chip ราคา $5
ชุมชน Home Assistant และนักพัฒนา Maker ค้นพบว่า ESP32-C6 ซึ่งมี 3 วิทยุในชิปเดียว (Wi-Fi 6, BLE 5.3, IEEE 802.15.4) สามารถทำงานเป็น Thread Border Router แบบ standalone ได้โดยตรงผ่าน ESP-IDF v5.4.1 โดยไม่ต้องใช้ OTBR add-on แยก ระบบจะ expose REST API บนพอร์ต 8080 ให้ Home Assistant ค้นพบและเชื่อมต่อกับ Matter over Thread devices ในบ้านได้ทันที
ข้อดีหลัก: ต้นทุนต่ำมาก (ESP32-C6 ราคาประมาณ $3–5), ใช้ไฟน้อย (RISC-V single-core 160 MHz + LP core 20 MHz), เหมาะทำ border router ที่เปิดตลอด 24/7 โดยไม่เปลือง power — ดีกว่าใช้ Raspberry Pi มาก

Solar IoT · ESP32-C3
SN1 Solar Node — บอร์ด ESP32-C3 พร้อม Solar + IP67 สำหรับงาน Off-Grid
SN1 Solar Node คือบอร์ดพัฒนาแบบ all-in-one สำหรับโปรเจกต์ IoT นอกอาคาร ตัวกล่องทำจากพลาสติก IP67 กันน้ำ/กันฝุ่น มีแผง Solar Cell ขนาดเล็กติดอยู่บนฝา รองรับแบตเตอรี่ 18650 และชาร์จอัตโนมัติผ่าน charging IC ในตัว ใช้ ESPHome เป็น firmware หลัก ทำให้ integrate กับ Home Assistant ได้ทันทีโดยไม่ต้องเขียนโค้ด
ด้วย deep sleep ที่ดึงกระแสเพียง 5–10µA บวกกับ Solar recharge — node หนึ่งตัวสามารถทำงานได้ นานหลายเดือนถึงปี โดยไม่ต้องชาร์จ เหมาะสำหรับ soil moisture monitoring ในไร่นา, rainfall gauge, air quality ริมถนน

ESPHome 2026 · Performance
ESPHome 2026 — Compile เร็วขึ้น 36%, Flash น้อยลง 44%, RAM ลด 50%
ESPHome เวอร์ชันปี 2026 มีการปรับปรุงด้าน performance อย่างมีนัยสำคัญ: compilation เร็วขึ้น 36%, binary size ลดลง 44%, และ static RAM usage ลดลง 50% ทำให้สามารถใช้งานบน ESP32 รุ่นเก่าและ ESP8266 ที่มี memory จำกัดได้ดียิ่งขึ้น นอกจากนี้ esp32_ble_tracker loop ใช้ CPU น้อยลงถึง 85% ด้วย state change tracking — ช่วยลดการตื่นนอนโดยไม่จำเป็นใน deep sleep applications
ผลกระทบจริง: โปรเจกต์ที่ต้องการ BLE scanning + Wi-Fi พร้อมกัน สามารถทำงานได้นานขึ้นบนแบตเตอรี่ เพราะ CPU ไม่ต้องทำงานหนักขนาดเดิม — เหมาะกับ battery-powered BLE gateway

TinyML · Sensor Fusion
ESP32-S3 + TinyML Multi-Sensor Fusion — AI ตัดสินใจจาก 5 Sensors พร้อมกัน
โปรเจกต์ล่าสุดบน ESP32-S3 แสดงให้เห็นว่า TensorFlow Lite Micro (TFLM) รองรับ multimodal sensor fusion โดยรับข้อมูลจาก microphone, light sensor, temperature, humidity, และ PIR พร้อมกัน แล้วให้ model ตัดสินใจว่าห้องอยู่ในสถานะ "occupied/noisy/secure" โดย dual-core ของ ESP32-S3 แบ่งงาน: core 0 เก็บข้อมูล sensor, core 1 รัน inference — latency รวมอยู่ที่ 40–60ms
ตัวอย่างที่น่าสนใจ: RC car ไร้คนขับแบบ bare-metal ใช้ INT8 MobileNetV2 บน ESP32-S3 ผ่าน FreeRTOS ทำ real-time inference บน camera + IMU sensor fusion ได้ที่ 40ms โดยไม่ต้องพึ่ง cloud เลย

Home Automation · Thread
DIY Thread Border Router ด้วย ESP32-C6 เชื่อม Matter กับ Home Assistant
ใช้ ESP32-C6-DevKitC-1 (ราคาประมาณ 150 บาท) flash firmware border router ผ่าน ESP-IDF v5.4.1 บอร์ดจะทำหน้าที่เป็นตัวกลางระหว่าง Thread mesh network กับ Wi-Fi router ทำให้ Matter-over-Thread devices เช่น smart bulb, sensor, lock สามารถ join เครือข่าย Home Assistant ได้โดยตรง Home Assistant ค้นพบ router ผ่าน OTBR REST API พอร์ต 8080 อัตโนมัติ ทั้งหมดทำงานในบ้าน ไม่พึ่ง cloud
1. ซื้อ ESP32-C6-DevKitC-1
2. ติดตั้ง ESP-IDF v5.4.1
3. Flash thread_border_router firmware
4. เปิด Home Assistant → Thread Integration
5. Pair Matter devices
ต้นทุนประมาณ: ~150–250 บาท · ระดับ: ปานกลาง · เวลา: 2–3 ชั่วโมง
Health · Wearable
Wearable Health Monitor — ECG + SpO2 + BPM ส่งข้อมูลผ่าน BLE Dashboard
รวม AD8232 (ECG single-lead) และ MAX30102 (SpO2 + Heart Rate) เข้ากับ ESP32 ทำ wearable patch สำหรับ monitor สุขภาพแบบ real-time MAX30102 วัด SpO2 ผ่าน I2C ดึงกระแสเพียง 600µA ขณะวัด / 0.7µA ขณะ standby — เหมาะมากสำหรับใช้แบตเตอรี่ coin cell ส่วน AD8232 วัดคลื่นไฟฟ้าหัวใจแบบ analog แล้ว ESP32 ประมวลผล HR variability และส่งผ่าน BLE Notify ไปแสดงบน smartphone app หรือ web dashboard ผ่าน Wi-Fi

Sensor 2: AD8232 (Analog)

UI: Web Dashboard / App

Solar · Off-Grid
Solar IoT Sensor Node แบบ Off-Grid — ทำงานได้นานหลายเดือนโดยไม่ต้องชาร์จ
ออกแบบ sensor node สำหรับวาง outdoor ระยะไกล: ใช้ ESP32 + โซล่าเซล 5W + TP4056 + แบตเตอรี่ 18650 กล่อง IP65 กันน้ำ เพิ่ม BME280 วัด temp/humidity/pressure และ LDR วัดแสง ใช้ deep sleep 5µA ตื่นทุก 5–15 นาทีเพื่อวัดและส่งข้อมูลผ่าน Wi-Fi/MQTT แล้วกลับ deep sleep ทันที คำนวณ power budget: ถ้าตื่น 3 วินาที ดึง 70mA, deep sleep ดึง 10µA — แบต 2000mAh จะอยู่ได้ >6 เดือน ถ้าไม่มีแสงอาทิตย์เลย

Maxim Integrated · Pulse Oximeter + Heart Rate
วัด SpO2 (ออกซิเจนในเลือด) และ Heart Rate (BPM) โดยใช้ LED แดง (660nm) + LED IR (880nm) ฉายผ่านผิวหนัง photodetector ตรวจ pulse ในเลือด ดึงกระแสเพียง 600µA ขณะทำงาน / 0.7µA standby — เหมาะสำหรับ wearable มีขนาดเล็กมาก (5.6×3.3mm) เชื่อมต่อผ่าน I2C มี built-in ambient light rejection

AD8232
Analog Devices · ECG Single-Lead Monitor
IC สำหรับวัด คลื่นไฟฟ้าหัวใจ (ECG) แบบ single-lead โดยขยาย bioelectric signal ที่อ่อนมาก (mV) ให้อยู่ในช่วงที่ ADC ของ ESP32 อ่านได้ มี built-in right leg drive (RLD) และ lead-off detection แบบ active ทำให้ signal สะอาด ใช้ในเครื่อง fitness tracker, patch ECG, และ research prototype
