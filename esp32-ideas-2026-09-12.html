🎬 ESP32-P4 Fresh Build
นาฬิกาปลุกวิดีโอ ESP32-P4 — ปลุกด้วยหนังแทนเสียง Beep

โปรเจกต์ล่าสุดจาก Hackaday (7 ก.ย. 2026) โดย brunokeymolen ที่ใช้ Waveshare ESP32-P4-WIFI6-Touch-LCD-4B สร้างนาฬิกาปลุกที่เล่นวิดีโอแทนเสียง Beep บนจอ MIPI-DSI 720×720px

  • ESP32-P4 — Dual-core RISC-V 400MHz + 32MB Flash + 32MB PSRAM
  • ES8311 Audio Codec — เสียง PCM Stereo 44.1kHz คมชัด
  • GT911 Touch Controller — กดหน้าจอปิดปลุกได้เลย
  • MicroSD FAT32 — เก็บวิดีโอ MJPEG ในรูปแบบ AVI ได้ไม่จำกัด
  • RTC ในตัว — เวลาแม่นยำไม่ต้องซิงก์ตลอดเวลา
🎯 ไม่ต้องต่อฮาร์ดแวร์เพิ่ม — Dev board มีทุกอย่างครบ งานทั้งหมดเป็น Software + 3D Print ขาตั้ง

🌤️ DIY Weather Station
ESP32-P4 Weather Station + LoRa/ESP-NOW — Dashboard จอ 10.1 นิ้ว

สถานีตรวจอากาศ DIY ด้วย ESP32-P4 จอ 10.1 นิ้ว แสดง Dashboard ครบ รับข้อมูลจาก Wireless Sensor Network ผ่าน LoRa และ ESP-NOW พร้อมดึง API Weather ออนไลน์

  • Sensirion SEN66 — PM1/2.5/4/10 + CO₂ + VOC + NOx + Temp + Humidity ตัวเดียว
  • LoRa Gateway — รับข้อมูลจาก Remote Sensor ห่างได้หลาย km
  • ESP-NOW Nodes — Sensor nodes ในบ้านไม่ต้องใช้ Router
  • Weather APIs — OpenWeatherMap, Open-Meteo, Visual Crossing
  • 10.1" Dashboard — แสดง Graph ประวัติย้อนหลัง 72 ชั่วโมง

🏠 Smart Home 2026
ESP32-C6 กับ Matter 1.5 — Wi-Fi 6 + Zigbee + Thread + BLE ในราคา $5

ESP32-C6 กลายเป็น MCU ที่ครบสุดสำหรับ Smart Home — รองรับ Wi-Fi 6, BLE 5, Zigbee 3.0, Thread 1.3 และ Matter 1.5 ทั้งหมดในชิปตัวเดียว ไม่ต้องใช้โมดูลเพิ่ม

  • Matter 1.5 เพิ่ม Water Leak Sensor และ Energy Management device types
  • เชื่อมกับ Apple HomeKit, Google Home, Amazon Alexa โดยตรง
  • ESP-Matter SDK เปิด Open Source บน GitHub
  • Commissioning ด้วย QR Code ผ่าน Bluetooth LE

🎙️ Voice AI On-Device
ESP32 + Edge Impulse — Voice Command Recognition ไม่ต้องใช้ Cloud

รัน Neural Network สำหรับจดจำเสียงสั่งการ บน ESP32/ESP32-S3 โดยตรง ด้วย Edge Impulse platform ฝึก Model ออนไลน์ Deploy ได้ใน 30 นาที

  • เก็บ Audio Data ผ่าน INMP441 MEMS Microphone (I2S)
  • Features: MFCC (Mel-Frequency Cepstral Coefficients) 13 coefficients
  • Model: 1D CNN / MobileNet — Quantized INT8 ≤80KB RAM
  • Inference latency: ~50ms บน ESP32-S3
  • คำสั่งพื้นฐาน: "เปิดไฟ", "ปิดไฟ", "เพิ่มอุณหภูมิ" ความแม่นยำ >92%
// รัน inference บน ESP32 ei_impulse_result_t result; signal_t signal; numpy::signal_from_buffer(raw_audio, N_SAMPLES, &signal); run_classifier(&signal, &result, false); // result.classification[] → scores per label

🌬️ Air Quality Monitor
🔬 Project Aura — Open-Source Professional Air Quality Monitor

Project Aura บน Hackaday.io เป็น Open-Source Air Quality Monitor ระดับมืออาชีพ ด้วย Sensirion Sensors และจอสัมผัส 4.3 นิ้ว รองรับ Home Assistant แบบ Local

  • วัด PM1 / PM2.5 / PM4 / PM10 — ฝุ่นทุกขนาด
  • วัด CO₂ (แม่นยำ NDIR ≤30ppm accuracy)
  • วัด VOC + NOx + Formaldehyde
  • วัด Temp + Humidity + Pressure
  • จอ 4.3" Touch Display — กราฟ real-time + Trend 24h
  • MQTT → Home Assistant หรือ Grafana Dashboard
📋 ต้นทุนประมาณ: ESP32-S3 + SEN66 + SCD41 + Display ≈ 1,800-2,500 บาท
🐟 Smart Agriculture
🌱 ระบบ Aquaponics อัจฉริยะ — ESP32 ควบคุมปลา+ผักพร้อมกัน

ระบบ Aquaponics (เลี้ยงปลา+ปลูกผักในระบบเดียว) อัตโนมัติด้วย ESP32 ครบวงจร — วัด Monitor ทุก Sensor สั่งปั๊มน้ำ, ระบบให้อาหาร และแจ้งเตือนผ่าน Line OA

  • pH Sensor — รักษาค่า 6.5-7.5 (เหมาะปลาและพืช)
  • DO Sensor — Dissolved Oxygen ≥5 mg/L สำหรับปลา
  • TDS/EC Meter — ธาตุอาหารพืช 1.0-2.5 EC
  • DS18B20 Waterproof — อุณหภูมิน้ำ 25-28°C
  • Water Level Ultrasonic — HC-SR04 กันน้ำ ตรวจระดับน้ำ
  • Relay Module 8ch — ควบคุมปั๊ม, หลอดไฟ, ให้อาหาร

🤚 Gesture Control
🚗 Gesture-Controlled RC Car ด้วย ESP32 + MPU6050

รถ RC ที่สั่งการด้วยท่าทือมือผ่าน MPU6050 (Accelerometer + Gyroscope) บน ESP32 ส่งคำสั่งผ่าน ESP-NOW latency ต่ำกว่า 10ms ไม่ต้องใช้ Router

  • ฝั่ง Controller: ESP32 + MPU6050 + LiPo 1000mAh
  • ฝั่ง Car: ESP32 + L298N Motor Driver + 2 DC Motor
  • เอียงซ้าย/ขวา → เลี้ยว | เอียงหน้า → เดินหน้า | เอียงหลัง → ถอย
  • Kalman Filter กรอง Gyro drift ออก
  • Range: ~100m ในที่โล่ง (ESP-NOW 2.4GHz)
🔩 ต้นทุน: ESP32 x2 (300฿) + MPU6050 (60฿) + L298N (80฿) = ~440 บาท
📍 Indoor Positioning
📡 BLE Beacon Trilateration — ระบุตำแหน่งในอาคารด้วย ESP32

ระบบ Indoor Positioning ด้วย ESP32 BLE Beacon 3+ จุด วัด RSSI ทำ Trilateration ระบุตำแหน่งคนหรือวัตถุในอาคาร ความแม่นยำ ±1-3 เมตร

  • Beacon Nodes: ESP32 ติดผนัง 3 มุมห้อง ส่ง BLE Advertisement
  • Tracker Tag: ESP32-C3 ขนาดเล็ก ติดวัตถุที่ต้องการติดตาม
  • RSSI → Distance (Log-Distance Path Loss Model)
  • Weighted Least Squares Trilateration
  • ส่งตำแหน่งไป MQTT → Node-RED → Floorplan Visualization
🏭 Use Case จริง: ติดตามเครื่องมือในโรงงาน, ระบุตำแหน่งพนักงานในคลังสินค้า

🌡️ All-in-One Environmental
Sensirion SEN66 — 6-in-1 Environmental Sensor

Sensor ตัวเดียววัดได้ 6 พารามิเตอร์: PM, CO₂, VOC, NOx, Temperature, Humidity อินเตอร์เฟส I2C ใช้งานง่ายกับ ESP32

  • PM1 / PM2.5 / PM4 / PM10 — Laser Particle Counter
  • CO₂ — NDIR ±30ppm (400-5000 ppm range)
  • VOC Index 0-500 + NOx Index 1-500
  • Temp ±0.2°C, Humidity ±3% RH
  • ราคา: ~35-45 USD
🎙️ MEMS Microphone
INMP441 — I2S MEMS Microphone สำหรับ Voice AI

ไมโครโฟน Digital MEMS ที่ใช้คู่กับ ESP32 สำหรับโปรเจกต์ Voice Command, FFT Spectrum Analyzer และ Sound Level Meter

  • อินเตอร์เฟส I2S — Digital ไม่มี noise ADC
  • SNR 61 dBFS, AOP 130 dBSPL
  • ช่วงความถี่ 60Hz - 15kHz
  • ราคา: ~30-60 บาท (โมดูล)
💡 เชื่อมกับ ESP32 I2S pins: SCK, WS, SD — ไม่ต้องใช้ ADC เลย
💨 CO₂ Precision
Sensirion SCD41 — Photoacoustic CO₂ Sensor ขนาดเล็กสุด

CO₂ Sensor ด้วยเทคโนโลยี PASens (Photoacoustic) แม่นยำกว่า NDIR ทั่วไป ขนาดเล็กพอดี DIP package ใส่บน Breadboard ได้เลย

  • ช่วง: 400 - 5000 ppm (Typical Indoor)
  • ความแม่นยำ: ±40ppm + 5% of reading
  • Self-calibration: Auto ด้วย Fresh Air algorithm
  • อินเตอร์เฟส I2C — ใช้ Library Sensirion-Arduino ได้เลย
  • ราคา: ~20-25 USD
❤️ Biometric
MAX30102 — Heart Rate + SpO₂ Pulse Oximeter

Sensor วัด อัตราการเต้นของหัวใจ และ ระดับออกซิเจนในเลือด (SpO₂) ด้วย Red/IR LED 2 สี ใช้กับ ESP32 สร้าง Health Monitor ได้ง่ายมาก

  • Heart Rate: 20-300 BPM ±5%
  • SpO₂: 0-100% ±2%
  • อินเตอร์เฟส I2C + Interrupt
  • กินไฟต่ำ: 600μA (HR Mode), 1.0mA (SpO₂ Mode)
  • ราคา: ~80-150 บาท
⚠️ ต้องใช้ Algorithm: Welch's FFT / Pan-Tompkins สำหรับความแม่นยำสูง
💧 Water Quality
DFRobot Gravity TDS Meter — วัดความบริสุทธิ์น้ำแบบ Analog

วัด Total Dissolved Solids (TDS) ในน้ำ บอกความบริสุทธิ์น้ำดื่ม, คุณภาพน้ำสระ หรือความเข้มข้นสารอาหารในระบบ Hydroponic

  • ช่วง: 0-1000 ppm TDS
  • Output: Analog 0-2.3V → ESP32 ADC
  • Compensation: ต้องวัดอุณหภูมิน้ำ (DS18B20) คู่กัน
  • ค่ามาตรฐาน: น้ำดื่ม <500ppm, น้ำบริสุทธิ์ <50ppm
  • ราคา: ~350 บาท
👃 AI Nose
Bosch BME688 — 4-in-1 Gas Sensor + AI สำหรับจดจำกลิ่น

BME688 จาก Bosch เป็น Sensor แรกที่รวม 4 Gas Heater ไว้ในตัว ทำงานร่วมกับ BSEC2 AI Algorithm เพื่อจำแนกกลิ่น สภาพอากาศ และตรวจ Air Quality Index (IAQ)

  • วัด: Temperature, Humidity, Pressure, Gas Resistance
  • BSEC2 Algorithm: IAQ, CO₂ equivalent, VOC equivalent
  • AI-Studio Software: Train Model จดจำกลิ่นเฉพาะได้
  • อินเตอร์เฟส I2C/SPI
  • ราคา: ~200-300 บาท
🧪 ไอเดีย: จดจำกลิ่นก๊าซรั่ว, กลิ่นอาหารเสีย, คุณภาพอากาศในห้องนอน
