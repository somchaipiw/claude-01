🕸️ ESP-MESH + ESP-NOW: สร้าง Self-Healing IoT Network ไม่ต้องพึ่ง Router

ESP-MESH เป็น stack ที่ Espressif พัฒนาบน Wi-Fi โดยเฉพาะ ทำให้ ESP32 หลายตัวรวมตัวกันเป็น mesh network แบบ self-organizing — ทุกโหนดเชื่อมต่อถึงกันได้โดยไม่ต้องผ่าน router กลาง เหมาะมากสำหรับโรงงาน, คลังสินค้า, หรือพื้นที่ขนาดใหญ่ที่ Wi-Fi signal ไม่ทั่วถึง

ปี 2026 Espressif ออก ESP-IDF 5.3 ที่ปรับปรุง ESP-MESH ให้รองรับ Dynamic Root Node — หากโหนด root ล่ม โหนดอื่นจะเลือก root ใหม่โดยอัตโนมัติภายใน 3–5 วินาที ทำให้ระบบทนทานต่อความล้มเหลวได้ดีขึ้นมาก

📡 mmWave Radar Sensor บน ESP32 — ตรวจจับการมีอยู่แบบ Privacy-First

เซ็นเซอร์ mmWave (60–77 GHz) รุ่นใหม่อย่าง HLK-LD2410C และ HLK-LD2450 สามารถตรวจจับ การหายใจ, การเคลื่อนไหวเล็กน้อย, และ จำนวนคน ได้โดยไม่ต้องใช้กล้อง — ความเป็นส่วนตัวสมบูรณ์ 100% เหมาะกับห้องนอน, ห้องน้ำ, ห้องผู้สูงอายุ

เชื่อมต่อกับ ESP32 ผ่าน UART (115200 baud) ใช้เพียง 2 สาย TX/RX — library ที่แนะนำคือ ncmreynolds/ld2410 ที่รองรับทุก mode ของ LD2410 series รวมถึง Engineering mode ที่แสดงค่า energy ในแต่ละ gate

ESP32 + Modbus RTU — เชื่อม PLC/VFD ในโรงงานแบบ Wireless

ESP32 ทำหน้าที่เป็น Modbus RTU Master ผ่าน RS-485 (MAX485 module) สื่อสารกับ PLC, VFD, energy meter และอุปกรณ์อุตสาหกรรมที่ใช้ protocol Modbus — แล้ว bridge ข้อมูลไปยัง MQTT/HTTP API เพื่อ visualization บน Grafana หรือ Node-RED โดยไม่ต้องแตะ legacy system

💻 ตัวอย่างโค้ด — ESP32 อ่านค่า HLK-LD2410C (UART) + MQTT Report ใช้ library ncmreynolds/ld2410 เชื่อม UART2 (GPIO16=RX, GPIO17=TX) แล้วส่งสถานะไปยัง MQTT
// ESP32 + HLK-LD2410C mmWave Presence Sensor via UART // Library: ncmreynolds/ld2410 (PlatformIO / Arduino IDE) #include <Arduino.h> #include <WiFi.h> #include <PubSubClient.h> #include <ld2410.h> #define RADAR_RX 16 #define RADAR_TX 17 ld2410 radar; HardwareSerial radarSerial(2); WiFiClient wifiClient; PubSubClient mqtt(wifiClient); void setup() { Serial.begin(115200); radarSerial.begin(256000, SERIAL_8N1, RADAR_RX, RADAR_TX); radar.begin(radarSerial, true); // true = print debug WiFi.begin("YOUR_SSID", "YOUR_PASS"); while (WiFi.status() != WL_CONNECTED) delay(500); mqtt.setServer("192.168.1.100", 1883); mqtt.connect("esp32-radar"); } void loop() { radar.read(); // อ่านข้อมูลจาก sensor if (radar.isConnected() && millis() % 1000 < 50) { String payload = "{"; payload += "\"presence\":" + String(radar.presenceDetected() ? "true" : "false"); payload += ",\"moving\":" + String(radar.movingTargetDetected() ? "true" : "false"); payload += ",\"static\":" + String(radar.stationaryTargetDetected() ? "true" : "false"); payload += ",\"move_dist\":" + String(radar.movingTargetDistance()); payload += ",\"stat_dist\":" + String(radar.stationaryTargetDistance()); payload += "}"; mqtt.publish("home/radar/bedroom", payload.c_str()); } mqtt.loop(); }

Deep Dive: ESP32 Modbus RTU Master — ขั้นตอนเชื่อมต่อ VFD จริง

คู่มือย่อสำหรับนักพัฒนาที่จะ bridge อุปกรณ์อุตสาหกรรม Modbus RTU เข้าสู่โลก IoT

1️⃣

Hardware Setup — MAX485 กับ ESP32

เชื่อม MAX485 module: DI → GPIO17 (TX), RO → GPIO16 (RX), DE+RE → GPIO4 (Direction control) เพิ่ม pull-up 120Ω ที่ปลายสาย A/B เพื่อป้องกัน reflections ใช้สายแบบ twisted pair (CAT5/CAT6 ตัดมา) สำหรับการ run สาย RS-485

MAX485RS-485Hardware
2️⃣

Software — Library ModbusMaster บน Arduino/ESP-IDF

ใช้ library 4-20ma/ModbusMaster (Arduino) หรือ Espressif's built-in ESP-Modbus (ESP-IDF) ตั้งค่า baud rate ให้ตรงกับ device (ทั่วไป 9600 หรือ 19200 baud), parity: None, stop bits: 1 และ node address ของ device (ดูจาก datasheet)

ModbusMasterESP-ModbusArduino
3️⃣

อ่าน Register — VFD Inverter (เช่น Delta C2000)

VFD ส่วนมากเก็บ output frequency ที่ holding register 0x2103, motor current ที่ 0x2104 และ DC bus voltage ที่ 0x2107 — แต่ละ brand ต่างกัน ต้องดู Modbus table ใน manual ด้วยเสมอ

4️⃣

MQTT Bridge — ส่งข้อมูลสู่ Grafana / HA

หลังอ่าน register ได้แล้ว serialize เป็น JSON payload แล้ว publish ไปยัง topic เช่น factory/line1/vfd01 ใช้ Telegraf อ่านจาก MQTT แล้วเขียนลง InfluxDB และสร้าง dashboard Grafana — เพิ่ม alert rule เมื่อ current สูงผิดปกติ (อาจบ่งบอก motor fault)

GrafanaInfluxDBTelegraf
🔒 ความปลอดภัย Modbus บน Industrial Network Modbus RTU เป็น protocol ที่ไม่มี authentication — หากนำ ESP32 ไปวางบนเครือข่ายโรงงานควร isolate ด้วย VLAN แยกจาก Wi-Fi ทั่วไป, ใช้ firewall บน router ป้องกัน unauthorized access ไปยัง MQTT broker และเพิ่ม TLS บน MQTT connection เสมอ (MQTT over SSL port 8883)
