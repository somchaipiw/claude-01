วิธีเชื่อมต่อ ESP32 กับ Modbus RTU ผ่าน RS485 ตั้งแต่ต้นจนจบ

Modbus RTU เป็น Protocol ยอดนิยมในงานอุตสาหกรรม การใช้ ESP32 เป็น Master อ่านค่าจาก Slave ผ่าน RS485 ทำได้ง่ายด้วยขั้นตอนต่อไปนี้:

  1. 1ต่อ MAX3485 (3.3V) ระหว่าง ESP32 กับ RS485 Bus: TX2→DI, RX2→RO, GPIO4→DE/RE
  2. 2ติดตั้ง Library ModbusMaster โดย Doc Walker ผ่าน Arduino Library Manager
  3. 3ตั้งค่า Baud Rate ให้ตรงกับ Slave (ทั่วไปคือ 9600 หรือ 19200 baud)
  4. 4เรียก node.readHoldingRegisters(addr, count) เพื่ออ่าน Register ที่ต้องการ
  5. 5ตรวจสอบผลด้วย node.ku8MBSuccess แล้วอ่านค่าด้วย node.getResponseBuffer(i)
  6. 6ส่งค่าขึ้น MQTT หรือ HTTP REST API เพื่อแสดงผลบน Dashboard
#include <ModbusMaster.h> ModbusMaster node; void preTransmission() { digitalWrite(DE_PIN, HIGH); } void postTransmission() { digitalWrite(DE_PIN, LOW); } void setup() { Serial2.begin(9600, SERIAL_8N1, RX_PIN, TX_PIN); node.begin(1, Serial2); // Slave ID = 1 node.preTransmission(preTransmission); node.postTransmission(postTransmission); } void loop() { uint8_t result = node.readHoldingRegisters(0x0000, 2); if (result == node.ku8MBSuccess) { float temperature = node.getResponseBuffer(0) / 10.0; Serial.printf("Temp: %.1f C\n", temperature); } delay(1000); }

เริ่มต้นใช้ LoRaWAN กับ ESP32 และ The Things Network (TTN)

LoRaWAN ช่วยให้ ESP32 ส่งข้อมูลได้ไกลโดยไม่ต้องพึ่ง Wi-Fi สำหรับ IoT กลางแจ้ง มีขั้นตอนดังนี้:

  1. 1สมัคร Account บน The Things Network (thethingsnetwork.org) และสร้าง Application พร้อม Register Device
  2. 2ใช้บอร์ด TTGO LoRa32 หรือ Heltec WiFi LoRa 32 V3 ที่มี LoRa SX1276/SX1262 ในตัว
  3. 3ติดตั้ง Library MCCI Arduino LoRaWAN และกำหนด APPEUI, DEVEUI, APPKEY จาก TTN Console
  4. 4ส่ง Payload แบบ Encoded (CayenneLPP หรือ Binary) เพื่อประหยัด Airtime
  5. 5ตั้ง TTN Webhook → Node-RED หรือ Tago.IO เพื่อแสดงผล Dashboard แบบ Real-time
  6. 6เพิ่ม Deep Sleep ระหว่าง Transmission รอบเพื่อให้แบตอยู่ได้หลายเดือน

⚠️ ใช้ frequency band ที่ถูกต้องสำหรับประเทศไทย: AS923 (923 MHz)
