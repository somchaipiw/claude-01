นวัตกรรม ESP32 ล่าสุด — ปิดท้าย Q3/2026

🚀

ESP32-P4 v3.x — 400 MHz Dual-Core พร้อม ISP ขั้นสูง

Espressif ปล่อยชิป ESP32-P4 เวอร์ชัน v3.x (พฤษภาคม 2026) อัปเกรด CPU จาก 360 MHz เป็น 400 MHz พร้อมรองรับ Zb bit-manipulation extension และ PIE acceleration ที่เร็วกว่าเดิม Image Signal Processor (ISP) ได้รับฟีเจอร์ใหม่: BLC, DPC, WBG, CROP ทำให้ถ่ายภาพในแสงน้อยดีขึ้นอย่างชัดเจน Pixel Processing Accelerator (PPA) รองรับ YUV422/YUV420 และ block ขนาด 32×32 แล้ว นอกจากนี้ยังเปิดใช้ Code Execution จาก PSRAM ได้แล้ว

ESP32-P4 400 MHz ISP v2 PSRAM Execute

ESP32-C6 — ชิปเดียวครบ WiFi 6 + Zigbee + Thread + Matter

สำหรับโปรเจกต์ Smart Home ในปี 2026 ผู้เชี่ยวชาญชี้ว่า ESP32-C6 คือจุดเริ่มต้นที่ดีที่สุด ด้วย RISC-V 160 MHz + Wi-Fi 6 + BLE 5 + IEEE 802.15.4 ในชิปเดียว รองรับ Zigbee 3.0, Thread 1.3 และ Matter แบบ native ราคาถูกและ ecosystem ครบที่สุด ESPHome ยังเพิ่ม OpenThread support แบบ native ในเวอร์ชัน 2026.3 ทำให้ build Thread device ง่ายขึ้นมาก

ESP32-C6 WiFi 6 Matter Thread 1.3
🔌

ESP32-H21 — น้องใหม่ตระกูล 802.15.4 เน้น Zigbee/Thread

Espressif เปิดตัว ESP32-H21 ซึ่งเป็นรุ่นอัปเกรดจาก H2 โดยยังคงเน้น 802.15.4 (Zigbee + Thread) และ BLE 5.0 แต่ไม่มี Wi-Fi เหมือนเดิม เหมาะสำหรับ Zigbee End Device และ Thread Border Router ที่ต้องการ power efficiency สูง ข้อดีคือราคาต่ำมาก (<$2) และประหยัดพลังงานในโหมด Deep Sleep ได้ดีกว่า C6 สำหรับ sensor node ที่ใช้แบตเตอรี่

ESP32-H21 Low Power Zigbee 3.0 BLE 5.0

มาตรฐาน Matter 1.5 เพิ่ม device type ใหม่รวมถึง Camera, Closures, Soil Sensor และ Energy Management ทำให้ ESP32-C6/C5 สามารถสร้าง Matter-native sensor สำหรับ Smart Agriculture ได้แล้ว โดย Home Assistant และ Apple HomeKit รองรับ Matter 1.5 เรียบร้อยแล้ว นับเป็นครั้งแรกที่ soil sensor เข้าไปอยู่ใน smart home ecosystem อย่างเป็นทางการ

Sensors น่าสนใจประจำวัน

ADS1292R — ECG/Biopotential ADC

Texas Instruments · SPI Interface · 24-bit

ADC ความละเอียดสูงสำหรับ biopotential ใช้วัด ECG, EEG, EMG ได้ รองรับ 2 channel 24-bit ต่อ ESP32 ผ่าน SPI ราคาประมาณ 180-250 บาท มี breakout board พร้อมใช้

SEN0517 — Soil NPK Sensor

DFRobot · RS485 Modbus · 3-in-1

วัด Nitrogen, Phosphorus, Potassium ในดินพร้อมกันด้วย sensor เดียว ใช้ RS485/Modbus ต่อ ESP32 ผ่าน MAX485 ทนทานต่อความชื้นและดิน เหมาะงาน Smart Farm จริงจัง

ICM-42688-P — 6-Axis IMU สำหรับ Wearable

TDK InvenSense · SPI/I2C · Ultra-low power

IMU รุ่นใหม่สำหรับ wearable ใช้กระแสต่ำมาก 2.7μA ใน WoM mode เหมาะ Elderly Fall Detection, Fitness Tracker, Gesture Control รองรับ FIFO buffer ทำให้ MCU sleep ได้นาน

SCD41 — CO₂ + Temp + Humidity

Sensirion · I2C · Photoacoustic NDIR

CO₂ sensor แม่นยำสูงด้วยเทคโนโลยี photoacoustic ขนาดเล็กมาก เหมาะสำหรับ indoor air quality monitor, HVAC control, office/school monitoring ร่วมกับ ESP32 และ Home Assistant

ENS160 — Multi-Gas AQI Sensor

ScioSense · I2C · TVOC + eCO₂

วัด TVOC และ eCO₂ แบบ digital ด้วย AI-based algorithm ที่อยู่ใน chip ให้ค่า AQI index โดยตรง ไม่ต้องคำนวณเอง เหมาะสำหรับ air quality dashboard ใช้ไฟเพียง 1.8V

MAX30102 — SpO₂ + Heart Rate

Maxim Integrated · I2C · Optical

Pulse oximeter ราคาถูก (~30-50 บาท) ต่อ ESP32 ง่ายมาก ผ่าน I2C มี library Arduino ครบ เหมาะโปรเจกต์ health monitor, wearable หรือ smartwatch DIY ร่วมกับ ADS1292R ทำชุด health ครบจบ

◆ Code Example

ตัวอย่าง Code — ESP32-C6 Zigbee Soil Sensor (Matter 1.5)

ESP-IDF / C — Zigbee End Device with Soil Moisture Cluster
#include "esp_zigbee_core.h"
#include "driver/adc.h"

/* Soil Moisture Cluster ID (Matter 1.5 Soil Sensor) */
#define SOIL_MOISTURE_CLUSTER_ID    0x0408
#define SOIL_MOISTURE_VALUE_ATTR    0x0000

static uint16_t read_soil_moisture(void) {
    /* Read ADC from capacitive soil sensor (0-4095) */
    int raw = adc1_get_raw(ADC1_CHANNEL_0);
    /* Map to 0-10000 (0.00% - 100.00% in 0.01% unit) */
    return (uint16_t)((4095 - raw) * 10000 / 4095);
}

void esp_zb_app_signal_handler(esp_zb_app_signal_t *signal_struct) {
    uint32_t *sig = signal_struct->p_app_signal;
    esp_err_t err = signal_struct->esp_err_status;
    switch (*sig) {
        case ESP_ZB_BDB_SIGNAL_STEERING:
            if (err == ESP_OK) {
                ESP_LOGI(TAG, "Joined Zigbee network!");
            }
            break;
        default: break;
    }
}

void zigbee_task(void *pvParameters) {
    /* Report soil moisture every 60 seconds */
    while (1) {
        uint16_t moisture = read_soil_moisture();
        esp_zb_zcl_set_attribute_val(
            HA_ESP_SENSOR_ENDPOINT,
            SOIL_MOISTURE_CLUSTER_ID,
            ESP_ZB_ZCL_CLUSTER_SERVER_ROLE,
            SOIL_MOISTURE_VALUE_ATTR,
            &moisture, false
        );
        vTaskDelay(pdMS_TO_TICKS(60000));
    }
}
