CES 2026 Highlight: Espressif เปิดตัว ESP32-E22 และ ESP32-H21 ในงาน CES 2026 (มกราคม 2026) ถือเป็นก้าวกระโดดครั้งใหญ่ — ด้านหนึ่งคือการเพิ่ม throughput ด้วย Wi-Fi 6E และอีกด้านคือการลด power consumption สำหรับ sensor node แบตเตอรี่ขนาดเล็ก

🆕 ชิปใหม่ล่าสุด

ESP32-E22 — Wi-Fi 6E Tri-Band ครั้งแรกจาก Espressif

ชิป RISC-V dual-core ความถี่สูงสุด 500 MHz พร้อม Wi-Fi 6E สามย่านความถี่ 2.4/5/6 GHz รองรับ 160 MHz channel width และ 2×2 MIMO ให้ physical throughput สูงสุด 2.1 Gbps ในการทดสอบ iperf

CPUDual-core RISC-V @ 500 MHz
On-chip RAM1 MB
Wi-Fi6E (2.4 / 5 / 6 GHz), 2×2 MIMO, 160 MHz BW
BluetoothBluetooth 6.0 (LE + BR/EDR)
InterfacesPCIe, USB, SDIO
Throughput (iperf)สูงสุด ~2.1 Gbps
Use caseGateway, NAS, Video Analytics, AV Bridge
Wi-Fi 6E RISC-V Bluetooth 6.0 PCIe
🆕 Ultra-Low-Power

ESP32-H21 — BLE + Thread/Zigbee สำหรับ Wearable & Sensor Node

ชิปพลังงานต่ำพิเศษสำหรับ BLE และ Thread/Zigbee node เน้น IoT wearable, presence sensing และ sensor node ที่ต้องใช้แบตเตอรี่นาน เป็นคู่แข่งโดยตรงกับ Nordic nRF5340/nRF52840 ในตลาด embedded IoT

  • Ultra-low-power deep sleep สำหรับอายุแบตฯ นานหลายปี
  • รองรับ Bluetooth LE, Thread และ Zigbee ในชิปเดียว
  • เหมาะกับ occupancy sensor, door/window sensor, wearable tracker
  • เป็นทางเลือกใหม่แทน nRF52840 ราคาต่ำกว่า เครื่องมือ development แบบ Espressif
  • รองรับ Matter over Thread สำหรับ smart home ecosystem
Ultra-Low-Power Bluetooth LE Thread Zigbee Matter

ไอเดียโปรเจกต์น่าสนใจ

Wearable Health Monitor, Matter Energy Manager และ ESP32-E22 Home Gateway

❤️ Health IoT

ESP32 DIY Wearable Health Watch — SpO₂ + ECG + อุณหภูมิ

นาฬิกาสุขภาพ DIY บน ESP32 วัด heart rate, SpO₂ (ความเข้มข้นออกซิเจนในเลือด) และ ECG พร้อมส่งข้อมูลแบบ real-time ผ่าน BLE ไปยัง smartphone แจ้งเตือนเมื่อค่าผิดปกติ

1 ใช้ ESP32 + MAX30102 วัด heart rate & SpO₂ ด้วย PPG (Photoplethysmography)
2 เพิ่ม AD8232 ECG module จับ electrical signal หัวใจ ตรวจ arrhythmia
3 MPU6050 ตรวจ fall detection สำหรับผู้สูงอายุ
4 ส่งข้อมูลผ่าน BLE ไปยัง app บน phone แจ้งเตือนเมื่อค่าผิดปกติ
5 บันทึก log ลง SD card และ upload ขึ้น MQTT broker เพื่อ dashboard
MAX30102 AD8232 MPU6050 BLE Healthcare IoT
⚡ Smart Energy

Matter 1.5 Home Energy Dashboard — Solar + EV Charger + Smart Plug

ระบบจัดการพลังงานบ้านแบบ open-source บน ESP32-C6 รองรับ Matter 1.4/1.5 ที่เพิ่ม energy management device categories ใหม่ เชื่อมต่อกับ Home Assistant, Apple Home และ Google Home ได้พร้อมกัน

  • ใช้ PZEM-004T วัด AC power (voltage, current, power, energy) แม่นยำ ±1%
  • รองรับ Matter Energy Management Cluster ใหม่ใน spec 1.4–1.5
  • ติดตาม solar production vs home consumption แบบ real-time
  • ควบคุม EV charger ตามช่วงเวลา solar surplus (solar-smart charging)
  • OTA update ผ่าน ESP-IDF seamless ไม่ต้องเปิด enclosure
Matter 1.5 PZEM-004T ESP32-C6 Home Assistant Solar IoT
🌐 Gateway

ESP32-E22 Wi-Fi 6E Home Gateway — Mesh Router + IoT Hub

ใช้ความสามารถ Wi-Fi 6E ของ ESP32-E22 สร้าง home gateway ที่รวม mesh Wi-Fi router กับ IoT hub ในอุปกรณ์เดียว รองรับ MQTT broker, Node-RED และ Home Assistant ทั้งหมดใน box เดียว

  • Wi-Fi 6E 6 GHz band แบนด์วิดท์กว้าง ไม่มี congestion จาก device เก่า
  • PCIe interface ต่อ NVMe SSD สำหรับ local storage ข้อมูล IoT
  • รัน MQTT broker (Mosquitto) + InfluxDB + Grafana dashboard
  • Thread Border Router สำหรับ Matter over Thread devices ในบ้าน
  • USB port สำหรับ Zigbee stick (ConBee III) ขยายการเชื่อมต่อ
ESP32-E22 Wi-Fi 6E MQTT Broker Home Assistant
🏥 Elderly Care

ESP32 + IMU Fall Detection System สำหรับผู้สูงอายุ

ระบบตรวจจับการล้มสำหรับผู้สูงอายุบนพื้นฐาน ESP32-H21 (ultra-low-power) + accelerometer แจ้งเตือนผ่าน BLE ไปยัง phone ผู้ดูแล และส่ง SMS/notification ผ่าน MQTT relay

  • ใช้ LSM6DSO IMU — accelerometer + gyroscope 6-axis ความแม่นยำสูง
  • Algorithm ตรวจจับการล้มแบบ threshold-based + ML บน ESP32
  • ESP32-H21 deep sleep < 5 µA ทำให้แบตเตอรี่ CR2032 อยู่ได้ > 1 ปี
  • BLE advertisement ทันทีเมื่อตรวจจับ event เวลา latency < 200 ms
ESP32-H21 LSM6DSO BLE Fall Detection CR2032
💓 Biometric

ESP32 Portable ECG Monitor — AD8232 + OLED + Wi-Fi Cloud

เครื่องวัด ECG พกพา DIY ราคาต่ำกว่า 500 บาท จับ electrical signal หัวใจ แสดงผลแบบ real-time บน OLED display และส่งข้อมูลขึ้น cloud เพื่อ trend monitoring และตรวจ arrhythmia เบื้องต้น

1 AD8232 module แปลง bio-electrical signal → ADC input ของ ESP32
2 ESP32 ADC 12-bit sampling rate 1000 Hz บันทึก ECG waveform
3 แสดงผล real-time บน SSD1306 OLED 128×64 px ด้วย u8g2 library
4 ส่งข้อมูล JSON ผ่าน Wi-Fi → MQTT → InfluxDB → Grafana dashboard
AD8232 ECG SSD1306 InfluxDB Grafana

Biometric & Health Sensors น่าสนใจ

Sensors สำหรับวัดสัญญาณชีพและสุขภาพ เหมาะกับ wearable และ health monitoring

💡 PPG Sensor

MAX30102 — Heart Rate & SpO₂ (Pulse Oximeter on a Chip)

IC pulse oximeter และ heart rate sensor ในชิปเดียว ใช้หลักการ PPG (Photoplethysmography) ด้วย LED สีแดง 660 nm และ IR 880 nm วัดทั้ง Heart Rate และ SpO₂ ผ่าน I2C ใช้กระแสไฟฟ้าต่ำมาก เหมาะมากสำหรับ wearable

InterfaceI2C (400 kHz Fast Mode)
VCC1.8V / 3.3V dual supply
LEDRED 660 nm + IR 880 nm
วัดได้Heart Rate + SpO₂
กระแสไฟ (low power)~600 µA
PackageOLGA-14 (5.6 × 3.3 mm)
LibrarySparkFun MAX3010x (Arduino)
SpO₂ Heart Rate I2C Wearable
⚡ ECG Sensor

AD8232 — Single-Lead ECG Front End IC

IC front end สำหรับวัด ECG (electrocardiogram) single-lead ออกแบบสำหรับ fitness และ medical monitoring ขนาดเล็ก กรอง noise ได้ดีด้วย instrumentation amplifier ในตัว output เป็น analog signal ต่อกับ ADC ของ ESP32 โดยตรง

OutputAnalog voltage (ต่อ ESP32 ADC โดยตรง)
Supply3.0V–3.5V (ใช้กับ ESP32 ได้เลย)
Gain100 V/V ปรับได้
CMRR80 dB
Leads Off Detectionมีขา LOD+ LOD– แจ้ง electrode หลุด
ใช้ร่วมกับElectrode pad แบบ 3-lead (RA, LA, RL)
ECG Analog Output 3-Lead Medical IoT
🏃 Motion Sensor

LSM6DSO — IMU 6-axis (Accel + Gyro) + Machine Learning Core

IMU 6-axis จาก ST Microelectronics มี Machine Learning Core (MLC) built-in ทำให้ตรวจจับ gesture, fall, activity recognition ได้บนชิป โดยไม่ต้องใช้กำลังประมวลผลของ ESP32 เลย เหมาะมากสำหรับ wearable ประหยัดพลังงาน

Axes3-axis Accel + 3-axis Gyro
InterfaceI2C / SPI
Accel Range±2 / ±4 / ±8 / ±16 g
Gyro Range±125 ~ ±2000 dps
ML Core4 decision tree classifiers (on-chip)
กระแสไฟ (full)~0.55 mA @ 104 Hz ODR
PackageLGA-14 (2.5 × 3.0 mm)
6-axis IMU ML Core Fall Detection Activity Recognition
🌡 Contactless Temp

MLX90614 — Infrared Non-Contact Temperature Sensor

Thermopile infrared sensor วัดอุณหภูมิแบบ non-contact (ไม่ต้องสัมผัส) ความแม่นยำ ±0.5°C เชื่อมต่อผ่าน SMBus (compatible กับ I2C) มี dual-zone thermopile ให้ทั้ง ambient temp และ object temp พร้อมกัน ใช้วัดไข้ได้อย่างรวดเร็ว

Range วัตถุ-70°C ถึง 382°C
Range ambient-40°C ถึง 125°C
Resolution0.02°C
Accuracy±0.5°C (0-50°C)
InterfaceSMBus / PWM
VCC3.3V หรือ 5V
Librarymlx90614-arduino
Infrared Non-Contact I2C/SMBus Body Temp
⚡ Power Meter

PZEM-004T v3.0 — AC Power Monitor (Voltage + Current + Power + Energy)

โมดูลวัด AC power ครบชุด voltage, current, power (W), energy (kWh), frequency และ power factor ผ่าน UART/Modbus RTU เชื่อมต่อ ESP32 ได้ง่าย ใช้ใน smart plug, solar monitoring, home energy dashboard ความแม่นยำดีและราคาถูก

Voltage Range80–260V AC
Current Max100A (ผ่าน current transformer)
Power0.1W resolution
Energy1 Wh resolution (สะสมได้ 9999.99 kWh)
Accuracy±1% (current), ±0.5% (voltage)
InterfaceUART / Modbus RTU (9600 baud)
Librarymandulef/PZEM-004T-v30 (Arduino)
PZEM-004T AC Power Monitor Modbus RTU Energy Management
