Wi-Fi 6E Co-Processor, Matter/Thread Certification, MCP over MQTT

ESP32-E22 — Wi-Fi 6E Tri-Band Radio Co-Processor

เปิดตัวที่ CES 2026 โดย Espressif นับเป็น ESP32 ตัวแรกที่รองรับ Wi-Fi 6E (2.4 / 5 / 6 GHz) พร้อม Bluetooth dual-mode ออกแบบมาเป็น Radio Co-Processor ที่ offload งาน networking stack ออกจาก host MCU ทำให้ host ประมวลผล application ได้เต็มที่

จุดเด่น: Wi-Fi 6E ลด interference จาก 2.4/5 GHz ที่แออัด — เหมาะสำหรับ Smart Home ที่มีอุปกรณ์หนาแน่น, Industrial Gateway, AR/VR accessories ที่ต้องการ latency ต่ำ
Wi-Fi 6E 6 GHz Co-Processor CES 2026

ESP32-H2 + Thread 1.3.0 — รองรับ Matter Certification

ESP32-H2 ได้รับ Thread 1.3.0 Certification ซึ่งเป็นข้อกำหนดเบื้องต้น สำหรับ Matter-over-Thread device certification ทำให้ผลิตภัณฑ์ IoT ที่ใช้ ESP32-H2 สามารถผ่านมาตรฐาน CSA (Connectivity Standards Alliance) ได้โดยตรง

Border Router แบบ DIY: ใช้ ESP32 Wi-Fi chip + ESP32-H2 เป็น RCP (Radio Co-Processor) ไม่ต้องใช้ Linux host — รัน OpenThread stack ได้บน ESP-IDF โดยตรง ค่าใช้จ่ายต่ำกว่า commercial router มาก
Matter Thread 1.3 ESP32-H2 OpenThread

ESP32 + MCP over MQTT — AI Agent ควบคุม IoT

แนวคิดใหม่ที่ emqx นำเสนอในปี 2026: เชื่อม ESP32 เข้ากับ Model Context Protocol (MCP) ผ่าน MQTT Broker ทำให้ AI Agent (เช่น Claude, GPT) สามารถ query สถานะ sensor, สั่ง actuator และ subscribe real-time data จากอุปกรณ์ IoT ได้โดยตรง

// ESP32 publish sensor data ผ่าน MQTT #include <PubSubClient.h> client.publish("esp32/sensor/temp", String(temp).c_str()); client.publish("esp32/mcp/tools", "{\"name\":\"read_temp\",\"value\":" + String(temp) + "}");

ESPHome + OpenThread บน ESP32-C6

ESPHome 2025.6+ เพิ่มการรองรับ OpenThread เบื้องต้นสำหรับ ESP32-C6 และ ESP32-H2 ทำให้ผู้ใช้ Home Assistant สามารถสร้าง Thread node ได้โดยไม่ต้องเขียน firmware เอง

ข้อจำกัดปัจจุบัน: ยังไม่รองรับ "Sleepy End Device" mode — ไม่เหมาะสำหรับ sensor ที่ส่งข้อมูลบ่อย เหมาะสำหรับ smart plug, relay control ที่ต้องการ low-latency แต่ไม่ได้ประหยัดพลังงานสูงสุด

🎤 Xiaozhi ESP32 — LLM Voice Interaction บน Edge

Framework open-source ชื่อ xiaozhi-esp32 (2026) ช่วยให้ ESP32 กลายเป็น voice assistant ที่คุยกับ cloud LLM ได้แบบ real-time โดย: audio capture และ VAD ทำงานบน ESP32 โดยตรง, ส่ง speech ขึ้น cloud ASR, ผล response ส่งกลับเป็น TTS และรองรับ MCP เพื่อ maintain context ข้ามการสนทนา

  • 1ESP32 + INMP441 microphone capture audio + VAD (Voice Activity Detection)
  • 2ส่ง audio stream ผ่าน WebSocket ไปยัง cloud ASR API
  • 3Cloud LLM (Claude / GPT) ประมวลผล intent + MCP context
  • 4TTS response ส่งกลับ ลำโพง MAX98357A เล่นเสียงตอบ

🏠 DIY Matter Thread Border Router ราคาประหยัด

ใช้ ESP32 Wi-Fi chip หลัก + ESP32-H2 เป็น 802.15.4 RCP สร้าง Thread Border Router ที่ได้ certificate-grade compatibility โดยไม่ต้องซื้ออุปกรณ์ราคาแพง

  • 1ESP32-S3 Dev Board (Wi-Fi) + ESP32-H2 Mini (802.15.4 RCP)
  • 2Flash ESP32-H2 ด้วย OpenThread RCP firmware จาก ESP-IDF
  • 3ESP32-S3 รัน Espressif Thread Border Router stack
  • 4เชื่อมต่อ Home Assistant ผ่าน OTBR (OpenThread Border Router) API
ต้นทุนประมาณ: ESP32-S3 (~฿250) + ESP32-H2 (~฿180) = ~฿430 เทียบกับ commercial Thread Border Router ~฿2,000+

Bosch BHI360 — Smart IMU พร้อม On-Sensor AI

Programmable Smart IMU ที่ประมวลผล gesture recognition บนตัว sensor เอง ไม่ต้องให้ MCU ทำงาน ลด power consumption อย่างมีนัยสำคัญ รองรับ wrist tilt, arm up/down, flick gestures พร้อม customizable algorithm

ข้อดี vs ESP32-S3 + MPU6050: BHI360 ตื่นขึ้นมาปลุก ESP32 เฉพาะเมื่อ detect gesture ได้ → ESP32 ประหยัดพลังงานสูงถึง 99% ในช่วงรอ
Smart IMU On-Sensor AI Wearable Ultra Low Power

Bosch BMI270 — IMU สำหรับ Smartwatch & Fitness

16-bit 6-axis IMU (accel + gyro) ที่ได้รับความนิยมในวงการ wearable มี built-in step counter, activity recognition และ gesture mode รองรับ I²C / SPI interface

// อ่านค่า acceleration + gyro จาก BMI270 bmi270.readAcceleration(ax, ay, az); bmi270.readGyroscope(gx, gy, gz); // คำนวณ pitch/roll สำหรับ gesture float pitch = atan2(ay, sqrt(ax*ax + az*az)) * 57.3; float roll = atan2(-ax, az) * 57.3;
BMI270 6-axis Fitness Step Counter

Piezoelectric Energy Harvesting — IoT ไม่ต้องใช้แบตเตอรี่

เทคโนโลยี Energy Harvesting จาก vibration/movement ผ่าน piezoelectric element ร่วมกับ Power Management IC เช่น e-peas AEM13920 เก็บพลังงานเข้า supercapacitor และจ่ายให้ ESP32-C6/H2 ที่ประหยัดพลังงาน

Use Case: ติด sensor บน เครื่องจักรโรงงาน ที่สั่นสะเทือนตลอดเวลา → harvest energy จากการสั่นสะเทือน ส่งข้อมูล predictive maintenance โดยไม่ต้องเปลี่ยนแบตเตอรีหรือเดินสายไฟ
Energy Harvesting Piezoelectric Battery-Free Industrial IoT

RF Energy Harvesting — พลังงานจากคลื่นวิทยุ

ดัก RF energy จากคลื่น Wi-Fi, 4G/5G รอบข้าง ผ่าน Rectenna (Rectifier Antenna) ที่ย่านความถี่ 900 MHz หรือ 2.4 GHz เหมาะสำหรับ sensor node ที่ต้องการ zero-maintenance ในพื้นที่มีสัญญาณดี

ข้อจำกัด: พลังงานที่ได้มักน้อย (µW–mW) เพียงพอสำหรับ sensor ที่ส่งข้อมูลเป็นระยะๆ ร่วมกับ ultra-low-power MCU เช่น ESP32-H2 ใน Deep Sleep
RF Harvesting Rectenna 2.4 GHz Zero Maintenance
