ESP32-H4 — ชิป Matter/Thread รุ่นใหม่ RISC-V 96 MHz + BT 5.4
ESP32-H4 เป็นชิปตัวล่าสุดจาก Espressif ที่ออกแบบมาสำหรับ IoT ประหยัดพลังงาน โดยเฉพาะ ใช้ RISC-V dual-core 96 MHz พร้อม Bluetooth 5.4 รองรับ LE Audio และโปรโตคอล Thread และ Zigbee ทำให้เหมาะสำหรับอุปกรณ์ Matter ที่ใช้แบตเตอรี่ยาวนาน เช่น สวิตช์ไร้สาย, เซ็นเซอร์ประตู

WirelessBT 5.4, Thread, Zigbee

TargetBattery-powered sensors

ESPHome 2026.6.0 — Visual Builder ไม่ต้องเขียน YAML แล้ว!
อัปเดตสำคัญที่สุดของ ESPHome ในปี 2026 Device Builder ถึงเวอร์ชัน 1.0.0 กลายเป็น dashboard หลักใน Home Assistant Add-on แทน legacy dashboard เดิม มาพร้อม Visual Component Editor, Component Catalog พร้อม dependency resolution, Pin Viewer แสดง GPIO ที่ใช้งาน, และ Firmware Job Queue รองรับ background compilation

ESP32Synth v2.4.0 — เครื่องสังเคราะห์เสียงดิจิทัล 350 Voices บน ESP32
ESP32Synth เป็น library สังเคราะห์เสียงแบบ bare-metal สำหรับ ESP32 ที่รองรับ Polyphony สูงถึง 350 voices พร้อมกัน ด้วย audio 48kHz@32bit ผ่าน I2S v2.4.0 เพิ่ม zero-latency audio, SD card streaming ในพื้นหลัง, custom DSP hooks, Chiptune bitcrush engine และ built-in filters+envelopes ไม่ต้องพึ่ง cloud หรือ DSP chip ภายนอก ออก Hackaday เมื่อ April 2026

Section 03

Sensors & Modules น่าสนใจ

ชิ้นส่วนอิเล็กทรอนิกส์ที่เหมาะกับโปรเจกต์ ESP32 ประจำสัปดาห์นี้

INMP441
I2S MEMS Digital Microphone
ไมโครโฟนดิจิทัล MEMS แบบ I2S ราคาประหยัด ให้คุณภาพเสียงสูง เชื่อมต่อ ESP32 ด้วย สายเพียง 3 เส้น (SCK, WS, SD) เหมาะสำหรับ Voice Recognition, Sound Classification, Audio Recording และ Wake Word Detection ความไวสูง SNR 61 dB
Interface I2S Standard
SNR 61 dB (A-weighted)
Frequency 60 Hz – 15 kHz
Voltage 1.8V – 3.3V
ราคา ~55–80 บาท
Voice AI I2S
PCM5102A
I2S Hi-Fi DAC Module
DAC (Digital-to-Analog Converter) คุณภาพสูง 32-bit 384kHz จาก Texas Instruments เชื่อมต่อ ESP32 ผ่าน I2S เพียง 3 pins ให้เสียงดนตรี Hi-Fi ระดับ 112dB SNR เหมาะสำหรับ Music Player, ESP32Synth, Streaming Audio และ Notification sounds มี onboard analog filter ไม่ต้องเพิ่มวงจร
Resolution 32-bit
Sample Rate สูงสุด 384 kHz
SNR 112 dB
Output Stereo Line Out (3.5mm)
ราคา ~100–140 บาท
Hi-Fi Audio I2S
MAX30102
SpO₂ & Heart Rate Sensor
เซ็นเซอร์วัด Pulse Oximetry (SpO₂) และ Heart Rate แบบ optical photoplethysmography ใช้ LED สีแดง + อินฟราเรดส่องผ่านผิวหนัง เชื่อมต่อ I2C ขนาดเล็กมาก 5.6×3.3mm เหมาะสำหรับ wearable health monitor, fitness tracker, patient monitor
Interface I2C (400kHz)
SpO₂ Range 70% – 100%
HR Range 0 – 300 BPM
Current 600 µA สูงสุด
ราคา ~70–100 บาท
Health I2C Wearable
u-blox NEO-M10S
Multi-Band GNSS Module
GNSS module รุ่นใหม่จาก u-blox ที่รองรับ GPS, GLONASS, Galileo, BeiDou พร้อมกัน ให้ความแม่นยำ 2.5m CEP และ Time-to-First-Fix เพียง 6 วินาที ประหยัดพลังงานเพียง 11mA ขณะติดตาม เหมาะกับ solar-powered tracker รองรับ I2C, SPI, UART หลาย interface
Constellations GPS + GLONASS + Galileo + BeiDou
Accuracy 2.5m CEP
TTFF (cold) ~24s (warm: 2s)
Current 11 mA tracking
ราคา ~300–400 บาท
GNSS GPS Low Power
MPR121
Capacitive Touch Controller
Capacitive Touch Controller 12 ช่อง จาก NXP ที่ใช้กันอย่างแพร่หลายในโปรเจกต์ synthesizer และเครื่องดนตรี DIY รองรับ electrode ได้หลากหลาย รวมถึง copper foil, fruit, water เชื่อมต่อ I2C ง่าย มี auto-calibration ในตัว ใช้ร่วมกับ ESP32Synth ทำ keyboard ได้ทันที
Channels 12 electrodes
Interface I2C
Detection Touch + Proximity
Calibration Auto
ราคา ~70–100 บาท
Capacitive Synthesizer I2C
