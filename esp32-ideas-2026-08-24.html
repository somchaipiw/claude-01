Espressif เพิ่งเริ่มจำหน่ายโมดูล ESP32-C61-MINI-1 และ ESP32-C61-MINI-1U (แบบ External Antenna) อย่างเป็นทางการในเดือนสิงหาคม 2569 ในราคาเริ่มต้นเพียงประมาณ $2 ต่อชิ้น (ซื้อ pack 5 ชิ้น ราว $10.70)

ESP32-C61 เป็นชิป RISC-V 32-bit ความเร็ว 160 MHz รองรับ Wi-Fi 6 (802.11ax) 2.4 GHz พร้อม OFDMA, MU-MIMO, Target Wake Time (TWT) สำหรับประหยัดพลังงาน และ Bluetooth 5.3 LE

จุดแตกต่างหลักจาก ESP32-C6 คือ ไม่มีวิทยุ 802.15.4 (Thread/Zigbee) ทำให้ราคาถูกลงอย่างมีนัยสำคัญ แต่ยังรองรับ Matter over Wi-Fi ได้ครบถ้วน ถ้าโปรเจกต์ต้องการแค่ Wi-Fi + BLE ไม่ต้องการ Mesh Protocol ตัวนี้คือตัวเลือกสุดประหยัด

Sensors น่าสนใจสำหรับ Predictive Maintenance

Vibration / Motion
ADXL345 — 3-Axis Digital Accelerometer
Accelerometer digital 3 แกน ความละเอียดสูงสุด 13-bit ย่านวัดปรับได้ ±2g ถึง ±16g ต่อกับ ESP32 ผ่าน SPI หรือ I2C ได้ทันที
  • Output Rate สูงสุด 3200 Hz สำหรับ FFT analysis
  • Built-in FIFO 32-level ลดภาระ MCU
  • Tap/Double-tap detection hardware
  • Free-fall detection
  • Supply: 2.0–3.6V, กระแสแค่ 40 µA (standby)
  • ราคา: ~$1–3 (DIP breakout)
Acoustic / Microphone
ICS-43434 — I2S MEMS Microphone ความไว High
MEMS microphone I2S สำหรับวิเคราะห์เสียงเครื่องจักร ต่อกับ ESP32 โดยตรงผ่าน I2S ไม่ต้องแปลง ADC
  • Frequency: 20 Hz – 20 kHz, SNR: 65 dB
  • I2S output (24-bit, 16 kHz – 48 kHz)
  • ใช้งานวิเคราะห์ sound anomaly ด้วย FFT
  • เหมาะสำหรับ motor noise / bearing fault detection
  • Supply: 1.8–3.3V, กระแส <600 µA
  • ราคา: ~$2–5 (breakout board)
Temperature · Industrial
MAX31865 — PT100/PT1000 RTD Temperature Converter
IC converter สำหรับ Platinum RTD (PT100/PT1000) ให้ความแม่นยำระดับ ±0.5°C ที่ 0°C ใช้กับ ESP32 ผ่าน SPI
  • วัดอุณหภูมิ: -200°C ถึง +850°C
  • ADC 15-bit (0.03125°C resolution)
  • Fault detection: open circuit, short circuit
  • สำหรับวัดอุณหภูมิมอเตอร์, ท่อ, เครื่องจักรอุตสาหกรรม
  • Breakout board พร้อม PT100 sensor: ~$5–10
Current / Power
INA226 — Bidirectional Current/Power Monitor I2C
IC วัดกระแสและพลังงานแบบ bidirectional ผ่าน I2C ใช้ shunt resistor เพื่อวัดกระแส DC ของมอเตอร์หรืออุปกรณ์ไฟฟ้า
  • Voltage range: 0–36V (bus), กระแสขึ้นกับ shunt
  • Resolution: 1.25 mV (voltage), 2.5 µV (shunt)
  • Alert pin เมื่อเกิน threshold
  • วัด power consumption real-time ของมอเตอร์
  • เหมาะงาน predictive: anomalous current = เครื่องพัง
  • ราคา breakout: ~$2–4

ตัวอย่างโค้ด — ESP32-C61 Wi-Fi 6 TWT Low-Power Mode

เปิดใช้งาน Target Wake Time (TWT) บน ESP32-C61 ผ่าน ESP-IDF v6.0
main.c — ESP32-C61 Wi-Fi 6 TWT Setup (ESP-IDF v6.0) 
// ESP32-C61 Wi-Fi 6 TWT (Target Wake Time) — ลดการใช้ไฟใน standby
#include "esp_wifi.h"
#include "esp_log.h"
#include "esp_netif.h"

#define TAG "TWT_DEMO"

// Callback เมื่อ TWT session setup สำเร็จ
static void wifi_twt_callback(void *arg, esp_event_base_t base,
                               int32_t event_id, void *event_data) {
    if (event_id == WIFI_EVENT_ITWT_SETUP) {
        wifi_event_sta_itwt_setup_t *twt = event_data;
        ESP_LOGI(TAG, "TWT Setup: wake=%dms, interval=%dms",
                 twt->actual_wake_duration_ms,
                 twt->actual_wake_interval_ms);
    }
}

void setup_twt_low_power(void) {
    // กำหนดค่า TWT: ตื่น 10ms ทุก 5,000ms (5 วินาที)
    wifi_config_twt_t twt_cfg = {
        .setup_cmd        = TWT_REQUEST,
        .trigger          = 0,       // 0 = unannounced
        .flow_type        = 0,       // 0 = solicited
        .wake_duration_us = 10000,   // ตื่น 10ms
        .wake_interval_us = 5000000, // ทุก 5 วินาที
        .min_wake_duration_us = 4096,
    };

    esp_err_t ret = esp_wifi_sta_itwt_setup(&twt_cfg);
    if (ret == ESP_OK) {
        ESP_LOGI(TAG, "TWT requested successfully");
    } else {
        ESP_LOGW(TAG, "TWT setup failed: %s", esp_err_to_name(ret));
    }
}

void app_main(void) {
    // Init Wi-Fi → Connect AP → เมื่อ connected แล้วจึงเปิด TWT
    esp_event_handler_register(WIFI_EVENT, WIFI_EVENT_ITWT_SETUP,
                                wifi_twt_callback, NULL);
    wifi_init_and_connect();     // connect AP ด้วย WPA3 SAE
    setup_twt_low_power();        // เปิด TWT หลัง connect
    // ตอนนี้ ESP32-C61 จะ wake 10ms ทุก 5 วินาที
    // กระแสเฉลี่ย deep idle <1 mA
}
TWT ช่วยให้ ESP32-C61 ประหยัดพลังงานได้มากในโหมด standby เนื่องจากวิทยุ Wi-Fi ไม่ต้องคอย beacon ตลอดเวลา — เหมาะมากสำหรับ sensor node ที่ส่งข้อมูลเป็นรอบๆ
