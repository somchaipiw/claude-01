ESP32-H21 — Ultra-Low-Power Thread & BLE 5 SoC
ประกาศที่ CES 2026 · อัปเกรดจาก H2
Espressif เปิดตัว ESP32-H21 ในงาน CES 2026 ร่วมกับ ESP32-E22 โดย H21 เป็นชิป RISC-V 32-bit ประหยัดพลังงานสูงสุด เหมาะกับ Smart Home Sensor ที่ต้องทำงานหลายปีด้วยแบตก้อนเดียว

จุดเด่นหลักคือ on-chip DC-DC Converter ที่ลดกระแสไฟขณะ active ได้อย่างมีนัยสำคัญ รองรับโปรโตคอล Thread 1.4, Zigbee 3.0, Matter และ BLE 5.0 ผ่านวิทยุ IEEE 802.15.4 ตัวเดียว — ไม่ต้องใช้ชิปแยก
CPURISC-V 32-bit, 96 MHz
RAM320 KB SRAM + 128 KB ROM
GPIO19 pins (compact form)
วิทยุ802.15.4 + BLE 5.0
พิเศษOn-chip DC-DC Converter
โปรโตคอลThread 1.4 / Zigbee 3.0 / Matter
Thread 1.4 Zigbee 3.0 Matter Ultra-Low-Power

ESP32-E22 — Wi-Fi 6E Tri-Band Co-Processor
ชิปแรกของ Espressif ที่รองรับ 2.4/5/6 GHz
ESP32-E22 คือก้าวกระโดดครั้งใหญ่ด้าน connectivity ใน ESP32 family — เป็น Tri-Band Wi-Fi 6E ตัวแรกของ Espressif รองรับทั้ง 2.4 GHz, 5 GHz และ 6 GHz (Wi-Fi 6E) พร้อม 2×2 MIMO และ 160 MHz channels

ออกแบบเป็น Radio Co-Processor (RCP) เชื่อมต่อกับ host processor ผ่าน PCIe, USB หรือ SDIO รันโปรโตคอล stack ทั้งหมดในตัวเอง ลด load จาก host ได้มาก เหมาะกับ Industrial Gateway และ Edge Compute
CPUDual-Core RISC-V, 500 MHz
Wi-Fi6E · 2.4/5/6 GHz · 2×2 MIMO
Bluetooth6.0 (LE + BR/EDR)
Throughputสูงสุด 2.4 Gbps
InterfacePCIe / USB / SDIO
สถานะEngineering Samples พร้อมแล้ว

ESPHome 2026.1 — ย้ายจาก Arduino เป็น ESP-IDF โดย Default
การเปลี่ยนแปลงสำคัญที่ส่งผลทั้ง ecosystem
ตั้งแต่ ESPHome 2026.1.0 เป็นต้นไป framework เริ่มต้นสำหรับ ESP32 เปลี่ยนจาก Arduino เป็น ESP-IDF อย่างเป็นทางการ — เป็นการตัดสินใจสำคัญที่สะท้อนความสมบูรณ์ของ ESP-IDF

ข้อดีที่ผู้ใช้จะได้รับ: ลด Flash ใช้งาน, ลด RAM overhead, รองรับฟีเจอร์ใหม่อย่าง AI Acceleration, MIPI CSI/DSI บน ESP32-P4 ได้เต็มที่ และรองรับชิปรุ่นใหม่อย่าง ESP32-H21, ESP32-E22 ได้เร็วขึ้น
ESPHome 2026.1 ESP-IDF v5.5 Arduino → IDF

Arduino-ESP32 v3.3.8 — ฐาน ESP-IDF v5.5.4
เสถียรภาพและความเข้ากันได้ระยะยาว
Arduino Core ESP32 v3.3.8 ปรับ ESP-IDF ฐานเป็น v5.5.4 — เวอร์ชัน LTS (Long-Term Support) ที่ได้รับการแก้ไขบัก security และ stability patch

สำหรับโปรเจกต์ใหม่ที่ต้องการ ความเสถียรระยะยาว ควรใช้ Arduino Core 3.3.x series นี้ เพราะ Espressif รับประกัน ABI compatibility และ patch ต่อเนื่อง ขณะที่ 3.4.x ยังอยู่ระหว่าง feature development

รัน Mac OS 8.1 บน ESP32-P4 ด้วย BasiliskII
โปรเจกต์ไวรัลที่พิสูจน์พลัง ESP32-P4
นักพัฒนา amcchord ได้ port Basilisk II — emulator Macintosh 68k — มาบน ESP32-P4 / M5Stack Tab5 ได้สำเร็จ สามารถรัน Mac OS 7.x ถึง 8.1 บนหน้าจอ touch ขนาด 5 นิ้ว

ประสิทธิภาพเทียบเท่า Macintosh Quadra 610 (25 MHz 68040) ได้ถึง 2-3 MIPS และ frame rate 15-24 FPS เพียงพอสำหรับงาน productivity บน OS เก่า โดยบอร์ดที่ใช้ราคาเพียง $60!

นอกจากนี้ยังรองรับ Waveshare ESP32-P4 10.1" สำหรับหน้าจอใหญ่ขึ้น

DIY Presence Sensor 25 เมตร ด้วย DFRobot C4001 + ESPHome
แทน PIR ด้วย mmWave ที่แม่นยำกว่ามาก
แทนที่ PIR sensor ธรรมดาด้วย DFRobot C4001 (24GHz FMCW mmWave) + ESP32 + ESPHome สำหรับตรวจจับการอยู่ในพื้นที่ได้ระยะ 25 เมตร — แม้แต่การหายใจขณะนอนนิ่ง

ขั้นตอนสร้าง:
1. เชื่อม C4001 กับ ESP32 ผ่าน UART (หรือ I2C)
2. configure ESPHome YAML ด้วย uart component
3. ตั้ง detection zone และ threshold ผ่าน command protocol
4. เชื่อมต่อ Home Assistant — ได้ presence sensor ที่ ไม่มี false trigger
mmWave 24GHz ESPHome Home Assistant 25m Range

ระบบติดตาม 5 คนพร้อมกันด้วย LD2461 + ESP32
Multi-Target Tracking พร้อม Trajectory Analysis
HiLink LD2461 เป็น mmWave radar 24GHz ที่มีความสามารถพิเศษ — แตกต่างจาก LD2410 ที่ track ได้แค่ 1 คน LD2461 ใช้ เสาอากาศ 2T4R (2 Transmit, 4 Receive) ทำให้ detect และ track ได้ 5 เป้าหมายพร้อมกัน

Use case ที่น่าสนใจ:
• ระบบนับคนในห้องแบบ real-time
• วิเคราะห์ Traffic flow ในอาคาร
• ระบบ Smart Lighting ที่รู้ว่าใครอยู่ตรงไหน
• Security system ที่แยก occupant ออกจากกัน
LD2461 2T4R MIMO 5 Targets Trajectory

ESP-VISION — Framework กล้องและวิดีโอสำหรับ ESP32-P4/S3
API เดียวครบทุกอย่าง ตั้งแต่กล้องถึง Stream
ESP-VISION เป็น framework unified สำหรับงาน camera, image processing และ video ที่ Espressif พัฒนาขึ้นโดยเฉพาะ รองรับ ESP32-P4, S3 และ S31

ครอบคลุมตั้งแต่ Camera Input → Image Processing → Display Output และ Video Encoding ในชุด API เดียว มี built-in algorithms สำหรับ color tracking, feature detection, QR code, และ barcode — ไม่ต้องพึ่ง library ภายนอก

รองรับ MIPI CSI (camera) และ MIPI DSI (display) บน ESP32-P4 เต็มรูปแบบ
ESP32-P4 ESP32-S3 MIPI CSI/DSI Vision AI

mmWave Radar Sensors เปรียบเทียบ

คู่มือเลือก HiLink / DFRobot mmWave สำหรับ ESP32 ปี 2026

เปรียบเทียบ mmWave Radar Sensors ยอดนิยมสำหรับ ESP32 — ทั้งสามตัวเชื่อมต่อผ่าน UART ง่ายกับ ESPHome
รุ่น เป้าหมาย ระยะ เสาอากาศ Interface Use Case
HiLink LD2410 1 คน 6m 1T1R UART + BLE ห้องเล็ก, DIY พื้นฐาน
HiLink LD2450 3 คน 6m 1T2R UART ห้องนั่งเล่น, ติดตามตำแหน่ง
HiLink LD2461NEW 5 คน 8m 2T4R UART ห้องประชุม, trajectory analysis
DFRobot C4001BEST 1 คน 25m FMCW UART + I2C โกดัง, ระยะไกล, outdoor
🔭
HiLink LD2461
Multi-Target 2T4R Radar
ตรวจจับ 5 เป้าหมายพร้อมกัน พร้อมวัด range และ angle ของแต่ละคน ใช้ระบบเสาอากาศ 2 Transmit 4 Receive (2T4R) ที่ให้ข้อมูล spatial resolution สูง

เหมาะกับงานที่ต้องรู้ว่า "ใครอยู่ตรงไหน" ไม่ใช่แค่ "มีคนอยู่หรือเปล่า"
24 GHz 5 Targets 8m Range
📻
DFRobot C4001
Long-Range FMCW mmWave
ใช้เทคโนโลยี FMCW (Frequency-Modulated Continuous Wave) ที่ detect ได้แม้แต่การหายใจ ระยะ presence detection 16 เมตร และ motion detection 25 เมตร

รองรับทั้ง UART และ I2C มี configurable detection zones ตั้งค่าผ่าน command protocol ไม่มี false trigger
25m Motion FMCW I2C + UART
🏠
HiLink LD2410 + LD2410B
จุดเริ่มต้น mmWave ราคาประหยัด
LD2410 ยังเป็นตัวเลือกยอดนิยมสำหรับผู้เริ่มต้น ราคาถูก เชื่อม ESPHome ได้ง่าย มี library ครบ ส่วน LD2410B เพิ่ม Bluetooth LE สำหรับ configure แบบ wireless ผ่าน phone app

รองรับใน ESPHome built-in component — ไม่ต้องเขียน custom UART parser แค่ใส่ YAML config ก็ใช้งานได้เลย
ESPHome Native BLE Config Entry Level
