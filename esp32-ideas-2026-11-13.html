Sensor / Module วัดอะไร Interface ราคาโดยประมาณ หมายเหตุ
MAX30102
Biometric 		Heart Rate, SpO2 I2C ~80–120 บาท Sensor ยอดนิยมที่สุดสำหรับโปรเจกต์ Wearable ต้องใช้ Library จาก Sparkfun
MAX30208
Temperature 		Body Temperature (±0.1°C) I2C ~150–200 บาท ความแม่นยำระดับทางคลินิก เหมาะสำหรับ Wearable ทางการแพทย์
LD2410 / HLK-LD2402
Radar 		Human Presence (mmWave 24GHz) UART ~200–400 บาท ตรวจจับได้แม้คนนิ่ง (Breathing Detection) ไม่ต้องใช้กล้อง
MPU6050
IMU 		Accelerometer + Gyroscope (6-axis) I2C ~40–80 บาท ใช้คู่กับ MAX30102 สำหรับ Wearable เพื่อตรวจจับการเคลื่อนไหวและ Sleep Stage
LIS3DH
Accelerometer 		3-axis Accelerometer + Fall Detection I2C / SPI ~50–100 บาท Interrupt-based Fall Detection ใช้พลังงานต่ำมาก เหมาะสำหรับ Patient Monitoring
Water Leak Module
Environment 		Water Detection Digital/Analog ~30–60 บาท Sensor ราคาถูกที่สุด เหมาะสำหรับป้องกันน้ำท่วมบ้านและการรั่วซึม
