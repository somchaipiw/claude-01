Tutorial ประจำวัน

Step by Step

🤖 รัน LLM 28.9M Parameters บน ESP32-S3 ด้วยเทคนิค Per-Layer Embeddings

Per-Layer Embeddings (PLE) เป็นเทคนิคที่ยืมมาจาก Google Gemma ช่วยให้ 25 ล้านพารามิเตอร์จาก 28.9 ล้านตัวเก็บอยู่ใน Flash แทน RAM ทำให้ ESP32-S3 ที่ RAM เพียง 512KB สามารถรัน LLM ได้จริง

  • 1Clone โปรเจกต์: git clone https://github.com/esp32-ai/esp32-ai
  • 2ติดตั้ง ESP-IDF v5.3+ และ partition table แบบ Large Flash (8MB+)
  • 3Flash model weights ลง SPI Flash ผ่าน esptool.py
  • 4Build และ flash firmware: idf.py build flash monitor
  • 5ส่ง prompt ผ่าน Serial Console และรอ inference ~9.5 tok/s
// ตัวอย่าง prompt ใน Serial Monitor "Describe the weather today in Thai language:" // Output: "วันนี้อากาศอบอุ่น อุณหภูมิประมาณ 28 องศา..." // ~9.5 tokens/second @ 240 MHz
ESP32-S3 ESP-IDF v5.3+ Open-Source 8MB Flash

🌿 สร้าง Matter Environmental Sensor ด้วย ESP32-C6 + BME680 ใน 1 ชั่วโมง

ใช้ library BSEC2 จาก Bosch วัด IAQ (Indoor Air Quality Index) แบบ Calculated จาก VOC, Humidity, Temperature และ Pressure รวมกัน จากนั้น expose ค่าผ่าน Matter protocol ให้ Apple Home, Google Home หรือ Amazon Alexa อ่านได้ทันที

  • 1ติดตั้ง ESP Matter SDK: idf.py add-dependency esp-matter
  • 2เชื่อม BME680 กับ ESP32-C6: SDA→GPIO6, SCL→GPIO7, VCC→3.3V
  • 3เพิ่ม BSEC2 library ใน CMakeLists.txt และ configure IAQ accuracy level
  • 4สร้าง Matter endpoint type: temperature_sensor + humidity_sensor
  • 5Commission ผ่าน Apple Home App (QR Code) แล้วดูค่าใน Dashboard ได้เลย
// esp32-c6 + bme680 matter sensor (simplified) matter::endpoint::temperature_sensor::config_t temp_cfg; temp_cfg.temperature_measurement.measured_value = (int16_t)(bme680_temp * 100); // multiply by 100 for Matter format matter::endpoint::temperature_sensor::create(node, &temp_cfg, ENDPOINT_FLAG_NONE, nullptr);
