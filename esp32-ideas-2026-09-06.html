ESP32-P4 Weather Station — สถานีตรวจอากาศ All-in-One บน 10.1" Display

Harald Kreuzer เปิดตัวโปรเจกต์ ESP32-P4 Weather Station ที่ครบเครื่องที่สุดในปี 2026 ขับ DSI Touchscreen 10.1 นิ้วโดยตรง รวมการแสดงผลสภาพอากาศ, คุณภาพอากาศ และ Sensor ไร้สายรอบบ้านไว้ในระบบเดียว

  • Display: 10.1" DSI Touchscreen (ขับตรงจาก ESP32-P4)
  • Sensor หลัก: Sensirion SEN66 — PM, CO₂, VOC, NOx, Temp, Humidity
  • Wireless Node: รองรับ LoRa + ESP-NOW สูงสุด 6 โหนด
  • Weather API: Open-Meteo, OpenWeatherMap, Visual Crossing
  • ข้อดี: ไม่ต้องใช้ Cloud หรือบัญชีผู้ใช้ ทำงานบน LAN ทั้งหมด
  • ใช้บอร์ดสำเร็จรูป: ไม่ต้องออกแบบ PCB เอง
⚡ Battery Node สามารถทำงานได้นานหลายปีด้วย Deep Sleep + LoRa

ESP32P4C61-TINY — AIoT Board ที่รวม P4 + C61 ไว้ในบอร์ดเดียว

Wireless-Tag ระดมทุนบน Kickstarter สำหรับ ESP32P4C61-TINY บอร์ด Open-Source AIoT ขนาดกะทัดรัดที่รวม ESP32-P4 (ประมวลผล 400 MHz) และ ESP32-C61 (Wi-Fi 6 + BLE) ไว้ด้วยกัน แก้จุดอ่อนที่ P4 ไม่มี Wireless ในตัว

  • Display: MIPI DSI Interface
  • Storage: MicroSD Card Slot
  • ใช้งาน: Edge AI, Computer Vision, AIoT Gateway

ESP32-H21 — ทายาท H2 สำหรับ Thread/Zigbee พลังงานต่ำสุด

ESP32-H21 คือ Low-Power Successor ของ ESP32-H2 สำหรับ IoT Endpoint แบบใช้แบตเตอรี่ยาวนาน จุดเด่นคือมี DC-DC Converter แบบ Integrated ทำให้ประหยัดพลังงานได้มากกว่าเดิม เหมาะกับ Zigbee และ Thread Sensor Node

  • Protocol: IEEE 802.15.4 — Thread, Zigbee, Matter
  • จุดเด่น: Integrated DC-DC Converter (ลดการสิ้นเปลืองพลังงาน)
  • Use Case: Door/Window Sensor, Motion Sensor แบบแบต 2-3 ปี
  • เทียบกับ H2: เหมาะกว่าสำหรับ Battery-Powered Device
  • Framework: ESP-IDF v6.0 + ESP-Matter SDK (สิงหาคม 2026)

ESP32-H21 Thread Sensor Network — เครือข่าย Sensor แบต 3 ปี

วางเครือข่าย Thread Sensor Node ทั่วบ้านด้วย ESP32-H21 พลังงานต่ำมาก ใช้แบต AA 2 ก้อนได้นานถึง 2-3 ปี โดยไม่ต้องเดินสายไฟ

  • MCU: ESP32-H21 (Thread + Integrated DC-DC)
  • Sensor: PIR Motion / Reed Switch / BME280
  • Protocol: Thread (IEEE 802.15.4) + Matter
  • Hub: Apple HomePod Mini หรือ Google Nest Hub (Thread Border Router)
  • Deep Sleep: ตื่นทุก 5 นาที ส่งข้อมูล แล้วหลับใหม่
  • อายุแบต: คาดว่า 2-3 ปี บน AA 2 ก้อน
💡 Thread ไม่ต้องผ่าน Wi-Fi Router — ลด Latency และ เพิ่ม Reliability

Sensirion SEN66 — Air Quality Sensor ครบจบในตัวเดียว

SEN66 เป็น All-in-One Environmental Sensor จาก Sensirion วัดได้ถึง 6 พารามิเตอร์พร้อมกัน: PM1.0, PM2.5, PM4.0, PM10, CO₂, VOC, NOx, Temperature และ Humidity ในโมดูลเดียว เชื่อมต่อด้วย I2C ง่ายมาก

  • PM: PM1.0 / PM2.5 / PM4.0 / PM10 (µg/m³)
  • CO₂: 0–40,000 ppm (Sensirion NDIR)
  • VOC: Volatile Organic Compounds Index
  • NOx: Nitrogen Oxide Index
  • Temp/Humidity: Built-in
  • Interface: I2C (3.3V)
  • ราคา: ~$35–45
🆕 ใช้ในโปรเจกต์ ESP32-P4 Weather Station ที่เพิ่งเผยแพร่เดือนนี้

Bosch BME280 — Climate Sensor ราคาต่ำประสิทธิภาพสูง

BME280 ยังคงเป็นตัวเลือกยอดนิยมปี 2026 สำหรับโปรเจกต์ที่ต้องการ Temperature, Humidity และ Pressure แบบครบชุด ราคาถูก (~$2), I2C/SPI, 3.3V — แนะนำโดย Espressif เองสำหรับ Matter + CO₂ Node

  • Temperature: ±0.5°C (-40 ถึง +85°C)
  • Humidity: ±3% RH (0–100%)
  • Pressure: ±1 hPa (300–1100 hPa)
  • Interface: I2C หรือ SPI
  • ราคา: ~$2 (Module บน AliExpress)
  • Library: Adafruit BME280, ESP-IDF built-in example

💡 Tutorial: Ultra-Cheap Matter Sensor Node ด้วย ESP32-C61 + BME280

ต้นทุนรวมไม่เกิน $5 — เชื่อม Home Assistant ผ่าน Matter over Wi-Fi 6 ได้เลย

⚙️ Hardware ที่ต้องการ

  • ESP32-C61-MINI-1: ~$2 (AliExpress, ชุด 5 ชิ้น = $10.7)
  • BME280 Module: ~$1.5
  • Breadboard + สาย: ~$0.5
  • USB-C Power: 5V 500mA

📄 การต่อวงจร BME280 กับ ESP32-C61

  • VCC → 3.3V
  • GND → GND
  • SCL → GPIO5 (I2C Clock)
  • SDA → GPIO4 (I2C Data)

💻 ตัวอย่าง Code: อ่าน BME280 ผ่าน I2C (ESP-IDF v6.0)

// ESP32-C61 + BME280 via I2C — ESP-IDF v6.0
#include "driver/i2c_master.h"
#include "bme280.h"

#define I2C_PORT    I2C_NUM_0
#define SDA_PIN     4
#define SCL_PIN     5
#define BME280_ADDR 0x76

void app_main(void) {
    // Init I2C Master Bus
    i2c_master_bus_config_t bus_cfg = {
        .clk_source = I2C_CLK_SRC_DEFAULT,
        .i2c_port   = I2C_PORT,
        .scl_io_num = SCL_PIN,
        .sda_io_num = SDA_PIN,
        .glitch_ignore_cnt = 7,
    };
    i2c_master_bus_handle_t bus;
    i2c_new_master_bus(&bus_cfg, &bus);

    // Add BME280 Device
    i2c_device_config_t dev_cfg = {
        .dev_addr_length = I2C_ADDR_BIT_LEN_7,
        .device_address  = BME280_ADDR,
        .scl_speed_hz    = 100000,
    };
    i2c_master_dev_handle_t dev;
    i2c_master_bus_add_device(bus, &dev_cfg, &dev);

    bme280_handle_t sensor;
    bme280_init(dev, &sensor);
    bme280_set_mode(sensor, BME280_MODE_NORMAL);

    while (1) {
        bme280_data_t data;
        bme280_read_data(sensor, &data);
        printf("Temp: %.2f C | Hum: %.2f %% | Press: %.2f hPa\n",
               data.temperature, data.humidity, data.pressure / 100.0f);
        vTaskDelay(pdMS_TO_TICKS(5000));
    }
}

🔗 ขั้นตอนต่อไป: เชื่อม Matter

  • ติดตั้ง ESP-Matter SDK ล่าสุด (สิงหาคม 2026)
  • ใช้ matter_temperature_sensor example เป็น Base
  • แก้ไข Cluster ให้ส่งค่า Temperature จาก BME280
  • Flash QR Code ลง Display หรือ Serial Monitor สำหรับ Commissioning
  • Pair ด้วย Apple Home / Home Assistant / Google Home

⚠️ ข้อควรระวัง ESP32-C61

  • ไม่มี 802.15.4 — รองรับแค่ Matter over Wi-Fi ไม่ใช่ Thread
  • RAM น้อยกว่า C6 (320KB vs 512KB) — ระวัง Memory เมื่อใช้ HTTPS/TLS
  • Arduino Support ยังไม่สมบูรณ์ — แนะนำใช้ ESP-IDF หรือ Arduino as Component
