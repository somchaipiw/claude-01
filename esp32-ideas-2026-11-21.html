ESP32-H21 — ชิปพลังงานต่ำสุดจาก Espressif (มีนาคม 2026)

Espressif ประกาศ ESP32-H21 เมื่อ 3 มีนาคม 2026 ซึ่งเป็นการอัปเกรดจาก ESP32-H2 โดยเพิ่ม DC-DC Converter ในตัวชิป (on-chip) ทำให้ลดกระแสไฟในโหมด Active ลงได้อย่างมีนัยสำคัญ เหมาะสำหรับอุปกรณ์ IoT ที่ต้องใช้ถ่านเป็นเวลานาน เช่น Smart Home Sensor, Building Automation และ Wearable

จุดเด่นหลัก: กระแส RX Active ลดเหลือ ~8.2 mA — เปรียบเทียบกับ H2 ที่สูงกว่า ทำให้อายุถ่านยาวนานขึ้นมากในโหมดรับสัญญาณต่อเนื่อง

ESP-IDF v6.0 — Major Release พร้อม PSA Crypto & MbedTLS 4.x (มีนาคม 2026)

ESP-IDF v6.0 เป็น major release ที่ออกในเดือนมีนาคม 2026 มีการเปลี่ยนแปลงสำคัญหลายด้าน โดยเฉพาะด้านความปลอดภัยที่ย้ายมาใช้มาตรฐาน PSA Crypto API และอัปเกรด MbedTLS เป็นเวอร์ชัน 4.x ซึ่งจำเป็นต้องแก้ไข code ที่ใช้ legacy API เดิม

  • MbedTLS v4.x + PSA Crypto API: Legacy cryptographic API ถูก deprecated — ต้องเรียก psa_crypto_init() ก่อนทำ cryptographic operation ใดๆ
  • Hardware Acceleration ผ่าน PSA Driver: HMAC peripheral และอื่นๆ ใช้งานผ่าน PSA driver แทน esp_hmac_calculate() เดิม
  • Picolibc แทน Newlib: C Standard Library เปลี่ยนมาใช้ Picolibc ที่เบากว่าและ modern กว่า
  • ESP-IDF Installation Manager: เครื่องมือใหม่สำหรับจัดการ SDK version ง่ายขึ้น
  • MCP Server: มี MCP (Model Context Protocol) server ในตัว — เชื่อมต่อกับ AI tools ได้
  • Wi-Fi Proximity Discovery + WPA3 Compatibility Mode: ค้นพบอุปกรณ์ใกล้เคียงผ่าน Wi-Fi ง่ายขึ้น
  • TLS 1.2 / DTLS 1.2: ระวัง — MbedTLS v4 ลบการรองรับ DHE และ RSA key exchange แบบไม่มี forward secrecy
สำหรับโปรเจกต์ใหม่ในปี 2026: แนะนำให้เริ่มด้วย ESP-IDF v6.x โดยตรง สำหรับโปรเจกต์เก่าที่ใช้ v5.x ให้ตรวจสอบ migration guide อย่างละเอียดก่อน port ขึ้น

🌬️ เครื่องวัดคุณภาพอากาศในอาคาร (Indoor Air Quality Monitor)

ระดับ: เริ่มต้น-กลาง

สร้างเครื่องตรวจวัดคุณภาพอากาศแบบ All-in-One ด้วย ESP32-S3 ผสาน Sensor Sensirion สองตัว ได้แก่ SCD41 สำหรับ CO₂ แบบ NDIR ที่แม่นยำสูง และ SGP41 สำหรับ VOC + NOx — แสดงผลบน e-paper display และส่งข้อมูลไป Home Assistant ผ่าน MQTT

  • SCD41 วัด CO₂ ได้ถึง 5,000 ppm พร้อม temp+humidity ในตัว — ไม่ต้องใช้ BME280 เพิ่ม
  • SGP41 มี 2 pixel — pixel แรกวัด VOC Index, pixel ที่สองวัด NOx Index (ต่างจาก SGP40 ที่วัดแค่ VOC)
  • Alert เมื่อ CO₂ > 1200 ppm (อากาศไม่ดี) หรือ VOC Index > 150
  • สรุปข้อมูลใน Grafana Dashboard ผ่าน InfluxDB

📡 LoRaWAN Environmental Node พลังงานแสงอาทิตย์ (Off-Grid)

ระดับ: กลาง

สร้าง Node ตรวจสภาพอากาศระยะไกลที่ไม่ต้องพึ่งไฟฟ้า — ใช้ ESP32-S3 + โมดูล LoRa E22-900M22S (SX1262) ส่งข้อมูลผ่าน LoRaWAN ไปยัง Gateway ระยะ 1–10 km ชาร์จด้วยโซล่าเซลล์ขนาดเล็ก เหมาะสำหรับฟาร์ม สวน สถานีอากาศ หรือพื้นที่ห่างไกล

  • LoRa SX1262: ระยะ 600 m ในเมือง → 10+ km ในพื้นที่โล่ง ขึ้นอยู่กับเสาอากาศและภูมิประเทศ
  • BME280: อุณหภูมิ ความชื้น ความดันบรรยากาศ + คำนวณ Dew Point และ VPD
  • Meshtastic Protocol: ทางเลือกสำหรับ peer-to-peer mesh relay ไม่ต้องพึ่ง Gateway
  • Deep sleep 99% ของเวลา → ถ่าน 18650 (3,000 mAh) + โซล่า 2W ใช้งานได้ไม่จำกัด
  • รองรับ The Things Network (TTN) และ ChirpStack ในฝั่ง Server

⚙️ Predictive Maintenance Node สำหรับมอเตอร์อุตสาหกรรม

ระดับ: สูง

ระบบตรวจสอบสภาพมอเตอร์แบบ Real-time ด้วย ESP32 + เซนเซอร์ Accelerometer ความแม่นยำสูง ADXL355 วิเคราะห์ Vibration Spectrum เพื่อตรวจจับ Bearing Fault, Imbalance และ Misalignment ก่อนที่จะเกิดความเสียหาย — ส่งแจ้งเตือนผ่าน MQTT ไปยัง Dashboard

  • ADXL355 มี Noise ต่ำกว่า ADXL345 มาก เหมาะกับการวิเคราะห์ Vibration ความถี่สูง (0–1000 Hz)
  • ทำ FFT บน ESP32 เพื่อดู Frequency Spectrum — ตรวจจับ characteristic frequency ของ bearing fault
  • ใช้ TFLite Micro หรือ threshold-based alert เพื่อ classify สภาพ: Normal / Warning / Critical
  • ต้นทุนต่อจุดวัด ~1,500–2,000 บาท ประหยัดกว่า Industrial Sensor แบบ proprietary มาก
  • รองรับ Modbus RTU ส่งข้อมูลไปยัง PLC / SCADA ได้

🔋 Ultra-Low Power Zigbee Sensor Node ด้วย ESP32-H21

ระดับ: กลาง

ออกแบบ Sensor Node ประหยัดพลังงานสุดขีดด้วย ESP32-H21 ใหม่ — DC-DC converter ในชิปช่วยลดกระแสไฟในโหมด light sleep เหลือเพียง 9 µA ทำให้ถ่าน CR2032 ใช้ได้นาน 2–3 ปี เหมาะสำหรับ Door/Window sensor, Temperature node ใน Smart Home

  • Zigbee 3.0 End Device: Join กับ Zigbee coordinator (เช่น Home Assistant Zigbee2MQTT) ได้เลย
  • Thread/Matter ในตัว: รองรับทั้ง ecosystem ล่าสุด ไม่ต้องซื้อชิปอื่นเพิ่ม
  • ตื่นทุก 30 วินาที วัดค่า ส่ง Zigbee Report กลับ sleep ใช้พลังงานน้อยมาก
  • Transmit power 20 dBm: ทะลุกำแพงและระยะ indoor ได้ดี ไม่ต้องใช้ router node ถี่
  • ⚠️ Pinout เปลี่ยนจาก H2 — ต้องใช้ module ใหม่ (H21-MINI หรือ custom PCB)

ตัวอย่างโค้ด: ESP32 + SCD41 CO₂ Monitor พื้นฐาน

อ่านค่า CO₂, อุณหภูมิ และความชื้นจาก SCD41 ผ่าน I2C (Arduino)

ใช้ library Sensirion I2C SCD4x ของ Sensirion ที่มีบน Arduino Library Manager โดยตรง — ติดตั้งผ่าน Library Manager ค้นหา "Sensirion I2C SCD4x"

#include <Arduino.h>
#include <SensirionI2CScd4x.h>
#include <Wire.h>

SensirionI2CScd4x scd4x;

void setup() {
  Serial.begin(115200);
  Wire.begin(); // SDA=21, SCL=22 (default ESP32)
  scd4x.begin(Wire);

  uint16_t error;
  error = scd4x.startPeriodicMeasurement();
  if (error) {
    Serial.println("Error starting SCD41 measurement");
  }
  delay(1000); // รอให้ sensor stabilize
}

void loop() {
  uint16_t co2 = 0;
  float temperature = 0.0, humidity = 0.0;
  bool isDataReady = false;

  // ตรวจสอบว่า data พร้อมหรือยัง
  scd4x.getDataReadyFlag(isDataReady);
  if (!isDataReady) {
    delay(100);
    return;
  }

  uint16_t error = scd4x.readMeasurement(co2, temperature, humidity);
  if (error == 0 && co2 != 0) {
    Serial.printf("CO2: %d ppm | Temp: %.1f°C | Humidity: %.1f%%\n",
                   co2, temperature, humidity);

    // แสดงสถานะคุณภาพอากาศ
    if (co2 < 800)        Serial.println("✅ อากาศดี");
    else if (co2 < 1200)   Serial.println("⚠️ อากาศปานกลาง");
    else                   Serial.println("❌ อากาศไม่ดี — เปิดหน้าต่าง!");
  }

  delay(5000); // SCD41 อ่านทุก 5 วินาที
}

💡 Tips: ใช้ scd4x.performForcedRecalibration(400) เพื่อ calibrate CO₂ baseline เมื่อใช้งานครั้งแรกในพื้นที่โล่ง ค่า 400 ppm คือ CO₂ ในอากาศปกติ
