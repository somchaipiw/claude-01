ESP32-H2

ESP32-H2 — Zigbee 3.0 + Thread 1.3 + BLE 5 บนชิปเดียว

ESP32-H2 คือ RISC-V SoC ตัวแรกของ Espressif ที่บูรณาการวิทยุ IEEE 802.15.4 ไว้ในตัว รองรับ Zigbee 3.0 และ Thread 1.3 พร้อมกัน โดยไม่ต้องใช้ชิปแยก ทำให้สามารถสร้าง Smart Home Gateway ราคาประหยัดได้บนบอร์ดเดียว

CoreRISC-V 32-bit · 96 MHz
Flash4 MB Internal
SRAM320 KB
WirelessIEEE 802.15.4 + BLE 5.0
Deep Sleep8 µA
ProtocolsZigbee 3.0 · Thread 1.3 · Matter
จุดเด่น: รองรับ Matter over Thread โดยตรง — เชื่อมต่ออุปกรณ์ Zigbee เดิมเข้ากับ ecosystem ใหม่ได้โดยไม่ต้องเปลี่ยนฮาร์ดแวร์
Architecture

Hybrid Edge Architecture — ESP32 + RPi5 Digital Twin

แนวทาง Production-Grade IoT ปี 2026 คือ Hybrid Architecture ที่ใช้ ESP32 เป็น Edge Node ประมวลผลแบบ Deterministic และ Raspberry Pi 5 เป็น Local AI Gateway สร้าง Digital Twin ของระบบ ลด Cloud Latency และ BOM Cost

ข้อดี: รองรับ Graceful Degradation — ถ้า Internet ขาด อุปกรณ์ยังทำงานได้ตาม Logic ที่กำหนดไว้ล่วงหน้า
MQTT Node-RED InfluxDB Grafana ESP-IDF
Matter / Thread

ESP32-H2 ในฐานะ Thread End Device สำหรับ Smart Home

ESP32-H2 ที่รัน Thread End Device สามารถส่งข้อมูล Sensor ผ่าน Thread Mesh ไปยัง Border Router (ESP32-C6) และเชื่อมกับ Matter Controller เช่น Apple Home, Google Home, Amazon Alexa ได้โดยตรง

  • ติดตั้ง ESP-IDF 5.4+ พร้อม Thread Stack
  • สร้าง Thread Network ด้วย ESP32-C6 Border Router
  • Flash esp-matter firmware บน ESP32-H2
  • Commission ผ่าน QR Code ใน Apple Home / Google Home
  • รับข้อมูล Sensor แบบ Real-time บน Controller
Industrial IoT

ESP32 + open62541 — OPC-UA Server น้ำหนักเบาสำหรับโรงงาน

ไลบรารี open62541 เวอร์ชัน Embedded สามารถรันบน ESP32-S3 ได้ ทำให้ ESP32 กลายเป็น OPC-UA Server ที่ SCADA/MES ระดับอุตสาหกรรมเชื่อมต่อได้โดยตรง ไม่ต้องผ่าน Gateway แยก

Use Case: ติดตั้งที่เครื่องจักรเก่าที่มีเพียง Sensor แบบ Analog และ Digital I/O แล้วส่งข้อมูลเข้า SCADA ด้วย Protocol มาตรฐาน IEC 62541
ESP32-S3 OPC-UA open62541 FreeRTOS

Automotive

ESP32 TWAI + OBD2 — วินิจฉัยรถยนต์ DIY แบบ Real-Time

ESP32 มี TWAI (Two-Wire Automotive Interface) บิวท์อินรองรับ ISO 11898-2 ทำให้สามารถสร้างเครื่องสแกน OBD2 ราคาต่ำกว่า 200 บาทได้ แสดงข้อมูล RPM, Speed, Coolant Temp, Fuel Trim แบบ Real-time ผ่าน Web Interface

// TWAI init config (ISO 11898-2) twai_general_config_t g_config = TWAI_GENERAL_CONFIG_DEFAULT( GPIO_NUM_21, GPIO_NUM_22, TWAI_MODE_NORMAL); twai_timing_config_t t_config = TWAI_TIMING_CONFIG_500KBITS(); twai_driver_install(&g_config, &t_config, &f_config);
ทดสอบบน Toyota C-HR Hybrid ผ่านแล้ว — SN65HVD230 CAN Transceiver + ESP32 = DIY Scanner ราคาประหยัด
Robotics

micro-ROS บน ESP32-S3 — หุ่นยนต์ควบคุมด้วย ROS2

micro-ROS ช่วยให้ ESP32-S3 กลายเป็น Node ใน ROS2 Network ได้โดยตรง รัน FreeRTOS + micro-ROS Agent ส่ง Topic และรับ Command จาก ROS2 Host บน PC หรือ Jetson Nano เพื่อควบคุม Servo, Motor, IMU

Energy Harvesting

Self-Powered Sensor Node — Piezo + TEG + ESP32-H2

สร้าง Sensor Node ที่ชาร์จพลังงานจากความสั่นสะเทือน (Piezoelectric) และ Gradient ความร้อน (Thermoelectric Generator) รวมกัน ผ่าน Power Management IC เก็บลง Supercapacitor ทำให้ Node ทำงานได้โดยไม่ต้องเปลี่ยนถ่าน

ข้อมูลวิจัย: ที่แสงสว่าง 200 lux + ΔT 13°C ระบบ Hybrid PV+TEG ให้พลังงาน 2.13W ชาร์จ Supercapacitor ได้ภายใน 20 วินาที
  • Piezo Bender + TEG Module เป็นแหล่งพลังงาน
  • LTC3588 หรือ BQ25570 เป็น Energy Harvesting IC
  • Supercapacitor 10F เก็บพลังงานสำรอง
  • ESP32-H2 Deep Sleep ส่งข้อมูลทุก 5 นาที
Wearable

Wearable Air Quality + SpO2 Monitor — ESP32-S3 + BME680 + MAX30102

อุปกรณ์ wearable ขนาดเล็กสำหรับวัดคุณภาพอากาศรอบตัว (VOC, CO2, PM2.5) และ SpO2 + Heart Rate พร้อมกัน ใช้ ESP32-S3 ขนาด Compact แสดงผลบน TFT จิ๋ว 0.96 นิ้ว และส่งข้อมูลไป Smartphone ผ่าน BLE

BME688 MAX30102 PMS5003 SGP30 BLE 5.0 LiPo 500mAh
BME688 + AI เรียนรู้ "นิสัย" ของ Sensor เพื่อแยกแยะ VOC ที่เป็นอันตราย จาก Background Gas ได้แม่นยำขึ้น
Smart Home

DIY Zigbee Sensor Hub — ESP32-H2 Coordinator + Multiple End Devices

Fleet IoT

ESP32 Fleet Monitor — OBD2 + GPS + LTE ติดตามยานพาหนะ

ระบบ Fleet Management DIY ใช้ ESP32 อ่านข้อมูลจาก CAN Bus ผ่าน TWAI, GPS ผ่าน NEO-M8N, และส่งข้อมูลผ่าน LTE (SIM7600) ไป Cloud Dashboard ติดตามตำแหน่ง, สุขภาพเครื่องยนต์, การขับขี่ ได้แบบ Real-time

ต้นทุน: ESP32 + SIM7600 LTE + GPS + PCB ราคาประมาณ 800–1,200 บาท เทียบกับ Commercial Fleet Tracker ราคา 3,000–8,000 บาท

Air Quality

SGP30 — TVOC + eCO2 Sensor สำหรับ Indoor Air Quality

Sensirion SGP30 เป็น Metal-Oxide Sensor วัด Total Volatile Organic Compounds (TVOC) และ equivalent CO2 (eCO2) ผ่าน I2C โดยมี On-chip Calibration Algorithm ทำให้ไม่ต้อง Calibrate บ่อย เหมาะสำหรับ Indoor Air Quality Monitor

เมื่อใช้คู่กับ BME688 จะให้ข้อมูล Air Quality ที่ครบถ้วนมากขึ้น — SGP30 ระบุ TVOC/eCO2 แบบ Numeric ในขณะที่ BME688 ให้ Gas Resistance + AI Index
TVOC 0–60,000 ppb eCO2 400–60,000 ppm I2C 3.3V
