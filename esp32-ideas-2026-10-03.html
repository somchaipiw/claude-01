Silicon Revision

ESP32-P4 Revision 3.0 / 3.1 — พร้อมสู่ Production แล้ว!

Espressif ประกาศ ESP32-P4 revision 3.0 และ 3.1 เป็น revision ที่แนะนำสำหรับ new designs ทุกชิ้น เปลี่ยนแปลงสำคัญคือ pin 54 ที่เดิมเป็น NC (Not Connected) ถูกแปลงเป็น power rail เพื่อความเสถียรของ SoC ทำให้ revision 1.0, 1.1 และ 1.3 ไม่แนะนำสำหรับงาน production อีกต่อไป

ทำไมสำคัญ? การเปลี่ยน revision นี้ช่วยแก้ปัญหา stability ใน high-performance multimedia workloads โดยเฉพาะ H.264 encoding ที่ 1080p@30fps และ AI inference แบบ concurrent ทำให้ P4 พร้อมสำหรับ mass production จริงๆ ในปี 2026 นี้
Dual-Core RISC-V @ 400MHz 32MB embedded PSRAM H.264 encoder HW MIPI-CSI/DSI USB 2.0 HS OTG
Framework

ESP-VISION — Computer Vision Framework เป็นทางการสำหรับ P4

Espressif ปล่อย ESP-VISION Programming Guide สำหรับ ESP32-P4 โดยเฉพาะ (docs อัปเดตล่าสุด กรกฎาคม 2026) ครอบคลุม AI Inference pipeline, Camera ISP management, 2D graphics acceleration และการรัน model หลายๆ ตัว concurrently บน dual-core ได้อย่างมีประสิทธิภาพ

ISP pipeline Model Inference API 2D Graphics Accel Camera Manager
Partnership

Bosch × Espressif — ESP32-C5 Multi-Sensor Platform

Bosch Sensortec และ Espressif ประกาศความร่วมมือสร้าง hardware platform สำหรับ ESP32-C5 ที่มุ่งเน้นการ prototype ระบบ multi-sensor อย่างรวดเร็ว เป้าหมายคือลดเวลาจาก idea สู่ prototype จาก 2-3 เดือนเหลือไม่กี่สัปดาห์ โดยรวม MEMS sensor ของ Bosch กับ Wi-Fi 6 dual-band ของ C5 ในแพลตฟอร์มเดียว

ESP32-C5 Wi-Fi 6 dual-band Bosch MEMS sensors Rapid Prototyping
Protocol

Matter 1.4 บน ESP32-C6 — Thread ผ่านกำแพงได้จริงแล้ว

Matter มาถึง version 1.4 แล้วในปี 2026 หลัง launch ปลายปี 2022 รองรับ Apple, Google, Amazon, Samsung SmartThings และผู้ผลิตอีกหลายร้อยราย ESP32-C6 คือตัวเลือกสำคัญสำหรับ Matter node ที่รวม Wi-Fi 6, Zigbee, Thread และ Bluetooth ไว้ในชิปเดียว ทำให้สร้าง DIY sensor บ้านได้โดยไม่ต้องใช้ bridge

AI Camera

DFRobot FireBeetle 2 ESP32-P4 AI Camera — "Mk32" Project

โปรเจกต์ที่ใช้ FireBeetle 2 ESP32-P4 Development Kit สร้าง 1080p AI Camera ด้วย IO Expansion Board เปิด interface ทั้ง MIPI และ parallel สำหรับ camera และ display ความสามารถหลักคือ AI inference บน edge แบบ real-time พร้อม HMI แสดงผลบนจอสัมผัส โดยมี ESP32-C6 เป็น co-processor จัดการ Wi-Fi 6 และ Bluetooth 5

Hardware: FireBeetle 2 ESP32-P4 + IO Expansion Board + MIPI camera (OV2640/GC0308) + MIPI display 4"
Framework: ใช้ ESP-VISION SDK + ESP-IDF 6.x configure camera pipeline และ model loading
AI Model: โหลด YOLO-nano หรือ MobileNet-V3 quantized (INT8) จาก flash ผ่าน ESP-NN accelerator
Output: แสดง bounding box บน display + ส่ง metadata ผ่าน MQTT ไปยัง Home Assistant
ESP32-P4 Rev 3.x 1080p AI Camera MIPI-CSI YOLO-nano DFRobot
Agriculture IoT

Smart Aquaculture Monitor — ESP32 วัดคุณภาพน้ำบ่อปลา

สร้างระบบ monitor บ่อปลา/กุ้ง วัดค่า pH, Turbidity, TDS (Total Dissolved Solids), อุณหภูมิ และ Dissolved Oxygen แบบ real-time ส่งข้อมูลผ่าน Wi-Fi ไปยัง dashboard และแจ้งเตือน LINE OA เมื่อค่าผิดปกติ ต้นทุนต่ำกว่าระบบ commercial ถึง 10 เท่า

// Sensor polling loop void readWaterQuality() { float pH = readPHSensor(); // 6.5-8.5 safe float turb = readTurbidity(); // NTU float temp = readDS18B20(); // °C float DO = readDO(); // mg/L ≥5 publishMQTT("aqua/pond1", pH, turb, temp, DO); }

Home Automation

DIY Thread Border Router — ESP32-C6 เชื่อม Matter กับ IP Network

สร้าง Thread Border Router ราคาย่อมเยา (ต่ำกว่า 400 บาท) จาก ESP32-C6 เพื่อเชื่อม Thread network กับ IPv6/IPv4 network ช่วยให้ Matter device (สวิตช์, sensor) คุยกับ Home Assistant โดยตรงโดยไม่ต้องผ่าน Apple TV หรือ Google Nest Hub ใช้ ESP-Thread-BR library จาก Espressif

ESP32-C6 OpenThread Matter 1.4 Home Assistant <400 บาท
Mesh Network

FGRFMesh — Sub-GHz Open Mesh Network ระยะไกลด้วย ESP32

FGRFMesh นำ open sub-GHz mesh networking มาสู่ ESP32 และ STM32 เหมาะสำหรับโครงการที่ต้องการส่งข้อมูลระยะไกล (กิโลเมตร) โดยไม่ต้องพึ่ง LoRaWAN infrastructure ใช้ระบบ mesh ให้แต่ละ node เป็นทั้ง sender และ relay ได้ แบตอยู่นานกว่า Wi-Fi 10–50 เท่า

Sustainable IoT

Solar-Powered ESP32-C6 Sensor Node — ไม่ต้องเปลี่ยนแบต

ใช้ Solar Devboard V1 ที่รวม ESP32-C6 กับ BQ25186 solar charger ชาร์จจาก solar panel 18W ได้โดยตรง เหมาะสำหรับ field deployment ที่ไม่มีไฟฟ้า เช่น สวน ป่า หรือหลังคา Deep sleep ระหว่างวัดข้อมูล ทำให้ แบต 2000mAh อยู่ได้หลายสัปดาห์แม้วันที่ไม่มีแดด
