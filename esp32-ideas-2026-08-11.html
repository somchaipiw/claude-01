ESP32-H2 · Certified 2026
ESP32-H2: ชิป "Thread + Zigbee" ผ่านการรับรองมาตรฐานสากล
Espressif ประกาศให้ ESP32-H2 เป็น Thread-Certified Component และ Zigbee-Compliant Platform อย่างเป็นทางการ ชิป RISC-V ตัวนี้รองรับ IEEE 802.15.4 ทั้ง Zigbee 3.0 และ Thread 1.3 พร้อมกันในตัวเดียว ใช้กระแสขณะ deep sleep เพียง 8 µA ทำให้เหมาะอย่างมากกับ battery-powered sensor node ที่ต้องการอายุแบตเตอรีหลายเดือนหรือปี
RISC-V 32-bit 96 MHz Deep-sleep: 8µA 802.15.4 BLE 5.0 Matter ready
💡 ไอเดีย: Border Router ราคาถูก

ใช้ ESP32-H2 + ESP32-S3 (ฝั่ง Wi-Fi) สร้าง Thread Border Router + Zigbee Coordinator แบบ DIY เชื่อม smart home device กับ Matter โดยไม่พึ่ง hub ราคาแพง

Meshtastic · LoRa Mesh 2026
Meshtastic 2026: เครือข่าย Off-Grid ไร้สาย ที่ทะลุ 331 km
Meshtastic คือ open-source project ที่ใช้ LoRa radio บน ESP32/ESP32-S3 สร้างเครือข่าย mesh แบบ encrypted สำหรับส่ง text, GPS location และ sensor telemetry โดยไม่พึ่ง cellular หรืออินเทอร์เน็ตเลย ปัจจุบันชุมชน Meshtastic ทำสถิติระยะ 331 km ผ่าน mesh relay — และในสถานการณ์ปกติให้พิสัย 2–5 km ต่อ hop
SX1262 LoRa 915/868/433 MHz AES-256 encrypted GPS overlay Bluetooth app
💡 ไอเดีย: Emergency Communication Node

สร้าง solar-powered Meshtastic node วางตามยอดเขา/ตึกสูง เพื่อขยาย mesh coverage สำหรับการสื่อสารฉุกเฉินในพื้นที่ห่างไกล

Sensor Board · Sensirion 2026
SparkFun Indoor Air Quality Combo: SCD41 + SEN55 ใน Board เดียว
SparkFun เปิดตัว Indoor Air Quality Combo Sensor รวม Sensirion SCD41 (CO₂ จริงๆ ผ่าน photoacoustic) และ SEN55 (PM1.0/2.5/4/10 + VOC + Temp + Humidity) ไว้ใน board เดียว ต่อกับ ESP32 แค่ Qwiic cable เส้นเดียว วัดอากาศในห้องได้ครบ 7 พารามิเตอร์ ใช้ I2C ทั้งคู่ SEN55 ออกแบบมีอายุใช้งาน 10+ ปี
CO₂: 0–40,000ppm PM2.5 ±10µg/m³ VOC index I2C / Qwiic Auto-calibrating
💡 ไอเดีย: Classroom Air Monitor

ติดตั้งในห้องเรียน วัด CO₂ > 1,000 ppm ให้สัญญาณเตือน LED + buzzer บน ESP32-C6 ส่งข้อมูลขึ้น Home Assistant ผ่าน MQTT

ESP32-S3 · Edge AI Vision
DFRobot ESP32-S3 AI CAM: TinyML + Night Vision + ChatGPT Voice
DFRobot ออก board DFR1154 ที่รวม ESP32-S3 dual-core 240 MHz, กล้อง OV5640, infrared สำหรับ night vision, microphone, และ SD card ไว้ในตัว รองรับ EdgeImpulse, YOLO, OpenCV สำหรับ on-device inference และเชื่อมกับ ChatGPT API ผ่าน Wi-Fi ได้ ทำการจำแนกวัตถุ (object detection) ใน <200ms บน device โดยไม่ต้องส่ง cloud
OV5640 5MP IR night vision 8MB PSRAM EdgeImpulse <200ms inference

Health IoT · ESP32 + MAX30102 + AD8232
🏥 ESP32 Patient Health Monitor: ECG + SpO₂ + BPM + Live Web Dashboard
โปรเจกต์นี้สร้าง health monitor แบบ real-time โดยใช้ ESP32 กับ sensor 3 ตัว ได้แก่ AD8232 (ECG signal), MAX30102 (heart rate + SpO₂) และ BME280 (อุณหภูมิ/ความชื้น) ข้อมูลทั้งหมดแสดงผลบน web dashboard แบบ live graph ผ่าน Wi-Fi — ไม่ต้องมีแอปพิเศษ เปิด browser บนมือถือก็ดูได้ทันที ต้นทุนรวมไม่เกิน 800 บาท
  1. ต่อ MAX30102 กับ ESP32 ผ่าน I2C (SDA=GPIO21, SCL=GPIO22)
  2. ต่อ AD8232 ECG: OUTPUT → ADC pin, LO± → digital GPIO สำหรับ lead-off detection
  3. ติดตั้ง library: MAX30105 (SparkFun), Adafruit BME280
  4. สร้าง web server บน ESP32 ใช้ ESPAsyncWebServer + Chart.js
  5. Push ข้อมูล ECG ผ่าน WebSocket ทุก 50ms (20Hz)
// ตัวอย่าง: อ่าน SpO2 + BPM ด้วย MAX30102 #include "MAX30105.h" #include "heartRate.h" #include "spo2_algorithm.h" MAX30105 particleSensor; uint32_t irBuffer[100], redBuffer[100]; int32_t spo2, heartRate; int8_t validSPO2, validHR; void setup() { particleSensor.begin(Wire, 400000); particleSensor.setup(60, 4, 2, 100, 411, 4096); } void loop() { // อ่าน 100 samples ก่อน compute for (int i = 0; i < 100; i++) { irBuffer[i] = particleSensor.getIR(); redBuffer[i] = particleSensor.getRed(); particleSensor.nextSample(); } maxim_heart_rate_and_oxygen_saturation( irBuffer, 100, redBuffer, &spo2, &validSPO2, &heartRate, &validHR ); }
ต้นทุน: ~800 บาท MAX30102: ~60 บาท AD8232: ~120 บาท BME280: ~80 บาท
DIY · LoRa + ESP32
📡 DIY Meshtastic Node ราคาถูก: ESP32 + SX1262
สร้าง Meshtastic node ได้เองโดยใช้ Heltec WiFi LoRa 32 V3 (ESP32-S3 + SX1262 onboard) ราคาประมาณ 500 บาท flash firmware Meshtastic ผ่าน web flasher หน้าเดียว จากนั้นตั้งค่าผ่าน Bluetooth ด้วยแอป Meshtastic บนมือถือ ใส่แบตเตอรี 18650 + เคส กันน้ำแล้วติดตั้งกลางแจ้งได้ทันที

ใช้ dipole antenna แนวตั้งยาว 8.2 cm (915 MHz) แทน wire stub สั้น — เพิ่ม range ได้ 30–50% โดยไม่เสียค่าใช้จ่าย

Water IoT · ESP32
💧 Smart Water Quality Monitor: pH + TDS + Turbidity + Temp
วัดคุณภาพน้ำแบบ real-time ด้วย ESP32 + sensor 4 ตัว: pH electrode (กรด/ด่าง 0–14), TDS sensor (ความเข้มข้นสารละลาย 0–1000 ppm), Turbidity sensor (ความขุ่น NTU) และ DS18B20 (อุณหภูมิน้ำ) ส่งข้อมูลขึ้น ThingSpeak ทุก 5 นาที ตั้ง alert เมื่อค่าเกินขีดจำกัดผ่าน LINE Notify
pH: 0–14 TDS: 0–1000ppm Turbidity: 0–1000NTU Temp: -10–85°C
💡 Use Case: บ่อปลา/ฟาร์มกุ้ง

ติดตั้งในบ่อเลี้ยงสัตว์น้ำ แจ้งเตือนเมื่อ pH ต่ำกว่า 6.5 หรือ TDS สูงกว่า 500 ppm ก่อนที่ปลาจะเริ่มป่วย

Sensors น่าสนใจ: Biometric & Air Quality

เปรียบเทียบ sensors สำหรับสุขภาพและคุณภาพอากาศที่ใช้กับ ESP32 ได้

Biometric Sensors
เปรียบเทียบ Heart Rate / SpO₂ Sensors สำหรับ ESP32
Sensor วัดได้ Interface ราคา เหมาะกับ
MAX30102 Heart Rate (BPM), SpO₂ (%), อุณหภูมิ chip I2C ~60–80 บาท Wearable, fitness tracker, pulse oximeter DIY
MAX30100 Heart Rate, SpO₂ (รุ่นเก่า) I2C ~50 บาท Project ง่าย ราคาถูก (ไม่แนะนำ IR LED burn-in)
AD8232 ECG waveform (1-lead) Analog + GPIO ~100–150 บาท ECG monitoring, heart rhythm analysis
MLX90614 อุณหภูมิร่างกาย (Non-contact) I2C ~180 บาท Fever screening, contactless temperature
Air Quality Sensors
เปรียบเทียบ CO₂ / TVOC / Particulate Matter Sensors
Sensor วัดได้ เทคโนโลยี ราคา ความแม่นยำ
Sensirion SCD41 CO₂ จริง (0–40,000 ppm), Temp, Humidity Photoacoustic (true CO₂) ~900–1,200 บาท ±40ppm ±3% — แม่นยำสูงสุด
MH-Z19B CO₂ (0–5,000 ppm) NDIR infrared ~350–450 บาท ±50ppm ±5% — คุ้มค่าดีมาก
Sensirion SEN55 PM1/2.5/4/10, VOC Index, Temp, Humidity Optical particle counter + MOX ~1,500–1,800 บาท PM2.5: ±10µg/m³ — อายุใช้งาน 10 ปี
SGP30 TVOC (ppb), eCO₂ (ppm) Metal Oxide (MOX) ~250–350 บาท ค่า eCO₂ เป็นค่าประมาณ ไม่ใช่ CO₂ จริง
ENS160 (ScioSense) TVOC, eCO₂, AQI (1–5) Multi-element MOX ~200 บาท 4-pixel MOX, UBA AQI standard
PMS7003 PM1/2.5/10 particles Laser particle counting ~400–500 บาท ±10µg/m³ — นิยมมากสำหรับ DIY AQI
🎯 คำแนะนำ: สำหรับ Home Assistant ครบเซ็ต

ใช้ MH-Z19B (CO₂ จริง ราคาถูก) + ENS160 (TVOC+AQI) + PMS7003 (PM2.5) + BME280 (Temp/Humidity) ต่อกับ ESP32-C6 ผ่าน ESPHome — ต้นทุนรวม ~1,500 บาท ครอบคลุมทุกพารามิเตอร์สำคัญของอากาศในบ้าน
