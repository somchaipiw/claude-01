ประสิทธิภาพ Vision Inference บน ESP32 — ตัวเลขจริงที่ควรรู้

ก่อนออกแบบโปรเจกต์ Vision ควรเข้าใจข้อจำกัดด้านความเร็ว inference ของแต่ละชิป

  • ESP32-S3: CNN ขนาดเล็ก (~200–500 ms/frame), Audio TinyML ~30–100 ms
  • ESP32-P4: เร็วกว่า S3 ประมาณ 3–5× ด้วย dual-core 400 MHz + vector unit
  • Resolution แนะนำ: 96×96 หรือ 160×160 px สำหรับ classification
  • Model size: ควร <500 KB สำหรับ S3, <2 MB สำหรับ P4 พร้อม PSRAM
กฎง่ายๆ: ถ้าต้องการ real-time (>10 fps) ให้ใช้ ESP32-P4; ถ้าแค่ "sense and decide" ทุก 1–5 วินาที ESP32-S3 เพียงพอ

📍 BLE Indoor Positioning & Asset Tracking — ติดตามตำแหน่งในอาคารด้วย ESP32

Technology

RSSI-Based BLE Trilateration — หลักการและความแม่นยำจริง

ระบบ BLE Indoor Positioning ใช้ ESP32 เป็น beacon ส่ง iBeacon signal และ ESP32 scanner วัด RSSI แล้วคำนวณระยะทางด้วย trilateration

  • ความแม่นยำดิบ: ± 3–5 เมตร (RSSI ผันผวนสูง)
  • หลังใช้ RSSI filtering: error ลดเหลือ <30% ที่ระยะ 10 เมตร
  • Algorithm: Kalman Filter หรือ Weighted Moving Average ลด noise
  • ต้องใช้ beacon อย่างน้อย 3 จุดต่อพื้นที่ เพื่อ trilateration
ข้อสังเกต: RSSI ได้รับผลกระทบจากผนัง คน และโลหะ — ควร calibrate ในสภาพแวดล้อมจริง และใช้ beacon หนาแน่นขึ้นในพื้นที่ซับซ้อน
ESP-NOW

ESP-NOW Asset Zone Tracking — ง่ายกว่า แม่นพอ สำหรับ Zone-Level

สำหรับงานที่ต้องการรู้เพียงว่า asset อยู่ "โซนไหน" ไม่ต้องการพิกัด XY แม่นยำ ESP-NOW เป็นทางออกที่เรียบง่ายกว่า BLE RSSI

  • Payload: 250 bytes, latency <10 ms, ระยะ <200 m indoor
  • ไม่ต้อง pair — ESP-NOW ใช้ MAC address โดยตรง
  • Tag ส่ง heartbeat ทุก 30 วินาที → gateway ระบุโซน
  • ใช้ ESP32 ราคาถูกเป็น anchor node กระจายทั่วพื้นที่
เหมาะกับ: คลังสินค้า โรงงาน หรือโรงพยาบาล ที่ต้องการรู้ว่า asset อยู่ห้องไหน ไม่ใช่พิกัด cm
Hybrid System

Wi-Fi RTT + BLE RSSI Hybrid — ความแม่นยำสูงสุดสำหรับ Industrial

ระบบ hybrid ที่รวม Wi-Fi RTT (Round-Trip Time) ระบุตำแหน่ง mobile device และ BLE RSSI ระบุ asset tag ในรัศมี ~10 เมตร

  • Wi-Fi RTT: ความแม่นยำ 1–2 เมตร (ต้องใช้ AP รองรับ IEEE 802.11mc)
  • BLE RSSI: ระบุ asset ที่ติด tag ในรัศมีจาก mobile device
  • Use case: พนักงานถือ phone → app รู้ว่าอยู่ where → แสดง asset ใกล้เคียง
  • อ้างอิงจาก BIBA MeshTrack Project (Bremen, Germany)
สำหรับโรงงานที่ต้องการความแม่นยำระดับ 1–3 เมตร และมี Wi-Fi AP กระจายทั่ว — hybrid นี้ให้ผลดีที่สุด
อนาคต

Bluetooth AoA/AoD + BLE Mesh — ทิศทางที่ Espressif กำลังพัฒนา

Espressif ประกาศ roadmap รวม Bluetooth AoA (Angle of Arrival) / AoD เข้ากับ Bluetooth Mesh เพื่อ indoor positioning ผ่าน smart lighting grid

  • AoA: วัดมุมสัญญาณด้วย antenna array → แม่นยำกว่า RSSI มาก (<0.5 เมตร)
  • AoD: กลับกัน — transmitter ที่มี antenna array, receiver ธรรมดา
  • รวมกับ BLE Mesh → ทุก node เป็นทั้ง anchor และ relay
  • ยังไม่มี ESP32 SDK ที่ deploy ได้ในปัจจุบัน — เป็น forward-looking roadmap
น่าจับตามอง: ถ้า Espressif release AoA SDK บน ESP32-C6 หรือ ESP32-H2 จะเปลี่ยน landscape ของ indoor positioning DIY อย่างสิ้นเชิง

🏭 ESP32 BLE Asset Tracker สำหรับอุปกรณ์ในโรงงาน

ระบบติดตาม tool และอุปกรณ์ในโรงงาน ใช้ BLE beacon ราคาถูก + ESP32 anchor node กระจายทั่วพื้นที่

🏷️ Asset Tag

ESP32-C3 Mini + แบตกระดุม CR2032, ส่ง BLE iBeacon ทุก 5 วินาที (UUID + Asset ID) อายุถ่าน 3–6 เดือน

📡 Anchor Node

ESP32 + Wi-Fi, scan BLE ทุก 1 วินาที → บันทึก RSSI ของ tag ที่เห็น → ส่ง MQTT ผ่าน Wi-Fi ไป server

🖥️ Backend

Node.js server รับ MQTT → Kalman filter RSSI → trilateration หรือ zone detection → บันทึกใน PostgreSQL

📊 Dashboard

Grafana floor plan overlay แสดง asset location แบบ real-time, แจ้งเตือนเมื่อ asset ออกนอกโซน
