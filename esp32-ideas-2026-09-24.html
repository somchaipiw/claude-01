Arduino ESP32 Core v3.3.12 — ESP-IDF v5.5.5

Espressif ปล่อย Arduino ESP32 Core เวอร์ชัน 3.3.12 เมื่อวันที่ 18 กันยายน 2569 พัฒนาบนฐาน ESP-IDF v5.5.5 ซึ่งเป็น patch release ล่าสุดในสาย v5.5.x รองรับบอร์ด ESP32 ทุกซีรีส์รวมถึง ESP32-S3, C6, H2 และ P4

ไฮไลต์สำคัญ: ปรับปรุงความเสถียร BLE stack, แก้บัค Wi-Fi reconnect, รองรับ Arduino IDE 2.x อย่างเต็มที่ และอัปเดต toolchain สำหรับ RISC-V targets

⚠️ หมายเหตุ: ESP-IDF v5.2 ถึงวันหมดอายุ (EOL) แล้วในเดือนสิงหาคม 2569 ควรอัปเกรดโปรเจกต์ไปใช้ v5.3+ หรือ v6.0 เพื่อรับ security patch และฟีเจอร์ใหม่

TinyML บน ESP32-S3 — Production-Ready ในปี 2569

TinyML (Machine Learning บน Microcontroller) บน ESP32-S3 ก้าวพ้นจากการเป็น proof-of-concept แล้ว ในปี 2569 ถือว่าพร้อมใช้งานจริง (production-ready) สำหรับ Smart Home Security, Fall Detection, Keyword Spotting และ Object Classification

EnviroGo — Wearable ESP32-S3 Environmental Monitor 7-in-1

EnviroGo คือ wearable device สำหรับตรวจสอบสภาพแวดล้อม 7 พารามิเตอร์พร้อมกัน ออกแบบบน ESP32-S3 มี built-in Wi-Fi + Bluetooth สามารถสวมใส่, หนีบกระเป๋า หรือดูดติดแม่เหล็กได้

ESP32-C6 Multi-Sensor Board — Plug & Play ครบในบอร์ดเดียว

Elecrow เปิดตัว ESP32-C6 Multi-Sensor Board ที่รวม sensor 8 ชนิดไว้ในบอร์ดเดียว รองรับ USB Type-C plug-and-play เหมาะสำหรับ Smart Indoor Monitor, Air Quality Station และ Home Automation Node

ใช้ ESP32-C6 ซึ่งรองรับ Wi-Fi 6, Bluetooth 5, Zigbee 3.0 และ Thread/Matter protocol ในตัว ทำให้เชื่อมต่อกับระบบ Smart Home รุ่นใหม่ได้ทันที

8 parameters: CO₂, VOC, อุณหภูมิ, ความชื้น, ความดัน, แสง, Human Presence (mmWave) และ 6-axis IMU

Elderly Fall Detection System — ESP32-S3 + Edge Impulse

ระบบตรวจจับการหกล้มสำหรับผู้สูงอายุ โดยใช้ XIAO ESP32-S3 + MPU6050 และโมเดล TinyML ที่ train ด้วย Edge Impulse Studio แสดงผลความแม่นยำ 95-96% ในการทดสอบจริง

เมื่อตรวจจับการหกล้ม ระบบส่ง GPS Location + แจ้งเตือนไปยังผู้ดูแลผ่าน Blynk App หรือ WhatsApp API มี 10-วินาที cancellation window เพื่อลด false alarm

  • 1เก็บ IMU data (accelerometer + gyroscope) จาก MPU6050
  • 2Train โมเดล classifier ด้วย Edge Impulse (Normal / Fall)
  • 3Export โมเดลเป็น Arduino library และ deploy บน ESP32-S3
  • 4เพิ่ม GPS module (NEO-6M) และ GSM/Wi-Fi notification
  • 5ทดสอบ + Calibrate ด้วย real-world fall scenarios

IoT Vehicle Motion Analyzer — MPU6050 + LIS3MDL + Dashboard

อุปกรณ์วิเคราะห์การขับขี่แบบ real-time ติดในรถยนต์ ใช้ MPU6050 (accelerometer + gyroscope) ร่วมกับ LIS3MDL (3-axis magnetometer) เพื่อวิเคราะห์: การเบรกหนัก, เลี้ยวเร็ว, ความเร่ง, ทิศทาง และ G-force

MPU6050 — 6-axis IMU คลาสสิกที่ยังครองตลาด

MPU6050 ยังคงเป็น IMU sensor ที่นิยมที่สุดสำหรับ ESP32 แม้จะมีอายุหลายปี เพราะราคาถูก (~20-40 บาท), library ครบ, tutorial เยอะ และ accuracy ดีพอสำหรับ hobby/prosumer projects

รองรับ: 3-axis Accelerometer (±2g ถึง ±16g) + 3-axis Gyroscope (±250°/s ถึง ±2000°/s) + built-in Temperature sensor + DMP (Digital Motion Processor) สำหรับคำนวณ Euler angle ในชิปเลย

InterfaceI2C / SPI
Power3.3V / 5V
ราคา~25 บาท
Use CaseFall Detection, Drone
6-axis IMU I2C DMP Built-in ยอดนิยม

LIS3MDL — 3-axis Magnetometer ความแม่นยำสูง

ST LIS3MDL เป็น 3-axis magnetometer ที่ออกแบบมาสำหรับ compass และ orientation applications ความละเอียดสูง 16-bit, noise ต่ำ และกินไฟน้อย เหมาะคู่กับ MPU6050 สร้างระบบ 9-axis IMU เต็มรูปแบบ

ใช้ร่วม MPU6050+LIS3MDL เพื่อ sensor fusion (Madgwick/Mahony filter) สร้าง AHRS (Attitude and Heading Reference System) แม่นยำสำหรับ robot/drone/navigation

Range±4 to ±16 Gauss
InterfaceI2C / SPI
ODRสูงสุด 1000 Hz
ราคา~80 บาท
Magnetometer 3-axis AHRS ST Microelectronics

INMP441 — MEMS I2S Microphone สำหรับ Audio AI

INMP441 เป็น MEMS microphone ที่สื่อสารผ่าน I2S protocol ตรงกับ ESP32 native I2S peripheral ทำให้ได้ audio quality ดี noise floor ต่ำ และสามารถ run TinyML audio model (Keyword Spotting, Sound Classification) ได้โดยตรง

เหมาะสำหรับ: Wake word detection ("Hey ESP!"), เสียงเตือนภัย, noise monitoring, baby monitor อัจฉริยะ และ speech analytics

InterfaceI2S (PDM)
Freq Range60 Hz – 15 kHz
SNR61 dBA
ราคา~35 บาท
MEMS Mic I2S TinyML Audio Keyword Spotting

ENS160 — MOX Gas Sensor ยุคใหม่ แทน CCS811

ScioSense ENS160 เป็น Metal Oxide (MOX) gas sensor รุ่นใหม่ที่ออกแบบมาแทน CCS811 โดยตรง วัด TVOC, eCO2 (equivalent CO2) และ AQI (Air Quality Index) มี built-in AI algorithm ประมวลผลในชิป calibration ดีกว่า CCS811 มาก

มักใช้คู่กับ AHT21/SHT4x เพื่อ humidity compensation ทำให้ค่า VOC/CO2 แม่นยำขึ้น เหมาะสำหรับ Indoor Air Quality Station, Smart Ventilation และ Classroom Monitor

TVOC Range0 – 65,000 ppb
eCO2 Range400 – 65,000 ppm
InterfaceI2C / SPI
ราคา~120 บาท
