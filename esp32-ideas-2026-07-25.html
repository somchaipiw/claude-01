Security · NFC · Open Source

NullTag RFID Toolkit — อ่าน/โคลน/เขียน Smart Card ด้วย ESP32 + PN532

โปรเจกต์ open-source จาก Hackaday.io ที่สร้าง DIY RFID & NFC Toolkit แบบพกพา ใช้ ESP32 จับคู่กับ PN532 เชื่อมผ่าน SPI รองรับ MIFARE Classic, NTAG, FeliCa และ Tag 13.56 MHz ส่วนใหญ่ใน Radius 2–5 cm Version 2 อัพเกรดเป็น PCB stack 3 ชิ้นพร้อม Antenna แยกเพื่อลด EMI

เมนูหลักมี 10 ฟีเจอร์รวมถึง อ่าน Tag, เขียน Tag, โคลน Card, และทดสอบ RFID Reader — แสดงผลบน OLED Display ขนาดเล็ก

ESP32 / ESP32-S3 PN532 NFC Module OLED 128×64 I2C LiPo Battery 500mAh Custom PCB Stack

ใช้ Library elechouse/PN532 สำหรับ Arduino IDE
เพิ่ม OLED เพื่อแสดงเมนูและผลการอ่าน Tag

Automotive · CAN Bus · IoT

DIY OBD-II Dashboard บน ESP32 + TWAI — ดูข้อมูลรถยนต์ Real-Time ผ่าน Wi-Fi

ESP32 มี Built-in TWAI (Two-Wire Automotive Interface) ที่ Compatible กับ CAN 2.0B รองรับ Standard Frame (11-bit ID) และ Extended Frame (29-bit ID) ทำให้สามารถต่อ OBD-II Connector ของรถได้โดยตรง เพียงเพิ่ม CAN Transceiver ภายนอก (เช่น SN65HVD230) เท่านั้น

ใช้ Library muki01/OBD2_CAN_Bus_Library (Arduino IDE / PlatformIO) ดึงค่า RPM, ความเร็ว, อุณหภูมิเครื่องยนต์, และ Error Code ผ่าน ISO15765-4 แล้วส่งข้อมูลไป Dashboard ผ่าน MQTT หรือ Web Server

อุปกรณ์ที่ใช้

ESP32 / ESP32-S3 SN65HVD230 CAN Transceiver OBD-II Connector TFT Display 3.5" muki01 OBD2 Library
เชื่อม SN65HVD230 กับขา GPIO ของ ESP32 (TX/RX TWAI)
ต่อ OBD-II Connector: Pin 6 (CAN-H) และ Pin 14 (CAN-L)
ติดตั้ง muki01/OBD2_CAN_Bus_Library ผ่าน PlatformIO
อ่านค่า PIDs ที่ต้องการ เช่น 0x0C (RPM), 0x0D (Speed), 0x05 (Coolant Temp)
แสดงผลบน TFT หรือส่งไป Grafana Dashboard ผ่าน MQTT
Library: github.com/muki01/OBD2_CAN_Bus_Library — รองรับ ESP32, ESP32-S3, ESP32-C6
Security · NFC · Home Automation

Smart Access Control ด้วย ESP32 + PN532 + Home Assistant — ล็อค/ปลดล็อคด้วยการ์ด NFC

สร้างระบบ Access Control สำหรับบ้านหรือสำนักงานโดยใช้ ESP32 + PN532 อ่านบัตร NFC (MIFARE, NTAG21x, หรือแม้แต่สมาร์ทโฟน Android/iPhone ที่รองรับ NFC) แล้วเปรียบเทียบ UID กับ Whitelist ที่เก็บไว้ใน SPIFFS ถ้าตรงก็สั่งควบคุม Electronic Lock หรือ Relay

Integration กับ Home Assistant ผ่าน MQTT หรือ ESPHome ทำให้ดูประวัติการเข้าออกแบบ Real-time และตั้ง Time-Based Access Rule ได้

อุปกรณ์ที่ใช้

ESP32 / ESP32-C6 PN532 NFC Module Electronic Magnetic Lock Relay Module 5V MIFARE Classic Card/Fob
เชื่อม PN532 กับ ESP32 ผ่าน I2C (SDA/SCL)
บันทึก Whitelist UID ลงใน SPIFFS หรือ SD Card
เมื่ออ่าน Card ได้ — ตรวจสอบ UID กับ Whitelist
สั่ง Relay เปิด/ปิด Lock พร้อม Buzzer แจ้งเตือน
Log เหตุการณ์ส่งไป Home Assistant ผ่าน MQTT
Gesture · Contactless · HCI

Gesture-Controlled Smart Home ด้วย PAJ7620U2 + ESP32 — สั่งงาน 9 ท่ามือไร้สัมผัส

PAJ7620U2 เป็น Gesture Sensor ที่รู้จักท่ามือ 9 แบบ ได้แก่ ขึ้น, ลง, ซ้าย, ขวา, เข้าหา, ออก, วนตามเข็ม, วนทวนเข็ม, และโบกมือ ทำงานผ่าน I2C ง่ายต่อการเชื่อม ESP32 ระยะตอบสนองไม่เกิน 20 cm ใช้สั่งไฟ, พัดลม, ปรับเสียง, หรือ Navigation Menu บน Display ได้โดยไม่ต้องแตะหน้าจอ

เหมาะสำหรับ Kitchen Display ที่มือเปื้อน, อุปกรณ์ Medical ที่ต้องการ Hygienic Control, หรือ Presentation Remote แบบสวมใส่

อุปกรณ์ที่ใช้

ESP32 / ESP32-S3 PAJ7620U2 Gesture Sensor Waveshare PAJ7620U2 Module Smart Home Relay / MQTT
เชื่อม PAJ7620U2 ผ่าน I2C (SDA GPIO21, SCL GPIO22)
ใช้ Library DFRobot_PAJ7620 หรือ acrobotic/PAJ7620 สำหรับ Arduino
อ่าน Gesture Register และ Map ท่าแต่ละแบบกับ MQTT Command
ทดสอบ Latency ให้ต่ำกว่า 100ms ด้วยการปรับ I2C Clock Speed
Integrate กับ Home Assistant ผ่าน MQTT หรือ ESPHome Script

Sensors & Modules น่าสนใจ

อุปกรณ์เสริมที่น่านำมาต่อยอดกับ ESP32 ในงาน NFC, Automotive และ Gesture

📶

PN532 NFC/RFID Module

13.56 MHz NFC Reader/Writer

รองรับ MIFARE Classic 1K/4K, MIFARE Ultralight, NTAG213/215/216, ISO14443A/B, FeliCa เชื่อมได้ทั้ง SPI, I2C, UART รัศมีอ่านประมาณ 2–5 cm ราคาประมาณ 80–150 บาท ถือเป็น NFC Module มาตรฐานของ Maker Community

👋

PAJ7620U2

9-Gesture IR Sensor — ระยะ 20cm

รู้จักท่ามือ 9 แบบ ด้วย IR Imaging Array 60×60 pixels ที่ 240fps เชื่อมผ่าน I2C ทำงานที่ 3.3V กินไฟต่ำ เหมาะสำหรับ Contactless Control ในทุก Application ราคาประมาณ 150–250 บาท

🌈

APDS-9960

4-in-1: Gesture + Light + RGB + Proximity

Sensor ขนาดเล็กที่รวม Proximity Detection, Ambient Light, Color (RGB), และ Gesture (ขึ้น/ลง/ซ้าย/ขวา) ในชิปเดียว ราคาถูกกว่า PAJ7620 แต่จำนวนท่ามือน้อยกว่า เหมาะสำหรับงาน Smart Phone Interaction

🚗

SN65HVD230 CAN Transceiver

CAN Bus Driver สำหรับ ESP32 TWAI

CAN Bus Transceiver 3.3V ที่จำเป็นต้องใช้คู่กับ ESP32 TWAI Controller รองรับ CAN 2.0B, ทำงานที่ 3.3V โดยตรง ไม่ต้องใช้ Level Shifter ราคาประมาณ 30–60 บาท ซื้อได้ในรูปแบบ Module หรือ IC เดี่ยว
