Zigbee vs Thread vs Matter — เลือกใช้อะไรกับ ESP32-H2?

ESP32-H2 มีวิทยุ IEEE 802.15.4 เพียงตัวเดียว จึงรัน Zigbee หรือ Thread ได้ครั้งละ protocol การเลือกขึ้นอยู่กับ ecosystem และอุปกรณ์ที่บ้านหรือระบบที่ต้องการต่อ

เกณฑ์ Zigbee 3.0 Thread 1.4
IPv6ไม่รองรับ✅ รองรับ
IP-Routableต้องการ Hub✅ ไม่ต้อง
Ecosystemใหญ่มาก (Philips Hue ฯลฯ)กำลังเติบโต
Matterผ่าน Bridge✅ native
Battery lifeดีมากดีมาก
Latency~10–50 ms~10–50 ms
⚠️ หมายเหตุ: วิทยุ 802.15.4 บน H2 ทำงาน Zigbee และ Thread ได้ แต่ไม่พร้อมกันในเวลาเดียวกัน

ESP32 Fuzzy Logic Smart Irrigation System
กลาง

ระบบรดน้ำอัตโนมัติด้วย Fuzzy Logic บน ESP32 ปรับปริมาณน้ำตาม input 2 ตัว: ความชื้นดิน (0–100%) และอุณหภูมิอากาศ คำนวณ fuzzy membership function แบบ real-time ไม่ต้องตั้งเกณฑ์แข็ง เหมาะกับพืชที่ความต้องการน้ำแปรผัน เช่น สตรอเบอร์รี่, มะเขือเทศ

ESP32 Soil Moisture v1.2 DHT11/22 Relay Module Water Pump 5V
ตัวอย่าง Fuzzy Rule
Dry + Hot→ รดน้ำ 100% (max)
Dry + Normal→ รดน้ำ 70%
Moist + Hot→ รดน้ำ 40%
Moist + Normal→ รดน้ำ 15%
Wet + Any→ ไม่รดน้ำ (0%)
ESP32-S3 TinyML — ทำนายความล้มเหลวของระบบแบบ Real-time
ยาก

งานวิจัยปี 2025 แสดงให้เห็นว่า ESP32 สามารถรัน AI model ขนาด ~32 KB ใน SRAM เพื่อทำนาย network failure และ memory leak แบบ real-time ได้ โดยใช้ TensorFlow Lite Micro inference เวลาน้อยกว่า 5ms ต่อรอบ เหมาะกับ Industrial IoT ที่ต้องการ predictive maintenance

ESP32-S3 TFLite Micro PSRAM 8MB Current Sensor Vibration Sensor
🧠 Key insight: Quantized INT8 model ใน 32 KB SRAM, inference <5ms, accuracy >92% สำหรับ anomaly detection ของมอเตอร์และ pump ในโรงงาน
  1. 1เก็บข้อมูล vibration + current signature ของอุปกรณ์ปกติ
  2. 2Train Autoencoder หรือ CNN ด้วย Python, export เป็น .tflite + quantize INT8
  3. 3Deploy ด้วย ESP-DL หรือ TFLM บน ESP32-S3 (512 KB SRAM + 8 MB PSRAM)
  4. 4Inference ทุก 100ms, alert ผ่าน MQTT เมื่อค่า reconstruction error สูงเกิน threshold
