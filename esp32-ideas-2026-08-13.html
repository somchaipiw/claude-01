🎯 ระบบระบุตำแหน่งภายในอาคาร DIY — ESP32 + UWB DWM3000 ความแม่นยำ 10 cm
สร้างระบบ Indoor Positioning System (IPS) แบบ DIY ที่ให้ความแม่นยำ sub-10 cm โดยใช้ ESP32 ร่วมกับ UWB module Qorvo DWM3000 ใช้เทคนิค DS-TWR (Double-Sided Two-Way Ranging) คำนวณระยะทางแล้วใช้ trilateration หาตำแหน่ง 2D
หลักการทำงาน: UWB วัดเวลาที่สัญญาณเดินทาง (Time of Flight) ระหว่าง anchor-tag ด้วยความแม่นยำระดับนาโนวินาที แปลงเป็นระยะทาง แล้ว trilaterate จาก anchor 3 จุด
Components
  1. ESP32 + DWM3000 UWB module × 3 (เป็น anchor ติดผนัง)
  2. ESP32 + DWM3000 × 1 (เป็น mobile tag)
  3. แหล่งจ่ายไฟ 5V สำหรับ anchor และแบต LiPo สำหรับ tag
  4. Server/Raspberry Pi รับ MQTT จาก anchor และคำนวณตำแหน่ง
  5. Dashboard (Node-RED, Grafana, หรือ web app) แสดง floor plan + position
// Arduino skeleton — Anchor node (DWM3000 + ESP32) #include "DW3000.h" #include "WiFi.h" #include "PubSubClient.h" DW3000Class dw3000; void loop() { // รับ ranging request จาก tag if (dw3000.isReceived()) { float dist = dw3000.doTWR(); // cm // ส่งระยะทางผ่าน MQTT mqtt.publish("uwb/anchor/A1", String(dist).c_str()); } }

🚗 ESP32 OBD-II Data Logger — อ่านข้อมูลรถผ่าน CAN Bus แบบ Wireless
ใช้ ESP32 ต่อกับ CAN Bus transceiver (TJA1050 หรือ SN65HVD230) เชื่อมต่อกับ port OBD-II ของรถยนต์ อ่านข้อมูล real-time เช่น RPM, ความเร็ว, อุณหภูมิน้ำหล่อเย็น, การใช้เชื้อเพลิง แล้วส่งผ่าน BLE/WiFi ไปยัง dashboard บนสมาร์ทโฟน
Hardware
MCUESP32 (built-in TWAI)
TransceiverTJA1050 หรือ SN65HVD230
ConnectorOBD-II 16-pin (SAE J1962)
แรงดัน12V → 5V → 3.3V (LDO)
ข้อมูลที่อ่านได้
  • → Engine RPM (PID 0x0C)
  • → ความเร็วรถ (PID 0x0D)
  • → Coolant Temp (PID 0x05)
  • → Engine Load (PID 0x04)
  • → Fuel Trim, MAP, MAF
  • → DTC (รหัสข้อผิดพลาด)
ESP32 TWAI Controller: ESP32 มี TWAI (Two-Wire Automotive Interface) ในตัว ซึ่งรองรับ CAN 2.0A/B protocol โดยตรง ต้องการแค่ transceiver IC ภายนอก 1 ชิ้น ราคาประมาณ 20-30 บาท
// ESP32 Arduino CAN Bus Init #include "driver/twai.h" twai_general_config_t g_config = TWAI_GENERAL_CONFIG_DEFAULT(GPIO_NUM_21, GPIO_NUM_22, TWAI_MODE_NORMAL); twai_timing_config_t t_config = TWAI_TIMING_CONFIG_500KBITS(); // OBD-II ใช้ 500kbps twai_filter_config_t f_config = TWAI_FILTER_CONFIG_ACCEPT_ALL(); // Install and start driver twai_driver_install(&g_config, &t_config, &f_config); twai_start();

📡 ESP-NOW Self-Healing Mesh Network — IoT ไร้ WiFi Router
สร้าง mesh network ที่ไม่ต้องการ WiFi router โดยใช้ ESP-NOW protocol ของ Espressif nodes แต่ละตัวส่งต่อข้อมูล (multi-hop relay) ซ่อมแซมตัวเองอัตโนมัติเมื่อ node ล้มเหลว เหมาะสำหรับฟาร์ม, คลังสินค้า, หรือพื้นที่ขนาดใหญ่ที่ไม่มี infrastructure
ข้อดีของ ESP-NOW vs WiFi Mesh
คุณสมบัติ ESP-NOW WiFi Mesh
Latency < 1 ms 5–50 ms
Power (Rx) ต่ำมาก ปานกลาง
Peer Limit 20 peer/node ไม่จำกัด
Payload 250 bytes/packet ไม่จำกัด
Setup ง่ายมาก ซับซ้อน
Router Required ไม่ต้องการ ต้องการ
Library แนะนำ: painlessMesh — open-source library ที่สร้าง dynamic ESP-NOW mesh โดยอัตโนมัติ nodes หา neighbor กันเอง ส่งข้อมูลแบบ JSON ผ่าน multi-hop รองรับ ESP32 ทุกรุ่นและ ESP8266

🍄 Smart Mushroom Farm — ESP32 + Computer Vision ตรวจโรคอัตโนมัติ
ระบบปลูกเห็ดอัจฉริยะใช้ ESP32 ควบคุมสภาพแวดล้อม (อุณหภูมิ, ความชื้น, CO₂) ร่วมกับ camera module ถ่ายภาพเห็ดสม่ำเสมอแล้วส่ง inference ผ่าน Edge AI ตรวจจับโรคราน้ำค้างและการปนเปื้อนแบคทีเรียได้ก่อนสายตาเปล่า
  1. DHT22/SHT40 วัด temp+humidity → ESP32 ควบคุม humidifier + fan ด้วย PID
  2. MH-Z19B วัด CO₂ → เปิด/ปิด ventilation ให้ CO₂ ต่ำกว่า 1000 ppm
  3. ESP32-CAM ถ่ายภาพทุก 30 นาที ส่งไป ESP32-P4 หรือ server
  4. Edge Impulse model classify: normal / contamination / harvest-ready
  5. แจ้งเตือนผ่าน LINE Notify เมื่อตรวจพบโรคหรือถึงเวลาเก็บเกี่ยว
ROI: เห็ดนางฟ้าที่โรคไม่ทันระบาด ลดการสูญเสียได้ 40-60% ระบบนี้ใช้ ESP32 ราคาต่ำกว่า 500 บาท แต่ช่วยประหยัดค่าเสียหายได้เป็นหมื่น
