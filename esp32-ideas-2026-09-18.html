MAX30102 — PPG Optical Sensor วัด Heart Rate + SpO2 ราคาต่ำ

Maxim MAX30102 เป็น optical pulse oximeter ที่ใช้ LED สีแดง (660nm) และ Infrared (940nm) วัดการดูดซับแสงในเส้นเลือด คำนวณ Heart Rate และ SpO2 ผ่าน I2C interface ได้ทันที เป็น sensor ที่นิยมที่สุดสำหรับ wearable health project

💊 ECG Sensor

AD8232 — Single-Lead ECG Signal Conditioning สำหรับ DIY Cardiac Monitor

Analog Devices AD8232 เป็น IC สำหรับวัดคลื่นไฟฟ้าหัวใจ (ECG) ที่มี instrumentation amplifier, right leg drive, lead-off detection ในชิปเดียว ใช้ขา Leads On/Off ตรวจสอบว่า electrode ยังสัมผัสผิวหนังอยู่ ส่งสัญญาณออกเป็น analog (อ่านด้วย ADC บน ESP32 ได้เลย)

📈 วิธีอ่านสัญญาณ ECG ด้วย ESP32 AD8232 OUTPUT → GPIO34 (ADC1_CH6) ของ ESP32 · ตั้ง sampling rate 500 Hz · ใช้ notch filter 50/60 Hz กรอง noise ไฟฟ้า · แสดงผล waveform ผ่าน Serial Plotter หรือ Web Dashboard

🎥 HDMI Bridge

TC358743 — HDMI-to-MIPI CSI Bridge IC หัวใจของ ESP-KVM

Toshiba TC358743XBG เป็น IC ที่แปลง HDMI signal ให้เป็น MIPI CSI-2 output ทำให้ ESP32-P4 (ซึ่งมี MIPI CSI interface) สามารถรับภาพจากจอคอมพิวเตอร์ผ่าน HDMI ได้โดยตรง นี่คือ chip สำคัญที่ทำให้ ESP-KVM เป็นไปได้

🔧 ใช้ใน Geekworm X630 Board Geekworm X630 เป็น breakout board สำเร็จรูปที่ใส่ TC358743 มาให้แล้ว มี HDMI input + MIPI CSI output connector ตรงพร้อมเชื่อมต่อกับ Waveshare ESP32-P4-ETH ได้ทันที ราคาประมาณ $15

🔧 Tutorial · MAX30102

วัด Heart Rate และ SpO2 ด้วย MAX30102 + ESP32 แบบ Real-time

MAX30102 เป็น I2C device ที่อ่านค่าได้ง่ายด้วย library ของ SparkFun ติดตั้งผ่าน Arduino Library Manager แล้วเชื่อมต่อ VCC→3.3V, GND→GND, SDA→GPIO21, SCL→GPIO22 สำหรับ ESP32 classic

1
ติดตั้ง Library

ใน Arduino IDE ไปที่ Library Manager ค้นหา SparkFun MAX3010x และติดตั้ง

2
เชื่อมต่อวงจร

MAX30102 VIN→3.3V · GND→GND · SDA→GPIO21 · SCL→GPIO22 (ESP32) หรือ SDA→GPIO8, SCL→GPIO9 (ESP32-S3 XIAO)

3
เรียกใช้ Example SpO2

File → Examples → SparkFun MAX3010x → Example8_SPO2 จะแสดง BPM และ SpO2 ใน Serial Monitor

4
ปรับแต่งสำหรับ Wearable

เปิด low-power mode, ตั้ง sample rate 50Hz, เพิ่ม moving average filter เพื่อลด noise จากการเคลื่อนไหว

📄 Sample Code

ส่งข้อมูลผ่าน BLE Notify ไปยัง Phone App

#include <BLEDevice.h> #include <BLEServer.h> #include <MAX30105.h> #include <heartRate.h> // UUID สำหรับ Heart Rate Service (Standard BLE) #define HR_SERVICE_UUID "180D" #define HR_CHAR_UUID "2A37" MAX30105 sensor; BLECharacteristic *pHRChar; void setup() { sensor.begin(Wire, I2C_SPEED_FAST); sensor.setup(60, 4, 2, 400, 411, 4096); BLEDevice::init("ESP32-HealthBand"); BLEServer *pServer = BLEDevice::createServer(); BLEService *pHR = pServer->createService(HR_SERVICE_UUID); pHRChar = pHR->createCharacteristic( HR_CHAR_UUID, BLECharacteristic::PROPERTY_NOTIFY ); pHR->start(); pServer->getAdvertising()->start(); } void loop() { long ir = sensor.getIR(); if (checkForBeat(ir)) { uint8_t bpm = (uint8_t)beatsPerMinute; pHRChar->setValue(&bpm, 1); pHRChar->notify(); } delay(20); }
💡 เคล็ดลับ ใช้ Standard BLE Heart Rate Service UUID (0x180D) ทำให้ app สุขภาพบน iOS/Android อย่าง nRF Connect หรือ Heart Rate Monitor apps อ่านค่าได้ทันทีโดยไม่ต้องเขียน custom app
