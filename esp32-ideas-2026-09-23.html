ESP32-P4

Video Alarm Clock บน ESP32-P4

โปรเจกต์นาฬิกาปลุกที่ตื่นด้วย video แทนเสียงบี๊บ ทำงานบน Waveshare ESP32-P4-WIFI6-Touch-LCD-4B ใช้ชิปที่มี ISP, H.264 encode 1080p@30fps และ 2D graphics accelerator

  • ชิป dual-core RISC-V 400 MHz + 32 MB PSRAM
  • H.264 encoding สูงสุด 1080p@30fps
  • ESP32-C6 module สำหรับ Wi-Fi 6
  • เหมาะกับงาน HMI, media, camera pipeline
Matter 1.5

ESP32-C6/H2 + Matter-over-Thread

Matter 1.5 เพิ่ม device category ใหม่: soil sensors, cameras, closures, smart energy metering และ EV charging ทำให้ ESP32-C6 (Wi-Fi 6 + Thread) เป็นตัวเลือกสำหรับ battery sensor ยุคใหม่

  • ESP32-C6: RISC-V 160 MHz, Wi-Fi 6, BLE 5, Thread/Zigbee
  • ESP32-H2: Thread/Zigbee sleepy-end-device ประหยัดพลังงาน
  • Native OpenThread ใน ESPHome ตั้งแต่ 2025.11
  • Matter 1.5 รองรับ soil sensor endpoint แล้ว
ESP-IDF Edgent

ESP-IDF Edgent — Production IoT Firmware

เปิดตัว March 2026 เป็น production path สำหรับ ESP32 firmware พร้อม BLE provisioning, OTA via Blynk.Air, network manager บันทึก Wi-Fi ได้ 16 เครือข่าย และ secure MQTT

  • BLE-assisted WiFi provisioning
  • FOTA (Firmware OTA) สำหรับ field-deployed devices
  • Network manager: บันทึก 16 SSIDs
  • Secure MQTT เข้ารหัสครบวงจร
ESP32-P4 Vision

ESP-VISION SDK สำหรับ Computer Vision

Espressif ปล่อย ESP-VISION Programming Guide (July 2026) สำหรับ ESP32-P4 โดยเฉพาะ รองรับ camera pipeline, image processing, และ AI inference แบบ end-to-end บน edge

  • Hardware ISP บน ESP32-P4
  • AI inference edge (TFLite/ESP-DL)
  • Camera → ISP → AI → LVGL display pipeline
  • Function-EV-Board: display + camera + audio

Water Quality

Smart Water Quality Monitor

ระบบตรวจสอบคุณภาพน้ำแบบ real-time ส่งข้อมูลผ่าน MQTT ไปยัง Home Assistant หรือ Dashboard

  • pH Sensor (E-201C): ตรวจค่าความเป็นกรด-ด่าง
  • TDS Sensor: วัดปริมาณของแข็งละลายในน้ำ
  • Turbidity Sensor: วัดความขุ่นใสของน้ำ
  • DS18B20: อุณหภูมิน้ำ (Waterproof)
  • ESP32 + MQTT + Node-RED Dashboard
Smart Farm

Soil Moisture → Matter Endpoint

สร้าง Matter 1.5 soil sensor node โดยใช้ ESP32-H2 (Thread radio) วัดความชื้นดิน แล้ว integrate เข้า Apple Home / Google Home / Home Assistant โดยตรง

  • Capacitive Soil Moisture Sensor v2
  • ESP32-H2 deep sleep < 10 µA
  • Matter Soil Moisture Endpoint (Matter 1.5)
  • Battery CR2032 อยู่ได้ 6–12 เดือน
  • Auto water pump control via Matter automation
Biometric

Portable ECG Monitor ด้วย AD8232

วัดคลื่นไฟฟ้าหัวใจ (ECG) ด้วย AD8232 sensor + ESP32 ส่งข้อมูลผ่าน BLE ไปยัง smartphone แบบ real-time เหมาะสำหรับ health monitoring prototype

  • AD8232: Single-lead ECG front-end
  • 3 electrodes: RA, LA, RL (right leg)
  • ESP32 ADC 12-bit sampling 1 kHz
  • BLE streaming ไปยัง app (Web BLE)
  • เก็บ waveform ใน SPIFFS/SD card
Air Quality

Multi-Gas Air Quality Station

สถานีตรวจคุณภาพอากาศหลาย parameter ด้วย ESP32 + sensors หลายตัว ส่งข้อมูลไปยัง MQTT Broker แล้ว visualize บน Grafana

  • MQ-2: แก๊ส LPG, methane, smoke
  • MQ-9: CO (Carbon Monoxide)
  • SFA40 (ESPHome component ใหม่): Formaldehyde
  • PM2.5 / PM10: ฝุ่นละออง
  • Stack: ESP32 → MQTT → InfluxDB → Grafana
Energy

Smart Energy Monitor ด้วย PZEM-004T

  • PZEM-004T v3: Voltage, Current, Power, Energy
  • ESP32 + ESP-IDF Edgent (OTA-ready)
  • Matter Energy Device Profile
  • Blynk.Air FOTA สำหรับ field update
  • แสดงผลบน OLED 1.3" + Blynk Dashboard

Arduino/ESP-IDF

Water Quality Sensor พื้นฐาน

อ่านค่า TDS และ pH พร้อมส่ง MQTT ด้วย ESP32:

#include <WiFi.h> #include <PubSubClient.h> #define TDS_PIN 34 #define PH_PIN 35 float readTDS() { int raw = analogRead(TDS_PIN); float voltage = raw * 3.3 / 4095.0; // Compensation formula return (133.42 * pow(voltage, 3) - 255.86 * pow(voltage, 2) + 857.39 * voltage) * 0.5; } void loop() { float tds = readTDS(); char msg[64]; snprintf(msg, sizeof(msg), "{\"tds\":%.1f}", tds); client.publish("water/quality", msg); delay(15000); }
Matter / Thread

ESP32-H2 Soil Sensor (Matter 1.5)

โครงสร้าง firmware สำหรับ battery-powered Matter soil sensor:

// esp-matter example sketch #include <esp_matter.h> #include <app/clusters/soil-moisture/ soil-moisture-cluster.h> // Endpoint ID สำหรับ soil sensor uint16_t soil_endpoint_id = 0; void app_main() { // Initialize Matter stack esp_matter::start(); // Create soil moisture endpoint // (Matter 1.5 device type 0x0307) soil_endpoint_id = esp_matter_soil_moisture_create( node, &config); // Deep sleep 5 min between readings esp_sleep_enable_timer_wakeup( 5 * 60 * 1000000ULL); esp_deep_sleep_start(); }
