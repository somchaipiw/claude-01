ใหม่ มีนาคม 2026 ESP32-H21

ESP32-H21 — ชิปพลังงานต่ำสุดจาก Espressif สำหรับ Matter/Thread/Zigbee

Espressif ประกาศ ESP32-H21 อย่างเป็นทางการเมื่อวันที่ 3 มีนาคม 2026 โดยเป็นการวิวัฒนาการจาก ESP32-H2 เพิ่ม DC-DC Converter ออนชิปเพื่อลดการใช้พลังงานขณะ Active ให้เหลือเพียง 8.2 mA เท่านั้น

พารามิเตอร์ค่าหมายเหตุ
CPURISC-V 32-bit, 96 MHzประมวลผลเร็วพอสำหรับ IoT Tasks
RAM320 KB SRAMรุ่น MINI-1
Flash4 MBรุ่น MINI-1
วิทยุIEEE 802.15.4 + BLE 5ไม่มี Wi-Fi
TX Powerสูงสุด 20 dBmสัญญาณแรงสำหรับ Mesh
Active Current (RX)~8.2 mAพร้อม DC-DC enabled
Light Sleep~9 µAต่ำมากสำหรับ Coin Cell
Deep Sleep~5 µAแบตเตอรี่อยู่ได้หลายปี
SDKESP-IDF 6.0 (Preview)รองรับแล้วตั้งแต่ v6.0

💡 เหมาะสำหรับ: Smart Home Sensor Node (Matter over Thread), Zigbee Remote Switch, BLE Asset Tag — ทุกอุปกรณ์ที่ต้องการอายุแบตเตอรี่นานเป็นปีโดยไม่ต้องชาร์จ

ใหม่ มีนาคม 2026 Breaking Change

ESP-IDF 6.0 — อัปเดตใหญ่ที่สุดในรอบหลายปีของนักพัฒนา ESP32

Espressif ปล่อย ESP-IDF 6.0 ในเดือนมีนาคม 2026 พร้อมการเปลี่ยนแปลงสำคัญที่ส่งผลต่อทุกโปรเจกต์ที่ใช้ framework นี้:

  • 🔁 Picolibc แทน Newlib — C Library ตัวใหม่ทำให้ Binary ขนาดเล็กลง, RAM ใช้น้อยลง
  • 🔐 Mbed TLS 4.x + PSA Crypto API — API เดิม mbedtls_* ต้องแก้ไขให้เป็น PSA
  • ⚠️ Legacy Driver ถูกลบ — ADC, DAC, I2S Driver รุ่นเก่าถูกนำออก ต้องใช้ Driver ใหม่
  • 🛠️ Build System v2 (CMake Preview) — สถาปัตยกรรมใหม่ที่ backward compatible กับ v1
  • 🤖 Built-in MCP Server — ใช้กับ AI Coding Assistant ได้โดยตรงจาก IDE
  • 📶 Wi-Fi Aware USD + WPA3 Compatible Mode — รองรับ Client ทั้ง WPA2/WPA3 พร้อมกัน
  • 🆕 Chip ใหม่ที่รองรับ: ESP32-C5 & C61 (เต็มรูปแบบ), ESP32-H21 & H4 (Preview)

⚠️ Migration Guide จำเป็นมาก: ก่อน Upgrade จาก v5.x ควรอ่าน Official Migration Guide เพราะ Compiler Warnings ถูกตั้งเป็น Error by Default ซึ่งอาจทำให้ Build ล้มเหลวโดยไม่คาดคิด

Trending 2026 TinyML

ESP32 Predictive Maintenance — ตรวจจับความผิดปกติของเครื่องจักรด้วย FFT + ML

งานวิจัยปี 2025–2026 แสดงให้เห็นว่า ESP32 สามารถทำ Predictive Maintenance ได้จริงในระดับอุตสาหกรรม โดยผสาน MEMS Accelerometer กับ FFT Analysis บนตัวชิปเอง:

  • ติด MEMS Accelerometer (MPU6050 หรือ ADXL345) บนตัวเครื่องจักร
  • Sample ข้อมูล Vibration ที่ความถี่ 1–100 kHz ขึ้นอยู่กับประเภทเครื่อง
  • ใช้ ESP-DSP Library คำนวณ FFT บน ESP32-S3 (รัน Core 1 สำหรับ DSP, Core 0 สำหรับ WiFi/MQTT)
  • เปรียบเทียบ Frequency Spectrum กับ Baseline ปกติ หรือ Deploy ML Model
  • ส่ง Alert ผ่าน MQTT เมื่อ Anomaly Score เกิน Threshold

📊 ผลการทดสอบจริง: ระบบที่ใช้ ESP32 + MEMS Accelerometer + Microphone ตรวจจับ Imbalance และ Wear Fault ได้ความแม่นยำ ~73% — ถือว่าดีมากสำหรับ Hardware ราคาต่ำกว่า 300 บาท

Edge AI ESP32-S3

ESP-AFE + MEMS Microphone — Offline Voice Command บน ESP32-S3

Espressif เปิดตัว ESP AFE (Audio Front-End) ที่ใช้ประโยชน์จากคำสั่ง AI/DSP ของ ESP32-S3 โดยเฉพาะ ทำให้ระบบสั่งงานด้วยเสียงทำงานได้โดยไม่ต้องใช้ Internet:

🎤 Pipeline

I2S Capture → Ring Buffer → Feature Extraction → Model Inference → Command Output

🔊 Hardware ที่เหมาะสม

ESP32-S3 + SPH0645LM4H-B (I2S MEMS Mic) หรือ INMP441 — Interface เดี่ยวเชื่อมต่อง่าย

🎯 Use Case: Smart Home Voice Switch โดยไม่ต้องพึ่ง Cloud, เครื่องมือในโรงงานที่สั่งงานด้วยเสียง, Accessibility Device สำหรับผู้ที่ใช้มือไม่ได้

Industry 4.0

ESP32-S3 Motor Health Monitor — ตรวจจับ Bearing Fault ด้วย Dual-Core + ESP-DSP

โปรเจกต์ตรวจสุขภาพมอเตอร์แบบ Non-Intrusive ราคาประหยัด ใช้แนวคิดจากงานวิจัยโปรตุเกส 2025 มาปรับใช้จริง:

// Core 1: Data Acquisition (ไม่ถูกขัดจังหวะโดย WiFi) void IRAM_ATTR task_dsp(void *param) { while(1) { sample_accelerometer_100Hz(buf, FFT_SIZE); dsps_fft2r_fc32(buf, FFT_SIZE); // ESP-DSP FFT float rms = compute_rms(buf); float peak_freq = find_peak(buf); xQueueSend(result_queue, &rms, 0); // ส่งไปให้ Core 0 } } // Core 0: MQTT Publish (WiFi safe) void task_mqtt(void *param) { float rms; while(1) { xQueueReceive(result_queue, &rms, portMAX_DELAY); if(rms > ANOMALY_THRESHOLD) mqtt_publish("factory/motor1/alert", ...); } }

Hardware: ESP32-S3 DevKitC + MPU6050 (I2C) + DS18B20 (วัดอุณหภูมิ Bearing) + Li-Ion + Solar Cell

Smart Home ESP32-H21

ESP32-H21 Thread Border Router Node — ขยาย Matter Mesh ในบ้านด้วยต้นทุนต่ำ

ใช้ ESP32-H21 ร่วมกับ ESP32-C6 สร้าง Thread Network ครอบคลุมทั้งบ้าน โดยที่ ESP32-C6 ทำหน้าที่ Border Router (มี Wi-Fi) และ ESP32-H21 เป็น End Device ประหยัดพลังงาน:

🌐 Border Router (ESP32-C6)

Wi-Fi 6 + Thread — เชื่อม Matter Network กับ Internet, ต้องต่อไฟถาวร

🔋 End Device (ESP32-H21)

Thread Only — Sensor Node ใช้แบตเตอรี่ AA 2 ก้อน ตื่นทุก 60 วินาที อยู่ได้ >3 ปี

💰 ต้นทุนโดยประมาณ: ESP32-H21 Module ~$2.5, ESP32-C6 Board ~$5 — สร้าง Smart Home Network ทั้งบ้านงบไม่ถึง 500 บาทต่อห้อง

Edge AI

ESP32-S3 Offline Voice Assistant สำหรับผู้สูงอายุ — ควบคุมบ้านด้วยเสียงไทย

ใช้ ESP-AFE + Wake Word Detection ทำ Voice Interface ภาษาไทยอย่างง่ายโดยไม่ต้องพึ่ง Cloud เหมาะสำหรับผู้สูงอายุที่ใช้ Smartphone ไม่คล่อง:

  • Wake Word: "เฮ้ ESP" หรือ "สวัสดี" — ตรวจจับด้วย Keyword Spotter บนชิป
  • Command Recognition: "เปิดไฟ", "ปิดแอร์", "โทรหาลูก" — 10–20 คำสั่ง
  • Execute: สั่ง Relay, ส่ง ESP-NOW, หรือ HTTP Request ไปยัง Home Assistant
  • Feedback: Text-to-Speech กลับทาง Speaker (I2S DAC + MAX98357)

Library ที่แนะนำ: esp-sr (Espressif Speech Recognition) + esp-tts

ESP32-S3

Smart Pump Guard — ระบบเฝ้าระวังปั๊มน้ำเกษตร ป้องกันปั๊มแห้งและ Bearing เสีย

โปรเจกต์ IoT สำหรับเกษตรกรไทย ตรวจสอบสภาพปั๊มน้ำแบบ Non-Intrusive ราคาต่ำกว่า 800 บาท:

📊 Sensors ที่ใช้

MPU6050 (Vibration) + DS18B20 (Temp) + CT Sensor (Current Draw) + Pressure Transducer (4–20mA)

🚨 Alarm Logic

Vibration RMS สูง → Bearing เสีย; กระแสลด → ปั๊มแห้ง; Temp สูง → ผิดปกติ

ส่ง Alert ผ่าน LINE Notify + Dashboard บน Grafana + InfluxDB บน Raspberry Pi

MPU6050 — 6-Axis IMU สำหรับ Vibration & Motion Analysis

Sensor วิเคราะห์การสั่นสะเทือนยอดนิยมที่สุด ราคา ~35 บาท/ชิ้น ทำงานร่วมกับ ESP32 ผ่าน I2C ได้เลยโดยไม่ต้องใช้ Library พิเศษ:

คุณสมบัติรายละเอียด
Axes3-Axis Gyro + 3-Axis Accelerometer
InterfaceI2C (400 kHz) / SPI
Accel Range±2g / ±4g / ±8g / ±16g
Gyro Range±250 / ±500 / ±1000 / ±2000 °/s
Sample Rateสูงสุด 1 kHz (DLPF Off)
Built-in DMPรองรับ — ประมวล Quaternion บนชิป
ราคา~35–60 บาท (Module พร้อม Level Shifter)

⚙️ Tip การใช้งาน: สำหรับ Vibration Analysis ควรปิด DLPF (Digital Low Pass Filter) เพื่อให้ได้ Sample Rate สูงสุด และ Mount PCB ให้แน่นสนิทกับ Housing เครื่องจักรโดยตรง

ไมโครโฟน MEMS Digital แบบ I2S ที่ใช้งานกับ ESP32 ได้ง่ายที่สุด ไม่ต้องใช้ ADC เพราะส่งข้อมูล Digital โดยตรง:

คุณสมบัติรายละเอียด
InterfaceI2S Standard (WS, SCK, SD)

SNR61 dBA (เสียงชัดเจน)

ADXL355 — Low-Noise Accelerometer สำหรับ High-Precision Vibration

สำหรับงาน Predictive Maintenance ที่ต้องการความละเอียดสูงกว่า MPU6050 ADXL355 จาก Analog Devices ให้ Noise Level ต่ำกว่ามากและเหมาะสำหรับ Industrial Use:

✅ ข้อดี

Noise: 25 µg/√Hz (เทียบ MPU6050: ~400 µg/√Hz), SPI Interface, ODR สูงสุด 4 kHz, ไม่มี Gyro (ลด Noise Cross-Talk)

⚠️ ข้อด้อย

ราคา ~$8–12/ชิ้น (แพงกว่า MPU6050 มาก), ต้องใช้ SPI ไม่มี I2C, เกินความต้องการสำหรับงาน DIY ทั่วไป
