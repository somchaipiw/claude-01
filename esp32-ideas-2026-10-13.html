ESP32-P4X-EYE — Vision Kit ครบครันพร้อม C6 Wireless

Espressif เปิดตัว development board ล่าสุดที่รวม ESP32-P4 (400 MHz dual-core) เข้ากับ ESP32-C6 ชิปไร้สาย บน PCB ขนาดกะทัดรัด เริ่มวางจำหน่ายทั่วโลกผ่าน Mouser Electronics ตั้งแต่ 17 สิงหาคม 2026

  • กล้อง MIPI-CSI 2MP สำหรับ machine vision และ edge AI inference
  • จอ SPI LCD ขนาด 1.54 นิ้วสำหรับแสดงผล real-time
  • ไมโครโฟนดิจิทัล + MicroSD slot สำหรับบันทึกข้อมูล
  • USB 2.0 High-Speed + 2×10 GPIO expansion header
  • ขั้วต่อแบตเตอรี่ LiPo เหมาะทำ portable vision device
ใช้งานได้: Smart surveillance, object detection, pose estimation, edge HMI
มกราคม 2026

ESP-SensairShuttle — ESP32-C5 + Bosch Sensortec Modular Kit

บอร์ดทดลองร่วมระหว่าง Espressif และ Bosch Sensortec ใช้ชิป ESP32-C5-WROOM-1-N16R8 ที่รองรับ dual-band Wi-Fi 6, Bluetooth 5 LE, Zigbee และ Thread ในตัวเดียว

  • Sensor Module แบบ plug-in เปลี่ยนได้โดยไม่ต้องออกแบบ PCB ใหม่
  • Environmental Module: BME690 (temp/humidity/pressure/VOC/CO₂eq)
  • Motion Module: BMI270 IMU + BMM350 Digital Compass
  • จอสัมผัสขนาด 1.83 นิ้ว + ลำโพง + ไมโครโฟน
  • รันด้วย USB หรือ LiPo battery, ราคาประมาณ $49.40
Wi-Fi 6 Dual-Band Thread/Zigbee Modular Sensor
สิงหาคม 2026

ESP DALI Component — ควบคุมระบบไฟ IEC 62386 ด้วย ESP32

Espressif เปิดตัว DALI (Digital Addressable Lighting Interface) component ใหม่ใน ESP-IoT-Solution ที่ implement IEC 62386 master controller บน RMT peripheral ของ ESP32

  • รองรับ commissioning, dimming, color control (DT8) ตามมาตรฐาน
  • เชื่อมต่อ sensor node ผ่าน DALI bus โดยตรง
  • บริดจ์ระหว่าง Matter 1.x กับ DALI device (Matter-to-DALI bridge)
  • ทำงานบน ESP32 ทุกรุ่นที่มี RMT peripheral
ประยุกต์ใช้: Smart building lighting control, office automation, ไฟถนนอัจฉริยะ
มีนาคม 2026

ESP32 กับ EU Cyber Resilience Act (CRA) — ข้อกำหนดใหม่ที่ต้องรู้

Espressif ออกเอกสารแนวทาง CRA compliance สำหรับนักพัฒนา หลังสหภาพยุโรปกำหนด Cyber Resilience Act ใช้บังคับกับผลิตภัณฑ์ IoT ทุกชิ้นที่จำหน่ายในตลาด EU

  • ข้อกำหนดด้าน cybersecurity ครอบคลุม ESP32 firmware, companion app และ cloud service
  • การรายงานช่องโหว่ด้านความปลอดภัยบังคับตั้งแต่กันยายน 2026
  • ข้อกำหนดหลักเริ่มบังคับใช้ธันวาคม 2027
  • ESP-IDF มี Secure Boot, Flash Encryption และ NVS Encryption รองรับ CRA
  • Espressif จัดทำเอกสาร SBOM (Software Bill of Materials) สำหรับชิปทุกรุ่น
2025–2026

ESP32-P4-Pi-VIEWE — บอร์ด Raspberry Pi Form Factor ราคาประหยัด

VIEWE ออกแบบ development board ที่ใช้ ESP32-P4 + ESP32-C6 แต่มี pinout เข้ากันได้กับ Raspberry Pi รองรับ Ethernet และ MIPI display/camera เหมาะทำ embedded display controller

  • ESP32-P4 (400 MHz) + ESP32-C6 (Wi-Fi 6 + BLE 5)
  • 10/100 Mbps Ethernet onboard + USB 2.0
  • MIPI DSI (display) + MIPI CSI (camera) connector
  • 40-pin GPIO header ทับ Raspberry Pi HAT
  • Dual microphone สำหรับ voice command
Raspberry Pi HAT MIPI DSI/CSI Ethernet

ESP32-P4X-EYE

Smart Warehouse Vision Counter — นับสินค้าอัตโนมัติด้วย Edge AI

ใช้ ESP32-P4X-EYE ติดตั้งที่สายพานหรือประตูโกดัง ให้ ESP-DL ตรวจจับและนับวัตถุ real-time แล้วส่งข้อมูลผ่าน ESP32-C6 ไปยัง MQTT broker โดยไม่ต้องพึ่ง cloud inference

  • MobileNetV2 หรือ YOLO-nano บน ESP32-P4 400 MHz
  • บันทึกภาพเหตุการณ์ผิดปกติลง MicroSD card อัตโนมัติ
  • แสดงจำนวน real-time บน LCD 1.54 นิ้วในตัวบอร์ด
  • เชื่อมต่อ Grafana dashboard ผ่าน MQTT + InfluxDB
ต้นทุนประมาณ: ESP32-P4X-EYE $45 + housing $5 รวมไม่ถึง $50
ESP-SensairShuttle

Indoor Environment Dashboard — ระบบตรวจสอบสภาพแวดล้อมสำนักงาน

ใช้ ESP-SensairShuttle + Environmental Module (BME690) ติดตั้งแต่ละห้องในสำนักงาน ส่งข้อมูลผ่าน Thread/Zigbee mesh มาที่ Border Router ESP32-H2 แล้วแสดงบน Home Assistant

  • วัด CO₂eq, VOC, อุณหภูมิ, ความชื้น, ความดัน ต่อเนื่อง
  • ระบบแจ้งเตือนเมื่อ CO₂eq เกิน 1000 ppm (ห้องอากาศถ่ายเทไม่ดี)
  • Motion Module ตรวจจับผู้ใช้งานห้อง ปิดระบบอัตโนมัติเมื่อไม่มีคน
  • Zigbee OTA update ผ่าน air ไม่ต้องถอดบอร์ด
ESP DALI

Matter-DALI Smart Office Lighting — ไฟ DALI ควบคุมด้วย iPhone/Android

สร้าง Matter-to-DALI gateway ด้วย ESP32-C6 + ESP DALI component เพื่อเชื่อม DALI ballast ที่ติดตั้งในอาคารกับ Apple Home / Google Home ให้ผู้ใช้สั่งงานด้วยเสียงหรือ app ได้ทันที

  • ESP32-C6 ทำหน้าที่เป็น Matter Commissioner + DALI Master
  • รองรับ Group Control (สั่งทุกหลอดในห้องพร้อมกัน)
  • Scene & Schedule ตั้งเวลาปิด/เปิด/หรี่อัตโนมัติ
  • รองรับ DALI ballast ที่มีอยู่แล้ว ไม่ต้องเปลี่ยนหลอด
ต้นทุน: ESP32-C6 DevKit ($5) + DALI interface circuit ($3) = ประหยัดกว่า bridge สำเร็จรูปมาก
CRA Compliant

CRA-Ready ESP32 OTA Update System — ระบบอัปเดต Firmware ปลอดภัย

สร้างระบบ Over-The-Air update ที่เป็นไปตาม EU CRA โดยใช้ Secure Boot V2 + Flash Encryption + signed firmware พร้อม rollback protection สำหรับผู้ผลิตอุปกรณ์ IoT ที่จะส่งออกยุโรป

  • Secure Boot V2 ป้องกัน firmware ปลอมบน ESP32-S3/C6/H2
  • HTTPS OTA ด้วย certificate pinning + mutual TLS
  • Signed firmware verification ก่อน flash ทุกครั้ง
  • Automatic rollback เมื่อ firmware ใหม่บูตไม่ติด
  • Vulnerability disclosure endpoint ตาม CRA Article 13
AirGradient

Open-Source Air Quality Monitor ด้วย ESP32-C3 + AirGradient Library

สร้างเครื่องวัดคุณภาพอากาศ open-hardware โดยใช้ AirGradient library เวอร์ชัน 3.6.5 (2026) กับ ESP32-C3 + sensor suite ครบ ส่งข้อมูลขึ้น platform หรือ Home Assistant ได้

  • Plantower PMS5003 — วัด PM1/PM2.5/PM10 particle count
  • SenseAir S8 — CO₂ NDIR sensor แม่นยำสูง
  • Sensirion SGP41 + SHT40 — VOC index + อุณหภูมิ/ความชื้น
  • เชื่อมต่อ AirGradient cloud หรือ local MQTT/HTTP ได้
  • Open PCB design บน GitHub พร้อม BOM ราคาถูก

ช่วงวัด±2000 µT ทุกแกน (X/Y/Z)

SGP41 — MOX VOC + NOx Sensor สำหรับ Indoor Air Quality

วัดได้VOC Index (1–500) และ NOx Index (1–500)

Sampling1 Hz recommended (continuous mode)
