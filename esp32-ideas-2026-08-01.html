ESP32-E22 — ชิป Tri-Band Wi-Fi 6E ตัวแรกของ Espressif

เปิดตัวที่ CES 2026 (มกราคม 2569) และได้รับ Wi-Fi CERTIFIED 6E™ เดือนมิถุนายน 2569 เป็นชิป Radio Co-Processor (RCP) ตัวแรกของ Espressif ที่รองรับ Wi-Fi บนสามย่านความถี่พร้อมกัน ออกแบบมาให้เป็น "ตัวช่วยด้านไวร์เลส" สำหรับ host processor (Linux/RTOS) ผ่านอินเทอร์เฟซความเร็วสูง

SpecESP32-E22
CoreDual-core RISC-V @ 500 MHz
RAM1 MB on-chip SRAM
Wi-Fi6E Tri-Band (2.4 / 5 / 6 GHz), 160 MHz BW, 2×2 MU-MIMO
Throughputสูงสุด ~2.1 Gbps (iperf)
BluetoothBT Classic (BR/EDR) + BLE 5.4
InterfacePCIe 2.1 / SDIO 3.0 / USB 2.0
ArchitectureRCP — ต้องใช้คู่กับ host MCU/SBC
เหมาะสำหรับ: Smart Home Hub, AR/VR accessories, กล้อง 4K/8K ไร้สาย, Industrial Wi-Fi bridge, Multimedia gateway

ESP32-H21 — Ultra-Low-Power 5 µA สำหรับ Mesh IoT

เปิดตัวพร้อมกับ E22 ที่ CES 2026 ออกแบบเน้น ประหยัดพลังงานสูงสุด มีออนชิป DC-DC converter และ deep sleep ที่ดึงเพียง 5 µA เหมาะกับเซ็นเซอร์แบตเตอรี่อายุยาว, wearables, และ sensor node ใน Zigbee/Thread mesh

SpecESP32-H21
CoreSingle-core RISC-V @ 96 MHz
RAM320 KB SRAM
WirelessBLE 5.0 + IEEE 802.15.4 (Zigbee/Thread/Matter)
TX Power20 dBm (สูงกว่า H2 เดิม)
Deep Sleep5 µA (มีออนชิป DC-DC)
SDKESP-Matter-SDK, ESP-BLE-MESH compatible
ไม่มีWi-Fi (ใช้เฉพาะ BLE + 802.15.4)
เหมาะสำหรับ: Battery-powered sensor node, Smart home end device (Matter over Thread), Presence sensor, Wearable health tracker

ESP32-S31 — RISC-V Dual-Core รองรับ Wi-Fi 6 + BT 5.4 + Ethernet ในตัว

ประกาศเดือนมีนาคม 2569 เป็น ตัวต่อจาก S3 ที่เปลี่ยนมาใช้ RISC-V และเพิ่มความสามารถสำคัญหลายอย่างไว้ในชิปเดียว — โดยเฉพาะ Gigabit Ethernet ในตัว พร้อม AI acceleration ผ่าน 128-bit SIMD data path

การเชื่อมต่อ

Wi-Fi 6 + BT 5.4 (LE + Classic) + 802.15.4 + Gigabit Ethernet — ครบในชิปเดียว

ประมวลผล

Dual-core RISC-V @ 320 MHz, 128-bit SIMD สำหรับ AI inference ขั้นพื้นฐาน

HMI

DVP Camera, 24-bit Parallel LCD, 14× Touch sensors, JPEG Codec ในตัว

Security

Trusted Execution Environment (TEE), APM, RAM-based PUF สำหรับ secure key storage

60 GPIOs — ยืดหยุ่นสูงสุดในซีรีส์ S | spec เต็มคาดเปิดเผยปลายปี 2569

Matter 1.5.1 เพิ่ม Camera Support — ESP32 รองรับด้วย ESP-IDF 6.x

Matter 1.5.1 released 31 มีนาคม 2569 เป็น maintenance update ที่เน้น camera device support เต็มรูปแบบ ทำให้กล้อง IP ที่ใช้ ESP32-S3 หรือ ESP32-P4 สามารถเชื่อมต่อกับ Apple Home, Google Home, Amazon Alexa ได้โดยตรงผ่าน Matter โดยไม่ต้องมี proprietary hub

Light Sensor

TSL237 — Light-to-Frequency Converter

Sensor ที่เปลี่ยนความเข้มแสงเป็น สัญญาณ frequency แทนแรงดันไฟฟ้า ทำให้วัดได้แม่นยำสูงในสภาพแสงน้อย เหมาะมากสำหรับ sky brightness และ dark sky monitoring

InterfaceDigital (Frequency out)
Range1 Hz – 800 kHz
Irradiance0 – 1 mW/cm²
Sensitivity2.3 kHz / (µW/cm²)
ราคาประมาณ~150 บาท
Water Sensor

SEN0189 — Turbidity Sensor (DFRobot)

Sensor วัดความขุ่นของน้ำด้วย optical emitter-detector คู่ ส่งสัญญาณ analog voltage หรือ digital (NTU threshold) ใช้ร่วมกับ ESP32 ADC ได้ทันที เหมาะสำหรับ ระบบกรองน้ำ บ่อเลี้ยงปลา ไฮโดรโปนิกส์

OutputAnalog 0–4.5V / Digital
Range0–3000 NTU
Voltage5V DC
Response< 500 ms
ราคาประมาณ~350 บาท
Ambient Light

BH1750 — Digital Ambient Light Sensor (I2C)

Sensor วัดแสงดิจิทัลที่ดีที่สุดสำหรับ ESP32 projects เพราะส่งค่า Lux โดยตรงผ่าน I2C ไม่ต้องแปลง ADC เอง resolution สูง และไม่ sensitive กับ IR radiation ทำให้ได้ค่า visible light ที่แม่นยำ

InterfaceI2C (400 kHz)
Range1 – 65535 lux
Resolution1 lux (high res mode)
Voltage2.4V – 3.6V
ราคาประมาณ~80–120 บาท
Air Quality

PMS5003 — Laser PM2.5 / PM10 Particle Sensor

Sensor วัดฝุ่นละอองด้วย Laser Scattering ที่ใช้มากที่สุดในงาน air quality monitor ด้วย ESP32 วัดทั้ง PM1.0, PM2.5, PM10 พร้อมส่งข้อมูลดิจิทัลผ่าน UART ค่าหน่วยเป็น µg/m³ ตามมาตรฐาน WHO

InterfaceUART (9600 baud)
วัดได้PM1.0 / PM2.5 / PM10
Range0.3 – 1.0 µm (particle)
Accuracy±10 µg/m³ ถึง ±15%
ราคาประมาณ~450–600 บาท
