ESP32-H21 NEW

ESP32-H21 — Thread/Zigbee ประหยัดไฟสุดขีด พร้อม DC-DC ในตัว

Espressif ประกาศ ESP32-H21 ในเดือนมีนาคม 2026 เป็น H2 รุ่นอัพเกรดที่เพิ่ม DC-DC Buck Converter ไว้ในตัวชิป ลดการใช้กระแสในโหมด Active ลงได้มาก เหมาะกับ sensor node ที่ใช้ถ่านอย่างยิ่ง

  • DC-DC converter ในตัว — ลด active current อย่างมีนัยสำคัญ
  • รองรับ IEEE 802.15.4 (Thread + Zigbee 3.0) เหมือน H2 เดิม
  • ไม่มี Wi-Fi — เหมาะจับคู่กับ ESP32-C6 เป็น Border Router
  • เหมาะ: sensor node ถ่านอายุ 2–3 ปี บน Matter over Thread

ESP32-S3

ESP32-S3 ยังคงเป็น King of Edge AI ในปี 2026

แม้ P4 จะแรงกว่า แต่ S3 ยังเป็นตัวเลือกหลักสำหรับ TinyML เพราะ ecosystem ครบ ราคาถูก และ Arduino/MicroPython support ดีกว่ามาก

  • TFLite Micro (LiteRT) ทำงานได้ดีบน 240 MHz dual-core
  • PSRAM 8MB ภายนอกรองรับโมเดลขนาดใหญ่ขึ้น
  • ESP-DL framework จาก Espressif รองรับ quantized model
  • Edge Impulse ออก SDK ที่ optimize สำหรับ S3 โดยเฉพาะ

โปรเจกต์ open-source ESP-KVM ใช้ ESP32-P4 กับบอร์ด Waveshare เพื่อสร้าง IP KVM (Keyboard/Video/Mouse over Network) ราคาถูก ควบคุมคอมพิวเตอร์ผ่าน browser ได้จากทุกที่ — เป็นทางเลือกสำหรับ Raspberry Pi KVM ในราคาที่ต่ำกว่ามาก

ESP32-P4 Project

ESP-KVM — IP KVM แบบ Open Source ราคาประหยัด

ควบคุมเซิร์ฟเวอร์หรือ Raspberry Pi ผ่าน browser โดยไม่ต้องต่อ monitor/keyboard/mouse โดยตรง โปรเจกต์นี้ fork มาแก้ให้รองรับ H.264 และ MJPEG บน P4 v3.x

  • Video capture ผ่าน HDMI-to-CSI converter + MIPI interface
  • Keyboard & Mouse emulation ผ่าน USB HID
  • Web interface พร้อม live stream ผ่าน WebRTC/MJPEG
  • เหมาะ: Homelab, server headless, remote access

Edge AI

Anomaly Detection ด้วย Autoencoder — Predictive Maintenance ต้นทุนต่ำ

แทนการ classify fault แบบ supervised learning ใช้ autoencoder เรียนรู้จากข้อมูลปกติอย่างเดียว แล้วแจ้งเตือนเมื่อ reconstruction error สูงผิดปกติ ไม่ต้องมีตัวอย่างความผิดปกติ

  • Train บน vibration/current sensor data ของเครื่องจักรปกติ
  • Autoencoder เล็ก (encoder 3 layers, bottleneck 8 nodes)
  • RAM <300KB, Flash <1.2MB — ใส่ ESP32-S3 ได้สบาย
  • แจ้งเตือนผ่าน MQTT เมื่อ anomaly score เกิน threshold
  • ไม่ต้องพึ่ง cloud: inference ทำบนชิปทั้งหมด

HDC2080 — Temperature & Humidity แม่นยำ ประหยัดไฟ

TI HDC2080 เพิ่งถูกเพิ่มเข้า ESPHome 2026.4.0 เป็น sensor อุณหภูมิและความชื้นที่มี interrupt output ในตัว ไม่ต้อง polling ตลอดเวลา

  • ความแม่นยำ: ±0.2°C, ±2% RH
  • Supply 1.62–3.6V — เหมาะมากกับ battery node
  • I2C interface, มี DRDY interrupt pin
  • ราคา: ~25–40 บาท ที่ AliExpress
  • เปรียบเทียบ: ดีกว่า SHT20 แต่ถูกกว่า SHT41
I2C ESPHome 1.62V
SENSOR

LD2410C — 24 GHz mmWave ราคาประหยัด

เซ็นเซอร์ radar 24 GHz จาก Hi-Link ที่ได้รับความนิยมสูงมากในปี 2026 ตรวจจับได้แม้คนนิ่งอยู่ (ผ่านการตรวจการหายใจ) แตกต่างจาก PIR ที่ต้องการการเคลื่อนไหว

  • ระยะตรวจจับ: 0–6 เมตร (adjustable gate by gate)
  • UART interface, มี Bluetooth config app
  • ตรวจจับ stationary human — breathing/micro-movement
  • ราคา: ~80–150 บาท, module พร้อมใช้
  • ESPHome support ผ่าน ld2410 component
24GHz UART ESPHome Presence
SENSOR

ICM-42688-P — IMU 6-Axis สำหรับ Industrial TinyML

InvenSense ICM-42688-P เป็น 6-axis IMU (Accel+Gyro) ที่มี noise floor ต่ำมาก เหมาะสำหรับ vibration analysis และ gesture recognition บน ESP32-S3

  • Accel noise: 70 μg/√Hz, Gyro noise: 2.8 mdps/√Hz
  • ความถี่ sample: สูงสุด 32 kHz (Accel), 8 kHz (Gyro)
  • SPI/I2C interface, มี FIFO 2KB ในตัว
  • เหมาะ: bearing fault detection, predictive maintenance
  • ทำงานร่วมกับ ESP32-S3 SPI ที่ 10 MHz
6-Axis IMU SPI Vibration FIFO
SENSOR

ENS160 — Multi-Gas Digital VOC + eCO2 Sensor

ScioSense ENS160 เป็น sensor คุณภาพอากาศรุ่นใหม่ที่ใช้ AI algorithm ในตัวชิปเพื่อคำนวณ TVOC, eCO2, AQI โดยตรง ไม่ต้องคำนวณเอง

  • Output: TVOC (ppb), eCO2 (ppm), AQI 1–5
  • ทำงานร่วมกับ AHT21/HDC2080 สำหรับ temperature compensation
  • I2C interface, power 1.71–1.98V (ต้องใช้ level shifter)
  • ESPHome: ใช้ ens160 component (community)
  • เหมาะ: air quality monitor, classroom, server room
