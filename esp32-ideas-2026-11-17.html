ESP32 ซ่อน SDR Mode — 80 MS/s Spectrum Analyzer ในชิปเดียว!
ESPARGOS / esp-sdr Firmware • Oct–Nov 2026

นักวิจัยจาก ESPARGOS ค้นพบว่า ESP32 หลายรุ่นมีความสามารถซ่อนอยู่ในรูปแบบ Software Defined Radio (SDR) โดยสามารถข้ามข้ามสแต็ก Wi-Fi/Bluetooth ปกติ แล้วจับตัวอย่าง I/Q (In-phase/Quadrature) แบบ raw ได้โดยตรง ทำให้ชิปกลายเป็น Spectrum Analyzer ราคาประหยัด

ESP32 ดั้งเดิมครอบคลุม 2.2–2.7 GHz ส่วน ESP32-C5 ครอบคลุมทั้ง 4.8–6.0 GHz ด้วย รองรับ Sample Rate สูงสุดถึง 80 MS/s (megasamples per second) และมี Analog Bandwidth ประมาณ 13–54 MHz ขึ้นอยู่กับรุ่นชิป

Firmware ที่ใช้ชื่อ esp-sdr และ ESP-WebSDR เผยแพร่ภายใต้ GPL-3.0 บน GitHub โดยผู้ใช้งานสามารถรับข้อมูลสเปกตรัมผ่าน WebSocket หรือแสดงผลบน touchscreen ได้เลย

ข้อสำคัญ: ESP32 ในโหมดนี้เป็นเพียง Spectrum Analyzer เท่านั้น ไม่สามารถ Demodulate หรือ Decode สัญญาณวิทยุต่อเนื่องได้เหมือน RTL-SDR ทั่วไป แต่ใช้สำหรับ ตรวจสอบสเปกตรัม, หา Interference และวัดความแรงสัญญาณ ได้เป็นอย่างดี

อุปกรณ์ทำงานเป็น Receive-Only Interference Detector สามารถสแกนทั้ง 2.4 GHz และ 5 GHz พร้อมแสดงกราฟ Spectrum ในแบบ Real-time บนหน้าจอ — เหมาะสำหรับตรวจสอบ WiFi Jammer หรือ Interference ในสภาพแวดล้อม RF ที่มีสัญญาณรบกวน

ESP-NOW Mesh Networks — Sensor ไร้ Router สูงสุด 20 Peer ต่อโหนด
Espressif Official + Community Tutorials 2026

ESP-NOW เป็น Protocol ของ Espressif ที่ให้ ESP32 หลายตัวสื่อสารกันโดยตรงโดย ไม่ต้องใช้ Router หรือ Access Point ทำงานที่ Layer 2 (MAC Layer) บน Wi-Fi Radio มี Latency ต่ำมาก (~2 ms) และ Overhead น้อย เหมาะสำหรับ Sensor Network ที่ต้องการ Battery Life ยาวนาน

แต่ละโหนด ESP32 ลงทะเบียนได้ สูงสุด 20 Peer และส่งข้อมูลได้สูงสุด 250 bytes ต่อ Packet Library ที่ใช้งานบ่อย ได้แก่ painlessMesh (Arduino, Wi-Fi based) และ zh_network (ESP-NOW based, GitHub: aZholtikov) สำหรับ Production แนะนำใช้ esp_mesh.h ใน ESP-IDF โดยตรง

เปรียบเทียบ Mesh Options:
• painlessMesh — ง่าย, Arduino-friendly, ใช้ Wi-Fi (ไม่ต้องพ่วง Router แต่กินไฟมากกว่า)
• zh_network — ESP-NOW จริงๆ, Lightweight, ประหยัดพลังงาน
• esp_mesh.h (ESP-IDF) — Official, ยืดหยุ่นสูงสุด, เหมาะ Production

Code Guide — ESP-NOW Basic Mesh Setup

ตัวอย่างโค้ดพื้นฐานสำหรับ ESP-NOW Sensor Node
📡
ESP-NOW Sender Node — ส่ง Sensor Data ไปยัง Gateway
Arduino / ESP-IDF Compatible • ไม่ต้องใช้ Router

โค้ดด้านล่างเป็นตัวอย่าง Sender Node ส่งข้อมูล Temperature/Humidity ผ่าน ESP-NOW ไปยัง Gateway (Receiver) โดยตรง ไม่ต้องพ่วง WiFi Router

// ESP-NOW Sender Node — Arduino IDE (ESP32)
#include <esp_now.h>
#include <WiFi.h>

// MAC Address ของ Gateway (Receiver Node)
uint8_t gatewayMAC[] = {0xAA, 0xBB, 0xCC, 0xDD, 0xEE, 0xFF};

// โครงสร้างข้อมูลที่ส่ง
typedef struct {
  uint8_t  nodeID;
  float    temperature;
  float    humidity;
  uint32_t uptime;
} SensorPacket;

SensorPacket packet;

void onDataSent(const uint8_t *mac, esp_now_send_status_t status) {
  Serial.println(status == ESP_NOW_SEND_SUCCESS ? "OK" : "FAIL");
}

void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_STA);       // STA mode ก่อน init ESP-NOW

  esp_now_init();
  esp_now_register_send_cb(onDataSent);

  esp_now_peer_info_t peer = {};
  memcpy(peer.peer_addr, gatewayMAC, 6);
  peer.channel = 0;
  peer.encrypt = false;
  esp_now_add_peer(&peer);

  packet.nodeID = 1;         // กำหนด Node ID
}

void loop() {
  packet.temperature = 28.5;  // อ่านจาก SHT41 ในโปรเจกต์จริง
  packet.humidity     = 65.0;
  packet.uptime       = millis() / 1000;

  esp_now_send(gatewayMAC, (uint8_t*)&packet, sizeof(packet));

  // Deep Sleep ระหว่างรอบ — ประหยัดพลังงาน
  esp_deep_sleep(30 * 1000000);  // ตื่นทุก 30 วิ
}
เคล็ดลับ Deep Sleep + ESP-NOW: การใช้ esp_deep_sleep() หลังส่งข้อมูลช่วยลดการกินไฟลงได้มาก Node ใช้แบตเตอรีอย่างยาวนานหลายเดือน ควรใช้ RTC_DATA_ATTR เก็บค่าที่ต้องการรักษาระหว่าง Deep Sleep เช่น Counter หรือ State
🔌
หาค่า MAC Address ของ Gateway Node
รันบน Gateway ESP32 เพื่อหา MAC Address

ก่อนตั้งค่า Sender Node ต้องรู้ MAC Address ของ Gateway ก่อน ใช้โค้ดนี้รันบนบอร์ด Gateway:

#include <WiFi.h>
void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_STA);
  Serial.print("Gateway MAC: ");
  Serial.println(WiFi.macAddress());  // copy ค่านี้ใส่ gatewayMAC[]
}
void loop() {}
