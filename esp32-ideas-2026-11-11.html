เปรียบเทียบ Industrial Protocols บน ESP32

เลือก protocol ให้ถูกกับงาน

Protocol ใช้งาน Latency ESP32 Support เหมาะกับ
Modbus RTU RS-485 wired ~10ms ✅ Library พร้อม PLC, VFD, เครื่องจักรเก่า
Modbus TCP Ethernet/WiFi ~5ms ✅ Library พร้อม SCADA เชื่อมผ่าน LAN
MQTT WiFi/Ethernet ~50ms ✅ PubSubClient IoT Cloud, Node-RED, HA
OPC UA Ethernet ~20ms ⚠️ open62541 (ESP-IDF) SCADA มาตรฐาน IEC
ESP-NOW WiFi radio <1ms ✅ built-in Sensor mesh, low-latency

Quick Start: Smart Farm Node ใน 7 ขั้นตอน

ESP32-C6 + Soil Moisture + SHT45 → Home Assistant

  1. เตรียม ESP32-C6 DevKit + Capacitive Soil Moisture Sensor + SHT45 (I2C)
  2. ติดตั้ง Arduino-ESP32 v3.3.12 ผ่าน Board Manager
  3. ติดตั้ง libraries: SensirionI2cSht4x + PubSubClient + ArduinoJson
  4. เขียน code อ่านค่า soil moisture (ADC) + SHT45 (I2C) แล้วส่ง JSON ผ่าน MQTT
  5. ตั้งค่า deep sleep 15 นาที เพื่อประหยัดพลังงาน ใช้ RTC memory เก็บค่าล่าสุด
  6. เพิ่ม MQTT discovery ใน Home Assistant เพื่อ auto-detect sensor
  7. สร้าง Automation ใน HA: หาก soil moisture < 30% → เปิด relay รดน้ำ 5 นาที
// Deep sleep 15 นาที
esp_sleep_enable_timer_wakeup(15 * 60 * 1000000ULL);
esp_deep_sleep_start();
// จะ wake up อีกครั้งใน 15 นาที
